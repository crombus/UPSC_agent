## Reading the map

- **Essential** = literal syllabus demand, indispensable prerequisite or verified
  PYQ. **Supporting** = standard critic, variant or comparison. **Enrichment** =
  useful but not essential to a Core answer.
- **Mention** means only named; **Substantive** means the relevant reasoning is
  present; **Answer-ready** also requires an executable objection/reply and PYQ
  route. **Not verified** is not the same as absent.
- A map entry cites the controlling Core owner; a separate comparison or
  workbook cannot replace it. Exact PYQ wording is controlled by the PYQ banks,
  not paraphrases in the map or owner.
- Audit progress here is not personal study progress and does not change
  `UPSC-PROGRESS-TRACKER.md` or the existing semantic-completeness status.
