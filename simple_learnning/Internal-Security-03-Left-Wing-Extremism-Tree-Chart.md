# Internal Security Topic 3 - Left-Wing Extremism (LWE)

```text
LEFT-WING EXTREMISM / NAXALISM
|
+-- 1. MEANING AND OBJECTIVE
|   |
|   +-- Origin: Naxalbari, West Bengal, May 1967
|   +-- Leaders: Charu Majumdar and Kanu Sanyal
|   +-- Ideology: Marxism-Leninism-Maoism
|   +-- Strategy: Protracted People's War
|   |
|   `-- Objective
|       +-- Capture State power through armed revolution
|       `-- NOT territorial secession
|
+-- 2. ORGANISATIONAL EVOLUTION
|   |
|   +-- People's War Group
|   +-- Maoist Communist Centre of India
|   |
|   `-- Merger in 2004
|       `-- CPI (Maoist)
|           `-- Listed under First Schedule of UAPA
|
+-- 3. FIVE-PHASE MAOIST STRATEGY
|   |
|   `-- Preparatory
|        -> Perspective
|        -> Guerrilla
|        -> Base
|        -> "Liberated" phase
|
+-- 4. CAUSES
|   |
|   +-- Land
|   |   +-- Alienation and insecure traditional rights
|   |   +-- Displacement
|   |   `-- Inadequate compensation
|   |
|   +-- Forest
|   |   +-- Weak recognition of tribal rights
|   |   `-- Disruption of jal-jangal-zameen relationship
|   |
|   +-- Governance
|   |   +-- Administrative absence
|   |   +-- Corruption and weak justice delivery
|   |   `-- Poor implementation of welfare schemes
|   |
|   +-- Development
|   |   +-- Poverty and unemployment
|   |   +-- Weak roads, telecom, health and education
|   |   `-- Regional inequality
|   |
|   `-- Mineral-belt political economy
|       +-- Mining and infrastructure projects
|       +-- Displacement and unequal benefit distribution
|       `-- Contractor/mining extortion finances insurgency
|
+-- 5. MAOIST OPERATING MECHANISM
|   |
|   +-- Exploit genuine grievances
|   +-- Mobilisation and recruitment
|   +-- Guerrilla attacks and intimidation
|   +-- Extortion and parallel taxation
|   +-- Jan Adalats / coercive parallel authority
|   +-- Target police and infrastructure
|   `-- Obstruct development
|       |
|       `-- Underdevelopment continues
|            -> grievances persist
|            -> recruitment space survives
|
+-- 6. EFFECTS ON PEOPLE
|   |
|   +-- Death, injury, fear and displacement
|   +-- Extortion and livelihood losses
|   +-- Destruction of roads, schools and telecom
|   +-- Reduced access to health and education
|   +-- Weak panchayats and civil administration
|   +-- Youth recruitment and lost opportunities
|   `-- Communities caught between extremists and security forces
|
+-- 7. GOVERNMENT RESPONSE
|   |
|   +-- National Policy and Action Plan, 2015
|   |   |
|   |   +-- Security
|   |   +-- Development
|   |   `-- Rights and entitlements of local communities
|   |
|   +-- Security measures
|   |   +-- State Police: primary responsibility
|   |   +-- CRPF and CoBRA support
|   |   +-- Greyhounds model: specialised State force
|   |   +-- Fortified police stations
|   |   `-- Inter-State intelligence and operational coordination
|   |
|   +-- Development measures
|   |   +-- Roads and mobile connectivity
|   |   +-- Health, education and banking access
|   |   +-- Livelihood and skill development
|   |   `-- Special Central Assistance
|   |
|   +-- Rights-based measures
|   |   +-- Forest Rights Act, 2006
|   |   +-- PESA, 1996
|   |   `-- Fifth Schedule governance
|   |
|   +-- Reintegration
|   |   +-- Surrender = one-time exit event
|   |   `-- Rehabilitation = long-term livelihood,
|   |       protection and social reintegration
|   |
|   `-- Trust restoration
|       +-- Civic Action Programme
|       +-- Accessible administration
|       +-- Grievance redressal
|       `-- Accountable and rights-bound policing
|
+-- 8. OPERATIONAL SEQUENCE
|   |
|   `-- CLEAR
|        -> remove immediate armed coercion
|        |
|        v
|       HOLD
|        -> permanent police and administrative presence
|        |
|        v
|       DEVELOP
|        -> infrastructure, services and livelihoods
|        |
|        v
|       DELIVER RIGHTS
|        -> FRA, PESA and land/forest entitlements
|        |
|        v
|       LEGITIMISE
|        -> participation, justice and public trust
|
+-- 9. MAJOR CHALLENGES
|   |
|   +-- Inter-State boundary and trijunction gaps
|   +-- Weak local administrative capacity
|   +-- Different surrender policies across States
|   +-- Delayed implementation of FRA and PESA
|   +-- Excessive dependence on security forces
|   +-- Rehabilitation and reintegration failures
|   `-- Security gains may reverse if governance does not follow
|
+-- 10. UPSC TRAPS
|   |
|   +-- LWE is NOT a secessionist movement
|   +-- Poverty alone does NOT automatically produce extremism
|   +-- LWE is NOT merely a law-and-order problem
|   +-- Development alone cannot operate under armed coercion
|   +-- Security operations alone cannot resolve grievances
|   +-- Enacting FRA/PESA != implementing rights
|   +-- Surrender count != successful rehabilitation
|   `-- Decline in violence != complete resolution of root causes
|
+-- 11. PYQ ANSWER ROUTE
|   |
|   `-- Definition and objective
|        -> structural causes
|        -> Maoist operating mechanism
|        -> effects on people
|        -> security + development + rights response
|        -> institutional limitations
|        -> qualified conclusion
|
`-- 12. QUALIFIED CONCLUSION
    |
    `-- Durable peace requires:
        lawful security
          + permanent civil administration
          + development
          + tribal and forest rights
          + rehabilitation
          + inter-State coordination
          + public trust
```

**Core line:** LWE ends sustainably not merely when violence declines, but when
coercive parallel authority is replaced by trusted constitutional governance.
