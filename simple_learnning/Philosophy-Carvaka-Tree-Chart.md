# Cārvāka (Lokāyata) - Terminal Tree Chart

```text
CĀRVĀKA / LOKĀYATA
|
+-- CENTRAL PRINCIPLE
|   |
|   `-- "Accept only what can be established through experience."
|       |
|       +-- Epistemology: perception alone gives certain knowledge
|       `-- Metaphysics: reject imperceptible/transcendent entities
|
+-- 1. IDENTITY
|   |
|   +-- Cārvāka = standard name of the materialist tradition
|   +-- Lokāyata = this-worldly or worldly doctrine
|   +-- Bārhaspatya = tradition associated with Bṛhaspati
|   |
|   `-- Unorthodox school (nāstika)
|       +-- Rejects authority of the Vedas
|       `-- Rejects post-mortem existence
|
+-- 2. THEORY OF KNOWLEDGE
|   |
|   `-- Valid knowledge (pramā)
|       |
|       `-- PERCEPTION (pratyakṣa) alone
|           |
|           +-- External perception
|           |   `-- Colour, sound, taste, smell and touch
|           |
|           `-- Internal perception
|               `-- Pleasure, pain, desire and consciousness
|
+-- 3. REJECTED MEANS OF KNOWLEDGE
|   |
|   +-- Inference (anumāna)
|   +-- Testimony (śabda)
|   +-- Comparison (upamāna)
|   +-- Postulation (arthāpatti)
|   `-- Non-cognition (anupalabdhi)
|
+-- 4. WHY INFERENCE IS REJECTED
|   |
|   +-- Every inference requires universal relation (vyāpti)
|   |
|   |   Example:
|   |   Smoke on hill
|   |       +
|   |   "Wherever smoke exists, fire exists"
|   |       |
|   |       v
|   |   Therefore, hill has fire
|   |
|   `-- Cārvāka attacks the universal premise:
|       |
|       +-- Perception observes only limited cases
|       +-- Past, future and distant cases remain unobserved
|       +-- Inference cannot prove vyāpti
|       |   `-- It would require another inference
|       |       `-- Circularity or infinite regress
|       |
|       +-- Hidden condition (upādhi) may exist
|       |   `-- Smoke may depend on fire + wet fuel
|       |
|       `-- Therefore:
|           repeated observation gives probability,
|           not necessary or exceptionless certainty
|
+-- 5. MODERATE INTERPRETATION
|   |
|   +-- Worldly inference (lokasiddha anumāna)
|   |   `-- May guide practical conduct
|   |
|   `-- Transcendent inference
|       `-- Cannot prove soul, karma, rebirth, God or heaven
|
+-- 6. SELF-REFUTATION PROBLEM
|   |
|   +-- Cārvāka claims:
|   |   "Inference is not a valid source of knowledge."
|   |
|   +-- Opponent asks:
|   |   "Is this universal claim itself inferred?"
|   |
|   `-- Dilemma
|       |
|       +-- If inferred -> Cārvāka uses what it rejects
|       `-- If not inferred -> the claim cannot be established
|
+-- 7. REJECTION OF TESTIMONY
|   |
|   +-- Hearing words reveals only that something was said
|   +-- Truth requires a reliable speaker
|   +-- Reliability is established through inference
|   `-- Therefore testimony is not an independent pramāṇa
|       |
|       `-- Vedic infallibility also cannot be perceived
|
+-- 8. MATERIAL REALITY
|   |
|   `-- Four elements (bhūtas)
|       |
|       +-- Earth
|       +-- Water
|       +-- Fire
|       `-- Air
|
|       Ether (ākāśa) rejected
|       `-- It is imperceptible
|
+-- 9. SELF AND CONSCIOUSNESS
|   |
|   +-- Body-self theory (dehātmavāda)
|   |   `-- The living conscious body is the self
|   |
|   +-- No separate eternal soul (ātman)
|   |
|   `-- Consciousness emerges from material combination
|       (bhūta-caitanya)
|       |
|       +-- Betel leaf + lime + areca nut -> red colour
|       +-- Ingredients individually lack that colour
|       |
|       `-- Similarly:
|           material elements combine
|               |
|               v
|           living body arises
|               |
|               v
|           consciousness emerges
|
+-- 10. REJECTION OF TRANSCENDENT ENTITIES
|   |
|   `-- General formula
|       |
|       Imperceptible entity
|             |
|             v
|       Can be known only by inference or testimony
|             |
|             v
|       Inference and testimony are unreliable
|             |
|             v
|       Entity cannot be established
|             |
|             +-- Eternal soul
|             +-- Karma as unseen moral force
|             +-- Rebirth and transmigration
|             +-- Heaven and hell
|             +-- Creator God (Īśvara)
|             +-- Vedic infallibility
|             `-- Liberation (mokṣa)
|
+-- 11. EXPLANATION OF NATURE
|   |
|   `-- Own-nature doctrine (svabhāvavāda)
|       |
|       +-- Fire burns by its own nature
|       +-- Water flows by its own nature
|       `-- Natural properties need no supernatural cause
|
+-- 12. ETHICS
|   |
|   +-- Pleasure (kāma) = principal human end
|   +-- Wealth (artha) = instrument for pleasure
|   +-- Scriptural duty (dharma) rejected
|   +-- Liberation (mokṣa) rejected
|   |
|   `-- Practical hedonism
|       |
|       +-- Seek available embodied pleasure
|       +-- Avoid foreseeable suffering
|       `-- Do not sacrifice present life for unverifiable afterlife
|
+-- 13. MAJOR STRENGTHS
|   |
|   +-- Demands evidence before belief
|   +-- Challenges dogmatism and ritual authority
|   +-- Exposes the problem of establishing universals
|   +-- Rejects unverifiable metaphysical multiplication
|   `-- Anticipates empiricist and naturalistic attitudes
|
+-- 14. MAJOR CRITICISMS
|   |
|   +-- Rejection of inference may be self-refuting
|   +-- Daily life and science require inference
|   +-- Perception can itself be mistaken
|   +-- Material emergence of consciousness is asserted,
|   |   but not fully explained
|   +-- Pleasure alone provides an incomplete morality
|   `-- Sources are mostly preserved by hostile opponents
|
+-- 15. IMPORTANT COMPARISONS
|   |
|   +-- Cārvāka vs Nyāya
|   |   |
|   |   +-- Cārvāka: perception alone
|   |   `-- Nyāya: perception, inference,
|   |       comparison and testimony
|   |
|   +-- Cārvāka vs Buddhism
|   |   |
|   |   +-- Cārvāka: conscious material body is self
|   |   `-- Buddhism: no permanent substantial self
|   |       but accepts karma, rebirth and liberation
|   |
|   `-- Cārvāka vs Jainism
|       |
|       +-- Cārvāka: materialism and perception-centred knowledge
|       `-- Jainism: plural souls, karma, rebirth,
|           liberation and multiple standpoints
|
+-- 16. UPSC TRAPS
|   |
|   +-- Cārvāka accepts FOUR elements, not five
|   +-- It does not deny consciousness
|   |   `-- It denies a separate transcendental soul
|   |
|   +-- Nāstika does not simply mean atheist
|   +-- Practical inference may be tolerated by refined readings
|   +-- Buddhism and Cārvāka do not hold identical no-self theories
|   +-- Svabhāvavāda is own-nature doctrine, not necessarily chance
|   `-- Cārvāka is not identical to modern scientific positivism
|
+-- 17. PYQ ANSWER ROUTE
|   |
|   `-- Define Cārvāka
|        -> Explain epistemology
|        -> Present arguments against inference
|        -> Derive rejection of transcendent entities
|        -> Explain materialism and body-self theory
|        -> Give objections and replies
|        -> Offer a balanced judgement
|
`-- QUALIFIED VERDICT
    |
    `-- Cārvāka successfully demands evidential restraint
        and exposes weaknesses in transcendental inference,
        but its complete rejection of inference is difficult
        to defend without using inferential reasoning itself.
```
