# Topic 10 — Regional, Global and Minilateral Groupings

```text
INDIA'S GROUPING DIPLOMACY
│
├─ CENTRAL THESIS
│  └─ Overlapping platforms = multi-alignment
│     ├─ different problems → different partners/instruments
│     └─ no single exclusive bloc → strategic autonomy
│
├─ 1. CLASSIFY BEFORE ANALYSING
│  ├─ Regional → SAARC | BIMSTEC | Mekong-Ganga Cooperation
│  ├─ Trans-regional/oceanic → IORA | IBSA
│  ├─ Continental → SCO
│  ├─ Global economic governance → G20 | BRICS
│  ├─ Minilateral → Quad | RIC | I2U2
│  └─ Treaty-alliance comparator → NATO
│
├─ 2. LEGAL-FORM TEST
│  ├─ Treaty → consent to be bound under international law
│  ├─ Charter → constitutive rules/organs of an organisation
│  ├─ Grouping/forum → coordination; may be informal
│  ├─ Framework/vision → direction, not self-executing delivery
│  └─ Alliance → defined defence commitments
│
├─ 3. STATUS TEST
│  ├─ Member → rights + obligations + decision role
│  ├─ Partner/dialogue partner → structured but limited participation
│  ├─ Observer → attendance under restricted rules
│  ├─ Guest/invitee → event-specific participation
│  └─ Chair/presidency → temporary agenda role, not higher membership
│
├─ 4. EVIDENCE LADDER
│  └─ announcement
│     → negotiation
│     → adoption/signature
│     → ratification/accession
│     → entry into force
│     → operation
│     → measured delivery
│
├─ 5. REGIONAL LAYER
│  ├─ SAARC
│  │  ├─ 8 members; charter-based
│  │  ├─ last Summit: Kathmandu, 26–27 Nov 2014
│  │  └─ constrained ≠ dissolved
│  ├─ BIMSTEC
│  │  ├─ 7 members; South Asia ↔ Southeast Asia bridge
│  │  ├─ Charter: adopted 30 Mar 2022 → in force 20 May 2024
│  │  ├─ 6th Summit: Bangkok, 4 Apr 2025
│  │  │  └─ Declaration + Bangkok Vision 2030 + Rules of Procedure
│  │  ├─ Maritime agreement: signed 3 Apr 2025
│  │  │  └─ in force 16 May 2026 only for Bhutan, India,
│  │  │     Myanmar, Thailand
│  │  ├─ Centres: Thimphu | Bengaluru | NOIDA | Colombo
│  │  └─ gained salience; did not legally replace SAARC
│  └─ MGC
│     └─ Cambodia, India, Lao PDR, Myanmar, Thailand, Viet Nam
│
├─ 6. ASEAN
│  ├─ 11 members; Timor-Leste admitted 26 Oct 2025
│  ├─ India = full Dialogue Partner since 1995, not member
│  ├─ CSP since 2022; Plan of Action 2026–2030
│  ├─ ASEAN centrality = organising principle, not legal privilege
│  └─ India not in RCEP
│
├─ 7. OCEANIC/TRILATERAL
│  ├─ IORA → 23 members + 12 dialogue partners
│  │  └─ Secretariat Ebène; India chair 2025–27
│  ├─ IBSA → India-Brazil-South Africa
│  │  └─ Leaders met Johannesburg, 23 Nov 2025
│  └─ RIC → Russia-India-China
│     └─ latest official Indian record located: 26 Nov 2021
│
├─ 8. SCO
│  ├─ charter-based Eurasian organisation
│  ├─ 10 members | 2 observers | 15 dialogue partners
│  ├─ India full member since 2017
│  ├─ value → Eurasian access + RATS + Central Asia dialogue
│  ├─ constraint → China/Pakistan + sovereignty + consensus
│  └─ 26th summit: Bishkek, 1 Sep 2026
│     ├─ Bishkek Declaration + 27 other approved documents
│     └─ Pakistan chair 2026–27
│
├─ 9. BRICS + NDB
│  ├─ political-economic grouping, not alliance
│  ├─ 11 members ≠ 10 partner countries
│  ├─ 18th Summit: New Delhi, 12 Sep 2026
│  │  └─ New Delhi Declaration
│  ├─ expansion → representation ↑; coherence may ↓
│  └─ NDB
│     ├─ separate treaty-based bank
│     └─ BRICS status ≠ automatic NDB membership
│
├─ 10. G20
│  ├─ informal forum; no constitutive charter
│  ├─ origin: finance ministers + central bank governors
│  ├─ 19 states + EU + AU
│  ├─ AU permanent member since 9 Sep 2023
│  └─ strength: agenda coordination | limit: implementation dependence
│
├─ 11. MINILATERALS + NATO
│  ├─ Quad → India, Australia, Japan, US
│  │  ├─ non-treaty; not military alliance; not trade bloc
│  │  └─ leaders: Wilmington 21 Sep 2024
│  │     foreign ministers: New Delhi 26 May 2026
│  ├─ I2U2 → India, Israel, UAE, US
│  │  └─ food/water/energy/transport/technology projects
│  └─ NATO → treaty alliance
│     ├─ Article 5 collective defence; consensus decisions
│     ├─ Sweden = 32nd member, 7 Mar 2024
│     └─ affects India via Russia, sanctions, technology, Europe
│
├─ 12. PRELIMS STATUS TRAPS
│  ├─ India: MTCR member (35th; 27 Jun 2016)
│  ├─ India: AIIB founding member; SCO member
│  ├─ India: not NSG member; 2008 waiver ≠ membership
│  ├─ IAEA Additional Protocol in force: 25 Jul 2014
│  ├─ India: ASEM member since 2007; not APEC member
│  └─ EU: Poland + Germany in; Belarus + Switzerland out
│
├─ 13. PYQ ROUTES
│  ├─ Quad → correct false alliance/trade-bloc premise
│  ├─ SCO → aims + Indian utility + internal conflict
│  ├─ BIMSTEC v SAARC → similarities, differences, India objectives
│  ├─ I2U2 → functional gains, not bloc transformation
│  ├─ NATO → benefits/costs transmitted through Europe and Russia
│  ├─ IPMDA (Topic 04 primary) → SAGAR bridge + capacity limits
│  └─ BRICS 2026 → counterweight claim + NDB + heterogeneity
│
└─ FINAL ANSWER SPINE
   └─ interest
      → platform layer
      → legal form
      → exact status
      → dated instrument
      → legal/operational stage
      → delivery evidence
      → constraint
      → calibrated strategic-autonomy verdict
```

> **Qualified conclusion:** More memberships do not automatically create influence. India's
> architecture works when platforms are complementary, status claims are exact and declarations
> are converted into measurable delivery.
