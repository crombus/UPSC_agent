│
├─ PROTECT WORKERS

├─ SOFT POWER
│  ├─ attraction through culture, values, competence, reputation

│  ├─ ICCR → cultural relations
│  ├─ ITEC → training + cultural diplomacy; stated South Asia salience
│  └─ attraction ≠ propaganda or automatic control
│
├─ ADVANCED CORE
│  ├─ “Now-Required-Indians” → conditional policy argument, not legal category
│  ├─ Tharoor: mainstream soft power into territorial divisions
│  │  └─ proposal ≠ verified implementation
│  ├─ authenticity → plural, multi-religious, multilingual India
│  │  └─ domestic exclusion damages external credibility
│  └─ bridge → reciprocity/autonomy; lever → backlash/instrumentalisation
│
├─ POLITICAL INFLUENCE / LIABILITY
│  ├─ channels: votes, organisations, networks, coalitions
│  ├─ civil-nuclear advocacy → contributory, not sole cause
│  ├─ host office-holder → host mandate, not Indian agent
│  ├─ risks: separatism, discrimination, polarisation, interference perception
│  └─ allegation ≠ charge ≠ plea ≠ finding; never generalise
│
├─ FACT → STATUS → DELIVERY → IMPACT
│  ├─ fact: what source records
│  ├─ status: citizen/foreign national; eligible/launched/convened
│  ├─ delivery: access, grievance action, insurance, training, evacuation
│  └─ impact: welfare, knowledge, reputation or policy change—prove causation

│  └─ audited Prelims ledgers → no objective PYQ routed
│
└─ MAINS SPINE
   ├─ define status/segment
   ├─ economic + knowledge + political + cultural channels
   ├─ protection architecture and exact consular limits
   ├─ host agency + diversity + authenticity + capacity constraints
   └─ map → protect → connect → negotiate → prepare → evaluate

VERDICT
Diaspora influence endures when protection, plural credibility,
host-country agency and differentiated engagement reinforce one another.
