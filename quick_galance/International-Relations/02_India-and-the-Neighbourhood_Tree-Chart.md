INDIA AND THE NEIGHBOURHOOD
├─ THESIS → manage asymmetric interdependence:
│  Indian capacity → reliable public goods + neighbour sovereignty/agency/confidence
├─ SCOPE
│  ├─ eight neighbours → Pakistan, China, Nepal, Bhutan, Bangladesh, Myanmar,
│  │                    Sri Lanka, Maldives
│  ├─ Afghanistan → strategic near-neighbour
│  └─ routes → China/LAC: Topic03; Maldives maritime: Topic04;
│              SAARC/BIMSTEC: Topic10; geography/economy/security/law to owners
├─ STARTING CONDITION
│  └─ proximity + Indian scale + partner domestic politics/diversification
│     → cooperation opportunity + dominance anxiety
│     └─ Tharoor: problems of varying difficulty with six of eight neighbours;
│        structural friction ≠ universal hostility
│
├─ NEIGHBOURHOOD FIRST
│  ├─ policy priority, not treaty/organisation/guaranteed result
│  └─ connectivity | development | first response/HADR | consultation | P2P
├─ GUJRAL DOCTRINE
│  ├─ no reciprocity demanded from smaller neighbours
│  ├─ non-interference; territory not used against another South Asian State
│  ├─ sovereignty/territorial integrity; peaceful bilateral settlement
│  └─ non-reciprocity = strategic reassurance, not unlimited concession
├─ DIFFERENTIATED LOGIC
│  ├─ smaller States may seek regional reassurance through numbers
│  ├─ complex ties require intensive bilateral bargaining
│  └─ regional reassurance complements—not replaces—bilateral delivery
│
├─ OPERATING NEXUS
│  └─ border → movement/trade + transmitted risk → connectivity
│     → development → shared benefit or dependence/security risk
├─ STATUS DISCIPLINE
│  ├─ legal/political → statement | vision | MoU/framework | treaty/agreement
│  ├─ delivery → announce → finance → build → operate → output → outcome
│  └─ MoU≠operation; groundbreaking≠commissioning; segment≠corridor;
│     target≠achievement; ToR≠FTA; Embassy status≠recognition; abeyance≠termination
│
├─ COUNTRY EVIDENCE
│  ├─ Bangladesh
│  │  ├─ Akhaura–Agartala rail inaugurated 1 Nov 2023; use/outcome separate
│  │  ├─ BBIN MVA 2015; Bhutan non-ratification limits four-country operation

│  ├─ Bhutan

│  │  └─ rail MoU 29 Sep 2025; links not commissioned
│  ├─ Nepal

│  ├─ Sri Lanka

│  │     groundbreaking—not commissioning
