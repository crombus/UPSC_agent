# Topic 12 — UN and International Institutions / Global Governance

```text
GLOBAL GOVERNANCE
├─ meaning → rule/coordination by States + institutions; not world government
├─ first test → legal basis → membership/status → mandate → decision rule
└─ second test → legal effect → implementation → outcome → accountability

UN CHARTER SYSTEM
├─ six principal organs (Art. 7)
│  ├─ UNGA → all Members; one State–one vote
│  │  ├─ important questions → 2/3 present and voting
│  │  ├─ other questions → simple majority present and voting
│  │  └─ normal external effect → recommendation
│  ├─ UNSC → 15 = P5 + 10 elected
│  │  ├─ elected term → 2 years; no immediate re-election
│  │  ├─ Art. 24 → primary peace-and-security responsibility
│  │  ├─ Art. 25 → Members accept/carry out Council decisions
│  │  └─ Art. 27 → 9 votes; P5 concurrence on non-procedural matters
│  │       └─ practice → P5 abstention ≠ veto
│  ├─ ECOSOC → economic/social coordination + specialised-agency link
│  ├─ ICJ → judicial organ
│  ├─ Secretariat → administration/mandate implementation
│  └─ Trusteeship Council → operations suspended 1 Nov 1994; not abolished
│
├─ LEGAL-EFFECT TRAP
│  ├─ “resolution” alone does not answer bindingness
│  ├─ UNGA recommendation ≠ UNSC decision
│  └─ operative wording + Charter basis + addressee decide effect
│
└─ UNSC REFORM
   ├─ four axes
   │  ├─ representation → who sits?
   │  ├─ decision rule/veto → who blocks?
   │  ├─ effectiveness → can mandate be delivered?
   │  └─ accountability → reasons/review/answerability?
   ├─ Art. 108 lock
   │  └─ 2/3 UNGA adoption + 2/3 Member ratification incl. all P5
   ├─ coalitions
   │  ├─ G4 → Brazil + Germany + India + Japan
   │  ├─ Africa → Ezulwini Consensus + Sirte Declaration
   │  └─ Uniting for Consensus → elected-seat-centred counter-model
   ├─ India (20 Apr 2026 IGN)
   │  ├─ both categories; 26-member model
   │  ├─ supports African model
   │  └─ parity for new/existing permanent members
   └─ status (28 Jul 2026)
      ├─ IGN continued into UNGA 81
      └─ no completed consolidated model/text-based negotiation/Charter change

PEACE AND SECURITY MACHINERY
├─ peacekeeping
│  ├─ consent
│  ├─ impartiality ≠ neutrality/inactivity
│  ├─ force only self-defence/defence of mandate
│  └─ robust tactical force ≠ peace enforcement without consent
├─ India → long troop/police contribution + all-women FPU, Liberia
│  └─ strengthens political case; no automatic permanent seat
└─ counter-terrorism
   ├─ CTC → UNSC subsidiary body; monitors resolution 1373
   ├─ CTED → assessment + technical-assistance support
   ├─ 1267/1989/2253 Committee → ISIL/Al-Qaida listings
   └─ FATF → intergovernmental AML/CFT/CPF standards + mutual evaluation
      └─ not UN sanctions committee, court or police; standards ≠ direct enforcement

COURTS AND JURISDICTION
├─ ICJ
│  ├─ parties → States only
│  ├─ contentious basis → State consent
│  ├─ judgment → final; binds parties/case
│  └─ advisory opinion → authorised UN bodies; generally non-binding
└─ ICC
   ├─ independent Rome Statute court → individuals
   ├─ gateways → territory/nationality; State referral; Prosecutor; UNSC referral
   └─ India → neither signatory nor State Party

SPECIALISED AGENCIES
├─ UNESCO → education/science/culture/communication
│  └─ US withdrawal notified; effective 31 Dec 2026 → still member on review date
├─ WHO → WHA + Executive Board + Secretariat
│  └─ Pandemic Agreement adopted 2025
│     └─ PABS unfinished 18 Sep 2026 → no signature/ratification yet
└─ core limit → standards/coordination depend on State data, finance, compliance

ECONOMIC GOVERNANCE
├─ IMF → monetary/BOP stability; quota-weighted voice
│  └─ equiproportional quota rise ≠ relative voice reform
├─ World Bank → development finance; Governors + Executive Directors
│  └─ resource expansion ≠ shareholding redistribution
└─ WTO → 166 members; normally consensus
   ├─ Ministerial Conference → top body
   ├─ General Council = DSB = TPRB in different guises
   └─ treaty obligations + dispute procedures; Appellate Body crisis limits review

STATUS LADDER — NEVER COMPRESS
proposal → negotiation → adoption → signature → ratification/accession
        → entry into force → domestic/institutional implementation → outcome

CURRENT EXAMPLES
├─ Pact for the Future (22 Sep 2024) → political outcome + 2 annexes
├─ UN80 (12 Mar 2025) → administration/mandate review; not UNSC reform
├─ BBNJ → in force 17 Jan 2026; India signed, not ratified
└─ WHO Pandemic Agreement → adopted; annex unfinished; not in force

EVALUATION MATRIX
├─ representation → voice/seat/vote
├─ legitimacy → acceptance + procedural fairness
├─ effectiveness → mandate + resources + compliance → result
└─ accountability → transparency + reasons + review + correction

PYQ ROUTE
├─ direct Mains → UNESCO 2019; WHO 2020; CTC 2024; UN reform 2025
├─ shared Mains → climate policy in international fora 2022
├─ direct objectives → conventions, Credentials Committee, observers,
│                      GCM, International Years, migration platforms,
│                      Nobel bodies, peacekeeping periods
└─ application objectives → famine/refugees/conflict geography + Polar Code

ANSWER SPINE
legal basis → exact status → mandate → decision rule → legal effect
→ India/coalition evidence → representation/effectiveness/accountability
→ implementation constraint → calibrated reform verdict
```

**Qualified conclusion:** International institutions remain indispensable, but legitimacy requires representative voice, effectiveness requires mandate-resource-compliance alignment, and accountability requires transparent review. Reform advocacy is not reform achieved.
