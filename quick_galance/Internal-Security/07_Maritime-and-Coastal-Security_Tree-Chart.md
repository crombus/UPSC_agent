# Internal Security 07 — Maritime and Coastal Security

```text

├─ 1. Scope/current denominator
│  ├─ maritime → SLOCs + zones + ships + offshore assets + ports
│  ├─ coastal → near-shore/landing/territorial-water interface

├─ 2. Zone ladder
│  ├─ internal waters → sovereignty

│
├─ 3. Threat-law classification
│  ├─ naval coercion → defence

│  ├─ piracy → private ends + statutory high-seas setting
│  ├─ armed robbery in territorial waters ≠ piracy automatically
│  ├─ smuggling goods ≠ trafficking persons
│  └─ IUU fishing/straying ≠ hostile infiltration
│
├─ 4. Mandates
│  ├─ Navy → overall maritime security + military defence

│  └─ port/PFSO + DG Shipping + CISF + Customs + immigration + police/courts

│  └─ NACP Okha established 7 Jul 2026
```
