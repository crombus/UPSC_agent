# Internal Security 09 — Social Media, Encrypted Messaging and Information Warfare

## Quick-Glance Tree Chart

```text
INFORMATION SECURITY → classify → trace amplification → choose narrow lawful remedy
├─ 1. Information categories
│  ├─ misinformation → false; no harmful intent at sharing
│  ├─ disinformation → false/misleading + deliberate deception/harm
│  ├─ malinformation → genuine + harmful context/disclosure
│  └─ “fake news” → umbrella, not standalone offence
│
├─ 2. Harm/campaign chain
│  ├─ item → coordination/algorithm/peer trust → exposure → belief → behaviour
│  ├─ radicalisation ≠ recruitment ≠ material support
│  └─ operation = actor + objective + narrative + vector + audience + effect
│     └─ viral/inaccurate item ≠ foreign coordinated campaign
│
├─ 3. Encryption firewall
│  ├─ E2EE → content protected between secure endpoints
│  ├─ anonymity → identity linkage
│  ├─ metadata → account/time/device/routing relationships
│  └─ endpoint compromise can expose plaintext
│
├─ 4. Rule 4(2) mechanics
│  ├─ SSMI primarily providing messaging
│  ├─ competent-court order OR s.69 competent-authority order
│  ├─ purpose → prevention/detection/investigation/prosecution/punishment
│  ├─ triggers → sovereignty/integrity, State security, friendly relations,
│  │  public order/incitement, rape, sexually explicit material or CSAM
│  ├─ offence punishable with not less than 5 years

│  ├─ content not required unless separately ordered under s.69
│  └─ foreign source → first originator within India for the rule
│
├─ 5. Unresolved traceability challenge
│  ├─ law says targeted identity, not routine content decryption
```
