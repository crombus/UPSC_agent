# Indian Art and Culture 08 - Indian Music

|
+-- FOUNDATION GRAMMAR
|   |
|   +-- Nada -> Shruti -> Swara -> Saptak

|   |     - Swara = usable note
|   |
|   +-- Raga

|   |     - vadi / samvadi
|   |     - pakad / chalan
|   |     - rasa / time link
|   |
|   +-- Rhythm
|         - Tala = rhythmic cycle
|         - Laya = tempo
|
+-- CLASSIFICATION MODELS
|   |
|   +-- Hindustani
|   |     - 10 thaats
|   |     - alap / bandish / taan / layakari
|   |     - gharana memory
|   |
|   +-- Carnatic
|         - 72 melakarta + janya
|         - kriti / varnam / alapana / neraval / kalpana swara / RTP
|         - temple / sabha memory
