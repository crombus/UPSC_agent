## 1 · WHAT A VALUE IS

```text
LADDER (read up = private feeling -> enforceable standard)
  L5 LAW/RULE/CODE      enforceable, sanction attached
  L4 NORM               social expectation, stigma
  L3 VALUE              ENDURING + TRANS-SITUATIONAL + EVALUATIVE   <-- syllabus unit
  L2 ATTITUDE           object-specific        -> Topic 03
  L1 BELIEF/FEELING     momentary

KEEP SEPARATE: norm (shared expectation) · virtue (settled excellence)
               interest (what benefits me) · aptitude (capacity -> Topic 04)

AUTHORITY BOTH WAYS
  ARC 2.2.1  values UPSTREAM of law: "Ethics provides the basis for the creation of such
             laws and rules ... Our legal system emanates from a shared vision of what
             is good and just."
  ARC 2.2.4  values INDISPENSABLE DOWNSTREAM: rules "cannot provide for all situations";
             "the higher the echelon ... the greater is the ambit of discretion".
  PREFACE    "One cannot mandate honesty."

TRAP  defining a value as "a good moral quality such as honesty" gives an EXAMPLE, not a
      definition, and collapses value into virtue.
```

## 5 · AFTER FORMATION

```text
OBSERVABILITY TEST
  unobserved + unchanged  -> INTERNALISED (robust under discretion)
  unobserved + changed    -> PERFORMANCE (display for appraisal/publicity/fear)
  observed                -> UNINFORMATIVE
=> any observation-based system can detect only PERFORMANCE.
   THIS is why vigilance cannot manufacture integrity.

CORROSION -> COUNTER
  NORMALISATION   [ARC 1.3]          -> make the deviation visible and countable
  INCREMENTALISM                      -> a BRIGHT LINE converts a gradient to a threshold
  EUPHEMISM ("facilitation")          -> restore ACCURATE NAMING in the record
  DIFFUSED AGENCY ("I only signed")   -> one NAMED officer + recorded reasons

PROXIES, NOT PROOF  low-observability conduct · consistency across differently placed
                    beneficiaries · willingness to record a reason for a hostile reader
```

## 6 · VALUE CONFLICT — FOUR-STEP SPINE

```text
1 NAME BOTH VALUES PRECISELY  (not "a dilemma" -- say WHICH two)
2 LEXICAL FILTER, IN ORDER
      constitutional value / fundamental right
   -> binding statute or rule
   -> institutional mandate and code
   -> professional norm
   -> personal conscience
   (a lower tier never overrides a higher one; where conscience cannot prevail ->
    recorded dissent, lawful escalation or resignation, NEVER quiet non-compliance)
3 DISSOLVE BEFORE TRADING   redact and disclose · interim order + short-dated review ·
                            relief granted AND recorded as a CLASS rule
4 IF A TRADE-OFF IS UNAVOIDABLE  state THRESHOLD + SAFEGUARD + RESIDUAL RISK

ARC 2.2.2  "all public functionaries are trustees of the people"
           -> a private claim is DISQUALIFIED, not merely outweighed -> RECUSE
LOSES MARKS  "a balance must be struck between the two"
CASE-STUDY ARCHITECTURE  owned by Topic 22
```
