# Polity 52 — NCRWC and Working of the Constitution

```text
NCRWC: REVIEW OF CONSTITUTIONAL WORKING, NOT A NEW CONSTITUTION
│
├─ 1. CHANGE-TYPE FIREWALL
│  ├─ Review → diagnosis + recommendations; no legal change by report alone
│  ├─ Article 368 amendment → Parliament; special majority; basic-structure limit
│  ├─ Proviso to Article 368(2) → specified federal changes + ratification by ≥ 1/2 States
│  └─ Replacement → fresh constituent claim; outside NCRWC mandate
│
├─ 2. VERIFIED IDENTITY
│  ├─ Constituted: Government of India resolution, 22 February 2000
│  ├─ Chair: Justice M.N. Venkatachaliah, former CJI
│  ├─ Composition: 11 members including Chair; P.A. Sangma later resigned
│  ├─ Secretary: Dr Raghbir Singh — not a Commission member
│  ├─ Report adopted/signed: 11 March 2002
│  └─ Presented to Prime Minister: 31 March 2002
│     ⇒ temporary + executive + advisory
│     ⇒ neither constitutional nor statutory; not constituent / Article 368 body
│
├─ 3. MANDATE + AUTHORITY
│  ├─ Review 50 years of working
│  ├─ Aim: efficient, smooth, effective government + socio-economic development
│  ├─ Boundary: parliamentary democracy + basic structure/basic features
│  ├─ Method: consultation papers + expert studies + public responses + deliberation
│  └─ Result: persuasive report; recommendations not binding
│
├─ 4. BOUNDED COMMISSION DISTINCTIONS
│  ├─ Sarkaria / Punchhi → Centre-State relations
│  ├─ Administrative Reforms Commissions → public administration
│  ├─ Law Commission → defined law-reform questions
│  └─ NCRWC → cross-system review of constitutional working
│     TRAP: overlap of topic ≠ common mandate or common recommendation
│
├─ 5. WHAT “WORKING” MEANS
│  └─ text → institutions → statutes/rules → conventions → political culture
│       → administrative capacity → remedies → outcomes
│     ├─ Authorisation: who may act?
│     ├─ Restraint: are role limits/rights/federalism respected?
│     ├─ Delivery: do staffing, procedure and finance produce results?
│     └─ Correction: can elections, legislatures, audit and courts remedy failure?
│
├─ 6. RECOMMENDATION MAP — 249 TOTAL
│  ├─ 58 constitutional-amendment route
│  ├─ 86 legislative route
│  └─ 105 executive-action route
│     CAUTION: route classification ≠ implementation
│
├─ 7. ELECTORAL + LEGISLATIVE REFORM
│  ├─ Criminalisation → disqualification proposals + speedy special adjudication
│  ├─ Campaign finance → audited accounts + donor/donee accountability
│  ├─ Political parties → comprehensive law, internal democracy, disclosure
│  ├─ ECI appointment panel → PM + LoP LS + LoP RS + Speaker LS + Deputy Chair RS
│  ├─ Anti-defection → resign/recontest + ECI decision + office bar + invalid destabilising vote
│  ├─ Sitting days → LS 120 | RS 100 | State Houses 90 / under 70 members: 50
│  ├─ Bills → committee scrutiny + public consultation + legislative planning
│  ├─ Privileges → define/delimit; corrupt acts not protected
│  └─ Constructive no-confidence → 20% notice + alternative leader
│
├─ 8. EXECUTIVE + SERVICES + GOVERNANCE
│  ├─ Council of Ministers ceiling proposed: 10% of popular House
│  ├─ Statutory Civil Services Boards → transfer/promotion/placement
│  ├─ Wider recruitment above suggested senior level, including open market
│  ├─ Article 311 review → protect honest officials, improve accountability
│  ├─ RTI culture → transparency, participation, less secrecy
│  ├─ Public-interest disclosure / whistle-blower protection
│  ├─ Anti-corruption → confiscation/benami measures
│  └─ Institutions → Lokpal/Lokayuktas, CVC, PAC/CAG and inquiry follow-up
│
├─ 9. JUDICIARY + TRIBUNALS + RIGHTS
│  ├─ NCRWC National Judicial Commission ≠ later NJAC ≠ current collegium
│  │  └─ CJI + 2 senior-most SC judges + Law Minister + 1 eminent person
│  ├─ Complaints mechanism; court planning; access; ADR/plea bargaining
│  ├─ Proposed retirement ages: HC 65 | SC 68
│  ├─ Tribunal test: expertise + independence + HC review (*L. Chandra Kumar*, 1997)
│  ├─ Rights proposals: torture, compensation, privacy, speedy/equal justice
│  ├─ Article 300A: public purpose/non-arbitrariness + specified rehabilitation protection
│  └─ DPSP implementation review + proposed voting/tax/family duties
│
├─ 10. FEDERALISM + DECENTRALISATION
│  ├─ Inter-State Council consultation under Article 263
│  ├─ Inter-State Trade and Commerce Commission under Article 307
│  ├─ Governor appointment after Chief Minister consultation
│  ├─ Article 356 → last resort + floor test + no premature dissolution
│  ├─ Reserved Bills → suggested Governor ~6 months; President ~3 months
│  │  CAUTION: not current text of Articles 200–201
│  ├─ Local devolution → clear functions + separate fiscal domain + staff control
│  └─ Elections + audit + dissolution safeguards → functions/funds/functionaries
│
├─ 11. WORKING-OF-CONSTITUTION DIAGNOSTIC
│  ├─ Anti-defection → Tenth Schedule; *Kihoto Hollohan* (1992)
│  ├─ Criminalisation → RPA 1951; *Lily Thomas* (2013); *PIF* (2018)
│  ├─ Political finance → law + *ADR v Union of India* (2024)
│  ├─ Legislative scrutiny → House rules/committees; not every Bill must be amended constitutionally
│  ├─ Ordinances → Arts 123/213; *D.C. Wadhwa* (1987); *Krishna Kumar Singh* (2017)
│  ├─ Governors/356 → Arts 155–156, 163, 174, 200–201, 356; *S.R. Bommai* (1994)
│  ├─ Judicial vacancies/accountability → Arts 124, 217, 124(4)–(5);
│  │  *Supreme Court Advocates-on-Record Association v Union of India* (2015)
│  ├─ Civil service → Arts 309–311; *T.S.R. Subramanian* (2013)
│  ├─ Transparency/corruption → RTI Act 2005; CVC Act 2003; Lokpal Act 2013
│  └─ Cooperative federalism → consultation + fiscal trust + dispute resolution
│     RULE: current controversy ≠ proof of defective text or NCRWC implementation
│
├─ 12. IMPLEMENTATION AUDIT
│  └─ exact proposal → later instrument → wording → route → legal effect
│       → official attribution → label
│     ├─ exact adoption
│     ├─ modified adoption
│     ├─ related/similar, causation unproved
│     ├─ judicial development
│     ├─ rejected/displaced
│     └─ pending
│     EXAMPLES
│     ├─ 10% ministry proposal vs 91st Amendment 15% → modified/related, not exact
│     ├─ judicial commission vs NJAC invalidated in 2015 → not current system
│     ├─ disaster to Concurrent List vs Disaster Management Act 2005 → no List transfer
│     └─ RTI/Lokpal → later statutes with independent legal designs
│
├─ 13. CHOOSE THE RIGHT REFORM ROUTE
│  ├─ convention/procedure defect → rules + norms + reasons
│  ├─ capacity defect → staffing + finance + technology + administration
│  ├─ statutory gap → ordinary legislation
│  ├─ constitutional allocation gap → Article 368
│  ├─ specified federal change → Article 368 + ≥ 1/2 State ratification
│  └─ open-textured rule → judicial interpretation
│     PRINCIPLE: least legally sufficient, institutionally workable route
│
├─ 14. LIMITS / CRITICISMS
│  ├─ Mandate: self-limited; no foundational replacement
│  ├─ Consultation: broad evidence, but not constituent consent
│  ├─ Basic structure: assurance ≠ judicial pre-clearance
│  ├─ Implementation: dispersed among Union, States, legislatures, courts, institutions
│  ├─ Democratic legitimacy: contested redesign needs debate/ratification where required
│  └─ Selectivity: 249 proposals differ in urgency, route, feasibility and later status
│
├─ 15. EXAMINER TRAPS
│  ├─ Do not call NCRWC constitutional/statutory/constituent
│  ├─ Do not claim presidential system or replacement Constitution
│  ├─ Do not call report binding or all proposals unimplemented
│  ├─ Do not infer causation from chronology/similarity
│  ├─ Do not say basic structure blocks all reform
│  └─ Do not prescribe constitutional amendment for every governance failure
│
└─ 16. PYQ / MAINS ANSWER ROUTE
   ├─ Opening: advisory constitutional-maintenance review, not constituent rewrite
   ├─ Body 1: verified identity + mandate
   ├─ Body 2: recommendations by institutional cluster
   ├─ Body 3: working diagnosis beyond text
   ├─ Body 4: implementation audit + route matching
   ├─ Critique: mandate + consultation + legitimacy + feasibility + selectivity
   └─ Qualified verdict: useful diagnostic menu; each proposal needs competent route and current-law proof
```
