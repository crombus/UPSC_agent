# Polity Topic 36 - CIC and SIC - Quick-Glance Tree

```text
CIC / SIC = CENTRAL / STATE INFORMATION COMMISSION
│
├─ IDENTITY
│  ├─ statutory bodies: Right to Information Act, 2005
│  ├─ constitutional root of right to know: Article 19(1)(a)
│  ├─ assent 15 Jun 2005 -> full working regime 12 Oct 2005
│  └─ not constitutional courts, general grievance bodies or anti-corruption agencies
│
├─ WHAT CAN BE REQUESTED? — SECTION 2
│  ├─ s.2(f) information = material in any form
│  │  └─ includes private-body information legally accessible to a public authority
│  ├─ s.2(j) access = inspect | copies/extracts | samples | electronic form
│  ├─ existing/held/controlled material only -> no fresh opinion or record creation
│  └─ s.2(h) public authority
│     ├─ Constitution | parliamentary/State law | notification/order
│     └─ owned | substantially controlled | substantially financed | financed NGO
│        ├─ Thalappalam (2013): regulation != substantial control
│        └─ DAV College Trust (2019): real/material direct or indirect finance
│
├─ PREVENTION + REQUEST — SECTIONS 4 TO 7
│  ├─ s.4: catalogue/index -> proactive disclosure -> reasons -> fewer requests
│  ├─ CPIO/SPIO = Central/State Public Information Officer: decides
│  ├─ CAPIO/SAPIO = Assistant PIO: receives/forwards; add 5 days
│  ├─ s.6: no reasons; assist oral request; transfer within 5 days
│  └─ s.7: 30 days | life/liberty 48 hours | silence = deemed refusal
│          delay beyond clock = information free of charge
│
├─ EXEMPTION + BALANCE — SECTIONS 8 TO 11
│  ├─ s.8(1): enumerated protected interests
│  ├─ s.8(2): public interest may outweigh protected harm
│  ├─ s.8(3): 20-year opening; clauses (a), (c), (i) continue
│  ├─ s.9: copyright of non-State person
│  ├─ s.10: sever/redact exempt part, disclose remainder
│  ├─ s.11: third-party procedure, not exemption/veto
│  │        notice 5 days -> representation 10 -> decision 40
│  └─ current s.8(1)(j), from 13 Nov 2025:
│       "information which relates to personal information"
│       -> old internal tests deleted; s.8(2) still survives
│
├─ CIC DESIGN — SECTIONS 12 TO 14
│  ├─ Chief Information Commissioner + up to 10 Information Commissioners
│  ├─ President appoints on PM + Lok Sabha LoP/deemed leader
│  │                         + nominated Union Cabinet Minister
│  ├─ expertise: law, science-tech, social service, management,
│  │             journalism, mass media, administration-governance
│  ├─ bars: legislature | office of profit | party | business | profession
│  └─ President removes; proved misbehaviour/incapacity -> Supreme Court inquiry
│
├─ SIC DESIGN — SECTIONS 15 TO 17
│  ├─ State Chief Information Commissioner + up to 10 State ICs
│  ├─ Governor appoints on CM + Assembly LoP/deemed leader
│  │                         + nominated State Cabinet Minister
│  ├─ same expertise/conflict bars
│  └─ Governor removes; proved misbehaviour/incapacity -> Supreme Court inquiry
│
├─ 2019 ACT / RULES DECODE
│  ├─ Act formerly fixed 5 years + Election-Commission-linked service status
│  ├─ Amendment delegates term/pay/service prescription to Central Government
│  ├─ Rules prescribe 3 years, subject to statutory age 65
│  ├─ pay: Central Chief Rs 2,50,000
│  │       Central IC / State Chief / State IC Rs 2,25,000
│  ├─ no same-office reappointment
│  └─ IC may become Chief by fresh process; aggregate service <=5 years
│
├─ FOUR ROLE FIREWALL
│  ├─ PIO: primary decision
│  ├─ FAA = First Appellate Authority: senior departmental review
│  ├─ CIC/SIC: s.18 complaint inquiry + s.19 second appeal + s.20 consequence
│  └─ court: constitutional judicial review
│     NOT Commission powers: create records | grant pension/licence |
│     prosecute corruption | rewrite exemptions | general contempt
│
├─ COMPLAINT V APPEAL
│  ├─ s.18 complaint triggers: no PIO/acceptance, refusal, delay, fee,
│  │                           incomplete/misleading/false info, other access issue
│  ├─ inquiry: summons | oath | affidavit | records | inspection
│  ├─ State of Manipur (2011): complaint != disclosure appeal
│  └─ s.19 route
│     ├─ first appeal within 30 days -> senior officer
│     ├─ second appeal within 90 days -> CIC/SIC
│     ├─ PIO bears burden to justify denial
│     └─ decision binding
│
├─ REMEDIES
│  ├─ s.19(8): disclose + appoint PIO + publish + improve records + train + report
│  ├─ compensation: public authority repairs applicant loss/detriment
│  ├─ s.20 penalty: responsible PIO, Rs 250/day, maximum Rs 25,000
│  │  └─ hearing + PIO proves reasonable and diligent conduct
│  └─ persistent default -> disciplinary recommendation under service rules
│
├─ OVERRIDE / SECURITY / REPORTING
│  ├─ s.22: RTI overrides the inconsistent Official Secrets Act, 1923/other law;
│  │        RTI's own limits remain
│  ├─ s.23: ordinary proceeding barred; Articles 226/32 review survives
│  ├─ s.24 listed intelligence/security bodies
│  │  ├─ corruption allegation -> exception
│  │  └─ human-rights allegation -> CIC/SIC approval + 45 days
│  ├─ s.25 annual report -> Government -> legislature
│  └─ s.26 awareness + disadvantaged-community outreach + PIO training + guide
│
├─ CASE ANCHORS
│  ├─ CBSE (2011): answer books; held records; no creation
│  ├─ Girish Deshpande (2012): personal records under old clause
│  ├─ Jayantilal Mistry (2015): no generic RBI fiduciary shield
│  ├─ Subhash Chandra Agarwal (2019): CJI office public authority; balance
│  └─ Association for Democratic Reforms Electoral Bonds (2024):
│       voter funding information under Article 19(1)(a)
│       └─ constitutional transparency context, not extra CIC jurisdiction
│
├─ PRELIMS TRAPS
│  ├─ statutory != constitutional
│  ├─ up to 10 != always 10
│  ├─ s.18 complaint != disclosure appeal
│  ├─ s.11 procedure != exemption/veto
│  ├─ compensation != personal penalty
│  ├─ civil-court evidence powers != court/contempt power
│  └─ human-rights approval/45 days != corruption route
│
└─ MAINS VERDICT
   binding legal teeth exist
      + advance appointments
      + independent capacity/staff
      + section 4 and sound records
      + reasoned penalty/compliance
      + assisted multilingual offline/digital access
      + proportionate privacy protection
   = timely democratic accountability
```
