# Modern Indian History 06 — Structure of Government & Constitutional Development, 1757–1858

STRUCTURE OF GOVERNMENT & CONSTITUTIONAL DEVELOPMENT, 1757-1858
|
+-- 1) CENTRAL QUESTION
|   -> How was a profit-seeking Company turned into a Crown-run imperial state?
|   -> Key idea: Parliament regulated a Company-state, not a democracy-in-the-making.
|
+-- 2) TOPIC BOUNDARY
|   -> Starts: post-Diwani Company-state anomaly after 1765
|   -> Ends: Government of India Act, 1858 + Queen's Proclamation boundary
|   -> OUT: detailed Revolt of 1857 narrative -> Topic 11
|   -> OUT: Indian Councils Act, 1861 onward -> Topic 12
|
+-- 3) STARTING PROBLEM
|   -> 1757 Plassey -> Company becomes political kingmaker
|   -> 1764 Buxar -> military supremacy
|   -> 1765 Diwani -> revenue power in Bengal, Bihar, Orissa
|   -> 1765-72 Dual Government -> power without full responsibility
|   -> Contradiction:
|      -> London joint-stock corporation
|      -> Indian territorial sovereign
|      -> private profit + public coercion
|      -> no settled constitutional accountability
|
+-- 4) WHY PARLIAMENT INTERVENED
|   -> 1772 loan request -> Company solvency crisis exposed to Parliament
|   -> Nabob/patronage anxiety -> Indian fortunes entering British politics
|   -> Bengal misgovernment as fiscal-political problem
|   -> NOT mainly humanitarian famine legislation
|
+-- 5) NINE-ACT LADDER
|   |
|   +-- Regulating Act, 1773
|   |   -> Governor-General of Bengal / Fort William
|   |   -> Council of four
|   |   -> Bombay/Madras subordinated in war and peace
|   |   -> reporting duty on Directors
|   |   -> Supreme Court framework (Calcutta begins 1774)
|   |
|   +-- Amending Act / Act of Settlement, 1781
|   |   -> official acts protected from Court overreach
|   |   -> revenue matters excluded from Supreme Court reach
|   |   -> Hindu law for Hindus / Muslim law for Muslims in personal law
|   |   -> fixes jurisdiction, NOT council deadlock
|   |
|   +-- Pitt's India Act, 1784
|   |   -> Board of Control + Court of Directors
|   |   -> dual control in Britain
|   |   -> Governor-General-plus-three council
|   |   -> stronger presidency subordination
|   |
|   +-- Act of 1786
|   |   -> Cornwallis gets bounded override power
|   |   -> Governor-General + Commander-in-Chief combination
|   |
|   +-- Charter Act, 1793
|   |   -> charter renewed for 20 years
|   |   -> continuation + codification, not liberalisation
|   |
|   +-- Charter Act, 1813
|   |   -> Indian trade opened to others
|   |   -> tea + China trade retained by Company
|   |   -> Crown sovereignty asserted
|   |   -> missionaries allowed
|   |   -> one lakh rupees annually for education
|   |
|   +-- Charter Act, 1833
|   |   -> Governor-General of Bengal -> Governor-General of India
|   |   -> William Bentinck first holder of all-India title
|   |   -> all-India legislative centralisation
|   |   -> Law Member + Law Commission
|   |   -> Company commerce ends completely
|   |
|   +-- Charter Act, 1853
|   |   -> no fixed-term renewal
|   |   -> legislative/executive work separated
|   |   -> additional legislative members
|   |   -> Directors' patronage ended in principle
|   |   -> 1854 Macaulay Committee + 1855 first exam implement competition
|   |
|   +-- Government of India Act, 1858
|       -> Company rule ends
|       -> Board of Control abolished
|       -> Court of Directors abolished
|       -> Secretary of State for India + Council of India
|       -> Lord Canning becomes Governor-General-and-Viceroy
|
+-- 6) NAMED PEOPLE / INSTITUTIONS
|   -> Warren Hastings -> first Governor-General of Bengal
|   -> Clavering / Monson / Francis / Barwell -> council arithmetic around Hastings
|   -> Elijah Impey -> first Chief Justice lens for court conflict

|   -> William Bentinck -> first Governor-General of India
|   -> Macaulay -> Law Member; 1854 ICS-competition design

|   -> Supreme Court at Calcutta / Board of Control / Court of Directors / Council of India

|      -> 1784 smaller council
|      -> 1786 bounded override
|      -> 1833 all-India title

|      -> 1833 all-India legislative centre

|   -> Judicial ladder:
|      -> Supreme Court vs Company courts conflict
|      -> 1781 carve-outs
|      -> 1833 codification impulse
