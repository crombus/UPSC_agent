# Environment and Ecology 14 — Water Pollution and River-Cleaning Missions

## Quick-Glance Tree Chart

```text
WATER POLLUTION + RIVER REJUVENATION
│
├─ 1. SOURCE → PATHWAY → LOAD
│  ├─ point: identifiable pipe/drain/outfall
│  │  └─ consent + outlet monitoring + STP/ETP/CETP
│  ├─ non-point: diffuse runoff/leaching
│  │  └─ land/farm practice + buffers + catchment monitoring
│  ├─ boundary: storm drain may combine both
│  └─ load kg/day = concentration mg/L × flow MLD
│     └─ dilution may lower concentration, not pollutant mass
│
├─ 2. POLLUTANTS + MECHANISMS
│  ├─ physical: solids, sediment, turbidity, heat
│  ├─ chemical: nutrients, salts, pesticides, oil, metals, PFAS
│  ├─ biological: bacteria, viruses, protozoa, helminths
│  ├─ organic load ↑ → BOD ↑ → DO ↓ if replenishment is inadequate
│  ├─ COD usually ≥ BOD; no universal conversion ratio
│  ├─ eutrophication: N/P → bloom → decay → hypoxia
│  ├─ pathogens: coliforms are indicators, not every pathogen
│  ├─ heat: oxygen solubility ↓ + metabolic stress ↑
│  ├─ salinity: ordinary biological STP removes little dissolved salt
│  └─ emerging: PFAS, pharmaceuticals, endocrine-active chemicals,
│              microplastics/microbeads, antimicrobial resistance
│
├─ 3. EXACT CPCB RECEIVING-WATER CRITERIA
│  ├─ A: TC≤50 | pH6.5–8.5 | DO≥6 | BOD₅≤2
│  ├─ B: TC≤500 | pH6.5–8.5 | DO≥5 | BOD₅≤3
│  ├─ C: TC≤5000 | pH6–9 | DO≥4 | BOD₅≤3
│  ├─ D: pH6.5–8.5 | DO≥4 | free ammonia-N≤1.2
│  ├─ E: pH6–8.5 | EC≤2250 | SAR≤26 | boron≤2
│  ├─ A–C BOD method: 5 days at 20°C
│  └─ separate bathing notification:
│     ├─ faecal coliform 500 desirable / 2500 maximum
│     ├─ faecal streptococci 100 / 500
│     └─ DO≥5; BOD₃ at 27°C≤3
│
├─ 4. STANDARD FIREWALL
│  ├─ ambient criterion = receiving-water condition
│  ├─ effluent standard = named outlet/source limit
│  ├─ general inland-surface-water discharge:
│  │  └─ BOD₃≤30; COD≤250 mg/L
│  └─ industry-specific/consent limits may differ or be stricter
│
├─ 5. MONITORING FIREWALL
│  ├─ process → influent/effluent → outfall → ambient → ecology/health
│  ├─ grab ≠ composite ≠ continuous/online
│  ├─ installed MLD ≠ actual flow/load treated
│  ├─ outlet compliance ≠ whole-river quality
│  └─ report station + season + flow + indicator + method + criterion
│
├─ 6. LAW + INSTITUTIONS
│  ├─ Water Act 1974
│  │  ├─ CPCB s16 | SPCB s17
│  │  ├─ sampling s21 | inspection s23
│  │  ├─ prohibition s24 | consent ss25–27
│  │  └─ emergency s32 | court s33 | directions s33A
│  ├─ EPA 1986: ss3/5/6 → powers, directions, rules/standards
│  ├─ 2024 amendment
│  │  ├─ initially HP + Rajasthan + UTs; other States adopt
│  │  ├─ s27A uniform consent-guideline power
│  │  └─ s45E retains imprisonment for ss25/26 failure
│  ├─ dated 28-1-2026: CTO till cancelled; Red timeline 90 days
│  ├─ SPCB/PCC: consent, inspection, enforcement
│  ├─ ULB/utility: sewage + faecal-sludge service
│  ├─ industry: prevention + ETP/CETP route + residuals
│  └─ NMCG: Ganga mission implementation, not CPCB replacement
│
├─ 7. TREATMENT TRAINS
│  ├─ sewage:
│  │  screening/grit → biological → separation/polishing
│  │  → disinfection → reuse/discharge + sludge line
│  ├─ faecal sludge:
│  │  containment → mechanised emptying → transport
│  │  → treatment/co-treatment → safe solids/liquid destination
│  ├─ industry:
│  │  minimise/segregate → equalise/neutralise
│  │  → physico-chemical → biological if compatible → advanced polish
│  ├─ STP = sewage | ETP = one unit | CETP = compatible cluster
│  ├─ MBR = biology + membrane solids separation
│  └─ activated carbon = adsorption; finite capacity, spent-media duty
│
├─ 8. BASIN + ECOLOGY
│  ├─ prevent source → treat → reuse safely
│  ├─ environmental flow ≠ licence to dilute waste
│  ├─ protect tributaries, groundwater, floodplains and recharge
│  ├─ wetlands/riparian buffers retain some sediment/nutrients
│  │  └─ finite capacity; not untreated-waste sinks
│  └─ riverfront works complement, never substitute, load control
│
├─ 9. MISSION EVOLUTION
│  ├─ GAP-I: June 1985 → closed 31-3-2000
│  ├─ GAP-II: recorded from 1993
│  ├─ NMCG society: 12-8-2011
│  ├─ Namami Gange: 2014–15
│  ├─ 2016 five tiers:
│  │  National Ganga Council → ETF → NMCG
│  │  → State Ganga Committees → District Ganga Committees
│  ├─ NRCP: other river basins; State/UT proposals
│  ├─ Arth Ganga, dated 3-8-2023:
│  │  natural farming | treated water/sludge reuse | livelihoods
│  │  | participation | culture/tourism | institution building
│  └─ Yamuna: preserve project status
│     └─ Dhandhupura 100 MLD was in trial testing on 2-7-2026
│
├─ 10. DATED STATUS — 2 JULY 2026
│  ├─ Namami: 524 sanctioned | 363 completed | ₹43,031 crore
│  ├─ sewerage: 218 sanctioned | 145 completed
│  ├─ 6610 MLD sanctioned | 4263 MLD created/rehabilitated
│  └─ these are outputs, not utilisation/compliance/river outcome
│
├─ 11. STATUS LADDER
│  announced → sanctioned → awarded → constructed → trial
│  → commissioned → connected/utilised → compliant
│  → load reduced → ambient/ecological outcome verified
│
└─ 12. EXAM SPINE
   source/pathway → pollutant/load → treatment
   → Water Act/EPA/actor → basin ecology
   → dated mission evidence → status/monitoring qualification
```

**Qualified conclusion:** River-cleaning success means verified source-load reduction,
continuously compliant treatment, environmental flow and stretch–season–indicator improvement;
sanctioned money, installed MLD or visible riverfront work cannot substitute for that chain.
