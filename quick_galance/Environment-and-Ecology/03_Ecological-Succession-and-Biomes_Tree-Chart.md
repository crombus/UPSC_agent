# Environment and Ecology 03 — Ecological Succession and Biomes

> Quick-glance revision tree · evidence checked 28 September 2026

```text
CORE THESIS
Succession = TIME axis of community change.
Biome = SPACE axis of broad ecological pattern.
Sound restoration must fit both the present stage and native biome.
│
├─ 1. SUCCESSION FIREWALL
│  ├─ directional community/process change through time
│  ├─ not seasonal fluctuation, evolution or spatial zonation alone
│  ├─ sere = whole sequence
│  └─ seral stage = one community in it
│
├─ 2. CLASSICAL PROCESS
│  nudation
│   → migration/invasion
│   → ecesis: establishment
│   → aggregation
│   → competition/coaction
│   → reaction: site modification
│   → relative stabilisation
│  trap: stages overlap; stabilisation ≠ permanence
│
├─ 3. PRIMARY vs SECONDARY
│  ├─ primary
│  │  no developed soil
│  │  soil-building is part of recovery
│  │  bare rock · fresh severe spoil · glacial exposure
│  └─ secondary
│     soil + microbes/roots/seed bank/survivors remain
│     abandoned field · jhum fallow · many post-fire sites
│     usually faster
│  decision test: what soil and biological memory survived?
│
├─ 4. NAMED SERES
│  ├─ lithosere = rock
│  ├─ psammosere = sand
│  ├─ halosere = saline site
│  ├─ hydrosere = fresh water
│  └─ xerosere = dry site
│  trap: name identifies start, not guaranteed endpoint
│
├─ 5. HYDRARCH / XERARCH
│  ├─ hydrarch
│  │  open water → submerged/floating plants
│  │  → reed/sedge → more mesic terrestrial conditions
│  └─ xerarch
│     lichen/moss → herbs → shrubs
│     as soil and moisture retention improve
│  limits: hydrology, sediment, climate and disturbance
│  forest is never a universal endpoint
│
├─ 6. CAUSAL DRIVERS
│  ├─ autogenic
│  │  organisms alter litter, soil, shade, nutrients, microclimate
│  └─ allogenic
│     flood · sediment · erosion · storm · climate
│     fire/grazing/land conversion
│
├─ 7. ESTABLISHMENT MODELS
│  ├─ facilitation: early species help later species
│  ├─ tolerance: later species need no help from residents
│  └─ inhibition: residents suppress until death/damage opens space
│  trap: alternatives, not compulsory stages
│
├─ 8. CLIMAX → NON-EQUILIBRIUM
│  ├─ classical: climate → one stable climax
│  └─ modern:
│     climate envelope + soil/topography
│     + species pool/dispersal + chance/history
│     + disturbance regime
│     → multiple pathways and patch mosaics
│  patch dynamics: local reset + landscape persistence
│  threshold/hysteresis: pressure removal may not restore old state
│
├─ 9. DISTURBANCE / RESILIENCE
│  ├─ regime = type + frequency + severity + season + extent
│  ├─ resistance = little immediate change
│  ├─ resilience = absorb/reorganise, retain identity/functions
│  └─ recovery = observed post-shock trajectory
│  trap: disturbance can maintain savanna; excess can degrade it
│
├─ 10. RESTORATION LADDER
│  reference ecosystem
│   → diagnose soil, hydrology, legacies, pressure
│   → protect remnants + remove driver
│   → passive recovery / assisted regeneration / active rebuilding
│   → match intervention to seral stage
│   → monitor composition, structure, process,
│      connectivity, resilience and livelihoods
│  planting ≠ restoration; hectares ≠ outcome
│
├─ 11. BIOME CONTROLS
│  ├─ broad: temperature + precipitation + seasonality
│  ├─ regional: altitude, monsoon/orography, continentality
│  └─ local: soil, drainage, topography, fire,
│     herbivory, fragmentation and land-use history
│  biome > ecosystem > habitat in spatial scale
│
├─ 12. TERRESTRIAL BIOMES
│  ├─ tropical rainforest
│  │  evergreen · layered · lianas/epiphytes
│  │  rapid cycling; lush biomass ≠ rich soil
│  ├─ seasonal/deciduous forest
│  │  dry-season leaf fall
│  ├─ savanna
│  │  grasses + scattered trees
│  │  rainfall seasonality + fire + herbivory
│  ├─ desert/xeric scrub
│  │  water limit · waxy/small leaves · spines/roots
│  ├─ Mediterranean
│  │  dry summer · wet winter · sclerophyll
│  ├─ temperate grassland
│  │  continental · grasses · often fertile soil
│  ├─ temperate deciduous forest
│  ├─ taiga = boreal conifer forest
│  └─ tundra/alpine = treeless, short growing season
│
├─ 13. AQUATIC SYSTEMS
│  ├─ lentic = lake/pond, standing water
│  ├─ lotic = river/stream, flowing water
│  ├─ wetland = saturation + hydroperiod
│  ├─ estuary/lagoon = brackish river-sea transition
│  ├─ intertidal = exposed/submerged by tides
│  ├─ pelagic = water column
│  └─ benthic = bottom/substrate
│  mangrove = intertidal salt-tolerant forest/ecotone
│  coral reef = light-temperature-chemistry constrained
│
├─ 14. ECOTONES / TREELINES
│  ├─ ecotone = transition zone, not line
│  ├─ edge effect may add overlap species
│  └─ edge may also raise heat, invasion or predation
│  treeline controls:
│  temperature + snow/moisture + wind/soil
│  + seed/recruitment + grazing/fire/cutting
│  trap: one upslope observation ≠ sole-cause attribution
│
├─ 15. INDIA MAP
│  ├─ wet evergreen: Western Ghats · Northeast · islands
│  ├─ deciduous: central/peninsular belts
│  ├─ desert/thorn/grassland: Thar · Kutch · open landscapes
│  ├─ temperate-alpine: Himalaya
│  ├─ estuary-mangrove: Sundarbans
│  ├─ jhum fallow = secondary succession
│  └─ mine spoil = staged primary-like restoration where soil is absent
│
├─ 16. OPEN-ECOSYSTEM FIREWALL
│  grassland · savanna · scrub · ravine · rocky outcrop
│  can be natural ecosystems, not incomplete forests
│  “wasteland” = administrative label
│  forest = legal/canopy category
│  grassland biome = ecological category
│
├─ 17. CLIMATE / LAND-USE SHIFT
│  climate alters suitability, mortality and recruitment
│  land use blocks movement or changes fire/grazing/hydrology
│  → lags · fragmentation · woody change · novel communities
│  IPCC AR6 WGII 2022: shifts occur; local response is mixed
│  ISFR 2023: 8,27,357 sq km; 25.17%
│  caveat: canopy extent cannot prove successional stage
│
├─ 18. PYQ ROUTE
│  ├─ direct: 2021 Prelims Q20 — lichen/moss without soil
│  ├─ biome applications:
│  │  2021 Q60 rainforest · Q61 savanna
│  │  2023 Q63 rainforest soil
│  │  2026 GS-I Q5 tundra
│  ├─ restoration:
│  │  2019 GS-I Q15 mountain ecosystem
│  │  2025 Q90 EU Nature Restoration Law
│  └─ essay: 2024 forests-civilisations-deserts
│
└─ ANSWER SPINE
   define process + scale
    → test soil/biological legacies
    → name autogenic/allogenic driver and establishment model
    → specify disturbance regime
    → fix native reference biome
    → use one Indian example
    → separate cover, composition, function and resilience
    → conclude with repeated monitoring + evidence limit
```
