# Environment and Ecology 01 — Ecosystem Structure and Function

> Quick-glance revision tree · evidence checked 28 September 2026

```text
ECOSYSTEM = BIOTIC COMMUNITY + ABIOTIC ENVIRONMENT + INTERACTIONS
│  A.G. Tansley, 1935
│  open functional unit; fix the spatial + temporal boundary
│
├─ 1. LEVELS — never interchange
│  organism
│   └─ population
│       └─ community
│           └─ ecosystem
│               └─ landscape
│                   └─ biome
│                       └─ biosphere
│
├─ 2. STRUCTURE — “what is present / arranged?”
│  ├─ abiotic
│  │  light · temperature · rainfall · water · air
│  │  soil · minerals · pH · salinity · topography
│  ├─ biotic guilds
│  │  producers · consumers · detritivores · decomposers
│  ├─ trophic structure
│  │  feeding position is relational; omnivores may occupy several levels
│  ├─ spatial structure
│  │  canopy → understorey → shrub/herb → forest floor
│  └─ quantities
│     standing crop = living stock
│     standing state = abiotic nutrient stock
│
├─ 3. FUNCTION — “what does the system do?”
│  ├─ productivity
│  ├─ trophic transfer
│  ├─ decomposition
│  ├─ nutrient return
│  ├─ regulation/services
│  └─ disturbance response
│
├─ 4. TROPHIC PATHWAYS
│  ├─ producer gate
│  │  photosynthesis OR chemosynthesis
│  │  ocean PYQ: cyanobacteria + diatoms = primary producers
│  ├─ grazing chain
│  │  living producer → herbivore → carnivore
│  ├─ detritus chain
│  │  dead matter → detritivore → microbial decomposer
│  ├─ food chain / food web
│  │  one route / interconnected routes; alternatives may aid resilience
│  │  BUT common habitat/resource failure can collapse many links
│  └─ functional examples
│     oyster = filter feeder
│     earthworm + millipede + woodlouse = detritivores
│
├─ 5. ENERGY ≠ MATTER
│  ├─ ENERGY
│  │  input → fixation → feeding/detritus → respiration → heat
│  │  one-way; transformed and progressively degraded
│  ├─ MATTER
│  │  biotic pool ↔ abiotic pool through uptake/death/decomposition
│  │  cycles, but may be imported/exported/leached at a local boundary
│  └─ ecological efficiency
│     production at level n+1 ÷ production at level n × 100
│     about 10% = heuristic average, not an invariant law
│
├─ 6. PRODUCTIVITY — rate, not stock
│  gross primary productivity (GPP) = total producer fixation
│   └─ minus producer respiration
│       └─ net primary productivity (NPP) = growth + consumer supply + detrital input
│  secondary productivity = new consumer biomass per time
│  biomass = conventionally dry mass
│  high productivity ≠ high biodiversity/resilience
│
├─ 7. DECOMPOSITION — nutrient-cycle hinge
│  detritus
│   ├─ fragmentation — detritivores make smaller particles
│   ├─ leaching — soluble material moves with water
│   ├─ catabolism — bacterial/fungal enzymes simplify compounds
│   ├─ humification — resistant humus accumulates
│   └─ mineralisation — inorganic nutrients released → uptake
│  fast: warm + suitable moisture + oxygen + labile/N-rich litter
│  slow: cold + anaerobiosis + lignin/chitin-rich material
│  verdict: nutrients return; energy still dissipates
│
├─ 8. SPACE, NICHE AND EDGE
│  ├─ habitat = address
│  ├─ niche = functional “job”
│  │  habitat niche · trophic niche · reproductive niche
│  ├─ resource partitioning
│  │  separates food/space/time → reduces direct competition
│  ├─ life zone
│  │  altitudinal community tied to temperature + precipitation
│  └─ ecotone = transition zone of variable width
│     edge effect = possible response, not definition
│     natural mangrove edge may add functions;
│     abrupt fragmented edge may harm interior specialists
│
├─ 9. DISTURBANCE AND LIMITS
│  ├─ resistance = limited change during shock
│  ├─ resilience = capacity to reorganise/rebound
│  ├─ recovery = observed post-shock trajectory
│  └─ carrying capacity
│     sustained load without eroding:
│     regenerative supply + assimilative capacity
│     + habitat/connectivity + disturbance response
│     dynamic with consumption · technology · governance · climate
│
├─ 10. SPECIES LABEL FIREWALL
│  ├─ keystone
│  │  effect disproportionate to abundance
│  │  Indian use: fruiting Ficus as keystone resource
│  ├─ foundation
│  │  abundant habitat former
│  │  Indian use: mangrove trees structure intertidal habitat
│  ├─ indicator
│  │  condition signals specified environmental state
│  │  example: lichen response to air-quality stress
│  ├─ umbrella
│  │  large habitat needs → co-benefits for co-occurring species
│  │  Indian use: tiger landscape
│  └─ flagship
│     public-support symbol; may overlap umbrella, never synonymous
│
├─ 11. INTERACTIONS TESTED
│  fig ↔ fig wasp = coevolved pollination mutualism
│  parasitoid = develops in/on one host and ultimately kills it
│  parasite ≠ parasitoid ≠ predator
│  symbiosis needs outcome specified
│
├─ 12. ECOSYSTEM SERVICES / NCP
│  ├─ provisioning — food · fibre · water
│  ├─ regulating — flood/wave moderation · pollination · climate
│  ├─ supporting — production · soil formation · nutrient cycling
│  ├─ cultural — spiritual · recreational · knowledge values
│  └─ NCP — adds relational + Indigenous/local-knowledge values
│
├─ 13. INDIA EVIDENCE
│  ├─ Sundarbans mangroves
│  │  zonation/roots → nursery + sediment + wave + livelihood functions
│  ├─ wetlands
│  │  plants/sediments/microbes → nutrient/pollutant retention
│  ├─ Western Ghats
│  │  layering/elevation → differentiated niches
│  ├─ ISFR 2023
│  │  forest+tree cover 8,27,357 sq km = 25.17%
│  │  extent ≠ native composition, connectivity or function
│  └─ Economic Survey 2025-26
│     MISHTI targets/estimates ≠ achieved outcomes
│     NPCA + National Coastal Mission = adaptation-function linkage
│

│     2024 + 2025 official · 2019-2023 inferred

│

   boundary + parameter
   → structure changed
```
