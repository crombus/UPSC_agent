# Environment and Ecology 19 — UNFCCC, COP, Kyoto and Paris Agreement

```text
GLOBAL CLIMATE-TREATY ARCHITECTURE
|
+-- CENTRAL THESIS
|   UNFCCC = framework; Kyoto = binding quantified targets for a listed group;
|   Paris = universal NDC participation within a binding procedural cycle.
|   Test effectiveness through equity + integrity + finance + verified delivery.
|
+-- 1. UNFCCC (adopted 9 May 1992; in force 21 March 1994)
|   |
|   +-- Art.2 objective
|   |   stabilise GHG concentrations -> prevent dangerous interference
|   |   -> protect natural adaptation, food production, sustainable development
|   |
|   +-- Art.3 principles
|   |   equity -> CBDR-RC -> developed-country lead
|   |   + special needs + precaution + sustainable development + open economy
|   |
|   +-- Art.4 commitments
|   |   all Parties: inventory/programmes/adaptation/sinks/research/reporting
|   |   Annex I: mitigation lead | Annex II ⊂ Annex I: finance + technology
|   |   non-Annex I: general duties; implementation linked to support
|   |
|   +-- bodies
|       COP: supreme body | SBSTA: science/technology | SBI: implementation
|       Secretariat: process support | Art.11 Financial Mechanism
|       GEF/GCF: operating entities | FRLD: entrusted entity
|       Adaptation Fund: Kyoto-origin route serving Paris
|
+-- 2. GOVERNING-BODY / LAW TEST
|   |
|   +-- COP -> Convention Parties
|   +-- CMP -> Kyoto Parties
|   +-- CMA -> Paris Parties
|   |
|   +-- treaty article > formal amendment > implementing decision
|       > political declaration/presidency roadmap > pledge > delivery
|       Decision effect depends on treaty authority; decision ≠ automatic amendment.
|
+-- 3. TREATY-STATUS LADDER
|   adoption -> signature -> ratification/acceptance/approval OR accession
|   -> entry into force -> implementation -> withdrawal -> possible re-entry
|   |
|   +-- Paris Art.28: notice after 3 years; effective after 1 year
|   +-- US: out 4 Nov 2020 -> re-entered 19 Feb 2021
|       -> second withdrawal effective 27 Jan 2026
|       re-entry requires fresh instrument + 30 days
|
+-- 4. KYOTO PROTOCOL (adopted 11 Dec 1997; in force 16 Feb 2005)
|   |
|   +-- Annex B percentage -> assigned amount -> AAUs (1 tCO2e)
|   +-- period 1: 2008-12; aggregate at least 5% below 1990
|   +-- Doha: adopted 8 Dec 2012; period 2 = 2013-20
|   |   at least 18% below 1990; in force 31 Dec 2020
|   |   periods ended; Protocol remains in force
|   |
|   +-- mechanisms
|   |   CDM: non-Annex I host -> CER
|   |   JI: Annex I project -> ERU
|   |   IET: eligible Kyoto-unit transfer; supplemental to domestic action
|   |
|   +-- limits
|       US never ratified | Canada withdrew | narrow coverage
|       surplus AAUs | additionality/baseline/geographic-demand problems
|
+-- 5. PARIS AGREEMENT (adopted 12 Dec 2015; in force 4 Nov 2016)
|   |
|   +-- Art.2: well below 2°C + pursue 1.5°C
|   +-- Art.4 cycle
|   |   prepare + communicate + maintain NDC -> pursue domestic measures
|   |   -> Art.13 transparency -> Art.14 GST -> next NDC every 5 years
|   |   progression + highest possible ambition; no universal percentage
|   |
|   +-- Art.7: adaptation goal = capacity + resilience - vulnerability
|   +-- Art.8: avert/minimise/address loss and damage
|   |   decision 1/CP.21 para 51: no liability/compensation basis
|   +-- Art.9: developed Parties shall provide finance; others encouraged
|   +-- Art.13: common framework + capacity-based flexibility
|   +-- Art.14: collective, facilitative GST; not national compliance
|
+-- 6. ARTICLE 6 — DO NOT MERGE
|   |
|   +-- 6.2: Party-led ITMOs
|   |   authorisation + reporting + corresponding adjustments
|   |   -> prevent double counting
|   |
|   +-- 6.4: CMA-supervised A6.4 mechanism
|   |   5% issued A6.4ERs -> Adaptation Fund
|   |   minimum 2% issued A6.4ERs cancelled -> OMGE
|   |
|   +-- 6.8: non-market cooperation; no transferred mitigation units
|   +-- integrity: additionality + baseline + permanence + rights + registry
|   +-- trap: mandatory 5%/2% belongs to 6.4, not every 6.2 transfer
|
+-- 7. MILESTONE RAIL
|   Bali 2007: action plan
|   -> Copenhagen 2009: Accord only “taken note of”
|   -> Cancun 2010: GCF + adaptation + technology institutions
|   -> Durban 2011: universal legal-outcome mandate
|   -> Warsaw 2013: loss-and-damage mechanism
|   -> Paris 2015: NDC treaty
|   -> Glasgow 2021: rulebook; unabated-coal phasedown wording
|   -> COP27 2022: loss-damage fund decision
|   -> UAE 2023: first GST; “transitioning away”; renewables ×3; efficiency ×2
|   -> Baku 2024: USD300bn goal + USD1.3tn all-actor scale-up by 2035
|   -> Belém 2025: implementation accelerator; Mission to 1.5;
|      triple adaptation-finance effort by 2035; 59 voluntary indicators
|      presidency fossil roadmap lies outside negotiated Mutirão decision
|
+-- 8. INDIA FIREWALL
|   India = non-Annex I; Paris Party; equity/CBDR-RC/finance/technology stance
|   COP speech ≠ formal NDC submission ≠ implementation outcome
|   2031-35 NDC active from 24 Apr 2026; target values -> Topic 20
|   detailed carbon-market implementation -> Topic 21
|
+-- UPSC TRAPS
|   UNFCCC ≠ Kyoto ≠ Paris | COP ≠ CMP ≠ CMA
|   Annex I ≠ Annex II ≠ Annex B | AAU ≠ CER ≠ ERU ≠ ITMO
|   GST ≠ compliance verdict | report ≠ achievement
|   decision ≠ declaration ≠ roadmap ≠ pledge ≠ disbursement
|
+-- PYQ ANSWER ROUTE
    identify instrument/body -> legal status/date -> mechanism/article
    -> named decision -> India firewall -> limitation -> qualified verdict

CONCLUSION
Paris solved Kyoto’s participation problem, not the adequacy problem:
credible ambition requires transparent evidence, sound Article 6 accounting,
differentiated support and delivery.
```
