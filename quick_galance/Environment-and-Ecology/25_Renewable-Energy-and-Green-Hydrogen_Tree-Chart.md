RENEWABLE ENERGY + GREEN HYDROGEN
│
├─ CENTRAL THESIS
│  ├─ installation ≠ integration
│  ├─ hydrogen = carrier/feedstock, not primary source
│  └─ success = reliable low-carbon service + verified lifecycle
│
├─ 1. CATEGORY FIREWALL
│  ├─ renewable
│  │  └─ solar | wind | hydro | sustainable biomass | geothermal
│  ├─ non-fossil
│  │  └─ renewables + nuclear
│  ├─ nuclear
│  │  └─ non-fossil, NOT renewable
│  ├─ electricity
│  │  └─ generated output
│  ├─ hydrogen
│  │  └─ manufactured molecule
│  └─ storage
│     └─ shifts already-generated energy
│
├─ 2. METRIC FIREWALL
│  ├─ installed capacity → MW/GW nameplate capability
│  ├─ generation → MWh/TWh actual energy
│  ├─ capacity factor → actual ÷ maximum possible output
│  ├─ reliable supply → delivered when/where demanded
│  ├─ dispatchable → output controllable within limits
│  └─ firm → specified dependable delivery
│     └─ capacity share never proves generation/firmness
│
├─ 3. SOURCE PORTFOLIO
│  ├─ solar
│  │  ├─ + modular | rooftop | low operating emissions
│  │  └─ − daylight/weather | land | minerals | panel recycling
│  ├─ wind
│  │  ├─ + complements solar | no fuel
│  │  └─ − roads/lines | birds/bats | offshore marine costs
│  ├─ hydro
│  │  ├─ + energy | flexibility | storage
│  │  └─ − displacement | flows | sediment | aquatic ecology
│  └─ biomass/biogas
│     ├─ + dispatchable | residues/waste
│     └─ − land/food | pollution | methane | feedstock logistics
│
├─ 4. VRE-INTEGRATION CHAIN
│  ├─ forecast resource + demand
│  ├─ schedule + dispatch
│  ├─ transmit resource-region → load-centre
│  ├─ geographic diversity
│  ├─ flexible generation + reserves
│  ├─ demand response
│  ├─ storage
│  │  ├─ battery → fast/intraday
│  │  └─ pumped hydro → longer duration/site-constrained
│  └─ result
│     ├─ lower curtailment
│     └─ higher reliability
│
├─ 5. CURTAILMENT TRAP
│  ├─ curtailment = available output not accepted
│  ├─ causes → congestion | security | oversupply | contracts
│  └─ NOT the same as weak sun/wind
│
