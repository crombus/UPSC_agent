# Environment and Ecology 13 — Air Pollution and CPCB Standards

## Quick-Glance Tree Chart

```text
AIR POLLUTION
│
├─ 1. CAUSAL FIREWALL
│  ├─ emission = source mass/time or activity
│  ├─ ambient concentration = mass/air volume + place + averaging time
│  ├─ exposure = concentration contacted × time/activity/route
│  ├─ dose → health/ecosystem outcome
│  └─ input/output ≠ outcome
│     ├─ input: funds, staff, monitors
│     ├─ output: plans, inspections, filters installed
│     └─ outcome: lower comparable concentration/exposure/harm
│
├─ 2. POLLUTANT SCIENCE
│  ├─ primary: CO, SO₂, NH₃, Pb/metals, primary PM, VOCs, NO
│  ├─ secondary: O₃, sulfate, nitrate, ammonium, SOA, acids, PAN
│  ├─ both pathways: PM; NO₂ partly emitted + formed from NO
│  ├─ chemistry
│  │  ├─ SO₂ → sulfate/H₂SO₄
│  │  ├─ NOx → O₃ + nitrate/HNO₃
│  │  └─ NH₃ + acids → ammonium PM₂.₅
│  └─ PM size ≠ chemistry/source
│
├─ 3. SOURCES + EFFECTS
│  ├─ PM₂.₅/PM₁₀: dust, combustion, secondary aerosol
│  │  └─ lungs/heart; visibility, soiling, deposited toxics
│  ├─ SO₂: sulfur fuel/smelting → airway harm + acidification
│  ├─ NOx/NO₂: combustion → airway harm + O₃/nitrate/acid
│  ├─ O₃: NOx+VOCs+sun → asthma + crop/forest injury
│  ├─ CO: incomplete combustion → impaired oxygen delivery
│  ├─ NH₃: fertilizer/manure → PM₂.₅ + eutrophication
│  ├─ Pb: smelting/batteries/dust → neurotoxicity
│  ├─ benzene: fuel/smoke → marrow toxicity/leukaemia
│  └─ BaP/As/Ni: combustion/metallurgy → carcinogenic/toxic deposition
│
├─ 4. ATMOSPHERIC FATE
│  ├─ London smog: cool+humid; coal/SO₂/PM; reducing
│  ├─ photochemical: sunlight+NOx+VOCs → O₃/PAN; oxidising
│  ├─ inversion = warm cap → weak vertical mixing
│  ├─ transport = turbulence + advection + chemical ageing
│  └─ removal
│     ├─ dry deposition
│     └─ wet: rainout in-cloud; washout below-cloud
│
├─ 5. INDOOR EXPOSURE
│  ├─ solid fuel/kerosene, tobacco, cooking, incense
│  ├─ VOCs/materials, radon, damp/mould, outdoor infiltration
│  └─ control: substitute → capture → ventilate/filter → maintain
│
├─ 6. NAAQS 2009 — 18 NOVEMBER
│  ├─ SO₂: annual 50/20; 24h 80/80 µg/m³
│  ├─ NO₂: annual 40/30; 24h 80/80
│  ├─ PM₁₀: annual 60; 24h 100
│  ├─ PM₂.₅: annual 40; 24h 60
│  ├─ O₃: 8h 100; 1h 180
│  ├─ Pb: annual 0.5; 24h 1.0
│  ├─ CO: 8h 2; 1h 4 mg/m³
│  ├─ NH₃: annual 100; 24h 400 µg/m³
│  ├─ annual only: benzene 5 µg/m³
│  │               BaP 1, As 6, Ni 20 ng/m³
│  └─ compliance
│     ├─ annual: ≥104 samples; twice/week, 24h
│     └─ short-term: 98%; 2% exceedance, not consecutive days
│
├─ 7. AQI — COMMUNICATION, NOT STANDARD
│  ├─ pollutants: PM₁₀, PM₂.₅, NO₂, O₃, CO, SO₂, NH₃, Pb
│  ├─ excludes: benzene, BaP, As, Ni
│  ├─ AQI = maximum pollutant sub-index
│  ├─ overall AQI: ≥3 pollutants + one PM fraction
│  ├─ sub-index: ≥16 hours; CO/O₃ use 8h, others 24h
│  ├─ bands: 0–50 Good | 51–100 Satisfactory
│  │           101–200 Moderate | 201–300 Poor
│  │           301–400 Very Poor | 401–500 Severe
│  └─ caution: real-time raw data may not be statutory evidence
│
├─ 8. EVIDENCE TOOLS
│  ├─ NAMP/manual = periodic ambient trends/compliance
│  ├─ CAAQMS = continuous ambient/AQI
│  ├─ OCEMS/CEMS = source emission
│  ├─ inventory = mass emitted by source
│  └─ apportionment = contribution to measured concentration
│     └─ shares vary by pollutant/place/season/method
│
├─ 9. LAW + INSTITUTIONS
│  ├─ Air Act 1981; Article 253/Stockholm route
│  │  ├─ CPCB s16: national plan, coordination, air standards
│  │  ├─ SPCB s17: State plan, inspection, emission standards
│  │  ├─ s19 control area | s21 consent | s22 emission limit
│  │  └─ s31A closure/regulation/service directions
│  ├─ EPA 1986: ss3/5/6 + industry/general standards
│  ├─ PCC = delegated UT pollution-control functions
│  └─ CAQM Act 2021
│     ├─ NCR + defined adjoining areas in HR/PB/RJ/UP
│     ├─ airshed coordination + binding directions
│     └─ CAQM prevails in specified statutory conflicts
│
├─ 10. POLICY RESPONSE
│  ├─ NCAP = structural
│  │  ├─ launched Jan 2019; 130 cities
│  │  ├─ target: up to 40% PM₁₀ reduction OR NAAQS by 2025–26
│  │  └─ FY2025–26: 108 improved; 72 >20%; 26 >40%; 14 met NAAQS
│  ├─ GRAP = episodic, cumulative, forecast-led; revision 21 November 2025
│  │  ├─ I 201–300 | II 301–400
│  │  └─ III 401–450 | IV above 450
│  └─ source controls
│     ├─ vehicle: BS-VI (1-4-2020), PUC, transit/EV, vapour recovery
│     ├─ industry: consent, OCEMS, PM/SO₂/NOx controls, clean fuel
│     ├─ agriculture: in-situ + ex-situ + diversification + enforcement
│     ├─ dust/waste: covered handling, sweeping, C&D rules, no burning
│     └─ indoor: clean energy + source ventilation
│
├─ 11. EXAMINER TRAPS
│  ├─ NAAQS ≠ AQI ≠ source-emission standard
│  ├─ city AQI ≠ personal exposure
│  ├─ target announced ≠ target achieved
│  ├─ monitor installed ≠ valid/comparable data
│  ├─ GRAP ≠ NCAP
│  ├─ WHO AQG ≠ Indian legal limit
│  └─ cloud seeding = contingent washout, not source control
│
└─ 12. ANSWER SPINE
   source mix → atmospheric mechanism → standard/index/evidence
   → Air Act/EPA/CAQM roles → structural + emergency measures
   → emission/concentration/exposure outcomes → qualified verdict
```

**Qualified conclusion:** Clean-air governance succeeds only when source-specific emission control, representative monitoring and airshed coordination produce verified and equitable reductions in concentration, exposure and harm.
