# Environment and Ecology 07 — Biosphere Reserves and Ramsar Sites

## Quick-Glance Tree Chart

```text
BIOSPHERE RESERVES + RAMSAR SITES
│
├─ CENTRAL FIREWALL
│  ├─ designation ≠ domestic statutory protection
│  ├─ mapped boundary ≠ ecological recovery
│  └─ BR ≠ WNBR ≠ Ramsar ≠ PA ≠ World Heritage
│
├─ 1. BIOSPHERE RESERVE — UNESCO MAB MODEL
│  ├─ functions
│  │  ├─ conservation
│  │  ├─ sustainable development
│  │  └─ logistic support: research • monitoring • education
│  ├─ zones
│  │  ├─ CORE
│  │  │  ├─ long-term conservation
│  │  │  ├─ legally secure
│  │  │  └─ often overlaps NP/WLS/forest law
│  │  ├─ BUFFER
│  │  │  └─ compatible research, education, monitoring, managed use
│  │  └─ TRANSITION
│  │     └─ settlements + livelihoods + cooperative sustainable use
│  ├─ geometry trap
│  │  └─ may have multiple cores; not compulsory concentric rings
│  └─ rights rule
│     ├─ BR label does NOT extinguish rights
│     └─ underlying law/tenure + participation govern restrictions

├─ 2. NATIONAL BR versus UNESCO WNBR
│  ├─ India designates national BR
│  ├─ India may nominate it to UNESCO
│  ├─ UNESCO review → MAB-ICC decision
│  ├─ sovereignty remains with India
│  └─ WNBR review every 10 years
│
├─ DATED INDIA BR STATUS
│  ├─ PIB, 3 Nov 2025: 18 national BRs
│  ├─ 13 in WNBR after Cold Desert (2025)
│  ├─ Nilgiri: first national BR (1986), first Indian WNBR (2000)
│  ├─ Gulf of Mannar: first marine BR
│  ├─ national-only 5
│  │  └─ Manas • Dibru-Saikhowa • Dihang-Dibang
│  │     • Great Rann of Kutch • Seshachalam Hills
│  └─ PYQ: Agasthyamala
│     └─ Neyyar + Peppara + Shendurney + Kalakad Mundanthurai
│
├─ 3. RAMSAR CONVENTION
│  ├─ adopted 1971; India party 1 Feb 1982
│  ├─ World Wetlands Day: 2 February
│  ├─ wetland scope
│  │  ├─ natural/artificial • permanent/temporary
│  │  ├─ static/flowing • fresh/brackish/salt
│  │  └─ marine water ≤6 m deep at low tide
│  ├─ classification: 42 types
│  │  └─ 12 marine/coastal + 20 inland + 10 human-made
│  └─ three pillars
│     ├─ wise use of all wetlands
│     ├─ designate + effectively manage Ramsar Sites
│     └─ international cooperation
│
├─ 4. WISE USE + ECOLOGICAL CHARACTER
│  ├─ wise use = maintain ecological character
│  │  through ecosystem approaches within sustainable development
│  ├─ NOT universal no-use
│  ├─ NOT unrestricted traditional/commercial use
│  └─ character = components + processes + benefits/services
│
├─ 5. NINE RAMSAR CRITERIA — ANY ONE SUFFICES
│  ├─ 1 representative/rare/unique wetland type
│  ├─ 2 threatened species/community
│  ├─ 3 regional biodiversity
│  ├─ 4 critical life stage/refuge
│  ├─ 5 ≥20,000 waterbirds
│  ├─ 6 ≥1% waterbird population
│  ├─ 7 indigenous fish diversity/interactions
│  ├─ 8 fish food/spawning/nursery/migration
│  └─ 9 ≥1% wetland-dependent non-avian population
│
├─ 6. DESIGNATION + BOUNDARY
│  ├─ national authority → RIS + map → Ramsar List
│  ├─ boundary precisely described
│  ├─ may include riparian/coastal zones, islands, deeper water
│  ├─ Ramsar boundary ≠ PA boundary ≠ water spread
│  ├─ Article 3.2: report adverse ecological-character change
│  └─ restriction/deletion
│     ├─ exceptional “urgent national interests”
│     └─ compensate wetland-resource loss as far as possible
│
├─ 7. INDIAN DOMESTIC DELIVERY
│  ├─ Wetlands Rules 2017 under Environment (Protection) Act
│  ├─ National Wetlands Committee → Ramsar recommendations
│  ├─ State/UT Wetland Authority
│  │  └─ identify • recommend notification • review plans • monitor
│  ├─ zone of influence = catchment pressure area
│  ├─ prohibit: conversion/encroachment, industry, dumping,
│  │  untreated effluent, restricted permanent construction, poaching
│  ├─ regulated: compatible traditional use, fisheries, boating, desilting
│  ├─ record pre-existing rights/privileges
│  └─ overlap rule
│     └─ PA/forest/CRZ parcel keeps its law; Rules fill gaps
│
├─ 8. ACCOUNTABILITY
│  ├─ MONTREUX RECORD

│  ├─ India current: Keoladeo + Loktak

├─ 9. FOUR-INSTRUMENT COMPARISON
│  ├─ BR → zoned people–nature landscape
│  ├─ Ramsar → wetland importance + wise use

│  └─ World Heritage → Outstanding Universal Value
```
