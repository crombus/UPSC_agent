# Coastal and Marine Ecology, CRZ and Blue Economy — Quick-Glance Tree

> Content-word count excludes box-drawing glyphs.

```text
COAST = COUPLED LAND–SEA SYSTEM
│
├─ CONNECTIVITY
│  ├─ river → freshwater + nutrients + sediment
│  ├─ waves/tides/currents → transport + erosion/accretion
│  ├─ aquifer ↔ sea → freshwater-head balance
│  └─ habitats ↔ fisheries ↔ settlements ↔ ports
│
├─ ECOSYSTEMS + SERVICES
│  ├─ Mangrove
│  │  ├─ salt-tolerant woody intertidal system
│  │  ├─ roots → roughness + sediment trapping + nursery habitat
│  │  └─ bio-shield + blue carbon + livelihood base
│  ├─ Seagrass
│  │  └─ submerged flowering plant → sediment stability + nursery + carbon
│  ├─ Salt marsh
│  │  └─ vegetated intertidal wetland → accretion + flood storage + carbon
│  └─ Coral reef
│     ├─ warming → symbiont loss → bleaching
│     ├─ bleaching ≠ death; recovery possible
│     ├─ prolonged/repeated stress → mortality
│     └─ acidification ≠ bleaching
│        └─ lower carbonate availability → weaker calcification
│
├─ SEDIMENT BUDGET
│  ├─ inputs: rivers + cliff/onshore/biogenic supply
│  ├─ stores: beach + dune + delta + mudflat + marsh
│  ├─ outputs: longshore/offshore loss + mining/dredging
│  ├─ inputs < outputs → erosion
│  └─ response
│     ├─ avoid exposure/setback
│     ├─ protect sediment + habitats
│     ├─ dune/mangrove/marsh/reef restoration
│     ├─ nourishment/hybrid design
│     └─ hard defence only with scour/down-drift audit
│
├─ CRZ LEGAL SPINE
│  ├─ EPA 1986, s.3 + EP Rules, rule 5 → G.S.R. 37(E), 18 Jan 2019
│  ├─ supersedes CRZ 2011, subject to savings/transition
│  ├─ national amendments
│  │  ├─ S.O. 4886(E), 26 Nov 2021
│  │  ├─ S.O. 5495(E), 24 Nov 2022
│  │  └─ G.S.R. 832(E), 22 Sep 2026; Gazette 23 Sep
│  │     └─ Annexure-II (xxiii)–(xxvi): Bitumen + LAB +
│  │        N-Paraffin + CBFS; receipt/storage outside CRZ-IA
│  └─ state/district CZMP approval ≠ national amendment
│
├─ CRZ CATEGORY TREE
│  ├─ CRZ-I
│  │  ├─ CRZ-IA: mangrove, coral, dune, active mudflat, salt marsh,
│  │  │      seagrass, nesting/protected/heritage areas
│  │  └─ CRZ-IB: LTL ↔ HTL intertidal land
│  ├─ CRZ-II: substantially built-up urban/designated area
│  ├─ CRZ-III: rural/relatively undisturbed
│  │  ├─ CRZ-IIIA: ≥2161 persons/km²
│  │  │  └─ 50 m NDZ only after approved 2019 CZMP; otherwise 200 m
│  │  └─ CRZ-IIIB: <2161 persons/km² → 200 m NDZ
│  └─ CRZ-IV
│     ├─ CRZ-IVA: LTL → 12 nautical miles
│     └─ CRZ-IVB: tidal water/bed → 5 ppt in driest season
│
├─ LINES + SPECIAL RULES
│  ├─ HTL: highest spring-tide water line, NCSCM demarcation
│  ├─ hazard line: disaster-planning tool, not HTL substitute
│  ├─ tidal-body reach: 50 m/creek width after 2019 CZMP approval
│  │                    pending approval: 100 m/creek width
│  ├─ CRZ-III tidal NDZ: 50 m/creek width
│  ├─ notified port limits: III-NDZ exception ≠ no CRZ control
│  ├─ 20 m island rule: backwater/mainland islands only;
│  │                    never generalise to A&N/Lakshadweep
│  └─ S.O. 1242(E), 8 Mar 2019 = ICRZ Notification
│     ├─ specified larger A&N islands → ICRZ Plans
│     └─ covered smaller A&N/Lakshadweep islands → IIMPs
│        (UT preparation, Annexure-IV, MoEFCC approval)
│
├─ CZMP ≠ PROJECT CLEARANCE
│  ├─ map: HTL/LTL + categories + ESA + hazard/community features
│  ├─ process: draft → hearing → CZMA → MoEFCC approval
│  └─ clearance
│     ├─ pure II/III → CZMA
│     ├─ I/IV or II/III traversing I/IV → MoEFCC on CZMA advice
│     ├─ EIA Category A/B → MoEFCC/SEIAA composite route
│     └─ separate forest/wildlife/pollution/local approvals may remain
│
├─ SEAWATER INTRUSION
│  ├─ pumping/reduced recharge → freshwater head falls
│  ├─ saline interface → landward/upward movement
│  ├─ aggravators: sea-level rise + canals + aquaculture + subsidence
│  └─ hierarchy
│     ├─ cap demand + relocate wells
│     ├─ protect/restore clean recharge
│     ├─ salinity/water-level monitoring
│     └─ injection/subsurface barriers if site-suitable
│        TRAP: desalination supplies water; it does not repair aquifer
│
├─ BLUE ECONOMY
│  ├─ sustainable ocean use
│  ├─ economic value + jobs
│  ├─ livelihoods + equity
│  └─ ecosystem health + intergenerational ceiling
│     ├─ fisheries/aquaculture
│     ├─ ports/shipping/tourism
│     ├─ offshore energy/biotechnology
│     └─ deep ocean → science opportunity + precaution
│
├─ UNCLOS + BBNJ
│  ├─ territorial sea 12 nm
│  ├─ contiguous zone 24 nm
│  ├─ EEZ 200 nm: resource rights, not full sovereignty
│  ├─ CRZ ≠ EEZ
│  └─ BBNJ = areas beyond national jurisdiction
│     ├─ genetic resources + benefit-sharing
│     ├─ area-based tools/MPAs
│     ├─ EIA
│     ├─ capacity + technology transfer
│     └─ status 30 Sep 2026
│        ├─ in force: 17 January 2026
│        └─ India signed 25 September 2024; no ratification/accession recorded
│
├─ INDIA CURRENT ANCHORS
│  ├─ coastline: 11,098.81 km; circular 29 Apr 2025
│  │  └─ measurement revision, NOT physical expansion
│  ├─ Deep Ocean Mission: MoES
│  │  └─ Samudrayaan + three-person Matsya-6000
│  ├─ National Coastal Mission + MISHTI + NPCA
│  │  └─ programme target/approval ≠ ecological outcome
│  └─ 2026 routes
│     ├─ direct: Q23 mangrove; Q50 Deep Ocean Mission
│     ├─ shared: FAO Blue Transformation
│     └─ not owned: Vizhinjam/Sagarmala (Economy);
│                   Andaman climate (Geography)
│
├─ 2025 PRELIMS OWNERSHIP NOTE
│  └─ GS-I Set A Q40 oxygen/phytoplankton
│     → Environment 01; official key B
│
└─ FINAL SPINE
   define → draw mechanism/map → name law/example → ecology + livelihood
   → authority/implementation → limitation → avoid-regulate-restore-monitor

TRAPS
• bleaching ≠ mortality • acidification ≠ thermal bleaching
• CZMP ≠ clearance • CRZ ≠ protected area ≠ EEZ
• NDZ ≠ zero permissible activity • one setback ≠ national rule
• blue economy ≠ maritime GDP • signature ≠ ratification
• revised coastline ≠ physical coastal growth
```
