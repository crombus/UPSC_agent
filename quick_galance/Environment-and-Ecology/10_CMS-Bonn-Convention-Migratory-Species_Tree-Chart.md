# Topic 10 — CMS / Bonn Convention and Migratory Species: Quick-Glance Tree

```text
CMS / BONN CONVENTION
├─ IDENTITY
│  ├─ concluded: Bonn, 23 Jun 1979
│  ├─ in force: 1 Nov 1983
│  ├─ binding treaty; UNEP aegis
│  ├─ Secretariat: Bonn
│  └─ purpose: migratory wild animals + habitats across complete range
│
├─ EXACT SCOPE
│  ├─ migratory species
│  │  └─ significant proportion cyclically + predictably crosses jurisdictions
│  ├─ range
│  │  └─ inhabited + temporary-stay + crossed + overflown route areas
│  ├─ Range State
│  │  ├─ jurisdiction over any range segment
│  │  └─ flag-vessel taking beyond national jurisdiction
│  └─ taking
│     └─ hunting/fishing/capture/harassment/deliberate killing/attempt
│
├─ APPENDIX I — ENDANGERED
│  ├─ conserve/restore important habitat
│  ├─ address migration obstacles
│  ├─ control endangering factors
│  └─ prohibit taking
│     └─ narrow grounds + precise + space/time limited + no disadvantage
│
├─ APPENDIX II — COOPERATION
│  ├─ unfavourable status requiring agreements
│  ├─ OR significant benefit from international cooperation
│  └─ Range States shall endeavour to conclude beneficial AGREEMENTS
│
├─ APPENDIX FIREWALL
│  ├─ I ≠ II obligation
│  ├─ dual listing allowed
│  ├─ COP amends on scientific advice
│  └─ normally effective after 90 days unless reservation
│
├─ INSTRUMENT LADDER
│  ├─ parent CMS: binding on Parties
│  ├─ Agreement: separate binding treaty
│  │  └─ whole range; all Range States; authority + monitoring + plans
│  ├─ MOU: non-legally binding cooperation
│  ├─ plan/initiative/resolution
│  │  └─ inspect constitutive text; title does not determine force
│  └─ listing/signature ≠ implementation/recovery
│
├─ BODIES
│  ├─ COP: decides, reviews, budgets, amends Appendices
│  ├─ Scientific Council: science/research/listing advice
│  ├─ Secretariat: UNEP coordination; meetings/instruments/information
│  └─ Standing Committee: intersessional policy/administration
│
├─ ACTION MECHANISM
│  ├─ current: Concerted Action
│  │  └─ priority + time-bound + multiple Range States + Appendix taxa
│  ├─ may bridge to / substitute for Article IV instrument
│  └─ Cooperative Action = historical separate track; consolidated at COP12
│
├─ FULL ANNUAL CYCLE
│  ├─ breeding
│  ├─ staging/fuelling
│  ├─ passage corridor/bottleneck
│  ├─ stopover/roost
│  ├─ wintering/non-breeding/feeding
│  └─ return
│     └─ flyway = route-and-site network; connectivity = seasonal linkage
│
├─ THREAT → RESPONSE
│  ├─ habitat loss → protect/restore connected site network
│  ├─ dams/weirs → fish passage/barrier removal
│  ├─ lines/turbines/buildings → siting + collision mitigation
│  ├─ artificial light → shielding/spectral control/dark periods
│  ├─ underwater noise → quieting + time/area controls
│  ├─ bycatch → gear + spatial/seasonal measures + monitoring
│  ├─ taking → enforcement + communities + demand reduction
│  └─ climate mismatch → refugia + flexible networks + adaptive monitoring
│
```
