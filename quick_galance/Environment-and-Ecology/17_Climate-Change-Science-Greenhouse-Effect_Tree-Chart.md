# Environment and Ecology 17 — Climate Change Science and Greenhouse Effect

## Quick-Glance Tree Chart

```text
CLIMATE CHANGE SCIENCE
│
├─ 1. LANGUAGE FIREWALL
│  ├─ Weather = short-term atmospheric state
│  ├─ Climate = long-period distribution: mean + variability + extremes
│  ├─ Variability = fluctuation around distribution
│  ├─ Climate change = persistent shift in distribution
│  └─ Global warming ⊂ climate change
│     TRAP: one event/year neither proves nor disproves a trend
│
├─ 2. EARTH ENERGY BALANCE
│  ├─ Incoming solar ≈ shortwave; global mean ≈ 340 W/m²
│  ├─ ≈29% reflected → albedo; remainder absorbed
│  ├─ Warm surface emits longwave infrared
│  ├─ GHGs absorb + re-emit selected longwave wavelengths
│  └─ Natural greenhouse effect ≈ +33°C → habitable
│     PROBLEM = anthropogenic enhancement, not greenhouse effect itself
│
├─ 3. CAUSAL RAIL
│  └─ emissions → concentration/stock → radiative forcing
│      → energy imbalance → warming → wider climate response
│      Emission = flow | concentration = abundance | stock = burden
│
├─ 4. FORCING AGENTS
│  ├─ CO2: fossil fuel + cement + land use
│  │  └─ cumulative; no single lifetime; net-zero CO2 stabilises CO2 warming
│  ├─ CH4: energy + livestock + rice + waste
│  │  └─ lifetime 11.8±1.8 y; strong near-term effect
│  ├─ N2O: soils/fertiliser + industry
│  │  └─ lifetime 109±10 y; warming + stratospheric ozone effect
│  ├─ F-gases: compound-specific high GWP/lifetimes
│  ├─ Water vapour: rapid positive feedback, not primary long-lived forcing
│  ├─ Ozone: tropospheric warming pollutant ≠ stratospheric UV shield
│  └─ Aerosols: many cool; black carbon warms + darkens snow
│
├─ 5. METRICS
│  ├─ RF/ERF = energy-balance perturbation, W/m²
│  ├─ GWP = integrated forcing over stated horizon
│  ├─ GTP = temperature at stated future time
│  └─ TRAP: never quote methane GWP without report + horizon
│
├─ 6. CARBON CYCLE
│  ├─ IPCC 2010-19 partition:
│  │  ├─ atmosphere 46%
│  │  ├─ ocean 23%
│  │  └─ land 31%
│  ├─ six-decade mean airborne fraction ≈44%
│  ├─ sinks slow accumulation; do not cancel emissions
│  ├─ ocean CO2 uptake → acidification
│  └─ warming/fire/stratification/permafrost can weaken sinks
│     TRAP: gross uptake ≠ permanent net storage
│
├─ 7. FORCING ≠ FEEDBACK ≠ RESPONSE
│  ├─ Forcing: fossil CO2, CH4, aerosol, solar/volcanic change
│  ├─ Feedbacks
│  │  ├─ Planck response −
│  │  ├─ water vapour +
│  │  ├─ ice-albedo +
│  │  ├─ lapse rate generally − globally
│  │  ├─ cloud net +; largest feedback uncertainty
│  │  ├─ carbon cycle +
│  │  └─ permafrost carbon +
│  └─ Responses: temperature/rainfall/ocean/ice/sea level/ecosystems
│
├─ 8. CLIMATE SENSITIVITY
│  ├─ ECS: equilibrium after CO2 doubling
│  │  └─ best 3°C; likely 2.5-4.0°C
│  ├─ TCR: near doubling during gradual increase
│  │  └─ best 1.8°C; likely 1.4-2.2°C
│  └─ TCRE: best 0.45°C per 1000 GtCO2
│     WHY TCR < ECS: deep-ocean heat uptake delays surface warming
│
├─ 9. EVIDENCE LOGIC
│  ├─ Detection: signal beyond expected variability?
│  ├─ Attribution: relative human/natural causes?
│  ├─ Event attribution: changed probability/intensity?
│  ├─ Observation: measured past/present
│  └─ Projection: conditional future under assumptions
│     TRAP: “increased likelihood” ≠ “sole cause”
│
├─ 10. MODELS + SCENARIOS
│  ├─ RCP = concentration/forcing pathway; suffix ≈ 2100 W/m²
│  ├─ SSP = socioeconomic pathway
│  ├─ SSPx-y = socioeconomic pathway + forcing level
│  ├─ scenario ≠ forecast/probability
│  └─ uncertainty branches:
│     ├─ internal variability
│     ├─ model response
│     ├─ future scenario
│     └─ observations/structure
│
├─ 11. INDICATORS
│  ├─ WMO 2025: 1.43±0.13°C above 1850-1900
│  ├─ record ocean heat; ocean stores most excess heat
│  ├─ sea level: expansion + land-ice melt
│  │  └─ 2012-25 rate 4.75 mm/y; local relative level varies
│  ├─ glacier/snow/sea-ice decline; permafrost thaw
│  ├─ ocean acidification = CO2 chemistry, not warming alone
│  └─ extremes: strongest general attribution for heat;
│     confidence varies by event type/region
│
├─ 12. INDIA QUALIFICATION
│  ├─ IMD 2025: +0.28°C vs 1991-2020; 8th warmest since 1901
│  ├─ Monsoon = moisture thermodynamics
│  │  + aerosols + Indian Ocean + ENSO + circulation + variability
│  ├─ seasonal total ≠ short-duration extreme
│  ├─ Heat risk = climate hazard + humidity + urban form + exposure
│  ├─ Coast = mean rise + surge/waves/erosion/subsidence
│  └─ Himalaya = glacier/basin-specific; avoid uniform claims
│
├─ 13. RESPONSE FIREWALL
│  ├─ Mitigation: reduce sources/enhance sinks
│  ├─ Adaptation: adjust to actual/expected effects
│  ├─ Loss and damage: residual adverse impacts
│  ├─ CDR: remove CO2 + durable storage → mitigation
│  └─ SRM: alter radiative budget; neither mitigation nor adaptation
│     SRM does not stop CO2 accumulation/acidification;
│     abrupt termination can cause rapid warming
│
├─ 14. PYQ ANCHORS
│  ├─ 2018: carbon fertilisation → constrained plant response
│  ├─ 2019: SRM methods; methane hydrate feedback
│  ├─ 2022: rice CH4/N2O; SRI; warming + Kyoto (Topic 19 split)
│  ├─ 2023: tropical food security → four pillars
│  └─ 2025: cement calcination; India emissions; island sea-level risk
│
└─ 15. ANSWER SPINE
   define scale/period
   → energy mechanism
   → forcing agent
   → feedbacks/responses
   → observation/attribution/projection label
   → global evidence + India-specific evidence
   → mitigation/adaptation/loss-damage route
   → qualify baseline, confidence, variability and residual risk
```

**Qualified conclusion:** Anthropogenic GHG forcing has created a measured energy imbalance; feedbacks determine its magnitude, internal variability shapes short-period expression, and scenario-dependent emissions determine future risk. Every answer must retain scale, baseline, horizon and confidence.
