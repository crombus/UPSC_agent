# Topic 09 — CITES and Wildlife Trade: Quick-Glance Tree

```text
CITES
├─ PURPOSE + LEGAL CHARACTER
│  ├─ signed: 3 Mar 1973, Washington, D.C.
│  ├─ in force: 1 Jul 1975
│  ├─ binding treaty; national implementation
│  └─ aim: international trade must not threaten survival
│
├─ JURISDICTION FIREWALL
│  ├─ “trade” = export + import + re-export + introduction from the sea
│  ├─ specimen = live/dead animal/plant + covered part/derivative
│  └─ not direct habitat, domestic hunting or internal-sale law
│
├─ TRADE-NOT-BAN LADDER
│  ├─ APPENDIX I
│  │  ├─ threatened with extinction; strict, exceptional trade
│  │  ├─ export: NDF + legal acquisition + welfare + import permit
│  │  └─ import: permit + not primarily commercial
│  ├─ APPENDIX II
│  │  ├─ may become threatened unless regulated
│  │  ├─ includes look-alikes needed for effective control
│  │  ├─ export: permit + NDF + legality + welfare
│  │  └─ import: export permit / re-export certificate
│  └─ APPENDIX III
│     ├─ one Party protects + requests cooperation
│     ├─ unilateral; no CoP vote
│     └─ listing-State permit / other-origin certificate
│
├─ LISTING + RESERVATION
│  ├─ Appendix I/II CoP amendment
│  │  ├─ 2/3 of Parties present and voting
│  │  └─ normally effective after 90 days
│  ├─ Appendix III: effective after 90 days; withdrawal after 30
│  └─ specific reservation
│     └─ Party treated as non-Party only for reserved trade
│
├─ TRANSACTION PAPERS
│  ├─ export permit
│  ├─ import permit: ordinary Appendix I route
│  ├─ re-export certificate: specimen previously imported
│  ├─ certificate of origin: Appendix III, non-listing State
│  ├─ introduction-from-sea certificate
│  └─ one document/consignment; export permit usable 6 months
│
├─ TWO-KEY GATE
│  ├─ SCIENTIFIC AUTHORITY
│  │  ├─ NDF: export non-detrimental?
│  │  └─ monitors Appendix II permits + actual exports
│  └─ MANAGEMENT AUTHORITY
│     ├─ legal acquisition, purpose, welfare, documents
│     └─ issues permit/certificate + reports
│
├─ CAPTIVE / SPECIAL ROUTES
│  ├─ Appendix I animal bred in captivity for commercial purposes
│  │  └─ deemed Appendix II for CITES trade
│  ├─ same logic: commercially artificially propagated plant
│  ├─ qualifying certificate may replace ordinary document
│  └─ trap: captive claim ≠ free trade; laundering risk remains
│
├─ CITES BODIES
│  ├─ CoP: implementation + Appendix I/II amendments
│  ├─ latest completed: CoP20, Samarkand, 24 Nov–5 Dec 2025
│  ├─ Standing Committee: intersessional policy/compliance
│  ├─ Animals Committee: animal scientific-technical advice
│  ├─ Plants Committee: plant scientific-technical advice
│  └─ UNEP Secretariat, Geneva: service/studies/reports; no police
│
├─ COMPLIANCE ≠ DOMESTIC ENFORCEMENT / PROSECUTION
│  ├─ reports/data → concern → Secretariat communication
│  ├─ facts/remedial plan → committee/CoP review
│  ├─ warning/assistance/recommendation to suspend trade
│  └─ domestic plane: search, seizure, arrest, trial, penalty
│
├─ INDIA: WPA 1972 AFTER 2022 AMENDMENT
│  ├─ Chapter VB operative: 1 Apr 2023
│  ├─ schedules: I animals | II animals | III plants | Schedule IV CITES
│  ├─ 49D definitions
│  ├─ 49E Management Authority
│  ├─ 49F Scientific Authorities
│  ├─ 49H trade/ports/reporting
│  ├─ 49-I/J/K/L export/import/re-export/sea
│  ├─ 49M living Schedule-IV animal registration
│  └─ 49N Appendix-I breeder licence
│
├─ CURRENT INDIA AUTHORITIES
│  ├─ MA: Shri Gobind Sagar Bhardwaj, ADGF
│  │  └─ S.O.1328(E), 13 Mar 2024; to 15 Aug 2027/further orders
│  ├─ 23 Scientific Authorities: S.O.3548(E), 8 Aug 2023
│  ├─ 12 designated ports: S.O.3547(E), 8 Aug 2023
│  ├─ Customs: border clearance + document/specimen check
│  └─ WCCB: intelligence, data, coordination, capacity,
│     prosecution support, foreign links + Customs assistance
│
├─ DO-NOT-CONFLATE MATRIX
│  ├─ IUCN = extinction-risk science
│  ├─ CMS = migratory range-state cooperation
│  ├─ CITES = international trade control
│  ├─ WPA = Indian domestic protection/enforcement
│  └─ UNTOC = qualifying transnational organized-crime cooperation
│
├─ ILLEGAL-TRADE CHAIN
│  ├─ demand → source/poaching → brokers → movement → market
│  ├─ laundering: false source/species/quantity/purpose
│  ├─ online ads + parcel routes + finance/corruption
│  └─ response
│     ├─ community incentives + targeted demand reduction
│     ├─ NDF/LAF + traceability + secure permits
│     ├─ Customs/WCCB intelligence + cyber/financial inquiry
│     └─ forensics + chain of custody + prosecution + cooperation
│
├─ PYQ ROUTE (2018–2026 LEDGERS)
│  ├─ direct/shared Topic-09 route: none
│  └─ applications: 2020 Q81; 2022 Q89; 2024 Q20 dropped;
│     2026 Q27 provisional
│
├─ EXAMINER TRAPS
│  ├─ Appendix I ≠ exception-free ban
│  ├─ Appendix II ≠ unregulated trade
│  ├─ Appendix III ≠ third extinction-risk rank
│  ├─ NDF ≠ legal acquisition
│  ├─ trade suspension ≠ criminal conviction
│  └─ proposal ≠ adopted/current listing
│
└─ QUALIFIED VERDICT
   └─ CITES succeeds only when science + lawful source +
      traceability + border verification + enforcement +
      demand/community action form one continuous chain.
```
