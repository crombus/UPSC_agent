# Environment and Ecology 23 — Desertification, UNCCD and Land Degradation

## Quick-Glance Tree Chart

```text
LAND HEALTH
├─ 1. DEFINITIONS / SCOPE
│  ├─ Land degradation
│  │  ├─ broad usage: decline of productivity/ecological condition
│  │  └─ UNCCD Art. 1(f): legal formulation within drylands
│  ├─ Desertification
│  │  └─ degradation in arid + semi-arid + dry sub-humid areas
│  │     caused by climatic variations + human activities
│  ├─ Drought
│  │  └─ temporary below-normal precipitation
│  │     → serious hydrological imbalance
│  ├─ Aridity = long-term climate; drought = event
│  └─ Dryland ratio P/PET = 0.05–0.65
│     └─ polar/sub-polar regions excluded
│
├─ 2. CAUSAL CHAIN
│  ├─ rainfall variability / warming
│  ├─ vegetation loss / overgrazing / poor cultivation
│  ├─ irrigation without drainage → salinisation
│  ├─ groundwater stress / mining / roads / urban sealing
│  └─ feedback:
│     cover loss → erosion/runoff → low infiltration/SOM
│     → low productivity → livelihood pressure → more extraction
│
├─ 3. AEOLIAN ROUTE
│  ├─ deflation = removal
│  ├─ abrasion = wearing
│  ├─ saltation = bouncing grains
│  └─ dust/sand export → nutrient loss + burial + off-site impact
│
├─ 4. DROUGHT RISK
│  ├─ hazard × exposure × vulnerability ÷ capacity
│  ├─ early warning → trigger → preparedness action
│  └─ resilience: soil moisture + water budget + diversification
│
├─ 5. UNCCD ARCHITECTURE
│  ├─ adopted 1994 | 197 Parties
│  ├─ legally binding Convention
│  ├─ COP = supreme decision body
│  ├─ CST = science | CRIC = implementation review
│  ├─ Global Mechanism, Art. 21 = resource mobilisation
│  ├─ Annexes
│  │  ├─ I Africa (Art. 7 priority)
│  │  ├─ II Asia
│  │  ├─ III Latin America/Caribbean
│  │  ├─ IV Northern Mediterranean
│  │  └─ V Central/Eastern Europe
│  └─ NAPs, Arts. 9–10
│     └─ diagnose drivers → roles/resources → measures → review
│
├─ 6. LDN + SDG 15.3
│  ├─ goal: land amount + quality stable/increasing
│  ├─ baseline: 2015 from 2000–2015 trends
│  ├─ indicators
│  │  ├─ land cover
│  │  ├─ land productivity
│  │  └─ carbon stocks / soil organic carbon
│  ├─ One Out, All Out + national validation
│  └─ hierarchy: AVOID > REDUCE > REVERSE
│
├─ 7. COUNTERBALANCING TEST
│  ├─ not a permissive offset licence
│  ├─ residual loss only after avoid/reduce
│  ├─ same land type + appropriate spatial domain
│  ├─ like-for-like; equal/greater natural-capital value
│  └─ trap: equal hectares ≠ equivalent functions/rights
│
├─ 8. EVIDENCE + QUALITY
│  ├─ satellite: cover/productivity trend
│  ├─ ground truth: SOC/salinity/infiltration/species/water
│  ├─ local evidence: tenure/use/livelihood history
│  └─ quality test
│     ├─ soil + water + biodiversity
│     ├─ productivity + permanence
│     └─ tenure + benefit distribution
│
├─ 9. RESPONSE BRANCHES
│  ├─ watershed: ridge → runoff control → infiltration
│  ├─ cropland: cover/rotation/drainage/balanced nutrients
│  ├─ rangeland: mobility/commons/seasonal grazing/tenure
│  └─ open-ecosystem trap: grassland ≠ failed forest
│
├─ 10. INDIA
│  ├─ MoEFCC/NAP 2023 | ISRO–SAC atlas | DoLR/WDC–PMKSY
│  ├─ 9 Sep 2019: target 26 million ha by 2030
│  ├─ Atlas 2021, reference 2018–19
│  │  └─ 97.85 million ha = 29.77% geographical area
│  └─ PIB 17 Jun 2026
│     └─ 21.76 million ha “under restoration efforts”
│        against Bonn Challenge target
│        ≠ independently verified ecological recovery
│
├─ 11. CURRENT ANCHORS
│  ├─ COP16 Decision 24
│  │  └─ continued drought talks; annex lacked consensus
│  │     → no binding drought protocol
│  ├─ COP17 concluded 28 Aug 2026
│  │  ├─ decisions in advance copy, 7 Sep 2026
│  │  ├─ Dec. 16: talks continue to COP18;
│  │  │  drought remains stand-alone COP item
│  │  ├─ Dec. 20: rangelands/pastoral mobility/tenure
│  │  └─ Dec. 22: welcomed Ulaanbaatar Declaration
│  │     └─ declaration ≠ treaty amendment
│  └─ IYRP 2026
│     └─ UNGA A/RES/76/253, adopted 15 Mar 2022
│
├─ 12. PYQ ROUTES
│  ├─ 2018 Prelims Q82: SOM + sulphur cycle + salinisation
│  ├─ 2020 GS-I Q5: process vs climatic stereotype
│  │  └─ retain strict dryland definition
│  ├─ 2024 Essay: ecological overshoot + natural-desert caveat
│  └─ 2026 GS-I Q6: aeolian process → productivity loss
│
└─ ANSWER SPINE
   define precisely
   → trace soil–water–vegetation–livelihood feedback
   → UNCCD/NAP/LDN
   → dated India evidence
   → restoration quality + tenure
   → prevention-first, field-validated conclusion
```

**Final verdict:** Healthy-land governance succeeds when it prevents avoidable loss, restores the right ecosystem, protects users' rights and proves durable function—not merely treated area.
