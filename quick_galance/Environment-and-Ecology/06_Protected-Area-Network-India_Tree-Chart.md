# Environment and Ecology 06 — Protected Area Network in India

## Quick-Glance Tree Chart

```text
PROTECTED AREA NETWORK IN INDIA
│
├─ CENTRAL RULE
│  ├─ identify parent law + notifying authority + land tenure
│  ├─ settle rights → assign management → regulate activity
│  └─ notification ≠ management effectiveness
│
├─ 1. FOUR WPA CHAPTER IV CATEGORIES
│  ├─ WILDLIFE SANCTUARY — ss.18–26A
│  │  ├─ intention: ss.27–33A apply; Collector within 30 days
│  │  ├─ admitted right: exclude land / acquire-surrender / continue
│  │  ├─ final notification: s.26A
│  │  ├─ CWLW manages via approved plan
│  │  ├─ Scheduled/FRA area → due Gram Sabha consultation
│  │  └─ grazing may be regulated / controlled / prohibited
│  ├─ NATIONAL PARK — s.35
│  │  ├─ rights inquiry applies
│  │  ├─ intention notice → ss.27–33A apply immediately
│  │  ├─ pending settlement → State arranges recorded-rights needs
│  │  ├─ NO s.24(2)(c) continuation route
│  │  ├─ all included-land rights vest in State before final notice
│  │  └─ grazing prohibited; extraction/diversion tightly permitted
│  ├─ CONSERVATION RESERVE — s.36A
│  │  ├─ Government land + local-community consultation
│  │  ├─ especially adjacent/linking PAs; landscape/seascape
│  │  └─ committee advises CWLW
│  └─ COMMUNITY RESERVE — ss.36C–36D
│     ├─ volunteered private/community land
│     ├─ outside NP/WLS/Conservation Reserve
│     ├─ committee = management authority + plan maker
│     ├─ community land: ≥5 local nominees + State representative
│     ├─ private land: owner + State + local/tribal representative
│     └─ land-use change: committee resolution + State approval
│
├─ SPECIAL CENTRAL ROUTE — s.38
│  ├─ transferred State land: Centre may declare NP/WLS
│  ├─ 2022 amendment adds Conservation Reserve
│  └─ NOT Community Reserve
│
├─ BOUNDARY SAFEGUARD
│  ├─ WLS alteration → NBWL recommendation [s.26A(3)]
│  └─ NP alteration → State-Legislature resolution [s.35(5)]
│
├─ 2. MARINE APPLICATION
│  ├─ Marine Protected Area (MPA) = setting, NOT fifth WPA category
│  ├─ territorial-water Sanctuary
│  │  ├─ prior Central concurrence
│  │  ├─ Chief Naval Hydrographer consultation
│  │  ├─ protect fishermen’s occupational interests
│  │  └─ innocent passage preserved
│  ├─ effective governance = WPA + CRZ/EPA + fisheries law
│  └─ PIB 18 Dec 2023
│     ├─ 130 notified MPAs
│     └─ 106 ICMBAs identified/prioritised ≠ notified PAs
│
├─ 3. TIGER RESERVE — WPA section 38V
│  ├─ NTCA recommendation → State notification
│  ├─ s.38XA: additive to, not replacement of, NP/WLS law
│  ├─ Tiger Conservation Plan
│  │  ├─ viable tiger/prey/co-predator habitat
│  │  ├─ compatible land use + livelihoods
│  │  └─ linking areas as dispersal corridors
│  ├─ CORE / CRITICAL TIGER HABITAT
│  │  ├─ NP/WLS area; scientific/objective criteria
│  │  └─ inviolate purpose, but rights safeguards remain
│  ├─ BUFFER
│  │  ├─ integrity + dispersal + coexistence
│  │  └─ Gram Sabha + expert consultation
│  ├─ RELOCATION: cumulative conditions
│  │  ├─ rights complete
│  │  ├─ irreversible damage proved
│  │  ├─ no reasonable coexistence option
│  │  ├─ livelihood package
│  │  ├─ informed Gram Sabha + affected-person consent
│  │  └─ land/facilities delivered first
│  ├─ boundary change → NTCA recommendation + NBWL approval
│  └─ de-notification → public interest + both approvals
│
├─ 4. ELEPHANT RESERVE / CORRIDOR
│  ├─ Project Elephant designation; NOT Chapter IV category
│  ├─ legal force comes from overlapping WPA/forest/land law
│  ├─ 33 reserves; 80,777 km² — official 2023 Atlas
│  └─ 150 corridors — official 2023 report
│     ├─ minimum/revisable count
│     ├─ direction indicative; exact boundary undemarcated
│     └─ identification ≠ secured legal corridor
│
├─ 5. ECO-SENSITIVE ZONE
│  ├─ EPA 1986 + Rules; NOT WPA PA
│  ├─ site notification: prohibited / regulated / permissible
│  ├─ no universal 10-km rule
│  └─ Supreme Court, 26 Apr 2023
│     ├─ blanket 1-km rule modified for notified/proposed
│     │  and inter-State/shared-boundary cases
│     └─ mining barred inside NP/WLS and within 1 km
│
├─ 6. CONNECTIVITY
│  ├─ function: dispersal + gene flow + recolonisation + climate shift
│  ├─ corridor is NOT automatically a legal category
│  ├─ legal routes: Conservation/Community Reserve, plan, agreement
│  └─ test permeability: roads, rail, power lines, fencing, land use
│
├─ 7. IUCN MANAGEMENT CATEGORIES ≠ INDIAN LAW
│  ├─ Ia strict reserve | Ib wilderness | II ecological processes
│  ├─ III natural monument | IV habitat/species management
│  ├─ V landscape/seascape | VI sustainable resource use
│  ├─ management objectives; NOT a hierarchy
│  └─ Indian “National Park” ≠ automatic IUCN II
│
├─ 8. RECOGNITION FIREWALL
│  ├─ Biosphere Reserve → core/buffer/transition programme
│  ├─ Ramsar → wetland international importance + wise use
│  ├─ World Heritage → Outstanding Universal Value
│  └─ all may overlap a WPA PA; none replaces domestic law
│
├─ 9. GOVERNANCE + EFFECTIVENESS
│  ├─ participation ladder: inform → consult → represent → consent → manage
│  ├─ reconcile WPA habitat protection with recognised forest rights
│  ├─ Management Effectiveness Evaluation (MEE): plan → output → outcome
│  └─ outcome test: habitat + viable population + connectivity + justice
│
├─ DATED COUNT CONTROL
│  ├─ NR-7: 1,134 PAs (2025); 309 Community Reserves
│  ├─ PIB 16 Mar 2026: 106 NPs; 574 Wildlife Sanctuaries; 58 Tiger Reserves; 33 Elephant Reserves
│  ├─ 145 Conservation Reserves by shown reconciliation
│  └─ never reuse WII’s 27 Nov 2023 total (1,014) as a 2026 total
│
├─ PYQ ROUTE
│  ├─ Direct Prelims: 2018 Q94; 2019 Q18;
│  │  2020 Q73/Q75/Q95/Q100; 2023 Q38; 2026 Q32
│  ├─ Direct Mains: 2023 GS-I Q15
│  └─ keys: 2018–23 unavailable locally; 2026 provisional
│
└─ 20-SECOND ANSWER SPINE
   ├─ DEFINE label + parent law
   ├─ DISTINGUISH land / rights / authority / activity
   ├─ EXPLAIN core–buffer / edge / corridor / seascape mechanism
   ├─ ADD one dated official example
   ├─ TEST participation + capacity + ecological outcome
   └─ CONCLUDE: lawful + connected + participatory + measurable
```

**Final recall:** Legal status starts conservation; rights, connectivity and outcomes complete it.
