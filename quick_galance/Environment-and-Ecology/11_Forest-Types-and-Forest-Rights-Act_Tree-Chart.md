# Topic 11 — Forest Types and Forest Rights Act: Quick-Glance Tree

```text
FOREST TYPES + FOREST RIGHTS ACT
├─ FIRST FIREWALL: FOUR DIFFERENT QUESTIONS
│  ├─ forest type → ecological formation
│  ├─ forest cover → canopy measurement
│  ├─ recorded/legal forest → government record/notification
│  └─ FRA right → recognised tenure, use or management
│     └─ never substitute one ledger for another
│
├─ ECOLOGICAL CONTROLS
│  ├─ climate → rainfall + seasonality + temperature + evapotranspiration
│  ├─ relief → altitude + aspect + exposure + rain shadow
│  ├─ soil/water → depth + drainage + waterlogging + salinity
│  └─ disturbance → fire + grazing + lopping + invasives + land-use history
│
├─ CHAMPION–SETH: 16 MAJOR GROUPS
│  ├─ tropical
│  │  ├─ 1 Tropical Wet Evergreen
│  │  ├─ 2 semi-evergreen
│  │  ├─ 3 moist deciduous
│  │  ├─ 4 littoral and swamp
│  │  ├─ 5 dry deciduous
│  │  ├─ 6 thorn
│  │  └─ 7 Tropical Dry Evergreen
│  ├─ subtropical
│  │  ├─ 8 broadleaved hill
│  │  ├─ 9 pine
│  │  └─ 10 dry evergreen
│  ├─ temperate
│  │  ├─ 11 montane wet temperate
│  │  ├─ 12 Himalayan moist temperate
│  │  └─ 13 Himalayan dry temperate
│  └─ high altitude
│     ├─ 14 subalpine
│     ├─ 15 moist alpine scrub
│     └─ 16 dry alpine scrub
│
├─ CLOSE OPTIONS
│  ├─ evergreen ≠ very dense forest
│  ├─ dry evergreen ≠ thorn
│  ├─ littoral/swamp > mangrove
│  ├─ subalpine = near tree line; alpine scrub = above it
│  ├─ jackfruit evergreen; mahua + teak deciduous
│  └─ cashew + papaya introduced; red sanders Indian endemic
│
├─ ISFR 2023 TERMS
│  ├─ forest cover → ≥1 ha + canopy ≥10%; any ownership/legal status
│  │  └─ includes qualifying natural forest, plantations, orchards, bamboo, palm
│  ├─ VDF ≥70% | MDF 40–<70% | open 10–<40%
│  ├─ scrub <10% → mapped separately; outside forest-cover total
│  ├─ RFA → recorded as forest; canopy may be present or absent
│  ├─ tree cover → single trees/patches <1 ha outside RFA
│  └─ Trees Outside Forests (TOF) → all trees outside RFA, any patch size
│
├─ CURRENT CANOPY BASELINE
│  ├─ forest cover 7,15,342.61 sq km = 21.76%
│  ├─ tree cover 1,12,014.34 sq km = 3.41%
│  └─ combined 8,27,356.95 sq km = 25.17%
│     └─ canopy gain ≠ automatic biodiversity/tenure outcome
│
├─ ECOSYSTEM FUNCTION → THREAT → RESTORATION
│  ├─ function → habitat + carbon + water/soil + nutrients + livelihoods
│  ├─ threats → conversion + fragmentation + fire + invasives
│  │           + grazing/lopping + mining/roads + climate stress
│  └─ hierarchy
│     └─ avoid intact loss → remove driver → assist natural regeneration
│        → diverse native planting if needed → restore process/connectivity
│        → monitor composition, regeneration, pressure and people
│
├─ FRA 2006: PURPOSE + ELIGIBILITY
│  ├─ purpose → remedy historical injustice; tenure/livelihood/food security
│  ├─ FDST → scheduled in relevant area + forest residence/dependence
│  ├─ OTFD → same livelihood link + three generations = 75 years
│  └─ cut-off → occupation before 13 December 2005
│
├─ RIGHTS
│  ├─ IFR → habitation/self-cultivation; actual occupation; max four hectares
│  │  └─ heritable; non-alienable/non-transferable; ordinarily joint spouses
│  ├─ community → nistar + grazing + fish/water + pastoral access
│  ├─ MFP → own/collect/use/dispose; bamboo included
│  ├─ Community Forest Resource (CFR) → protect + regenerate + conserve + manage
│  ├─ habitat → PVTGs/pre-agricultural communities
│  ├─ tenure correction → disputed land/pattas/forest villages/rehabilitation
│  └─ excluded → hunting/trapping/wild-animal body parts
│
├─ DEVELOPMENT RIGHT: SECTION 3(2)
│  └─ 13 government facilities + <1 ha/case + ≤75 trees/ha
│     + Gram Sabha recommendation
│
├─ DUTIES: SECTION 5
│  └─ protect wildlife/forest/biodiversity + catchments/water
│     + habitat/cultural heritage + enforce CFR-access decisions
│
├─ CLAIM PROCESS
│  ├─ Gram Sabha/FRC → receive + acknowledge + verify + map
│  ├─ Gram Sabha resolution
│  ├─ SDLC → examine + reconcile + first petition
│  ├─ DLC → final approval/rejection + title + record direction
│  └─ record update + post-claim support → effective right
│
├─ EVIDENCE + APPEAL
│  ├─ records + maps + physical works + customs + sacred/burial sites
│  │  + genealogy + elder statements
│  ├─ more than one item; no compulsory single document
│  ├─ satellite imagery supplements; never replaces
│  ├─ GS→SDLC: 60 days | SDLC→DLC: 60 days
│  ├─ hearing notice ≥15 days; possible 30-day extension
│  └─ no technical-only rejection; give reasons; remand incomplete claim
│
├─ SECTION 4(5)
│  └─ no eviction/removal until recognition + verification complete
│     └─ safeguard ≠ automatic approval
│
├─ CRITICAL WILDLIFE HABITAT ≠ CORE/CRITICAL TIGER HABITAT
│  ├─ CWH → FRA; wildlife; NP/Sanctuary; Central notification
│  ├─ CTH → WPA s.38V; tiger-reserve core; State notification
│  └─ relocation only after
│     └─ rights settled + irreversible-damage finding + no coexistence
│        + secure package + informed consent + completed facilities
│
├─ STATUTORY INTERFACES
│  ├─ PESA → Scheduled-Area Gram Sabha + MFP; complements FRA
│  ├─ WPA → conservation overlay; PA status does not erase FRA
│  ├─ Van (Sanrakshan Evam Samvardhan) Adhiniyam/former FCA
│  │  └─ forest-diversion approval, not tenure title
│  └─ Indian Forest Act
│     ├─ Reserved: prohibited unless permitted
│     └─ Protected: permitted unless prohibited
│
├─ CURRENT FRA STATUS: 30 JUN 2026
│  ├─ claims 54,01,561
│  ├─ titles 25,42,359
│  └─ disposed 43,55,591 = 80.64%
│     └─ claim ≠ title ≠ record update ≠ exercised right ≠ outcome
│
├─ ROUTED PYQS
│  ├─ 2018 CWH + Baiga habitat rights
│  ├─ 2019 forest-cover ranking + bamboo/MFP
│  ├─ 2020 forest resources–climate Mains
│  ├─ 2022 Miyawaki
│  ├─ 2023 deciduous species
│  └─ 2024 native trees; official Set-A key A
│
└─ MAINS VERDICT
   └─ protect intact natural forest first; restore native processes;
      recognise lawful rights; then test titles and canopy programmes
      through verified habitat, regeneration and livelihood outcomes.
```
