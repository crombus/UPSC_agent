# Environment and Ecology 05 — IUCN Red List and Endemism

## Quick-Glance Tree Chart

```text
IUCN RED LIST + ENDEMISM
│
├─ CENTRAL THESIS
│  ├─ Red List = scientific extinction-risk assessment
│  ├─ Endemism = natural distribution restricted to a named area
│  └─ Neither label alone creates law, trade control, PA status or funding
│
├─ 1. GLOBAL CATEGORY RAIL
│  ├─ NE = not yet evaluated
│  ├─ DD = information inadequate; not “safe”
│  ├─ LC → NT → VU → EN → CR → EW → EX
│  ├─ THREATENED = VU + EN + CR only
│  ├─ EW = only captivity/cultivation or naturalised outside past range
│  └─ EX = no reasonable doubt last individual died
│
├─ 2. ASSESSMENT IDENTITY
│  ├─ State: taxon + scale + category/criteria + assessment date
│  ├─ Global = entire natural range
│  ├─ Regional/national = subglobal population
│  │  ├─ apply criteria
│  │  └─ consider outside rescue/immigration
│  ├─ Regional additions: RE + NA
│  └─ True regional endemic → regional population = global population
│
├─ 3. CRITERIA A–E
│  ├─ A: population reduction
│  │  ├─ A1 CR/EN/VU = 90/70/50%
│  │  └─ A2–A4 = 80/50/30%
│  ├─ B: restricted range
│  │  ├─ B1 EOO: <100 / <5,000 / <20,000 km²
│  │  ├─ B2 AOO: <10 / <500 / <2,000 km²
│  │  └─ PLUS ≥2: fragmentation/few locations; decline; fluctuation
│  ├─ C: small population + continuing decline + C1/C2
│  ├─ D: very small population
│  │  └─ CR/EN/VU D1: <50 / <250 / <1,000 mature
│  ├─ E: modelled extinction probability
│  │  └─ CR/EN/VU: 50% / 20% / 10% at stated horizons
│  └─ One COMPLETE route suffices; one isolated threshold does not
│
├─ 4. EVIDENCE + REASSESSMENT
│  ├─ observed / estimated / inferred / projected / suspected
│  ├─ DD → survey + proportionate precaution
│  ├─ uplisting: lower → higher risk without delay when supported
│  ├─ normal downlisting: former criteria unmet ≥5 years
│  ├─ genuine change = real status crosses threshold
│  └─ non-genuine = new information / taxonomy / criteria / error
│
├─ 5. DISTRIBUTION VOCABULARY
│  ├─ native/indigenous = naturally present
│  ├─ endemic = native + nowhere else in named area
│  ├─ alien/exotic = human-introduced beyond natural range
│  ├─ invasive alien = alien whose spread threatens biodiversity
│  ├─ range-restricted = small range; may cross borders
│  └─ endemic ≠ rare ≠ threatened ≠ legally protected
│
├─ 6. ENDEMISM RISK PATHWAYS
│  ├─ isolation + heterogeneity → speciation → centre of endemism
│  ├─ island endemic
│  │  ├─ one event can affect whole global range
│  │  ├─ invasive species / disease / cyclone exposure
│  │  └─ no outside natural recolonisation source
│  ├─ montane endemic
│  │  ├─ sky-island fragmentation
│  │  ├─ narrow climatic belt
│  │  └─ upslope compression + low connectivity
│  └─ India: Western Ghats; Himalaya/Northeast; Eastern Ghats;
│             Andaman–Nicobar islands
│
├─ 7. STATUS FIREWALL
│  ├─ IUCN → extinction risk
│  ├─ CITES → international-trade control
│  ├─ WPA → binding Indian species law
│  ├─ PA → place-based legal protection
│  └─ category / appendix / schedule / PA occurrence may diverge
│
├─ 8. RED LIST INDEX
│  ├─ same species set + repeated assessment + category weights
│  ├─ counts only genuine category change
│  ├─ 1 = all included species LC; 0 = all EX
│  ├─ falling = aggregate risk worsening
│  └─ LIMITS
│     ├─ broad categories miss within-category decline
│     ├─ reassessment lag + DD + taxonomic coverage bias
│     ├─ aggregate can hide opposite species trends
│     └─ not an abundance, habitat or funding index
│
├─ 9. INDIA ANCHORS
│  ├─ Western hoolock
│  │  ├─ EN A4acd; IUCN publication 2019
│  │  └─ Bangladesh + NE India + Myanmar → not Indian-endemic
│  ├─ Narcondam Hornbill
│  │  ├─ island endemic; VU D1+2, 2020
│  │  └─ downlisting may mix real increase + better knowledge
│  ├─ Gooty tarantula
│  │  └─ CR B1ab(iii), 2008 → restricted-range example
│  ├─ Nilgiri tahr
│  │  └─ official montane-endemism / habitat-restoration example
│  └─ Great Indian Bustard
│     ├─ current IUCN record displays CR
│     └─ SC, 19 December 2025
│        ├─ revised areas: Rajasthan 14,013 km²; Gujarat 740 km²
│        ├─ 250 km critical power-line treatment within two years
│        └─ directions ≠ proof of recovery
│
├─ 10. CONSERVATION PRIORITY
│  ├─ Red List category = vital input, not funding entitlement
│  ├─ combine:
│  │  ├─ risk + trend + threat urgency
│  │  ├─ endemicity / irreplaceability
│  │  ├─ feasibility + cost + ecological role
│  │  ├─ legal duty + equity + co-benefits
│  │  └─ DD survey need
│  └─ portfolio: emergency recovery + prevention + knowledge
│
├─ PYQ ROUTE
│  ├─ direct: 2019 Q22/Q29; 2022 Q47; 2023 Q12;
│  │          2024 Q23; 2026 Q22
│  ├─ shared/application: 2018 Q60; 2023 Q13;
│  │                       2024 Q20; 2025 Q37
│  └─ key warning: 2018–2023 local official keys unavailable;
│                  2024/2025 official; 2026 provisional
│
└─ 20-SECOND ANSWER SPINE
   ├─ DEFINE risk + endemism + scale
   ├─ EXPLAIN category subset + A–E mechanism
   ├─ DISTINGUISH IUCN / CITES / WPA / PA
   ├─ EVIDENCE with dated Indian case
   ├─ QUALIFY DD / reason-for-change / RLI limit
   └─ CONCLUDE: assess → act → monitor → reassess
```

**Final recall:** diagnose risk with IUCN, identify irreplaceability through endemism, choose the correct legal/habitat tool, and fund monitored action rather than a label.
