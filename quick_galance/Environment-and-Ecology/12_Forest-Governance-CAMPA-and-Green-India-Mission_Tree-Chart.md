# Topic 12 — Forest Governance, CAMPA and Green India Mission: Quick-Glance Tree

```text
FOREST GOVERNANCE = STATUS + APPROVAL + RIGHTS + FINANCE + RESTORATION
│
├─ CONSTITUTION
│  ├─ Article 48A → State protects environment, forests, wildlife
│  ├─ Article 51A(g) → citizen environmental duty
│  └─ Concurrent List → 17A forests | 17B wildlife
│
├─ WHO DOES WHAT?
│  ├─ Union/MoEFCC → rules + prior approval + National CAMPA + GIM
│  ├─ State/UT → records + screening + final State order + field work
│  ├─ Gram Sabha → FRA/PESA functions + GIM micro-plan
│  └─ FSI/CAG/courts → science + audit + review; not implementation
│
├─ LAW MAP
│  ├─ IFA 1927 → Reserved | Village | Protected Forest
│  │  └─ legal status/produce/transit ≠ canopy/type/right
│  ├─ Van Adhiniyam 1980 → Central prior approval
│  ├─ FRA 2006 → IFR/community/CFR rights + conservation duties
│  ├─ CAF Act 2016 → diversion-linked Funds + Authorities
│  └─ GIM → NAPCC policy mission; not CAMPA statute
│
├─ CURRENT VAN ACT SCOPE
│  ├─ covered
│  │  ├─ notified/declared forest
│  │  └─ other government-record forest on/after 25 Oct 1980
│  ├─ proviso → authorised pre-12 Dec 1996 conversion
│  ├─ exclusions, condition-bound
│  │  ├─ qualifying access/amenity strip ≤0.10 ha
│  │  ├─ plantations outside covered categories
│  │  └─ specified strategic/security/LWE categories
│  └─ litigation control
│     ├─ 19 Feb 2024 interim Godavarman direction
│     └─ case still pending in official 15 Jul 2026 proceedings
│        └─ never claim final invalidation or permanent settlement
│
├─ DIVERSION PROCESS
│  ├─ portal proposal → DFO/Collector/Conservator/Nodal scrutiny
│  ├─ Project Screening Committee + field verification where applicable
│  ├─ State recommendation
│  ├─ Regional Office/REC OR Centre/Advisory Committee route
│  ├─ Stage-I → preliminary, conditional
│  ├─ DFO demand → CA + NPV + mitigation + CA land/documents
│  ├─ compliance → DFO → Nodal/PCCF → State → Centre
│  ├─ Stage-II → Central final approval
│  └─ State order only after other laws + FRA-rights settlement
│     └─ working permission = limited linear-project preliminary work
│
├─ CA ≠ NPV ≠ OUTCOME
│  ├─ CA cost → approved plantation/restoration scheme
│  ├─ NPV → monetary recognition of foregone ecosystem services
│  ├─ default CA → required non-forest land
│  ├─ twice-shortfall/twice-area routes → specified conditions only
│  └─ payment ≠ permission ≠ mature-forest replacement
│
├─ CAF / CAMPA
│  ├─ money → interest-bearing, non-lapsable Public Account Funds
│  ├─ 90% State Fund | 10% National Fund
│  ├─ use
│  │  ├─ site-specific money → approved site scheme
│  │  └─ NPV → ≥80% core forest/wildlife; ≤20% support capacity
│  ├─ National → Governing Body + Executive + Monitoring Group
│  ├─ State → Governing Body + Steering + Executive
│  ├─ CAG audit → Parliament / State Legislature
│  └─ 23 Mar 2026 reply
│     └─ ₹12,515.30 crore unutilised at 31 Mar 2025
│        └─ transfer ≠ APO ≠ spend ≠ outcome
│
├─ GREEN INDIA MISSION
│  ├─ original NAPCC mission; domestic, not Paris-mandated
│  ├─ objectives
│  │  ├─ +5 mha forest/tree cover
│  │  ├─ improve another 5 mha
│  │  ├─ biodiversity + water + carbon services
│  │  └─ improve income of ~3 million forest households
│  ├─ five sub-missions = 10 mha
│  │  ├─ quality/ecosystem services 4.9
│  │  ├─ restoration/cover increase 1.8
│  │  ├─ urban/peri-urban 0.2
│  │  ├─ agro/social forestry 3.0
│  │  └─ wetlands 0.1
│  ├─ landscape chain
│  │  └─ L1 State → L2 cluster → L3 village/micro-watershed
│  │     └─ Gram Sabha-approved micro-plan; JFMC as GS committee
│  └─ convergence → CAMPA + MGNREGS + NAP
│     └─ common landscape plan, separate law/account/audit
│
├─ TARGET ≠ ACHIEVEMENT
│  ├─ PIB 24 Jul 2025 → ₹982.34 crore released; 17 States + J&K
│  └─ CAG Report 4/2026, audit 2015-16 to 2024-25
│     ├─ budgetary support ₹1,149.14 crore
│     ├─ audited target 1.4 mha quality → observed 0.11384
│     ├─ audited target 1.4 mha cover → observed 0.03409
│     ├─ only MP/Chhattisgarh assessed carbon
│     └─ 70% sampled sites → no noticeable attributable GIS change
│        └─ sampled finding ≠ every site failed; audit ≠ mission repeal
│
├─ RESTORATION INTEGRITY
│  ├─ afforestation → establish trees on non-recent forest land
│  ├─ reforestation → re-establish forest after loss
│  ├─ restoration → recover structure + process + services
│  ├─ ANR → remove pressure; use surviving ecological memory
│  └─ test → monoculture | additionality | leakage | permanence
│           | native-biome fit | hydrology | connectivity | tenure
│
├─ RIGHTS INTERFACE
│  ├─ FRA CFR → protect/regenerate/conserve/manage
│  ├─ Section 4(5) → no eviction before recognition/verification
│  ├─ PESA → Scheduled-Area Gram Sabha/community-resource interface
│  ├─ Rule 11(7) → FRA settlement before State diversion order
│  └─ no universal identical “Gram Sabha consent” formula
│     └─ apply the exact law, area and project
│
├─ MONITORING
│  ├─ FSI ISFR → biennial canopy assessment; not programme attribution
│  ├─ fire → MODIS + SNPP-VIIRS alerts
│  │  └─ hotspot ≠ unique incident ≠ burnt area
│  ├─ CAMPA → levy/APO/spend + validated polygon + survival/function
│  └─ GIM → landscape baseline + biodiversity/water/carbon/livelihood
│
├─ ROUTED PYQS
│  ├─ 2019 Q68 → CAMPA levels; participation trap
│  ├─ 2021 Q24 → New York Declaration on Forests
│  ├─ 2021 Q97 → FAO + Arbor Day; Hyderabad Tree City
│  └─ 2026 Q40 → Khasi Hills Plan Vivo REDD+; local key provisional C
│
└─ MAINS VERDICT
   └─ avoid intact loss first → approve transparently → secure rights
      → earmark/audit money → restore native processes
      → verify permanence, ecosystem function and fair benefits.
```
