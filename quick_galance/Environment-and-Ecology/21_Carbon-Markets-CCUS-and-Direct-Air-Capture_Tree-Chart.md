# Environment and Ecology 21 — Carbon Markets, CCUS and Direct Air Capture

> Evidence: 30 September 2026

```text
CARBON MITIGATION TOOLKIT
│
├─ 1. HIERARCHY
│  ├─ AVOID demand/emissions
│  ├─ REDUCE: efficiency → electrification → renewables → process change
│  ├─ PRICE remaining emissions
│  ├─ CAPTURE difficult point-source emissions
│  └─ REMOVE residual atmospheric CO2
│     └─ rule: complement, never replace direct cuts
│
├─ 2. CARBON-PRICING TAXONOMY
│  ├─ Carbon tax
│  │  └─ fixes price/tCO2e → quantity uncertain
│  ├─ ETS / cap-and-trade
│  │  └─ fixes absolute cap → issues/auctions allowances → price discovered
│  ├─ Baseline-and-credit
│  │  └─ benchmark/intensity target → credit for outperformance
│  │     └─ absolute emissions may rise with output
│  └─ Offset
│     └─ external credit used to compensate buyer emissions; not a market type
│
├─ 3. UNIT + MARKET BOUNDARIES
│  ├─ Allowance = permission within cap
│  ├─ Credit = verified reduction/avoidance/removal vs baseline/target
│  ├─ Compliance = demand created by law
│  └─ Voluntary = non-mandated purchase/claim
│
├─ 4. CREDIT-INTEGRITY GATE
│  ├─ Baseline = credible counterfactual
│  ├─ Additionality = would not occur in claimed amount anyway
│  ├─ Leakage = emissions displaced outside boundary
│  ├─ Permanence = storage duration
│  ├─ Reversal = stored carbon later released
│  ├─ MRV = monitor → report → verify
│  ├─ Validation = ex ante design test
│  ├─ Registry = serialise → transfer → surrender/retire/cancel
│  └─ Double counting
│     ├─ double issuance
│     ├─ double use
│     └─ double claim
│        └─ registry/CA cannot cure false baseline or reversal
│
├─ 5. PARIS AGREEMENT ARTICLE 6
│  ├─ Article 6.2 cooperative approaches
│  │  ├─ authorised international outcome → ITMO
│  │  └─ corresponding adjustment prevents two NDC claims
│  ├─ Article 6.4 UNFCCC-supervised crediting
│  │  ├─ authorised A6.4ER → international use + CA
│  │  ├─ non-authorised unit → host mitigation contribution
│  │  ├─ SOP: 5% issued units to Adaptation Fund
│  │  └─ OMGE: minimum 2% cancellation
│  ├─ Article 6.8 non-market approaches
│  │  └─ mitigation/adaptation/finance/technology/capacity; no unit transfer
│  └─ 6.2 contrast
│     └─ adaptation contribution + OMGE strongly encouraged, not 5%/2% mandate
│
├─ 6. KYOTO/CDM TRANSITION FIREWALL*
│  ├─ Activity request deadline: 31 Dec 2023
│  ├─ Host approval deadline: 30 June 2026 (extended)
│  ├─ No automatic A6.4 conversion
│  └─ Legacy CER lane
│     ├─ CDM activity registered on/after 1 Jan 2013
│     ├─ identified as pre-2021 reduction
│     ├─ first/first-updated NDC only
│     └─ no host CA / no A6.4 SOP for this legacy lane
│     *“firewall” = study mnemonic, not treaty wording
│
├─ 7. INDIA CCTS — LEGAL LADDER
│  ├─ Energy Conservation Act
│  │  ├─ s.14(w): specify CCTS
│  │  └─ s.14AA: issue/buy/sell CCCs under scheme
│  ├─ S.O. 2825(E), 28 Jun 2023: CCTS
│  ├─ S.O. 5369(E), 19 Dec 2023: offset mechanism added
│  ├─ GEI Rules, 8 Oct 2025: Al, cement, chlor-alkali, pulp/paper
│  ├─ Final amendment, 13 Jan 2026:
│  │  secondary Al + refinery + petrochemical + textile
│  ├─ Iron/steel schedule, 26 Jun 2026: DRAFT
│  └─ CERC CCC regulations, 27 February 2026
│
├─ 8. INDIA INSTITUTIONS
│  ├─ NSC-ICM: recommends/oversees
│  │  └─ Power/Environment Secretaries: chair/co-chair
│  ├─ BEE: administrator, targets/methods/accreditation, CCC issuance
│  ├─ MoP: scheme + recommends GEI targets
│  ├─ MoEFCC: notifies GEI targets under EPA
│  ├─ Grid Controller: registry/accounts/transfers
│  ├─ CERC: exchange rules, price discovery, oversight
│  └─ ACVA: validation/verification
│
├─ 9. INDIA MECHANISMS + STATUS
│  ├─ Compliance
│  │  └─ GEI intensity baseline-credit; beat target → CCC;
│  │     miss target → buy/surrender
│  ├─ Offset
│  │  └─ non-obligated project + approved methodology + validation/MRV
│  ├─ Approved scopes: 10, including CCUS/other removals
│  ├─ Approved methods, 30 Sep 2026: 12; none for CCUS
│  ├─ CERC: separate compliance/offset exchange segments
│  └─ Status caution
│     └─ no verified public issuance, price or volume tally
│
├─ 10. CCUS CHAIN
│  ├─ capture → purify/dehydrate/compress → transport → use/store
│  ├─ capture methods
│  │  ├─ post-combustion: flue gas
│  │  ├─ pre-combustion: H2-rich gas + CO2
│  │  └─ oxy-fuel: near-pure O2; CO2 + water exhaust
│  ├─ use-duration test
│  │  ├─ fuel/beverage/chemicals → usually re-release
│  │  └─ mineral products → quantify retained carbon
│  └─ geological storage
│     ├─ saline formations / depleted reservoirs / emerging basalt
│     ├─ caprock + wells + injectivity
│     ├─ injected mass + plume/pressure + leakage MRV
│     └─ closure, remediation, financial security, long-term liability
│
├─ 11. CCS ≠ CCU ≠ CDR
│  ├─ CCS: point-source capture + durable storage → usually avoidance
│  ├─ CCU: climate value depends on product lifetime/lifecycle
│  ├─ CCUS: umbrella; not automatically negative
│  └─ CDR: ambient CO2 removed + durable storage
│     └─ potential: DACCS / sustainable BECCS
│
├─ 12. DAC
│  ├─ ambient air → sorbent/solvent → regeneration → concentrated CO2
│  ├─ S-DAC: lower-temperature heat + electricity
│  ├─ L-DAC: may need heat up to ~900°C
│  ├─ needs low-carbon energy + materials + compression + storage
│  ├─ IEA 2022 capture estimate: USD 125-335/tCO2
│  │  └─ dated, uncertain, not full delivered cost/market price
│  ├─ DAC + fuel = recycling; CO2 returns on combustion
│  └─ DAC + durable storage − lifecycle emissions = possible removal
│
├─ 13. CDR PORTFOLIO
│  ├─ Afforestation: removal + co-benefits; land/reversal risk
│  ├─ Avoided deforestation: avoided emission, usually not removal
│  ├─ BECCS: biomass uptake + capture/storage; land/water/lifecycle limits
│  ├─ Biochar: stable fraction varies by feedstock/process/soil
│  ├─ Enhanced weathering: minerals; mining/energy/metals/MRV limits
│  └─ Ocean approaches
│     ├─ alkalinity enhancement
│     ├─ fertilisation/biological export
│     └─ ecology, permanence, deoxygenation, transboundary uncertainty
│
├─ 14. JUSTICE + DETERRENCE
│  ├─ future removals may delay feasible cuts
│  ├─ land/food/water/biodiversity and tenure
│  ├─ pipelines/wells/mining burden communities
│  ├─ benefit sharing + carbon ownership
│  └─ liability must not shift to future taxpayers
│
├─ 15. PYQ ROUTE
│  ├─ Direct: 2023 Q23, 2023 Q68, 2025 Q34, 2025 Q36, 2025 GS-III Q7
│  ├─ Application: 2021 Q29, 2024 Q96
│  └─ 2025 Mains spine
│     └─ define chain → hard-to-abate role → limits → avoidance/removal verdict
│
└─ QUALIFIED CONCLUSION
   └─ price incentives + difficult-source capture + durable residual removal
      work only with direct cuts first, conservative MRV, transparent claims
      and just allocation of land, infrastructure, reversal and liability risk.
```
