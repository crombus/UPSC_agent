# Environment and Ecology 18 — IPCC Assessment Reports

## Quick-Glance Tree Chart

```text
IPCC ASSESSMENT ARCHITECTURE
│
├─ 1. IDENTITY + MANDATE
│  ├─ Created 1988: WMO + UNEP
│  ├─ UN body; Panel of member governments
│  ├─ Assesses scientific, technical + socio-economic literature
│  ├─ Comprehensive • objective • open • transparent
│  └─ Neutral with respect to policy
│     NOT: research lab / UNFCCC COP / regulator / fund / NDC setter
│
├─ 2. WHO DOES WHAT?
│  ├─ Panel/Plenary
│  │  └─ consensus; programme, scope, outlines, elections, endorsement
│  ├─ Bureau
│  │  └─ scientific-technical guidance + cycle management
│  ├─ WG I → physical science, attribution, scenarios, projections
│  ├─ WG II → impacts, risk, vulnerability, adaptation, limits
│  ├─ WG III → mitigation pathways/options + enabling conditions
│  ├─ TFI/TFB → national-inventory methodologies; NOT “WG IV”
│  ├─ Authors → assess + draft | Review Editors → audit comments
│  ├─ TSUs → production support
│  └─ Secretariat → coordination/administration; NOT scientific authorship
│
├─ 3. ASSESSMENT CYCLE
│  └─ programme → scoping → Panel-approved outline
│     → nominations → Bureau selection
│     → FOD: expert review
│     → SOD + draft SPM: government + expert review
│     → revision + final government SPM comments
│     → plenary endorsement → publication + review record
│
├─ 4. REPORT FAMILY
│  ├─ Assessment Report = 3 WG contributions
│  ├─ Synthesis Report = integrates WGs + relevant Special Reports
│  ├─ Special Report = focused assessment
│  ├─ Methodology Report = inventory guidance under TFI
│  └─ Technical Paper = synthesis from existing IPCC reports
│
├─ 5. ENDORSEMENT VERBS
│  ├─ APPROVAL = line by line → SPM
│  ├─ ADOPTION = section by section
│  │  ├─ longer Synthesis Report
│  │  └─ Methodology Overview Chapter
│  └─ ACCEPTANCE = underlying report; not line/section agreed
│     WG route: approve SPM + accept report
│     SYR route: Panel approves SPM + adopts longer report
│     SAFEGUARD: SPM must remain consistent with accepted report
│
├─ 6. CALIBRATED UNCERTAINTY
│  ├─ Confidence = evidence + agreement
│  │  └─ very low / low / medium / high / very high
│  ├─ Likelihood = assessed probability
│  │  ├─ virtually certain 99–100%
│  │  ├─ very likely 90–100%
│  │  ├─ likely 66–100%
│  │  └─ about as likely as not 33–66%
│  └─ TRAP: high confidence ≠ 90%; qualifier stays with exact finding
│
├─ 7. ASSESSMENT EVOLUTION
│  ├─ FAR 1990 → UNFCCC impetus
│  ├─ SAR 1995 → Kyoto run-up
│  ├─ TAR 2001 → impacts + adaptation
│  ├─ AR4 2007 → post-Kyoto / 2°C focus
│  ├─ AR5 2013–14 → Paris input + carbon-budget reasoning
│  └─ AR6 2021–23 → attribution + SSPs + limits + pathways
│     Reports inform treaties; they do not negotiate them
│
├─ 8. AR6: SCIENCE → RISK → RESPONSE
│  ├─ WGI
│  │  ├─ human influence unequivocally warmed atmosphere/ocean/land
│  │  ├─ SSPs = conditional futures; NOT assigned forecasts
│  │  ├─ start-2020 budgets:
│  │  │  ├─ 1.5°C, 50% → 500 GtCO2
│  │  │  └─ 1.5°C, 67% → 400 GtCO2
│  │  └─ SSP5-8.5 sea level 2100:
│  │     likely 0.63–1.01 m vs 1995–2014
│  ├─ WGII
│  │  ├─ risk = hazard × exposure × vulnerability
│  │  ├─ widespread adverse impacts; unequal vulnerability
│  │  ├─ adaptation progress + gaps
│  │  └─ soft limits may be overcome; hard limits cannot
│  ├─ WGIII
│  │  ├─ limiting pathways → rapid/deep, mostly immediate cuts
│  │  ├─ sectors + demand + efficiency + finance + governance
│  │  └─ CDR balances residuals; constraints remain
│  └─ SYR
│     ├─ A: current status/trends
│     ├─ B: future risks/long-term responses
│     └─ C: near-term responses
│        every increment of warming intensifies hazards
│
├─ 9. SPECIAL + METHODOLOGY REPORTS
│  ├─ SR1.5 (2018) → 1.5°C impacts/pathways
│  ├─ SRCCL (2019) → land, degradation, food security
│  ├─ SROCC (2019) → ocean, cryosphere, sea level
│  ├─ 2006 Inventory Guidelines
│  └─ 2019 Refinement → use WITH; does not replace 2006 Guidelines
│     METHOD ≠ inventory result ≠ target ≠ policy outcome
│
├─ 10. INDIA USE
│  ├─ member-government route: nominate → review → plenary
│  ├─ Indian experts participate as authors
│  ├─ IPCC global/regional finding
│  │  + Indian official observation
│  │  + Indian policy/implementation evidence
│  └─ TRAP: IPCC report ≠ Indian law / NDC / scheme / clearance
│
├─ 11. AR7 STATUS — 29 September 2026
│  ├─ cycle began Jul 2023; 3 WG contributions agreed Jan 2024
│  ├─ WG outlines agreed Feb 2025; authoring under way
│  ├─ WGIII LAM: 28 Sep–1 Oct 2026 → FOD follows
│  ├─ Cities Special Report → Mar 2027
│  ├─ SLCF Methodology SOD review → 31 Aug–25 Oct 2026
│  │  └─ publication: second half 2027
│  ├─ CDR/CCUS Methodology → completion 2027
│  └─ AR7 Synthesis Report → late 2029
│     FIREWALL: outline/draft/meeting ≠ finding
│     AR6 remains the latest completed assessment
│
├─ 12. DIRECT PYQ ROUTE — 2023 GS-III Q18
│  └─ one-metre stem
│     → state AR6 scenario + baseline + likelihood
│     → expansion + land-ice mechanism
│     → regional relative-level qualification
│     → India/Indian Ocean: flooding, erosion, salinity,
│       ecosystems, ports, livelihoods, mobility
│     → mitigation + adaptation + local evidence
│
└─ 13. FINAL ANSWER SPINE
   define institution/product
   → identify WG/TFI owner
   → attach report/year/baseline/scenario/confidence
   → explain mechanism and risk/response
   → separate assessment from treaty/national policy
   → add India evidence
   → qualify lag, scale, uncertainty and implementation
```

**Qualified conclusion:** The IPCC supplies a dated, calibrated and government-endorsed evidence floor; it neither eliminates uncertainty nor substitutes for treaty negotiation and national implementation.
