# Environment and Ecology 04 — Biodiversity Levels and Hotspots

> Quick-glance revision tree · evidence checked 28 September 2026

```text
CORE THESIS
Biodiversity = variability within species, between species,
and of ecosystems. Hotspot = threatened endemic-rich REGION,
not a synonym for richness and not a legal protected area.
│
├─ 1. THREE LEVELS
│  ├─ GENETIC
│  │  alleles · genotypes · population structure
│  │  example: crop landraces / wild relatives
│  │  loss → narrower adaptive capacity
│  ├─ SPECIES
│  │  richness + evenness + composition
│  └─ ECOSYSTEM
│     habitats + communities + ecological processes
│     example: forest-wetland-grassland-coastal mosaic
│  trap: success at one level ≠ whole biodiversity conserved
│
├─ 2. COMPONENT FIREWALL
│  ├─ richness = number of species
│  ├─ evenness = equality of relative abundances
│  ├─ composition = identity of species present
│  ├─ endemic = naturally restricted range
│  ├─ native = natural occurrence; may occur elsewhere
│  ├─ rare = low abundance/range/frequency
│  └─ threatened = assessed extinction risk
│  trap: endemic ≠ automatically rare or threatened
│
├─ 3. SCALE LADDER
│  ├─ α = within one local unit
│  ├─ β = turnover/differentiation among units
│  │  turnover ≠ nestedness
│  └─ γ = regional total
│  multiplicative β = γ / mean α
│  additive β = γ - mean α
│  trap: high β can coexist with low α
│
├─ 4. MEASUREMENT TOOLBOX
│  ├─ richness S → effort/area sensitive
│  ├─ Shannon H' = -Σpi ln pi
│  ├─ Simpson D = Σpi² → higher D = more dominance
│  ├─ Gini-Simpson = 1-D; reciprocal Simpson = 1/D
│  ├─ Pielou J' = H'/ln S
│  ├─ Jaccard/Sørensen → composition similarity
│  └─ genes: allelic richness + heterozygosity
│  control: equal method/season/effort/detectability
│  use rarefaction or common sample coverage
│  trap: one index cannot prove ecosystem health
│
├─ 5. WHY BIODIVERSITY MATTERS
│  ├─ direct use: food · fibre · medicine · recreation
│  ├─ indirect use: pollination · water · soil · buffering
│  ├─ option: possible future use
│  ├─ existence: value of persistence itself
│  ├─ bequest: value for future generations
│  └─ intrinsic/relational values exceed market price
│  services: provisioning · regulating · cultural · supporting
│  trap: avoid double counting one ecological function
│
├─ 6. THREAT CAUSALITY
│  IPBES direct-driver order:
│  land/sea-use change
│   → direct exploitation
│   → climate change
│   → pollution
│   → invasive alien species
│  HIPPCO = mnemonic, not official ranking
│  population/consumption = indirect pressure
│  fragmentation:
│  less area + more edge + isolation
│   → lower gene flow / smaller populations
│   → demographic + genetic risk
│
├─ 7. DELAYED / HIDDEN LOSS
│  ├─ extinction debt
│  │  future loss caused by past habitat damage
│  │  current persistence ≠ long-term security
│  └─ biotic homogenisation
│     widespread winners replace local/endemic losers
│     α richness may rise while β distinctiveness falls
│  response: restore quality + area + connectivity early
│
├─ 8. HOTSPOT GATE
│  BOTH required:
│  ├─ ≥1,500 endemic vascular plant species
│  └─ ≥70% original natural vegetation lost
│     (= ≤30% remains)
│  function: global conservation triage
│  no automatic Indian legal protection
│
├─ 9. HOTSPOT HISTORY
│  1988 Myers: 10 tropical-forest hot spots
│   → 1990: 18
│   → 2000 quantitative assessment: 25
│   → 2004 Hotspots Revisited: 34
│   → 2011: 35
│   → 2016: 36
│  current CI/CEPF count checked in 2026: 36
│
├─ 10. INDIA: FOUR TRANSBOUNDARY PORTIONS
│  ├─ HIMALAYA
│  │  Indian Himalayan arc, northwest → northeast
│  │  elevation-banded endemism
│  ├─ INDO-BURMA
│  │  non-Himalayan Northeast + ANDAMAN
│  │  freshwater/reptile endemism
│  ├─ WESTERN GHATS-SRI LANKA
│  │  Western Ghats chain:
│  │  Maharashtra-Goa-Karnataka-Kerala-Tamil Nadu
│  │  amphibian/freshwater-fish endemism
│  └─ SUNDALAND
│     India portion = NICOBAR only
│     island-restricted plant/vertebrate ranges
│  master trap: Andaman = Indo-Burma; Nicobar = Sundaland
│  boundary is biogeographic, not a whole-state list
│
├─ 11. LABEL FIREWALL
│  ├─ hotspot = region + plant endemism + habitat loss
│  ├─ megadiverse = country-scale richness/endemism portfolio
│  │  India belongs to widely cited 17-country set
│  ├─ LMMC = negotiating coalition
│  ├─ centre of endemism = restricted-range concentration
│  ├─ centre of origin = domestication history
│  ├─ centre of diversity = current crop genetic variation
│  │  may differ from origin
│  └─ protected area = legal/managed category
│
├─ 12. CONSERVATION LADDER
│  ├─ IN-SITU foundation
│  │  viable wild populations + habitats + processes
│  │  protected/community areas · sacred groves · corridors
│  │  on-farm landraces can be in-situ
│  └─ EX-SITU insurance
│     NBPGR National Gene Bank · seed/field/in-vitro/cryo
│     botanical collections · CZA-linked breeding
│     → habitat repair → reintroduction → monitoring
│  trap: ex-situ cannot warehouse an ecosystem
│
├─ 13. GOVERNANCE / CURRENT LINK
│  NBA → SBB → BMC/PBR
│  BSI/ZSI → dated taxonomic inventories
│  ABS links resource/knowledge use to benefit sharing
│  KMGBF 2022: 4 goals + 23 targets
│  Target 3: ≥30% by 2030 through PAs + OECMs
│  plus representation, connectivity, effectiveness, equity
│  India NBSAP 2024-2030: 23 aligned national targets
│  COP16 concluded: 27 February 2025
│  Cali Fund: DSI benefit-sharing; first contribution end-2025
│  trap: launched/adopted/covered ≠ achieved
│
├─ 14. PYQ ROUTE
│  ├─ direct:
│  │  2018 P Q60 sixth extinction
│  │  2023 P Q13 IUCN-ISSG
│  │  2025 P Q90 EU Nature Restoration Law
│  ├─ shared:
│  │  2023 P Q79 BMC/Nagoya
│  │  2018 GS-III Q17 variation + Biodiversity Act
│  │  2026 GS-III Q8 KMGBF + India
│  └─ application:
│     Prosopis · India-only range · habitat pairs
│     Gooty tarantula · GenomeIndia
│
└─ ANSWER SPINE
   define level + spatial scale
    → richness/evenness/composition + metric caveat
    → value
    → threat mechanism and lag
    → hotspot / in-situ / ex-situ tool as demanded
    → exact Indian example and institution
    → status/boundary/implementation qualification
    → connected, representative, multi-level conservation
```
