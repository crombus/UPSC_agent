# Environment and Ecology 15 — Solid, Plastic and E-Waste Rules

## Quick-Glance Tree Chart

```text
WASTE GOVERNANCE = MATERIAL FLOW + ACTOR DUTY + VERIFIED OUTCOME
│
├─ 1. HIERARCHY / CIRCULARITY
│  ├─ prevent → reduce → reuse/repair/refurbish
│  ├─ → recycle → recover → dispose
│  ├─ source segregation preserves quality + worker safety
│  └─ recycling alone ≠ circular economy
│
├─ 2. ACTIVITY FIREWALL
│  ├─ collection = taking/aggregation
│  ├─ processing = scientific handling/transformation
│  ├─ recycling = new material/product
│  ├─ recovery = material or useful energy
│  ├─ disposal = final safe residual destination
│  └─ registration/certificate ≠ verified physical outcome
│
├─ 3. STREAM FIREWALL
│  ├─ ordinary solid waste → SWM Rules 2026
│  ├─ plastic → PWM Rules 2016; latest used: G.S.R. 73(E), 23-1-2025
│  ├─ listed EEE → E-Waste Rules 2022; latest used: G.S.R. 164(E), 8-3-2024
│  ├─ batteries / biomedical / hazardous / C&D → separate rules
│  └─ common EPA 1986 parent ≠ one combined rule
│
├─ 4. SWM: 2016 PYQ BASELINE
│  ├─ three streams: biodegradable | non-biodegradable | domestic hazardous
│  ├─ generator: segregate; wrap sanitary; no litter/burn/bury; pay fee
│  ├─ bulk generator: listed entity >100 kg/day
│  ├─ >5,000 sq m gated/institutional + hotels/restaurants:
│  │  on-site wet processing as far as possible
│  ├─ ULB: door collection → waste-picker integration → MRF
│  │  → compost/biomethanation/recycling/RDF → residual landfill
│  ├─ landfill: inert + non-usable rejects, not mixed waste
│  ├─ 2019: recyclable bin white → blue
│  └─ 2020: villages >3,000 + MoHUA + compartmentalised transport
│
├─ 5. SWM: CURRENT 2026
│  ├─ S.O. 388(E), 27-1-2026; effective 1-4-2026
│  ├─ supersedes 2016; urban + rural coverage
│  ├─ four streams: wet | dry | sanitary | special-care
│  ├─ current BWG if any one:
│  │  20,000 sq m | 40,000 L/day | 100 kg/day
│  ├─ BWG: register + decentralised wet processing
│  │  or lawful EBWGR route
│  ├─ EBWGR certificate: local-body generated
│  │  after registered processing; valid 3 years
│  ├─ landfill: no wet or C&D; wrong-waste fee > collection
│  │  + transport + processing cost
│  ├─ legacy-site mapping deadline: 31-10-2026
│  └─ RDF substitution: 6% → 10% → 15% for specified units
│
├─ 6. PLASTIC: RESTRICTION + EPR
│  ├─ categories
│  │  ├─ I rigid
│  │  ├─ II flexible plastic-only / plastic multilayer
│  │  ├─ III plastic + non-plastic multilayer
│  │  ├─ IV compostable
│  │  └─ V biodegradable
│  ├─ SUP prohibition from 1-7-2022:
│  │  identified sticks/flags/cutlery/plates/cups/straws/trays/
│  │  stirrers/films/thermocol + PVC/plastic banners <100 μm
│  ├─ not a blanket plastic ban
│  ├─ carry bags 120 μm; non-woven 60 GSM
│  ├─ FY 2026-27
│  │  ├─ EPR target 100%
│  │  ├─ recycle I/II/III/IV = 70/50/50/70
│  │  ├─ recycled content I/II/III = 40/10/5
│  │  └─ rigid reuse = 15% / 75% by size band
│  ├─ registered PWP → portal certificate → PIBO compliance
│  ├─ portal reconciles; lower figure counts; audit survives
│  ├─ certificate price band = 30–100% of EC
│  ├─ cross-category paragraph 15A expired after 2025-26
│  ├─ plastic EC return if cured = 75/60/40
│  └─ 2025 label route: barcode/QR | brochure | unique number
│
├─ 7. E-WASTE: LIFECYCLE CONTROL
│  ├─ effective 1-4-2023
│  ├─ exclusions: batteries | packaging plastic | micro enterprise
│  │  | radioactive waste
│  ├─ registrants: manufacturer | producer | refurbisher | recycler
│  ├─ dismantler works in recycler chain; not fifth portal category
│  ├─ FY 2026-27 normal target:
│  │  70% of EEE placed in market in Y–X
│  ├─ recent seller: 20% of sales two years earlier
│  ├─ used-EEE import: 100% at end of life if not re-exported
│  ├─ solar PV: no target; store through 2034-35
│  ├─ recycler certificate validity: 2 years after generation FY
│  ├─ producer purchase: current + arrears + 5%
│  ├─ refurbish certificate:
│  │  defer → 75% later returns → recycling finally extinguishes
│  ├─ e-waste EC return = 85/60/30
│  └─ 2024 platform price band = 30–100% of EC
│
├─ 8. RoHS + SAFETY
│  ├─ Pb/Hg/Cr6+/PBB/PBDE ≤0.1% homogeneous material
│  ├─ Cd ≤0.01%; schedules/exemptions apply
│  ├─ self-declaration + technical file + CPCB sampling/recall
│  ├─ 2023: refrigerant management + revised exemptions
│  └─ residues → registered recycler / authorised TSDF
│
├─ 9. JUST TRANSITION
│  ├─ informal collectors = reach + livelihood
│  ├─ unsafe burning/acid leaching = unacceptable exposure
│  └─ recognise + organise + fair pay + PPE/health + skills
│     → authorised aggregation/processing, not exclusion
│
├─ 10. EVIDENCE LADDER
│  ├─ registered ≠ collected
│  ├─ collected ≠ processed
│  ├─ processed ≠ recycled
│  ├─ certificate ≠ independent outcome
│  └─ verify: weighment + input/output mass balance + capacity
│     + recovered-product sale + emissions + residue destination
│
├─ 11. PYQ ROUTES
│  ├─ direct: 2018 Mains; 2019 Q26/Q59/Q78; 2021 Q16;
│  │  2022 Q46; 2024 Q22; 2025 Q44; 2026 Mains Q17
│  ├─ shared: 2020 steel slag; 2025 circular economy
│  └─ application: 2026 tribal-hamlet facility-siting conflict
│
└─ 12. ANSWER SPINE
   hierarchy → source segregation → identify stream/legal vintage
   → assign generator/local-body/producer/processor duty
   → explain target/certificate → overlap + worker safety
   → audit material/residue → distinguish flow from legacy stock
   → conclude: verified circular use, not paper compliance
```

**Qualified conclusion:** India has shifted from mixed disposal toward stream-specific lifecycle
responsibility; success requires prevention, preserved segregation, verified material recovery,
safe residue management and a just transition—not registrations or certificates alone.
