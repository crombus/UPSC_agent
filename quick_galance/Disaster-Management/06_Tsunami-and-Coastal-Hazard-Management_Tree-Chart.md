# Disaster Management 06 — Tsunami and Coastal Hazard Management

```text
CENTRAL THESIS
│
├─ tsunami = sudden displacement wave
├─ not astronomical tide
├─ not cyclone wind-pressure storm surge
└─ safety = source science → warning → understood action → recovery

1. GENERATION
│
├─ undersea earthquake
│  └─ tsunamigenic when rapid vertical seabed displacement moves water
├─ submarine landslide
├─ volcanic collapse/activity
└─ rare meteorite impact

TRAP → undersea earthquake ≠ automatic destructive tsunami

2. PROPAGATION → IMPACT
│
├─ deep ocean: long wavelength/period, rapid travel, low visible amplitude
├─ shallowing: speed ↓ + wavelength ↓ + height/current ↑ = shoaling
├─ run-up = vertical reach
├─ inundation = horizontal flooding
└─ return flow = debris + scour + seaward drag

LOCAL MODIFIERS
├─ bathymetry / shelf / channels
├─ bay or estuary shape
├─ elevation / slope / land cover
└─ exposure + vulnerability + capacity

3. INDIA EVIDENCE
│
├─ eastern source → Andaman-Sumatra
├─ western source → Makran
├─ 26 December 2004 → institutional turning point
└─ heavier damage where dunes were mined

4. ITEWC / INCOIS CHAIN
│
├─ seismic networks → event parameters
├─ pre-run model / TUNAMI-N2 → preliminary threat
├─ Bottom Pressure Recorders → open-ocean evidence
├─ tide gauges → coastal sea-level evidence
├─ ITEWC bulletin → technical advisory
└─ State/district/local authority → evacuation + local all-clear

CURRENT SOP
├─ Type I → preliminary earthquake information
├─ Type II → model-based threat
├─ Type III → observed sea-level evidence
└─ <60-minute coast may be warned before confirmation

FACTS
├─ ITEWC at INCOIS, Hyderabad
├─ operational since 15 October 2007
├─ detection about 10 minutes
└─ UNESCO-IOC service provider under IOTWMS

TRAPS
├─ detection ≠ confirmation
├─ advisory ≠ evacuation order
└─ threat passed ≠ local all-clear

5. MAPPING + LAND USE
│
├─ bathymetry + topography + source scenario + exposure
├─ output → inundation map / routes / refuge / facility siting
├─ CRZ 2019 categories + local hazard map
└─ model boundary = scenario with uncertainty, not guaranteed safe line

6. EVACUATION
│
├─ natural signs → strong/long shaking; abnormal sea change; ocean roar
├─ near source → self-evacuate without waiting
├─ horizontal → reachable safe inland/high ground
├─ vertical → engineered + designated + accessible refuge
└─ first wave may not be largest → await authorised all-clear

7. LAYERED PROTECTION
│
├─ engineered → shelters / retrofit / wall / breakwater / barrier
├─ ecosystem → dune / mangrove / forest / reef / bio-shield
└─ portfolio chosen by local morphology, exposure and residual risk

LIMITS
├─ wall → overtopping / scour / maintenance / transferred erosion
├─ buffer → condition / width / location / event-scale dependence
└─ neither replaces warning, evacuation or safe siting

8. PEOPLE + ECONOMY
│
├─ fishers → at-sea communication + boats/landing sites/markets
├─ ports → shutdown + hazardous cargo + channel/reopening plan
├─ tourists → multilingual signs + unfamiliar-route support
├─ islands → medical/supply redundancy
└─ disability/age/patients → assisted evacuation

9. READINESS + RECOVERY
│
├─ Tsunami Ready = community performance recognition
│  └─ Venkatraipur + Noliasahi, Odisha; 7 August 2020
├─ renewal/drills counter low-frequency readiness decay
├─ response → rescue + health + water + shelter + service restoration
└─ Build Back Better → safer siting without livelihood-blind relocation

10. PYQ ROUTE
│
├─ 2025 GS-I Q7 — SHARED
│  └─ definition → formation → shoaling → consequences → example
├─ 2023 GS-I Q14 — SHARED
│  └─ coastal potential ↔ preparedness chain
├─ 2024 GS-III Q17 — APPLICATION
│  └─ warning + land use + buffers + evacuation + recovery
└─ 2026 Prelims Q23 — APPLICATION
   └─ mangrove bio-shield + livelihood; local key provisional D

ANSWER SPINE
source → coast transformation → exposure/vulnerability
→ ITEWC assessment → local action → mapping/CRZ
→ layered protection → inclusive evacuation → BBB

QUALIFIED CONCLUSION
└─ ITEWC is the technical backbone; resilience is proved only when
   warnings become accessible evacuation, continuity and safer recovery.
```
