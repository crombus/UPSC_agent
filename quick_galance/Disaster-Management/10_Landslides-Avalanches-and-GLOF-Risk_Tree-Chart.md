# Disaster Management 10 — Landslides, Avalanches and GLOF Risk

```text
CENTRAL THESIS
│
└─ mountain disaster risk = hazard × exposure × vulnerability ÷ capacity
   → identify the exact moving material/process
   → separate conditioning factors from triggers
   → connect mapping/monitoring to authorised action
   → manage cascades and rebuild away from repeated exposure

1. RISK GRAMMAR
│
├─ conditioning factor = persistent predisposition
│  geology · slope · weathering · drainage · land cover
│  toe condition · old failure · cutting/loading/spoil
├─ trigger = initiating change
│  intense/prolonged rain · earthquake · snowmelt/freeze-thaw
│  snow loading/warming · erosion · excavation/vibration
├─ susceptibility → WHERE relatively likely
├─ hazard → probability/frequency/magnitude/time
├─ exposure → people/assets in path
├─ vulnerability → propensity to suffer
└─ capacity → anticipate/withstand/evacuate/respond/recover

TRAP → rainfall is not the whole cause; map colour is not risk by itself

2. HAZARD TAXONOMY
│
├─ landslide → rock/debris/earth downslope under gravity
├─ rockfall → detached rock falls/bounces/rolls
├─ debris flow → rapid water-rich sediment mixture
├─ avalanche → unstable snow/ice mass; release → track → runout
├─ GLOF → sudden release from naturally dammed glacial lake
└─ cloudburst → local intense rainfall; possible trigger, not mass movement

3. LANDSLIDE FAILURE ENGINE
│
├─ infiltration → pore pressure ↑ → effective resistance ↓
├─ toe cutting/erosion → support ↓
├─ loading/vibration → driving stress ↑
└─ shear stress > shear strength → fall/topple/slide/spread/flow

4. REGIONAL DIFFERENTIATION
│
├─ HIMALAYA
│  young · fractured · seismic · high relief
│  rain/cloudburst · snowmelt/freeze-thaw
│  roads/tunnels/hydropower/tourism · narrow corridors
└─ WESTERN GHATS/NILGIRIS
   old but deeply weathered steep slopes
   intense monsoon saturation · toe erosion
   quarrying/roads/deforestation/settlement change

QUALIFICATION → neither region is uniform; use site evidence
SOURCE-PERIOD → ≥15% land-area estimate; mining/subsidence State list
                must not be presented as a current safety map

5. ZONATION → DECISION
│
├─ inventory + terrain/land-use factors → susceptibility
├─ + trigger probability/intensity/time → hazard
├─ + exposure/vulnerability/capacity → risk
└─ decisions:
   avoid/condition development · investigate site · align route
   drainage/slope treatment · monitor · evacuate · protect lifelines

TRAP → 1:50,000 planning map ≠ individual-site clearance

6. AVALANCHE
│
├─ weak layer/slab + slope + snow-weather trigger
├─ typical release range ~30°–45°; not absolute
├─ zoning = release area + track + runout
├─ forecast = current snowpack/weather danger
├─ DGRE (DRDO) → specialist bulletin
└─ actions → seasonal siting · route closure · shelters
             snow fence/deflection where designed · rescue plan

TRAP → bulletin ≠ every slope safe/unsafe; DGRE ≠ civil evacuation authority

7. GLOF SYSTEM
│
├─ glacier change → lake formation/expansion
│  black-carbon heating = possible general melt factor, not event attribution
├─ moraine/ice/bedrock/other natural dam
├─ trigger:
│  slope/ice entry · overtopping wave · degradation/seepage
│  earthquake · outlet change/blockage
├─ breach → water + sediment + ice
└─ downstream erosion/debris bulking → bridges/dams/settlements

MONITORING CHAIN
satellite inventory/change (ISRO/NRSC)
→ field dam/slope/bathymetry assessment
→ instruments + scenarios
→ warning threshold + authority
→ redundant message + evacuation/drill

TRAP → expanding lake = screening signal, not imminent-failure proof

8. GLOF MITIGATION
│
├─ dynamic inventory + prioritisation
├─ inundation/runout maps
├─ controlled lowering/outlet/protective work — site-specific
├─ safe sites/routes + community warning
└─ response/recovery with residual-hazard reassessment

STATUS
├─ NDMA GLOF Guidelines — Oct 2020
├─ NGRMP — ₹150 crore; 4 Himalayan States
└─ 195 high-risk lakes — official list dated 4 Dec 2024; dynamic

9. CLOUDBURST / COMPOUND EVENT
│
├─ local extreme rainfall; canonical benchmark ~10 cm/hour over ~20–30 sq km
├─ tiny space/time scale → precise prediction difficult
└─ rain → runoff/flash flood + saturation/slide/debris flow
   → possible blockage and later breach

10. MOUNTAIN DEVELOPMENT
│
├─ roads → connectivity/rescue BUT cut slope/drainage/spoil risk
├─ hydropower → energy BUT valley/cascade exposure
├─ tourism → livelihoods BUT seasonal crowd/load/waste
└─ answer → cumulative basin/corridor assessment
            carrying capacity · safe siting/design · maintenance
            alternative access · operator + district emergency plans

TRAP → neither “all development causes disaster” nor “engineering removes risk”

11. INSTITUTIONAL MAP
│
├─ GSI/NLFC → landslide science, mapping, forecast development
│  Bhukosh (mapped data) · Bhusanket (forecast portal)
│  · Bhooskhalan (mobile dissemination/crowdsourcing)
├─ DGRE/DRDO → avalanche science and warnings
├─ ISRO/NRSC → remote-sensing inputs, including glacial lakes
├─ IMD → weather/rainfall information
├─ NDMA/MHA → national guidance/programme
├─ State/SDMA + district/DDMA/local administration → protective action
└─ project authority/operator → lifecycle safety + emergency duty

12. COMPLETE CYCLE
│
├─ prevent/avoid → no-build/conditional siting
├─ mitigate → drainage · stabilisation · bioengineering · protection
├─ prepare → thresholds · closure/evacuation · drills · redundancy
├─ respond → incident command · scene safety · SAR · triage
├─ relieve → shelter/water/health/access
└─ recover/BBB → reassess · restore · relocate/redesign · learn

13. WARNING + EVIDENCE LADDER
│
└─ observe → analyse → forecast/warn → authorised decision
   → disseminate → receive/understand → act → safe destination
   → review lead time/miss/false alarm/loss

EVIDENCE FIREWALL
├─ map exists ≠ site safe
├─ portal/app exists ≠ warning received
├─ experimental ≠ operational service
├─ warning issued ≠ evacuation completed
├─ allocation ≠ release/expenditure
└─ activity/output ≠ reduced loss/outcome

14. PYQ ROUTES
│
├─ DIRECT
│  2019 GS-III Q18 → zonation as mitigation
│  2021 GS-I Q4 → Himalaya vs Western Ghats
│  2021 GS-III Q18 → causes/effects/NLRMS
│  2026 GS-III Q7 → infrastructure–DRR contradiction
├─ SHARED
│  2022 GS-III Q8 + 2024 GS-I Q6 → cloudburst
└─ APPLICATION
   2020 GS-I Q6 → glacier-water/GLOF link
   2025 GS-III Q17 → mining slope/subsidence link

ANSWER SPINE
define exact hazard → condition vs trigger
→ map hazard/exposure/vulnerability/capacity
→ institution + full DM cycle
→ warning/evidence limit → development/equity trade-off
→ measurable recovery and qualified conclusion

FINAL VERDICT
└─ hazard-specific science + integrated cascade governance;
   information becomes resilience only when it changes authorised,
   inclusive action and safer reconstruction.
```
