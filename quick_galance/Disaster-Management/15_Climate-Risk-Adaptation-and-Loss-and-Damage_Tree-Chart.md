# Disaster Management 15 — Climate Risk, Adaptation and Loss and Damage

```text
CENTRAL THESIS
└─ climate-disaster governance = attribute carefully
   + reduce future hazard + lower present vulnerability
   + protect residual risk + fairly address realised harm

1. RISK ≠ CLIMATE SIGNAL ALONE
├─ hazard × exposure × vulnerability ÷ capacity
├─ trend attribution → long-term hazard change
├─ event attribution → likelihood/intensity of one event
└─ loss attribution → hazard + exposure + vulnerability + response
   TRAP: climate influence ≠ sole cause of every disaster/loss

2. TWO RISK CLOCKS
├─ slow onset → drought · desertification · soil degradation · climate change
│  └─ monitor trend → thresholds → early livelihood/water support
└─ rapid onset → forecast/warn → anticipatory action/evacuation

3. POLICY BOUNDARIES
├─ mitigation → reduce future GHG-driven change
├─ adaptation → adjust to actual/expected climate impact
├─ DRR → manage climatic + non-climatic disaster risk
└─ response/recovery → manage residual realised event

4. ADAPTATION PATHWAYS
├─ incremental → improve existing system
├─ transformational → change land use/livelihood/settlement/governance
├─ maladaptation → shifts/increases risk, emissions, inequality or lock-in
└─ limits
   ├─ soft → finance/technology/institutions/knowledge may overcome
   └─ hard → adaptation cannot avoid loss within system considered

5. AVOID–MINIMISE–ADDRESS
├─ avert → mitigation
├─ minimise → adaptation + DRR + anticipatory action
└─ address → residual/realised loss: protection + recovery + support
   TRAP: loss and damage ≠ every relief payment or adaptation project

6. LOSS TYPES
├─ economic → assets · output · income; state baseline/method
└─ non-economic → life · health · culture · identity · territory
   · biodiversity · social cohesion; money may be inadequate

7. INTERNATIONAL ARCHITECTURE
├─ WIM → COP19, 2013
│  └─ knowledge → coordination → action/support
├─ Paris Agreement Art.8 → avert/minimise/address
├─ Suva Expert Dialogue → COP23; dialogue/expertise
├─ Santiago Network → technical-assistance architecture
└─ FRLD → established COP27; operationalised COP28
   └─ status ≠ access ≠ approval ≠ disbursement ≠ outcome

8. INDIA PLAN LADDER
├─ NAPCC 2008 → eight original missions; umbrella
├─ SAPCCs → State/UT contextual plans; versions/delivery vary
├─ Initial Adaptation Communication → 2023 instrument
└─ stand-alone NAP process
   ├─ MoEFCC Adaptation Cell: Aug 2024
   └─ NAP Central check 27 Sep 2026: India not listed as submitted
      TRAP: process ≠ approved/submitted/implemented NAP

9. DELIVERY
└─ risk/projection → local diagnosis → choice/plan → budget
   → delivery/maintenance → reduced vulnerability → review

CLIMATE SERVICE
└─ data/model + co-design + usable threshold/message + feedback/action
   TRAP: projection/app alone ≠ service/outcome

LOCALLY LED ADAPTATION
└─ meaningful local power + predictable resources + information
   + accountability; consultation alone ≠ leadership

10. ECO-DRR
├─ mangroves · wetlands · dunes · reefs · catchment treatment
├─ hazard buffer + livelihood + carbon co-benefit
└─ Assam: ₹519.04 crore NDMF, 24 wetlands, sanctioned 2 Dec 2025
   TRAP: sanction ≠ restored ecosystem/avoided loss

11. DISPLACEMENT + JUSTICE
├─ temporary/prolonged · internal/cross-border · planned/forced
├─ not automatically a 1951 Convention refugee
├─ rights → evacuation · documents · housing · health · GBV protection
│  · education · livelihoods · hosts · return/integration/relocation
└─ equal hazard ≠ equal harm: capacity and wealth differ

12. FINANCE/OUTCOME FIREWALL
└─ pledge → deposit → commitment → approval → receipt → delivery
   → vulnerability reduced / loss addressed / durable outcome

PYQ ROUTES
├─ APPLICATION 2024 GS-III Q18 → attribution + urban adaptation
├─ SHARED 2024 GS-III Q17 → resilience/residual risk; Topic 01 owns Sendai
├─ ADJACENT 2025 GS-III Q18 → Paris/NDC; Environment owns details
└─ APPLICATION 2026 GS-III Q7 → adaptation + maladaptation test

ANSWER SPINE
└─ risk/attribution → mitigation/adaptation/DRR
   → pathway + limit → avoid/minimise/address
   → plan/status + local delivery → loss/displacement/finance
   → evidence-qualified justice verdict

FINAL VERDICT
└─ climate justice is proved by timely, accessible and equitable risk
   reduction and support—not by a plan, dialogue, pledge or fund label.
```
