# Disaster Management 13 — Epidemics and Public Health Emergencies

```text
CENTRAL THESIS
│
└─ public-health emergency management =
   route-specific prevention + sensitive surveillance
   + federal/One Health coordination + surge/continuity
   + trusted communication + equitable recovery

1. EPIDEMIOLOGICAL LABELS
│
├─ outbreak → above expected in defined place/group/time
├─ epidemic → above expected in community/region
├─ pandemic → wide international spread; NOT severity by itself
├─ endemic → usual/persistent presence; NOT harmless
└─ public-health emergency → coordinated exceptional action

LEGAL/INTERNATIONAL STATUS
├─ domestic emergency ≠ WHO status
├─ PHEIC → extraordinary cross-border risk; WHO DG determination
└─ pandemic emergency → higher alert for qualifying communicable PHEIC

2. RISK ENGINE
│
└─ agent/toxin + reservoir
   → route: water/food · vector · respiratory/contact
             blood/sexual · zoonotic
   → exposure + susceptibility/immunity
   → transmission/severity
   × health-system vulnerability/capacity

3. SURVEILLANCE → ACTION
│
├─ IDSP: Centre + State + District units
├─ S = suspected / health worker
├─ P = presumptive / clinician
├─ L = laboratory confirmed / lab staff
└─ signal → verify/case definition → RRT investigation
   → lab/environment/animal evidence → control/care → feedback

TRAP → dashboard/case count ≠ timely representative surveillance

4. ONE HEALTH
│
├─ human health
├─ animal health
├─ environment/wildlife/food/water
└─ shared risk assessment + coordinated action

EVIDENCE → Surat plague 1994 + avian influenza 2006:
cross-sector coordination is a recurring lesson

5. PREVENTION / MITIGATION
│
├─ WASH + food safety
├─ vector surveillance/control
├─ vaccination + coverage-gap detection
├─ ventilation/hygiene/IPC
├─ zoonotic biosecurity
└─ post-disaster shelter/waste/carcass management

TRAP → intervention must match transmission route

6. PREPAREDNESS
│
├─ workforce + RRT/lab training
├─ sample transport + quality + referral
├─ staffed beds/oxygen/medicines/PPE
├─ stock forecasting + rotation + logistics
├─ essential-care continuity
├─ communication/community plan
└─ exercise → corrective action → retest

7. RESPONSE
│
└─ detect → verify → define cases → investigate
   → control source/transmission → isolate cases
   → quarantine exposed where lawful/appropriate
   → clinical surge + worker protection
   → communicate → monitor → adapt

8. FEDERAL AUTHORITY
│
├─ State List Entry 6 → public health/sanitation; State service lead
├─ Concurrent List Entry 29 → prevent interstate spread
├─ Concurrent List Entry 23 → canonical general DM Act basis
├─ MoHFW → national policy/advisory/coordination
├─ NCDC/IDSP → surveillance/technical/RRT architecture
├─ ICMR/labs → research/diagnostics within mandate
├─ district/local → investigation/WASH/vector/care/action
└─ MHA/NDMA → general disaster coordination when lawfully invoked
   MHA → source-identified nodal ministry for biological-warfare consequences

9. LAW + COVID STATUS
│
├─ Epidemic Diseases Act 1897 remains on India Code
│  └─ 2020 amendment = statutory healthcare-worker protection
├─ DM Act 2005 used for nationwide COVID coordination
└─ MHA March 2022 → no further COVID-specific DM Act
   containment orders after expiry

CORE TRAP → temporary lockdown/order ≠ permanent public-health law

10. RISK COMMUNICATION
│
├─ known + uncertain + changing
├─ audience/place-specific action + next update
├─ trusted local messengers + accessible formats
├─ two-way feedback + rumour correction
├─ privacy + anti-stigma
└─ outcome = understood/protective action, not posts issued

11. CONTINUITY + EQUITY
│
├─ preserve emergency/maternal/child/chronic/mental-health care
├─ migrant/informal worker income, food, transport and shelter
├─ disability/age/language/digital access
├─ health-worker PPE, rest, support and fair deployment
└─ restrictions: lawful · necessary · proportionate · time-limited · reviewed

12. TECHNOLOGY BY FUNCTION
│
├─ RT-PCR/labs → diagnosis
├─ IDSP/IHIP/dashboard → surveillance
├─ Aarogya Setu → COVID contact/risk tool
├─ telemedicine → selected continuity
├─ logistics systems → beds/oxygen/supplies
└─ CoWIN → vaccine-phase delivery

TRAP → app/platform ≠ data quality/access/action/outcome

13. RECOVERY
│
└─ recurrence/sequelae surveillance
   → deferred-care backlog + routine services
   → workforce + mental health + education/livelihoods
   → after-action review → law/plan/lab/supply reform

14. INTERNATIONAL FRAMEWORK
│
├─ amended IHR in force 19 Sep 2025 for applicable States Parties
├─ National IHR Authorities + pandemic-emergency alert
├─ WHO cannot compel domestic lockdown/law
├─ Pandemic Agreement adopted 20 May 2025
├─ PABS annex still under negotiation 18 Sep 2026
└─ not yet open for signature/in force; 60 ratifications required later

HEPR (WHA78, May 2025)
└─ international systems benchmark; not proof of national implementation

15. ACTIVITY → OUTCOME FIREWALL
│
├─ reports received ≠ representative data
├─ test performed ≠ timely result/action
├─ app download ≠ equitable access
├─ order issued ≠ lawful/proportionate outcome
├─ bed announced ≠ staffed functioning bed
└─ cases fall ≠ one measure proved causal

BEST METRICS
signal-to-verification · lab turnaround · RRT action
health-worker safety · service continuity · equity
avoidable morbidity/mortality · backlog + livelihood recovery

16. PYQ ROUTES
│
├─ DIRECT 2020 GS-III Q15 → technology in COVID management
├─ SHARED 2020 GS-II Q9 → WHO/global health security
├─ SHARED 2026 GS-III Q18 → community participation
└─ APPLICATION
   2020 GS-III Q18 → proactive DM
   2023 Prelims Q75 → curative/preventive + State role
   2024 GS-III Q17 → resilience

ANSWER SPINE
define label/status → route and risk
→ surveillance/lab/RRT → authority + One Health
→ proportionate control + surge/continuity
→ communication/equity → recovery/evidence limits

FINAL VERDICT
└─ institutionalise durable health capacity between crises;
   do not preserve temporary coercive measures as permanent law.
```
