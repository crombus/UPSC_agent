# Disaster Management 08 — Riverine Floods and Urban Flood Resilience

```text
CENTRAL THESIS
│
└─ follow the water pathway:
   catchment → river/reservoir → floodplain → city drainage → household

1. FLOOD TAXONOMY
│
├─ riverine → discharge exceeds channel/floodplain capacity
├─ flash → rapid runoff or sudden release; short lead
├─ urban/pluvial → runoff exceeds built-catchment storage/drainage
├─ coastal → surge/tide/waves/tsunami impede or inundate
└─ dam-break → uncontrolled release after loss of safe control

TRAP → urban flood ≠ river flood merely located in a city

2. RIVERINE CHAIN
│
├─ catchment rain / snowmelt / tributary inflow
├─ soil saturation + runoff + sediment
├─ channel capacity + floodplain/wetland storage
├─ dam / barrage / embankment operation
└─ level rise → inundation / erosion / service loss

BASIN GOVERNANCE
├─ upstream land/forest/soil
├─ tributary + main-river data
├─ reservoir rule curves
├─ downstream warning
└─ China / Nepal / Bhutan data dimension

3. URBAN AMPLIFICATION
│
├─ impervious cover → infiltration ↓
├─ wetland/lake/waterway loss → storage ↓
├─ undersized/disconnected drain → conveyance ↓
├─ silt + solid waste → blockage
├─ floodplain/basement occupation → exposure ↑
└─ river backwater / tide / release → compound flood

SOURCE-PERIOD RELATION
└─ urban peak 1.8–8×; volume up to 6×
   → illustrative, not universal design constant

4. FORECAST CHAIN
│
├─ IMD → rainfall
├─ CWC → river level/discharge + reservoir inflow
├─ April 2026 network → 350 stations
│  ├─ 200 level forecast
│  └─ 150 inflow forecast
├─ Warning Level → Danger Level → HFL
│  └─ site-specific, not national depth
└─ forecast → official warning → local action → verified outcome

5. LAND + WATER STORAGE
│
├─ floodplain zoning → exposure control
├─ flood proofing → raised platform / water facility / safe upper storey
├─ wetlands/lakes → store + delay runoff
├─ blue-green corridor → preserve flow and ecology
└─ housing/tenure support → equitable enforcement

6. URBAN DRAINAGE
│
├─ inventory drains / contours / inlets / outfalls
├─ catchment-based capacity and connectivity
├─ desilt + remove solid waste
├─ separate/coordinate sewage and storm water
├─ detention / retention / permeable surface
└─ account for river and tidal backwater

TRAP → wider drain alone can transfer peak downstream

7. STRUCTURAL PORTFOLIO
│
├─ reservoir → finite flood storage
├─ embankment → breach / overtopping / drainage congestion
├─ channel work → sediment/ecology/downstream effects
├─ diversion → capacity + receiving-area risk
└─ catchment treatment → slower runoff; long horizon

DAMODAR LESSON → dams may not control every flood

8. DAM / RESERVOIR GOVERNANCE
│
├─ dam = storage; barrage = regulation/diversion
├─ inflow forecast + level + rule curve
├─ release decision + downstream warning + monitoring
├─ controlled release ≠ dam failure
└─ Dam Safety Act 2021
   └─ surveillance / inspection / O&M / EAP

FAILURE CAUSES
├─ overtopping / spillway capacity
├─ structural / foundation / seepage-piping
├─ gate / operation / maintenance
└─ earthquake / reservoir landslide / external trigger

9. URBAN INSTITUTIONS
│
├─ NDMA Urban Flood Guidelines 2010
├─ Urban Flooding Cell → recommendation, not assumed body
├─ ULB → local drainage and action
├─ EOC / IRS → response coordination
├─ Aapda Mitra → source-period volunteer design
└─ UFRMP / NDMF → sanction ≠ completion

10. CASE EVIDENCE
│
├─ Mumbai 2005 → intense rain + low/reclaimed land + drainage/waste
├─ Chennai 2015 → NE-monsoon/cyclone rain + wetlands/waterways/drainage
├─ Delhi 2023 → upstream flow + barrage + floodplain + urban systems
├─ Uttarakhand 2013 / Amarnath 2022 → cloudburst/flash application
└─ Machhu II 1979 / Panshet 1961 → dam-failure application

11. PYQ ROUTES
│
├─ 2020 GS-I Q15 → DIRECT urban causes + lasting remedies
├─ 2022 GS-III Q8 → DIRECT cloudburst mechanism + two examples
├─ 2023 GS-III Q7 → DIRECT dam failures + two examples
└─ 2024 GS-III Q18 → DIRECT causes + two floods + frameworks

ANSWER SPINE
classify flood → trace water pathway → identify exposure/vulnerability
→ forecast/authority → zoning/storage/drainage/structures
→ inclusive action → recovery → measured risk reduction

QUALIFIED CONCLUSION
└─ flood resilience requires basin-city coordination;
   maps, dams, drains and sanctions are inputs until outcomes are verified.
```
