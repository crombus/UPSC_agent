# Disaster Management 03 — Community-Based DRR and Inclusive Protection

```text
CENTRAL THESIS
│
├─ community = first exposed + locally informed + often first to act
├─ CBDRR = participation in risk assessment, planning, action and review
└─ participation supplements; never replaces State responsibility

1. CO-PRODUCTION
│
├─ COMMUNITY CONTRIBUTES
│  ├─ routes / households / trust / lived experience
│  ├─ local resources / skills / social networks
│  └─ warning relay / mutual aid / feedback
│
├─ FORMAL SYSTEM CONTRIBUTES
│  ├─ science / forecast / engineering standards
│  ├─ legal authority / finance / logistics
│  └─ professional rescue / health / protection
│
└─ JOIN → technically sound + locally actionable plan

TRAP → local knowledge ≠ complete scientific proof
TRAP → consultation ≠ shared decision-making

2. PARTICIPATORY RISK ASSESSMENT
│
├─ hazard calendar
│  └─ season / onset / frequency / duration / warning time
├─ social-resource map
│  └─ homes / schools / health / water / livestock / vehicles
├─ vulnerability register
│  └─ mobility / medicine / language / documents / care
├─ capacity map
│  └─ volunteers / boats / first aid / shelters / SHGs
├─ route-shelter plan
└─ drill → feedback → update

3. ROLE CHAIN
│
├─ BEFORE
│  ├─ awareness / mapping / training / drills
│  └─ household assistance + shelter planning
├─ DURING
│  ├─ authorised warning relay
│  ├─ bounded rescue / first aid / mutual aid
│  └─ assisted evacuation + unmet-needs report
└─ AFTER
   ├─ damage/needs verification
   ├─ relief accountability
   ├─ psychosocial support
   └─ livelihood-sensitive safer recovery

ROLE TEST
└─ actor + task + trigger + training + command link + safeguard

4. INSTITUTIONAL BRIDGE
│
├─ SDMA / State departments
│       ↓
├─ DDMA
│       ↓
├─ PRI / ULB
│       ↓
└─ SHG / CBO / NGO / youth / local leader / household

LOCALISATION RISKS
├─ elite capture
├─ exclusion / gatekeeping
├─ misinformation
└─ unfunded transfer of public duty

5. VOLUNTEER SYSTEMS
│
├─ AAPDA MITRA PILOT — 2016
│  ├─ 30 flood-prone districts / 25 States
│  ├─ target 6,000
│  └─ canonical NDMA record: 5,186 trained / 23 project States
│
├─ EXPANDED AAPDA MITRA — official 2024 status
│  ├─ 1,00,000 trained
│  ├─ 350 multi-hazard districts
│  ├─ two-week training
│  ├─ responder kit + five-year insurance
│  └─ district emergency resource reserve
│
└─ YUVA AAPDA MITRA — distinct programme
   ├─ target 2,37,326 youth
   ├─ 315 districts / 28 States
   └─ 1,300 trainers/master trainers

READINESS TEST
└─ headcount → retention → refresher → equipment → activation →
   safe tasking → interoperability → performance

6. VULNERABILITY
│
├─ social → poverty / gender / age / disability / health / exclusion
├─ economic → insecure work / debt / no savings / one livelihood
├─ physical → unsafe house / inaccessible route / fragile services
├─ environmental → degraded protective ecosystems
└─ attitudinal → distrust / fatalism / resistance

INTERSECTIONALITY
└─ overlapping conditions compound risk

EQUALITY ≠ EQUITY
└─ same provision ≠ support needed for comparable safety

7. GROUP-SPECIFIC PROTECTION
│
├─ WOMEN
│  └─ voice / privacy / sanitation / reproductive health /
│     GBV protection / livelihood recovery
├─ CHILDREN
│  └─ age-appropriate warning / family tracing / nutrition /
│     learning / protection from abuse and trafficking
├─ OLDER PERSONS
│  └─ mobility / medicine / caregiver / isolation register
├─ PERSONS WITH DISABILITIES
│  ├─ RPwD Act 2016, s. 8 → equal protection and safety
│  └─ accessible warning / assisted evacuation / barrier-free shelter
├─ MIGRANTS / DISPLACED
│  └─ language / documents / tenure / work / relief visibility
└─ ANIMALS / LIVELIHOODS
   └─ evacuation and shelter where safety/recovery depends on them

LEGAL TRAP
└─ disaster displacement alone ≠ automatic 1951 Convention refugee status
   ≠ absence of all rights

8. WARNING → RECOVERY
│
├─ issue
├─ receive
├─ understand
├─ trust
├─ act
├─ reach accessible transport/route
├─ remain safe in dignified shelter
├─ receive fair relief
└─ recover services + livelihood + agency

TRAPS
├─ alert sent ≠ alert acted upon
├─ evacuated ≠ protected
├─ relief distributed ≠ every eligible person received it
└─ rebuilt ≠ Build Back Better

9. RELIEF ACCOUNTABILITY
│
├─ public criteria
├─ multi-source verification
├─ privacy for sensitive data
├─ accessible/offline appeal
├─ time-bound correction
└─ social audit

10. NAMED POLICY ANCHORS
│
├─ CBDRR Guidelines — Oct 2024
├─ Disability Inclusive DRR — Sep 2019
├─ Temporary Shelters — Sep 2019
├─ Updated MHPSS — Dec 2023
└─ Animal-inclusive DRR — Apr 2026

11. PYQ ROUTES
│
├─ 2026 GS-III Q18 — DIRECT
│  └─ cornerstone + examples + challenges + strengthening
├─ 2019 GS-III Q8 — SHARED/APPLICATION
│  └─ vulnerability types + differentiated protection
├─ 2020 GS-III Q18 — APPLICATION
│  └─ community preparedness operationalises proactive DM
└─ 2024 GS-III Q17 — APPLICATION
   └─ local knowledge + inclusion + social capacity = resilience elements

ANSWER SPINE
define CBDRR
→ map local risk/capacity
→ assign before/during/after roles
→ name institutions/programme
→ disaggregate vulnerable groups
→ trace warning-to-recovery protection
→ test participation and outcome

QUALIFIED CONCLUSION
└─ Community participation becomes resilience only when representative,
   trained, resourced, safe, formally connected and publicly accountable.
```
