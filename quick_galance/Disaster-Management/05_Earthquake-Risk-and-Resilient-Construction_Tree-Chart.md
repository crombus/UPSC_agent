# Disaster Management 05 — Earthquake Risk and Resilient Construction

```text
CENTRAL THESIS
│
├─ earthquake rupture cannot be prevented or precisely predicted
└─ therefore reduce exposure + constructed vulnerability + service failure

1. HAZARD MECHANISM
│
├─ plate motion
├─ stress accumulates at fault
├─ rupture releases energy
└─ seismic waves → ground shaking

DISASTER RESULT
└─ hazard × exposure × vulnerability ÷ capacity

2. MEASUREMENT
│
├─ MAGNITUDE
│  ├─ source energy
│  └─ large events commonly reported as Mw
├─ INTENSITY
│  ├─ observed effects at a place
│  └─ MMI / MSK
├─ P-WAVE
│  ├─ faster / arrives first
│  └─ particle motion parallel to propagation
└─ S-WAVE
   ├─ slower
   └─ transverse; does not pass through liquids

TRAP → magnitude ≠ intensity

3. INDIA’S SEISMIC SETTING
│
├─ Indian–Eurasian convergence
│  └─ canonical rate ≈5 cm/year
├─ Alpine-Himalayan belt
│  └─ canonical frame: 14 highly prone States
├─ Kachchh / Gulf of Khambhat
├─ peninsular seismic areas
├─ Lakshadweep
└─ Andaman-Nicobar

OPERATIVE ZONING
├─ IS 1893 (Part 1): 2016
├─ Zones II / III / IV / V
├─ Zone V = highest hazard
├─ dated 2021 shares
│  └─ V ~11% / IV ~18% / III ~30% → III–V ~59%
└─ proposed revision withdrawn March 2026

TRAPS
├─ zone ≠ forecast
└─ regional zone ≠ individual-building safety

4. SCALE OF ASSESSMENT
│
├─ zoning → broad regional design hazard
├─ microzonation → soil / rock / slope / groundwater / built form
├─ site investigation → project-specific input
└─ building assessment → actual design/material/detail/condition

5. CONSTRUCTED VULNERABILITY
│
├─ unsafe siting
├─ irregular configuration
├─ broken load path / weak lateral resistance
├─ poor connections / brittle behaviour
├─ deficient materials / workmanship
├─ unauthorised alteration
├─ weak inspection / maintenance
└─ unanchored non-structural components

CLAIM
└─ earthquake mortality often expresses construction-governance failure

6. NDMA SIX PILLARS
│
├─ 1 safe new construction
├─ 2 selective retrofit of priority/lifeline structures
├─ 3 regulation and enforcement
├─ 4 awareness and preparedness
├─ 5 capacity development
└─ 6 emergency response

SYSTEM RULE
└─ pillars are linked; one cannot compensate fully for a broken neighbour

7. RESILIENT NEW CONSTRUCTION
│
├─ suitable site/foundation
├─ regular configuration
├─ continuous load path
├─ lateral resistance
├─ ductile detailing
├─ materials + workmanship
├─ inspection + maintenance
└─ anchored contents / utilities

❌ “earthquake-proof”
✅ designed for specified seismic performance

8. EXISTING-STOCK RETROFIT
│
├─ inventory
├─ rapid screening
├─ detailed assessment
├─ risk-based priority
├─ design + finance + occupant plan
├─ execution + quality control
└─ completion verification + maintenance

STATE PRIORITY EXAMPLES
├─ Raj Bhavans / legislatures / courts
├─ schools / academic institutions
├─ hospitals and public utilities
├─ dams / reservoirs
└─ buildings of five or more storeys

TRAP → listed / audited / sanctioned ≠ retrofitted

9. STRUCTURAL ↔ NON-STRUCTURAL
│
├─ structural
│  └─ frame / walls / foundation / load path
└─ non-structural
   └─ ceilings / parapets / tanks / equipment / utilities

LIFELINE TEST
└─ standing building + failed power/water/access
   = non-collapse, not full resilience

10. GOVERNANCE CHAIN
│
├─ BIS / NBC → standards
├─ NDMA → earthquake and retrofit guidance
├─ NCS / MoES → monitoring + event information
├─ BMTPC → construction promotion + Vulnerability Atlas
├─ Central ministries → structures under their control
├─ States → enforcement + priority-structure identification
├─ ULB / PRI → local regulation and implementation
└─ professionals / masons → design and construction quality

COMPLIANCE EQUATION
code × adoption × design × workmanship × inspection × maintenance
= real safety

11. CURRENT MONITORING STATUS
│
├─ NSN → 174 observatories, 13 Aug 2026
│  └─ supersedes 170-observatory snapshot of 1 Apr 2026
├─ BhooKamp → rapid detected-event information
└─ earthquake early warning
   ├─ P-wave detection after rupture
   ├─ possible few-second lead depending on distance
   └─ NCS development = pilot phase

❌ EEW ≠ prediction
❌ pilot ≠ nationwide operational coverage

12. EQUITY
│
├─ informal / owner-built housing
├─ weak access to engineers and permits
├─ limited retrofit credit / insurance
├─ tenure and relocation constraints
└─ enforcement without assistance may deepen vulnerability

13. HISTORICAL USE
│
├─ Latur 1993 → peninsular risk + rural masonry vulnerability
├─ Bhuj 2001 → Kachchh + built/lifeline disruption
└─ Koyna → Peninsula is not aseismic

RULE → do not add casualty/magnitude/cause without event source

14. PYQ ROUTES
│
├─ 2021 GS-III Q8 — DIRECT
│  └─ India vulnerability + recent examples + mitigation
├─ 2023 Prelims Q65 — APPLICATION
│  └─ P/S arrival and particle motion; key unavailable, answer inferred
├─ 2019 GS-III Q8 — APPLICATION
│  └─ vulnerability types through seismic risk
└─ 2024 GS-III Q17 — APPLICATION
   └─ retrofit / redundancy / lifeline continuity as resilience

ANSWER SPINE
state prediction limit
→ map Indian hazard
→ add exposure + site/building vulnerability
→ apply six pillars
→ assign institutions and compliance chain
→ prioritise retrofit + lifelines + equity
→ test verified performance

QUALIFIED CONCLUSION
└─ monitoring observes earthquakes;
   enforced construction and prepared systems prevent catastrophe.
```
