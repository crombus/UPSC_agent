# Disaster Management 11 — Forest Fire Risk Management

```text
CENTRAL THESIS
│
└─ fire disaster ≠ hotspot/flame alone
   ignition + fuel/weather/terrain behaviour
   × exposure/vulnerability ÷ capacity
   → prevent → detect → verify → suppress safely
   → recover ecosystem/watershed/livelihood

1. FIRE GRAMMAR
│
├─ hazard → potentially damaging uncontrolled combustion
├─ ignition → heat source that starts combustion
├─ danger rating → conducive potential, not confirmed fire
├─ exposure → people/assets/ecosystems/services in harm's way
└─ vulnerability/capacity → severity and ability to act/recover

2. FIRE TRIANGLE + BEHAVIOUR
│
├─ fuel + oxygen + heat/ignition → combustion
└─ behaviour:
   fuel moisture/load/continuity/vertical arrangement
   + temperature/humidity/wind
   + slope/aspect/access
   → spread · intensity · direction · spotting · persistence

TRAP → triangle explains burning; fuel–weather–terrain explains behaviour

3. FIRE TYPES
│
├─ surface → litter/grass/shrubs; may ladder upward
├─ ground → duff/peat/roots; hidden smouldering; re-ignition
├─ crown → canopy; fast/intense; often surface-supported
└─ spot → ember ignition beyond main front/fire line

4. CAUSES
│
├─ natural ignition → lightning; source-listed natural sparks
├─ deliberate human → shifting cultivation; tendu/fodder flush;
│                    encroachment; concealment of illicit felling
├─ accidental human → escaped residue/camp fire; smoking;
│                    vehicle spark; resin work
└─ spread conditions → dry fuel · wind · heat · low humidity · slope

CAUTION → “>95% human-caused” is document-period, not timeless

5. INDIA RISK EVIDENCE
│
├─ FSI analysis: detected fire points, 2004–2021
├─ 5 km × 5 km grid + forest cover
├─ nearly 10.66% forest cover extremely/very highly fire-prone
└─ use for targeted patrol/crew/fuel work

TRAP → detection frequency ≠ burned area ≠ severity ≠ damage
OLDER SOURCE → 20 districts / 3% land / 44% detections, 2003–2016

6. FSI INFORMATION CHAIN
│
├─ PRE-FIRE
│  Fire Danger Rating / weekly PFA during fire season
│  weather + fuel indices + terrain/type/archive
├─ ACTIVE FIRE
│  MODIS 1 km + SNPP-VIIRS 375 m hotspots
│  NRSC processing → FSI → State users/subscribers
│  local-source FAST 3.0 chain; ~40,000 users = document-period
├─ LARGE FIRE
│  candidate = ≥3 contiguous VIIRS pixels
│  track boundary + possible restart
├─ PORTAL
│  Van Agni 3.0 → single-point viewing
└─ POST-FIRE
   burnt area/severity assessment

CORE LIMIT → alert/pixel/portal ≠ field containment

7. PREVENTION
│
├─ legitimate seasonal resource-use rules
├─ awareness + patrol + rapid reporting
├─ maintained fire line/fuel break — ecologically suitable
├─ hazardous-fuel treatment around critical assets/WUI
├─ water/access/equipment maintenance
├─ enforcement against harmful ignition
└─ prescribed burning ONLY authorised + scientific + trained
   weather/smoke/escape/monitoring safeguards

8. PREPAREDNESS + RESPONSE
│
└─ alert/report → field verify → incident command
   → current fuel/weather/terrain assessment
   → lookout + communications + escape + safety zone
   → direct/indirect containment within capability
   → mop-up + patrol + re-ignition watch + all-clear

9. COMMUNITY
│
├─ local knowledge of paths/water/ignition
├─ co-designed NTFP/pasture/farming practices
├─ paid + trained + insured local crews
├─ women/tribal/pastoral/poor representation
├─ grievance + benefit-sharing + feedback
└─ participation complements, not replaces, State duty

SOURCE CRITIQUE
└─ excluding communities routinely but seeking crisis labour = structural gap

10. IMPACT + ECOLOGICAL TRADE-OFF
│
├─ burns/smoke/evacuation
├─ habitat/regeneration/biodiversity change
├─ soil/runoff/erosion/water damage
├─ carbon + livelihood/service loss
├─ post-fire flood/debris-flow/landslide
└─ effect depends on fire regime:
   ecosystem + season + frequency + intensity + severity

TRAPS
├─ every fire is ecologically harmful — false
└─ every “natural” fire is beneficial — false

11. WILDLAND–URBAN INTERFACE
│
├─ vegetation meets/intermingles with development
├─ control new exposure + defensible critical assets
├─ access/water/evacuation + utility continuity
└─ smoke protection: alerts · clean-air space · vulnerable groups

12. RECOVERY / BUILD BACK BETTER
│
└─ containment → burn-severity/soil/water/livelihood assessment
   → erosion + water protection → natural/native regeneration
   → invasive/re-ignition watch → livelihood restoration
   → update map/fuel/access/command plan

TRAP → planting count ≠ ecological recovery

13. INSTITUTIONAL MAP
│
├─ FSI → national danger/detection/tracking/proneness information
├─ State Forest Departments → prevention, verification, suppression
├─ district/SDMA/support services → escalation, evacuation, health/logistics
├─ NAPFF 2018 → national cycle/community framework
├─ FPM Scheme → Centrally Sponsored support to States/UTs
└─ JFFM/National Master Plan → source-described policy lineage

14. ACTIVITY → OUTCOME FIREWALL
│
├─ alert sent ≠ received/verified
├─ crew deployed ≠ safe/rapid containment
├─ fire line length ≠ effective break
├─ allocation ≠ release/expenditure
├─ extinguished ≠ no ground-fire restart
└─ hectares planted ≠ watershed/ecological/livelihood recovery

BEST METRICS
lead time · verification/arrival · containment · crew injury
WUI/smoke exposure · severity · recurrence · erosion/water
native regeneration · livelihood/service restoration

15. PYQ ROUTES
│
├─ no verified DIRECT forest-fire question
├─ APPLICATION 2020 GS-III Q18 → proactive DM
├─ APPLICATION 2024 GS-III Q17 → resilience framework
└─ SHARED 2026 GS-III Q18 → community participation

ANSWER SPINE
define hazard/type → fire triangle + behaviour
→ ignition and risk geography → prevention + FSI alert chain
→ State/community suppression → ecology/WUI/health
→ recovery → outcome audit

FINAL VERDICT
└─ rapid detection is an asset, not the endpoint;
   resilience requires legitimate fuel governance, safe field capacity
   and measurable ecological and livelihood recovery.
```
