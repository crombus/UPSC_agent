# Disaster Management 01 — Concepts, Risk, Resilience and Sendai

```text
CENTRAL THESIS
│
├─ Hazard = damaging potential
├─ Disaster = serious realised disruption
└─ Risk is socially produced through:
   HAZARD × EXPOSURE × VULNERABILITY ÷ CAPACITY
   └─ heuristic, not universal numerical law

1. RISK GRAMMAR
│
├─ HAZARD
│  ├─ process / phenomenon / human activity
│  ├─ natural: geophysical / hydrological / meteorological /
│  │           climatological / biological
│  ├─ anthropogenic: industrial / chemical / pollution / negligence
│  └─ socio-natural: natural process amplified by human action
│
├─ EXPOSURE
│  └─ people / housing / livelihoods / infrastructure / ecosystems
│     located where hazard may occur
│
├─ VULNERABILITY = susceptibility
│  ├─ physical: siting / construction / lifelines
│  ├─ social: age / disability / health / marginalisation
│  ├─ economic: poverty / insecure livelihoods / weak finance
│  ├─ environmental: degraded wetlands / forests / slopes
│  └─ attitudinal: distrust / fatalism / resistance to preparedness
│
├─ CAPACITY = usable ability
│  ├─ anticipatory
│  ├─ absorptive
│  ├─ adaptive
│  └─ transformative
│
└─ DISASTER THRESHOLD
   └─ disruption exceeds or severely tests coping ability

TRAP → exposure is location; vulnerability is susceptibility;
       capacity is an input; resilience is performance across time.

2. RISK PATTERNS
│
├─ Rapid onset → sudden/acute: earthquake / cyclone / flood / tsunami
├─ Slow onset → months/years: drought / desertification / soil degradation
│
├─ Intensive → high severity + mid/low frequency + concentrated exposure
├─ Extensive → low severity + high frequency + recurrent local loss
└─ Systemic → cascades through interdependent sectors/networks
   power → water → health → telecom → payments

3. RISK TREATMENT
│
├─ Acceptance → knowingly retain consequences
├─ Avoidance → do not undertake risk-generating activity
├─ Reduction → lower likelihood/consequence
└─ Transfer → shift specified financial burden; risk still exists

4. DISASTER-RISK-MANAGEMENT MODES
│
├─ PROSPECTIVE → prevent new risk
│  └─ risk-sensitive land use / safe new infrastructure
├─ CORRECTIVE → reduce existing risk
│  └─ retrofit / relocate already exposed assets
└─ COMPENSATORY → manage residual risk
   └─ preparedness / response / recovery / contingency finance /
      insurance / safety nets

5. MANAGEMENT CYCLE
│
├─ PRE-DISASTER
│  ├─ Prevention → avoid risk
│  ├─ Mitigation → lessen adverse impact
│  └─ Preparedness → plans / warning / training / drills
│
├─ IMPACT
│  └─ Response + relief → life safety / basic needs
│
└─ POST-IMPACT
   ├─ Rehabilitation → restore basic functioning
   ├─ Reconstruction → rebuild assets/systems
   └─ Recovery + BBB → restore/improve and reduce future risk

DRR FIELD
policy/legal framework
→ risk assessment
→ risk awareness
→ implementation
→ early warning
→ knowledge/feedback

6. RESILIENCE
│
├─ resist
├─ absorb
├─ accommodate
├─ adapt
├─ transform
└─ recover while preserving/restoring essential functions

DETERMINATION
│
├─ risk baseline: hazard / exposure / vulnerability / capacity
├─ robustness: withstand stress
├─ redundancy: alternate routes/systems
├─ resourcefulness: mobilise people/information/finance
├─ inclusive preparedness: warning received + understood + acted upon
├─ rapid/equitable recovery: services + livelihoods
└─ adaptation: do not recreate risk

TRAP → plan / budget / warning / membership = input;
       continuity / recovery / reduced loss = outcome.

7. RISK-CREATION LOOP
│
├─ risk-blind development
│  └─ unsafe siting / weak construction / ecosystem loss /
│     infrastructure concentration
├─ exposure + vulnerability accumulate
├─ hazard produces loss
└─ recovery choice
   ├─ rebuild as before → recreated risk
   └─ Build Back Better → safer, inclusive, risk-informed development

8. SENDAI FRAMEWORK 2015–2030
│
├─ adopted: 18 March 2015, Sendai, Japan
├─ successor: Hyogo Framework for Action 2005–2015
├─ status: voluntary + non-binding; NOT a treaty
├─ State has primary responsibility
└─ implementation is shared across levels/stakeholders

FOUR PRIORITIES — CAUSAL ORDER
│
├─ P1 Understand disaster risk
├─ P2 Strengthen risk governance
├─ P3 Invest in DRR for resilience
└─ P4 Preparedness + effective response + Build Back Better

SEVEN TARGETS
│
├─ LOSS / OUTCOME: A–D
│  ├─ A mortality
│  ├─ B affected people
│  ├─ C direct economic loss / global GDP
│  └─ D critical infrastructure + basic-service disruption
│
└─ MEANS / CAPACITY: E–G
   ├─ E national + local DRR strategies — deadline 2020
   ├─ F international cooperation to developing countries
   └─ G multi-hazard warning + risk information — deadline 2030

TRAPS
├─ global targets ≠ binding national quotas
├─ deadline ≠ achievement
└─ strategy/platform ≠ verified loss reduction

9. HYOGO → SENDAI
│
├─ Hyogo: five priorities
│  institution / assessment-warning / knowledge /
│  underlying risk / preparedness
└─ Sendai:
   risk dimensions / governance / investment /
   seven targets / explicit BBB

10. INDIA BRIDGE
│
├─ pre-Sendai: DM Act 2005 + National Policy 2009
├─ post-Sendai: NDMP 2016 → revised NDMP 2019
└─ PM ten-point DRR agenda
   └─ AMCDRR, New Delhi, November 2016

QUALIFICATION → alignment does not prove uniform implementation.

11. CURRENT OFFICIAL ANCHORS
│

├─ EW4All
│  ├─ universal protection aim: end-2027
│  └─ risk knowledge → forecasting → communication → preparedness/action
└─ MCR2030
   ├─ launched 28 October 2020
   └─ Cities Know Better → Plan Better → Implement Better

VOLATILITY RULE

   MCR2030 city counts or city stages without dated official data.
```
