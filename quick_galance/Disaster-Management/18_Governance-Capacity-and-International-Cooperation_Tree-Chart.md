# Disaster Management 18 — Governance, Capacity and International Cooperation

```text
CENTRAL THESIS
└─ cooperation multiplies capacity only when global/national inputs become
   interoperable, inclusive and accountable local performance

1. FIVE GOVERNANCE QUESTIONS
├─ policy → what direction?
├─ governance → who has authority/rules/resources?
├─ coordination → how are actors aligned?
├─ capacity → can they perform?
└─ accountability → who explains and corrects failure?

2. MULTI-LEVEL ARCHITECTURE
└─ Union standards/surge ↔ State plans/resources ↔ district command
   ↔ ULB/PRI/utilities/community ↔ households
   SUBSIDIARITY = local action + higher support, not abandonment

3. WHOLE-OF-SOCIETY
├─ government · community · civil society · volunteers
│  academia · media · private/critical-service operators
└─ participation ≠ dilution of public duty

4. PLAN → CAPABILITY
└─ risk assessment → plan/SOP → named people/authority
   → equipment/finance/data → interoperable communication
   → exercise → correction → maintenance/retest

TRAINING/DRILL TRAPS
├─ attendance ≠ deployable skill
└─ exercise completed ≠ gap corrected

5. INCIDENT COORDINATION
├─ lead/support roles + escalation
├─ shared terminology/contact/data standards
├─ mutual aid + interoperable communications
└─ common picture retains source confidence/uncertainty

6. ACCOUNTABILITY CHAIN
└─ duty → resources/standard → reporting → review
   → grievance → corrective owner/deadline/budget → retest

NPDRR
├─ chaired by Union Home Minister
├─ multi-stakeholder review/appraisal/advice
└─ not a binding direction/enforcement body over States

7. GLOBAL EVOLUTION
├─ Yokohama 1994 → 10 principles
├─ Hyogo 2005–15 → 5 priorities
└─ Sendai 2015–30 → 4 priorities + 7 targets
   ├─ A–D reduce mortality/affected/economic/infrastructure loss
   ├─ E–G increase strategies/cooperation/warning-information
   ├─ E deadline 2020; others 2030
   └─ all voluntary/non-binding

SENDAI REVIEW
└─ 2023 Political Declaration → UNGA resolution 77/289
   TRAP: review/reaffirmation ≠ target achievement

8. INTERNATIONAL MECHANISMS
├─ UNDRR → UN DRR coordination
├─ GPDRR → review + knowledge exchange; not enforcement
├─ UNDAC → requested rapid assessment/information/coordination
├─ INSARAG → requested international USAR standards/coordination
└─ CDRI → infrastructure risk/standards/finance/recovery cooperation

CDRI STATUS
├─ launched 23 Sep 2019; HQ New Delhi; international-organisation status
├─ membership dynamic → avoid unstable snapshot totals
└─ membership/report ≠ resilient assets/outcome

9. EARLY WARNINGS FOR ALL
└─ target end-2027
   ├─ UNDRR → risk knowledge
   ├─ WMO → detection/forecasting
   ├─ ITU → dissemination
   └─ IFRC → preparedness/response
   TRAP: coverage ≠ message understood/acted upon

10. REGIONAL/BILATERAL COOPERATION
├─ SAARC · BIMSTEC · SCO · BRICS · G20 · bilateral routes
├─ outputs → warning/data · training · exercises · mutual aid
└─ historical hosting chronology ≠ current intensity/local outcome

11. HADR / SOVEREIGNTY
├─ offer ≠ automatic access
├─ affected-State request/consent + domestic law
├─ entry/customs/tasking/coordination/handover
├─ national leadership + requested international surge
└─ tactical/security detail → Internal Security boundary

12. LOCALISATION
├─ local leadership + resources + information + voice
├─ international actor → requested surge/expertise/finance
├─ proximity ≠ representation; guard against elite capture
└─ global support → national translation → district capability
   → inclusive local action → measured outcome

13. MEDIA / DIGITAL
├─ benefit → rapid factual communication and coordination
├─ risk → rumour · panic · hacking · outage · exclusion
└─ authoritative briefing + verification + multi-channel fallback

14. EVIDENCE LADDER
└─ agreement/summit/membership → implementation → output
   → deployable capability → event action → changed risk/outcome

PYQ ROUTES
├─ SHARED 2018 GS-III Q18 → India before/after Sendai + Hyogo comparison
├─ SHARED 2024 GS-III Q17 → resilience + Sendai targets
├─ APPLICATION 2020 GS-III Q18 → proactive governance/capacity
└─ SHARED 2026 GS-III Q18 → community/localisation; Topic 03 primary

ANSWER SPINE
└─ define governance gap → assign levels/actors → capability chain
   → framework/mechanism/status → consent/HADR/localisation
   → accountability + output/outcome test → verdict

FINAL VERDICT
└─ international leadership is credible only when it produces maintained,
   inclusive district/community capability and measurable risk reduction.
```
