# Disaster Management 16 — Disaster Finance, Risk Transfer and Build Back Better

```text
CENTRAL THESIS
└─ finance resilience by matching instrument to loss layer and time,
   then proving timely, equitable delivery and lower future risk

1. TIMING
├─ ex-ante → mitigation · preparedness · contingent response/recovery
└─ ex-post → reallocation · grants · borrowing · response funds · appeals
   TRAP: arranged before event ≠ physically risk-reducing

2. FOUR RISK STRATEGIES
├─ accept/retain → reserve/deductible
├─ avoid → no new exposure
├─ reduce → retrofit/ecosystem protection
└─ transfer → insurance/pool/cat bond
   TRAP: financial transfer ≠ physical risk reduction

3. STATUTORY FOUR-FUND GRID
├─ Union response → NDRF fund, s.46
├─ Union mitigation → NDMF, s.47
├─ State response → SDRF, s.48
└─ State mitigation → SDMF, s.48
   ├─ response = eligible immediate post-event need
   ├─ mitigation = ex-ante risk reduction
   └─ NDRF fund ≠ National Disaster Response Force

4. FC16 CURRENT AWARD: 2026–31
├─ State total ₹2,04,401 crore
│  ├─ SDRF ₹1,63,521 crore = 80%
│  └─ SDMF ₹40,880 crore = 20%
├─ national NDRF+NDMF pool ₹79,406 crore
│  └─ 75% NDRF; maximum 25% NDMF
├─ Centre:State → 75:25 generally; 90:10 specified NE/Himalayan
├─ inter-State formula → 70% past expenditure + 30% Risk Index
└─ no SDRF→SDMF transfer; preparedness moves to mitigation window

5. ELIGIBILITY
├─ MHA current list = 14 disasters
│  avalanche · cloudburst · cyclone · drought · earthquake · fire
│  flood · frost/cold wave · hailstorm · heatwave · landslide
│  lightning · pest attack · tsunami
└─ local window → up to 10% SDRF for outside-list State-notified
   natural disasters with norms + SEC approval

6. FINANCE LADDER
├─ relief → immediate life/basic needs
├─ rehabilitation → services/housing/livelihoods
├─ reconstruction → durable assets/systems
└─ BBB → safer location/design/services/institutions/livelihoods

7. RISK LAYERING
├─ frequent/small → retention + reserves
├─ medium → contingent credit + insurance/pool
└─ rare/severe → sovereign/external support + reinsurance/cat bond

8. INSURANCE
├─ indemnity → verified covered loss; slower assessment
├─ parametric → index trigger; rapid
└─ basis risk → payout and actual loss mismatch

9. POOLS / CAT BONDS
├─ pool → diversification; correlation/governance/pricing matter
└─ cat bond → specified severe layer transferred to investors
   TRAP: CDRI names tool; do not assume widespread Indian deployment

10. SOCIAL PROTECTION
└─ scalable cash · food · employment · health · housing
   + inclusive registries/payments + grievance redress
   TRAP: sovereign liquidity ≠ household protection

11. ASSESSMENT
├─ damage → physical destruction
├─ loss → reduced economic flows
└─ needs → resources/reforms for recovery + BBB
   TRAP: one monetary estimate cannot substitute for all three

12. BBB SAFEGUARDS
├─ participation + tenure/livelihood security
├─ accessibility + environment assessment
├─ maintenance finance + safe siting
└─ avoid rushed rebuilding of old vulnerability

13. TRADE-OFFS
├─ federal → SDRF-first; State capacity varies
├─ fiscal → mitigation today vs relief liability tomorrow
├─ incentive → spending weight ≠ risk-reduction reward
├─ equity → risk pricing/deductibles can exclude poor households
└─ debt recovery → shifts cost to future taxpayers

14. TRANSPARENCY / STATUS
├─ 2025 Amendment in force 9 Apr 2025
├─ s.2(da) database includes allocation/expenditure
├─ NDMA s.6(2)(v); SDMA s.18(2)(p)
└─ sanction → release → utilisation → completion → maintenance → outcome

PYQ ROUTES
├─ SHARED 2024 GS-III Q17 → finance + BBB in resilience
├─ APPLICATION 2024 GS-III Q18 → urban mitigation/relief/recovery
├─ APPLICATION 2023 GS-III Q7 → dam safety + downstream recovery
└─ APPLICATION 2026 GS-III Q7 → lifecycle finance/incentives

ANSWER SPINE
└─ loss layer + timing → exact fund/instrument/trigger
   → current award/status → delivery chain → risk layering/equity
   → BBB + outcome/fiscal verdict

FINAL VERDICT
└─ corpus, premium, payout or reconstruction budget is an input;
   resilience requires timely protection, safer recovery and lower liability.
```
