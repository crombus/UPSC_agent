# Disaster Management 14 — Urban and Critical Infrastructure Resilience

```text
CENTRAL THESIS
│
└─ urban resilience = risk-informed growth + interdependent lifeline continuity
   + enforceable lifecycle standards + inclusive, accountable recovery

1. URBAN SYSTEM RISK
├─ hazard × dense exposure × unequal vulnerability ÷ capacity
├─ assets concentrated; services tightly coupled
└─ local damage → cross-system cascade → prolonged disruption

2. WHAT IS CRITICAL?
├─ critical infrastructure → failure has disproportionate consequence
├─ lifelines → water · power · health · transport · telecom · sanitation
├─ criticality → function/consequence, NOT ownership or asset price
└─ dependencies
   ├─ physical → power for pumps/hospitals
   ├─ digital → telecom/control/data
   ├─ geographic → co-located flood exposure
   └─ organisational → one operator delays another

3. RESILIENCE CAPACITIES
├─ robustness → withstand stress
├─ redundancy → spare capacity/alternate route
├─ diversity → different failure mode/location
├─ recovery → restore priority function in planned time
└─ TRAP: co-located/shared-system backups may fail together

4. SERVICE CONTINUITY
└─ priority function → minimum service → priority users
   → backup duration + alternate site/route + manual fallback
   → communication → restoration sequence → exercise/retest

HOSPITAL/EOC TEST
└─ safe structure + power + water + oxygen/supplies
   + telecom + staff/access + referral/repair chain

5. PREVENT NEW RISK
├─ hazard/drainage maps inside development control
├─ protect floodplains, wetlands, water bodies and natural drains
├─ catchment drainage + inlet/waste/maintenance coordination
└─ preserve evacuation and emergency-access routes

6. CODE–DELIVERY CHAIN
└─ standard → adoption → competent design → supervision
   → occupancy control → maintenance → existing-stock retrofit
   TRAP: published code ≠ compliance

7. STATUS LADDER
├─ ULBs · utilities · DDMA · SDMA · regulators → distinct mandates
├─ Urban Flooding Cell → NDMA 2010 recommendation
│  └─ not proof of constitution/current operation
├─ UFRMP → NDMF-financed sanctioned mitigation programme
│  ├─ Phase 2: 11 cities, ₹2,444.42 crore, approved 1 Oct 2025
│  └─ sanction ≠ completion/maintenance/avoided loss
├─ s.41A UDMA → enabling law in force 9 Apr 2025
│  ├─ State may constitute; Delhi/Chandigarh excluded
│  ├─ Municipal Commissioner chair; Collector vice-chair
│  └─ BBMP = Feb 2026 example, not nationwide rollout
└─ CDRI → global risk/standards/finance/BBB cooperation
   ├─ launched 23 Sep 2019; HQ New Delhi
   ├─ membership is dynamic → omit unstable snapshot totals
   └─ membership/publication ≠ domestic command or resilient asset

8. CDRI FOUR AREAS
├─ risk assessment
├─ design/implementation standards
├─ finance and risk-cover mechanisms
└─ reconstruction/recovery: BBB physical + management systems

9. CYBER-PHYSICAL LAYER
├─ sensors/SCADA/platforms improve awareness
├─ risks → power/connectivity/software/vendor/privacy failure
└─ controls → segmentation · least privilege · secure updates
   · interoperability · offline/manual fallback · audit trails

10. CROWD DISASTER
├─ density + force + information + space + time
├─ capacity-linked access · separate flows · holding areas
│  · clear information · emergency access · trained command
├─ main lethal mechanism → compressive asphyxia
└─ NDMA May 2014 document = advisory guide

11. EQUITY
├─ informal settlement → exposure + weak drainage + intermittent service
├─ disability/age/migration/income/medical dependence → access needs
└─ aggregate restoration ≠ equitable restoration;
   risk reduction ≠ summary displacement

12. PROOF LADDER
└─ law/fund/plan → process → delivered capacity → maintained service
   → restoration/equity outcome → impact

PYQ ROUTES
├─ SHARED 2026 GS-III Q7 → infrastructure v DRR: lifecycle governance
├─ SHARED 2024 GS-III Q17 → resilience + Sendai; Topic 01 owns A–G
├─ APPLICATION 2024 GS-III Q18 → urban flood; Topic 08 primary
└─ APPLICATION 2023 GS-III Q7 → dam cascade; Topic 08 primary

ANSWER SPINE
└─ define function → map dependencies → trace cascade
   → plan/code/retrofit/continuity → correct status verb
   → deliver/maintain → measure service + equity → verdict

FINAL VERDICT
└─ resilient city = continued and equitably restored services;
   plans, funds, authorities and smart platforms are inputs only.
```
