# Disaster Management 02 — Indian Legal and Institutional Architecture

```text
CENTRAL THESIS
│
├─ DM Act 2005 = permanent, whole-cycle statutory architecture
├─ Act 10 of 2025 = current institutional/data/plan update
└─ RESULT depends on weakest delivery tier, not apex design alone

1. CHRONOLOGY
│
├─ 1990s → DM Cell, Ministry of Agriculture
├─ 2005 → Disaster Management Act
├─ 2009 → National Policy on Disaster Management
├─ 2016 → first National Disaster Management Plan
├─ 2019 → revised NDMP; latest published plan checked
├─ 29 Mar 2025 → Amendment Act gazetted
└─ 9 Apr 2025 → all 2025-amendment provisions commenced

LEGAL BASIS
├─ no dedicated Seventh Schedule entry for “disaster management”
└─ canonical basis → Concurrent List Entries 23 + 29

2. FUNCTIONAL ARCHITECTURE
│
├─ POLICY / APPROVAL
│  ├─ NDMA — PM
│  └─ SDMA — CM
│
├─ EXECUTIVE COORDINATION
│  ├─ NEC — Union Home Secretary
│  └─ SEC — Chief Secretary
│     └─ State DGP = ex officio member after 2025 amendment
│
├─ LOCAL DELIVERY
│  ├─ DDMA — Collector / DM / DC
│  │  └─ elected local-authority representative = Co-Chair
│  └─ PRIs / municipalities / other local authorities
│
└─ SPECIALIST CAPACITY
   ├─ NDRF force → specialist national response
   └─ NIDM → training / research / documentation / capacity

ADVISORY PLATFORM
└─ NPDRR — Union Home Minister; review + coordination advice
   ❌ not executive command

TRAP
└─ Authority sets/approves ≠ Executive Committee coordinates ≠
   district/local tier delivers

3. NATIONAL TIER
│
├─ NDMA
│  ├─ policy + guidelines
│  ├─ National Plan coordination/approval
│  ├─ technical guidance
│  ├─ national disaster database
│  └─ general superintendence/direction/control of NDRF
│
└─ NEC
   ├─ monitor plans
   ├─ evaluate preparedness
   ├─ coordinate response
   └─ issue directions within statutory mandate

4. STATE → DISTRICT → LOCAL
│
├─ SDMA
│  ├─ State policy
│  ├─ coordinate + approve State Plan
│  └─ State database → national database inputs
│
├─ SEC
│  └─ coordinate / monitor / implement
│
├─ DDMA
│  ├─ District Plan
│  ├─ departments + local-body coordination
│  └─ warning / evacuation / relief / recovery bridge
│
└─ LOCAL AUTHORITIES
   ├─ own plan
   ├─ trained staff + resources
   └─ assigned prevention-to-reconstruction functions

5. 2025 AMENDMENT — EXACT MAP
│
├─ s. 2(da) → disaster database definition
├─ s. 6(2)(v) → NDMA creates national database
├─ s. 18(2)(p) → SDMA maintains State database
├─ s. 8A → NCMC
├─ s. 8B → HLC
├─ s. 41A → Urban DM Authority
├─ s. 44A → State Disaster Response Force
├─ s. 60A → temporary hazard-action order
│  ├─ specified period or 6 months, whichever earlier
│  └─ notified penalty ≤ ₹10,000
└─ s. 76A → NDMA regulations with prior Central approval

❌ No section 9B
❌ NIDM was not abolished

6. ESCALATION
│
├─ NCMC — Cabinet Secretary
│  └─ major disasters with serious/national ramifications
├─ HLC — Union minister in charge of DM
│  └─ s. 46 response assistance + s. 47 mitigation assistance
└─ CCS
   └─ serious security implications

TRAP → NCMC ≠ NDMA ≠ HLC ≠ CCS

7. UDMA / STATE FORCE
│
├─ UDMA, s. 41A
│  ├─ State **may** notify
│  ├─ State capital + Municipal-Corporation cities
│  ├─ excludes Delhi + Chandigarh
│  ├─ Municipal Commissioner = Chair
│  ├─ District Collector = Vice-Chair
│  └─ Urban Plan → SDMA approval → UDMA coordination
│
└─ State Disaster Response Force, s. 44A
   └─ State **may** notify specialist force

STATUS CHECK
└─ MHA, 11 Feb 2026 → only Karnataka’s BBMP UDMA reported
   ≠ nationwide rollout

8. PLAN CYCLES
│
├─ National Plan — NDMA
│  └─ review 3 years / update at least 5 years
├─ State Plan — SDMA
│  └─ review 3 years / update at least 5 years
├─ District Plan — DDMA
│  └─ review at least 2 years or earlier
└─ Urban Plan — constituted UDMA; SDMA approval

9. FORCE / FUND FIREWALL
│
├─ NDRF force → national specialist responders
│  └─ MHA 22 Jul 2025: 16 operational battalions;
│     sanctioned strength 18,581
├─ State force → optional s. 44A institution
├─ NDRF fund → s. 46
├─ NDMF → s. 47
└─ State + district response/mitigation funds → s. 48

TRAP → force ≠ fund

10. FINANCE AND ACCOUNTABILITY
│
├─ 16th FC, 2026–31
│  ├─ State corpus split: SDRF 80 : SDMF 20
│  ├─ allocation uses past expenditure + Disaster Risk Index
│  └─ district funds reported as exception
│
└─ evidence chain
   law → allocation → release → expenditure → output → reduced risk

11. MANDATE–OUTCOME LADDER
│
├─ LAW: section / plan / guideline
├─ STATUS: notified / constituted / approved / allocated
├─ DELIVERY: staffed / trained / spent / exercised / connected
└─ IMPACT: warning acted on / services sustained / loss reduced

❌ mandate ≠ delivery
❌ database duty ≠ complete public database
❌ battalion count ≠ attributable loss reduction

12. PYQ ROUTES
│
├─ 2020 GS-III Q18 — DIRECT
│  └─ relief-only → whole-cycle law/plans/capacity → local gap
├─ 2020 GS-II Q11 — SHARED
│  └─ national coordination ↔ State responsibility/subsidiarity
└─ 2024 GS-III Q18 — APPLICATION
   └─ urban flood → SDMA/DDMA/ULB + current s. 41A UDMA

ANSWER SPINE
define legal shift
→ map policy / coordination / delivery
→ name exact section and institution
→ distinguish mandatory / enabling
→ trace finance and data to implementation
→ test local and equitable outcome

QUALIFIED CONCLUSION
└─ India’s architecture is comprehensive;
   resilience depends on costed plans, permanent local capacity,
   interoperable data, usable finance and verified outcomes.
```
