# Multi-Hazard Early Warning and Disaster Technology — Quick Glance

## Central thesis

Early warning is a people-centred action chain, not a sensor or application.
Judge the system from risk knowledge to last-mile action and feedback.

```text
RISK KNOWLEDGE -> MONITOR / FORECAST -> AUTHORITATIVE WARNING
-> REDUNDANT DISSEMINATION -> COMPREHENSION -> EARLY ACTION -> FEEDBACK
```

## Core distinctions

| Distinction | Exam-safe rule |
|---|---|
| Observation / forecast / warning / order | Four separate stages. |
| Earthquake information / prediction | Post-event parameters are not prediction. |
| Platform availability / reach | Availability does not prove receipt or action. |
| CAP / mandate | CAP standardises message format, not agency ownership. |
| Technology / outcome | Tool deployment is an input; protection needs separate evidence. |

## Lead-time ladder

- Earthquake: no deterministic exact prediction.
- Tsunami: ITEWS under-ten-minute earthquake detection; public warning and evacuation are later stages.
- Nowcasting: WMO convention roughly 0-6 hours; IMD commonly issues three-hour products.
- Urban rainfall: source-specific three-to-six-hour Doppler/hydromet planning example.
- Cyclone: potentially longer tracking window; action depends on preparedness.

## Institution map

- IMD — weather and cyclone.
- CWC — river-flood forecasting.
- INCOIS/ITEWC — tsunami assessment.
- NCS/MoES — earthquake parameters; BhooKamp.
- ISRO/NRSC — earth observation and GIS.
- NDMA/SACHET — integrated CAP dissemination.
- State/district/local authorities — protective decisions and action.

## Named evidence

- Odisha: GIS-linked cyclone-shelter siting.
- Sikkim: landslide search-and-rescue planning.
- Gujarat: post-earthquake damage and rehabilitation mapping.
- Phailin: accurate forecast/tracking plus preparedness, not deterministic prediction.
- Vulnerable ocean-observation platforms: redundancy and maintenance matter.

## Last-mile test

Issued -> delivered -> received -> understood -> trusted -> acted -> avoided loss.

Disaggregate by language, disability, gender, income, location and connectivity.

## Mains answer spine

Define chain -> identify hazard/agency -> state qualified lead time
-> explain impact message -> add CAP/SACHET plus redundant channels
-> connect to local action -> evaluate equity/outcome -> close with EW4All.

## Traps

- One agency or lead time for every hazard.
- Under-ten-minute detection = evacuation.
- App existence = universal reach.
- Alert count = resilience.
- AI output = verified truth.
- EW4All target = achieved coverage.
