# Disaster Management 09 — Drought, Heat Waves and Slow-Onset Risk

```text
CENTRAL THESIS
│
└─ slow onset → cumulative loss before formal visibility
   → monitor multiple indicators → act early → adapt structurally

1. DROUGHT CASCADE
│
├─ meteorological → inadequate/maldistributed rainfall
├─ agricultural → soil-moisture/crop stress
├─ hydrological → river/reservoir/groundwater stress
└─ ecological → ecosystem productivity/function loss

TRAP → drought ≠ rainfall deficit alone

2. DECLARATION
│
└─ Manual for Drought Management 2016
   updated through Dec 2020
   ├─ rainfall
   ├─ vegetation/crop condition
   ├─ sowing progress
   ├─ soil moisture
   └─ hydrological indicators

GRADE → Normal / Moderate / Severe
TRAP → no universal crop-loss cut-off

3. INDIA RISK DRIVERS
│
├─ concentrated/variable monsoon
├─ groundwater depletion
├─ degraded watershed / wetland loss
├─ abandoned harvesting systems
├─ water-intensive crop incentives
└─ poverty / debt / weak livelihood buffers

CASE → Bundelkhand Mentha
└─ profitable crop ↔ water-security trade-off

4. DROUGHT GOVERNANCE
│
├─ IMD rainfall
├─ NRSC vegetation
├─ crop sowing + soil moisture
├─ reservoir + groundwater
├─ State Drought Monitoring Cell / SDMA
└─ declaration → water/agriculture/livelihood action

5. MANAGEMENT PORTFOLIO
│
├─ water budget + drinking/livestock priority
├─ watershed / aquifer / tank / wetland restoration
├─ demand control / reuse / leakage repair
├─ crop contingency + protective irrigation
├─ fodder + livestock health
├─ insurance / employment / cash-food support
└─ migration and nutrition safeguards

6. IMD HEAT-WAVE CRITERIA
│
├─ entry: plains ≥40°C; hills ≥30°C
├─ coastal: actual ≥37°C + departure ≥4.5°C
├─ departure 4.5–6.4°C → Heat Wave
├─ departure >6.4°C → Severe Heat Wave
├─ actual ≥45°C → Heat Wave
├─ actual ≥47°C → Severe Heat Wave
└─ ≥2 stations + 2 consecutive days → declare day 2

TRAP → 45°C ≠ sole national definition

7. WET-BULB
│
├─ temperature + humidity → evaporation limit
├─ high humidity → sweat cooling ↓
├─ ~35°C → theoretical upper benchmark
└─ dangerous stress occurs below benchmark

TRAPS
├─ wet bulb ≠ dry-bulb maximum
├─ wet bulb ≠ IMD declaration threshold
└─ 35°C ≠ universal safe/unsafe cliff

8. HEAT VULNERABILITY
│
├─ outdoor / informal work
├─ hot indoor work + poor housing
├─ urban heat island / low tree cover
├─ water / power / cooling inequality
├─ age / pregnancy / illness / medication
└─ hot nights + unprepared health facilities

9. HEAT ACTION PLAN
│
├─ forecast / early warning
├─ health-professional capacity
├─ community outreach
├─ inter-agency / civil-society coordination
├─ immediate → hours / water / shade / cooling / clinical care
└─ long term → cool roof / ventilation / trees / water bodies

EVIDENCE
├─ Ahmedabad first HAP, summer 2013
└─ 250+ cities/districts in 23 States, 7 Jun 2025
   → adoption count, not outcome

10. HEALTH + COMMUNITY
│
├─ NCDC Heat-Related Illness Plan 2021
├─ hospital readiness + surveillance
├─ ASHA / anganwadi / SEWA / local councils
├─ work-rest-water-shade protocol
└─ accessible cooling + transport

11. RELATED HAZARDS
│
├─ cold wave/frost → location-specific crop/shelter plans
└─ lightning → NDMA 2019 + Damini
   └─ minutes-scale behavioural action

12. FINANCE / STATUS
│
├─ MHA 2026–31 SDRF list = 14 disasters
│  └─ includes heatwave + lightning + drought + cold wave
├─ notified status → relief eligibility
├─ HAP → administrative plan
└─ outcome → delivered protection + reduced loss

TRAP → relief eligibility ≠ mitigation or HAP performance

13. PYQ ROUTES
│
├─ 2025 Prelims Q64 — DIRECT
│  └─ wet-bulb implication; official Set-A key B
├─ 2020 GS-I Q14 — SHARED
│  └─ interlinking: drought/flood/navigation benefits + limits
└─ 2024 GS-III Q17 — APPLICATION
   └─ slow-onset monitoring + early protection + adaptation

ANSWER SPINE
name drought type / heat metric → trace cascade
→ monitor + trigger → water/agriculture/work/health protection
→ long-term adaptation → outcome review

QUALIFIED CONCLUSION
└─ thresholds must trigger early, equitable action;
   declaration, plan count and relief eligibility are not resilience outcomes.
```
