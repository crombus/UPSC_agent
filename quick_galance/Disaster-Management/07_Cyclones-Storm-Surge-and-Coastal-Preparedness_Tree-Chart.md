# Disaster Management 07 — Cyclones, Storm Surge and Coastal Preparedness

```text
CENTRAL THESIS
│
└─ resilience = multi-hazard forecast
   → understood warning → evacuation/shelter
   → lifeline continuity → recovery

1. CYCLOGENESIS
│
├─ warm sea-surface temperature
├─ atmospheric instability
├─ moist lower/middle troposphere
├─ sufficient Coriolis force
├─ pre-existing disturbance
└─ low vertical wind shear

STRUCTURE
├─ eye → relatively calm
└─ eyewall → strongest wind + convection

2. HAZARD PACKAGE
│
├─ extreme wind
├─ storm surge → wind stress + low pressure
├─ storm tide → surge + astronomical tide
├─ high waves / erosion
├─ intense rain → inland floods
└─ lifeline cascades

SURGE MODIFIERS
└─ wind field + pressure + track/speed + bathymetry
   + coast shape + tide at landfall

TRAPS
├─ cyclone ≠ wind alone
├─ surge ≠ tide
└─ surge ≠ tsunami

3. IMD INTENSITY
│
├─ Depression 17–27 kt
├─ Deep Depression 28–33 kt
├─ Cyclonic Storm 34–47 kt → naming begins
├─ Severe 48–63 kt
├─ Very Severe 64–89 kt
├─ Extremely Severe 90–119 kt
└─ Super ≥120 kt

4. TWO WARNING LANGUAGES
│
├─ LEAD TIME
│  └─ Watch 72 h → Alert 48 h → Warning 24 h
│     → Post-Landfall Outlook 12 h
└─ ACTION COLOUR
   └─ Green/no warning → Yellow/update
      → Orange/prepare → Red/act

TRAP → stage ≠ colour; Red ≠ guaranteed impact

5. END-TO-END CHAIN
│
├─ observe → satellite / radar / ocean data
├─ forecast → track / intensity / wind / rain / surge
├─ warn → stage + colour + impact
├─ deliver → State / district / harbour / household
├─ act → evacuate / shelter / close port / protect utility
└─ verify → receipt / comprehension / movement / outcome

6. INSTITUTIONS
│
├─ IMD / RSMC New Delhi → forecast + bulletin
├─ ACWC → Kolkata / Chennai / Mumbai
├─ CWC → Bhubaneswar / Visakhapatnam / Ahmedabad
├─ NDMA / MHA → guidelines + NCRMP history
├─ SDMA / DDMA / local authority → evacuation + shelter
└─ NDRF / SDRF / ICG / Navy → specialist response

7. SHELTER SYSTEM
│
├─ safe location + resilient structure
├─ all-weather access + route signage
├─ water + sanitation + power + communication
├─ disability / age / gender access
├─ cattle mound / livestock plan
└─ trained management + inspection + drill

TRAP → shelter built ≠ shelter usable

8. NCRMP
│
├─ warning dissemination
├─ shelters + evacuation roads
├─ saline embankments + coastal protection
├─ community / institutional capacity
├─ Category I / II → differentiated priority, not safe/risky binary
└─ Phase I closed Dec 2018; Phase II Mar 2023

LIVE ISSUE → completed project → State/local O&M duty
TRAP → do not invent NCRMP-III

9. RESILIENT COAST
│
├─ infrastructure → power / telecom / water / health / ports
├─ engineered → embankment / shelter / road / selective wall
├─ ecosystem → mangrove / dune / wetland / vegetation
└─ non-structural → zoning / drainage / warning / evacuation

LIMITS
├─ embankment → breach / overtopping / blocked drainage
├─ hard structure → transferred erosion
└─ ecosystem → condition / width / location / event dependence

10. PEOPLE + RECOVERY
│
├─ fishers → at-sea alert + harbour + boats/markets
├─ tourists/migrants → multilingual routes
├─ disability/age/patients → assisted transport
├─ post-landfall → flood / landslide / electrocution / contamination
└─ BBB → safe return + housing + livelihoods + services

11. PYQ ROUTES
│
├─ 2022 GS-I Q5 — DIRECT
│  └─ colours + action meanings + stage distinction
├─ 2024 GS-I Q4 — SHARED
│  └─ SST mechanism + six-condition qualification
├─ 2026 GS-I Q4 — APPLICATION
│  └─ Fujiwhara: track effects > conditional intensity effects
├─ 2020 Prelims Q99 — APPLICATION
│  └─ eye statement; key unavailable, answer inferred C
└─ 2024 GS-III Q17 — APPLICATION
   └─ warning + shelter + lifeline + ecosystem + recovery

ANSWER SPINE
compound hazard → IMD forecast → stage/colour
→ inclusive delivery → evacuation/shelter
→ resilient lifelines + layered coast → response/BBB

QUALIFIED CONCLUSION
└─ forecast skill is necessary; maintained assets and last-mile action
   determine whether a cyclone becomes a disaster.
```
