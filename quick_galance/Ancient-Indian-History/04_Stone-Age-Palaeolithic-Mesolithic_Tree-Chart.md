# The Stone Age — Palaeolithic and Mesolithic: Quick-Glance Tree

```text
THE STONE AGE IN INDIA
|
+-- 1. SCOPE + EVIDENCE RULE
|   +-- Topic 04 owns: Palaeolithic/Mesolithic chronology, tools, hominin evidence,
|   |   foraging, mobility, habitation, burials, rock art, sites and transition
|   +-- evidence = fossils + lithics/debitage + strata/sediments + fauna/flora/residues
|   |   + burials + hearths + ornaments/art + scientific dates
|   +-- observe -> associate -> date -> interpret -> qualify
|   +-- context first: redeposition, preservation and sampling shape every apparent absence
|   +-- Pleistocene cold/warm oscillations -> rivers, sea level, vegetation and fauna change
|   `-- Holocene (about 12,000 years ago) -> wetlands, forests, grasslands and coasts reorganise
|
+-- 2. CHRONOLOGY: BROAD BANDS, NOT SYNCHRONOUS ALL-INDIA STAGES
|   +-- Lower Palaeolithic: c. 600,000-150,000 BCE
|   |   -> core/flake systems; Acheulian handaxes and cleavers
|   +-- Middle Palaeolithic: c. 150,000-35,000 BCE
|   |   -> flakes, scrapers, points/borers; prepared-core methods
|   +-- Upper Palaeolithic: c. 35,000-10,000 BCE
|   |   -> blades, burins, bone tools, ornaments and stronger symbolic visibility
|   +-- Mesolithic: c. 9000-4000 BCE (regional variation)
|   |   -> microlithic composites, broad-spectrum foraging, burials/art at some sites
|   `-- macro-phase -> regional sequence -> dated stratum -> assemblage -> qualified inference
|
+-- 3. HOMININ + DATING CAUTION
|   +-- South Asia: abundant lithics, sparse authenticated hominin fossils
|   +-- Narmada/Hathnora (1982, Arun Sonakia)
|   |   -> cranial fragment + vertebrate fossils + late Acheulian tools
|   |   -> Homo erectus / archaic Homo sapiens / intermediate readings; date/taxon debated
|   +-- Denisovans
|   |   -> archaic human population first identified from Denisova Cave remains/DNA
|   |   -> not a dinosaur, geological period or north-east Indian cave system
|   `-- tool industry != automatically one species; no established Denisovan fossil in India
|
+-- 4. LITHIC OPERATING CHAIN
|   raw material -> core preparation -> flake/blade production
|       -> retouch/backing/hafting -> use/resharpening
|       -> discard + debitage + spatial context
|   +-- core = stone mass; flake = detached blank; debitage = manufacturing waste
|   +-- primary context = near activity/deposition; secondary context = displaced/reworked
|   +-- Lower: handaxes (often bifacial), cleavers, choppers/chopping tools, flakes
|   +-- Middle: smaller flakes, scrapers, points, borers; older bifaces may continue
|   |   `-- Levallois = prepared-core reduction strategy, NOT a finished tool
|   `-- Upper: parallel-sided blades, burins, bone tools, ostrich-eggshell ornaments
|
+-- 5. PALAEOLITHIC REGIONAL MAP
|   +-- Soan/Potwar -> terrace/pebble-core traditions; fluvial redeposition caution
|   +-- Didwana/Thar -> Lower-Middle-Upper sequence in arid/palaeolake setting
|   +-- Narmada valley/Hathnora -> widespread lithics + rare hominin evidence
|   +-- Bhimbetka (Raisen, Madhya Pradesh)
|   |   -> long occupation; quartzite, water, shelters; later microliths/art
|   +-- Hunsgi-Baichbal/Isampur (Karnataka)
|   |   -> quarrying + cores + flakes + unfinished tools + debitage + hammerstones
|   |   -> manufacture context with habitation evidence
|   +-- Attirampakkam (Tamil Nadu)
|   |   -> deep Acheulian; Acheulian-Middle transition about 385 +/- 64 ka
|   |   -> regional date, NOT an all-India phase boundary
|   +-- Nevasa/Chirki-Nevasa -> stratified flake industry ("Nevasan" label)
|   +-- Son-Belan/Retlapalle -> dense sequences, chert/core strategies and manufacture
|   +-- Kurnool/Patne/Baghor -> bone tools, ornaments and lithic/symbolic evidence
|   |   `-- Kurnool Upper Palaeolithic dates include about 19,224 BP and 16,686 BP
|   `-- Sanghao cave -> Middle/Upper tools, hearths, animal bones and possible burials
|
+-- 6. LIFEWAYS + SUBSISTENCE
|   +-- plants/tubers/seeds/grasses + game + fish/turtles + shellfish/coastal foods
|   |   + scavenging/opportunistic capture + grinding/residue/starch evidence
|   +-- quarry/factory -> short task camp -> recurrent habitation -> processing area
|   |   -> shelter/cave -> linked landscape cluster
|   +-- mobility planned around water, food, raw stone and seasons
|   +-- hearth/fire requires secure anthropogenic context
|   +-- hunter-gatherer != meat-only; plant evidence is preservation-sensitive
|   +-- grinding stone = processing, NOT by itself cultivation; rank/gender need evidence
|   `-- site function/social organisation -> whole assemblage + context, not showcase artefact
|
+-- 7. MESOLITHIC: REGIONAL HOLOCENE ADAPTATIONS
|   +-- microliths (often < about 5 cm)
|   |   -> non-geometric: blades/points/scrapers/borers
|   |   -> geometric: lunates/crescents, triangles, trapezes
|   |   -> composite inserts in wood/bone: arrows, spears, knives, sickles, harpoons
|   +-- wetlands/plains/coasts/forests/shelters
|   +-- mobile -> semi-sedentary -> longer residence (continuum, not a universal shift)
|   +-- pottery/managed or domestic animals at some sites -> reported but questioned
|   `-- microlith != exclusive Holocene/Mesolithic marker; earlier and later occurrences exist
|
+-- 8. MAJOR MESOLITHIC SITES
|   +-- Bagor (Rajasthan, Kothari zone)
|   |   -> long microlithic sequence; subsistence; domestic cattle/sheep-goat claims disputed
|   |   `-- dates include about 5418-4936 BCE and 4575-4344 BCE
|   +-- Langhnaj (north Gujarat) -> microliths + burials + wild fauna + some pottery
|   +-- Adamgarh (Madhya Pradesh) -> Palaeolithic-Mesolithic sequence;
|   |   early-domestication claims weakened by uncertain dates/stratigraphy
|   +-- Bhimbetka -> long occupation + microliths + multi-period rock art
|   +-- Sarai Nahar Rai (middle Ganga) -> oxbow ecology + aquatic fauna + 11 graves
|   |   `-- dated around 9958-9059 BCE
|   +-- Mahadaha -> habitation/butchery + aquatic resources + long-distance stone + burials
|   +-- Damdama -> thick occupation + hearths + microliths + 41 burials
|   +-- Chopani Mando (Belan) -> huts/hearths/grinding + wild-rice evidence
|   `-- Baghor II (Son valley) -> Mesolithic manufacture and strong debitage evidence
|
+-- 9. BURIAL, ART + SOCIAL INFERENCE
|   +-- burial -> treatment, convention, memory and place attachment
|   |   `-- grave goods != automatic afterlife belief or hereditary class
|   +-- multiple burial/trauma/unequal goods -> possible relationships/events/distinction
|   |   `-- kinship, violence or hierarchy require corroborating evidence
|   +-- Bhimbetka superimposition -> relative sequence, not automatic calendar dates
|   +-- motifs/themes != dietary census; pigment/style != exact date by itself
|   +-- rock art = cognition/culture evidence, not a readable text or named religion
|   `-- heritage use -> conservation/public interpretation/tourism must not damage evidence
|
+-- 10. TRANSITION TO FOOD PRODUCTION
|   broad-spectrum foraging + longer residence in some settings
|       -> plant processing / pottery / animal management at some sites
|       -> regional interaction and experimentation
|       -> Neolithic cultivation, domestication and village systems
|   +-- grinding/wild rice/pottery alone != cultivation
|   +-- domestication requires morphology + secure context + chronology
|   +-- Bagor/Adamgarh and Sarai Nahar Rai-Mahadaha-Damdama faunal claims -> reported but questioned
|   +-- foragers, herders and cultivators could coexist/exchange
|   `-- established food production, polished stone, pottery complexes and villages -> Topic 05
|

|   +-- Levallois = prepared-core method, NOT finished tool
|   +-- microlith = small tool element, NOT exclusive date
|   +-- Bhimbetka = long multi-period archive, NOT Mesolithic-only
```
