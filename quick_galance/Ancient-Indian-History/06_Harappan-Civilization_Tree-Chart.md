THE HARAPPAN CIVILIZATION
|
+-- 1. EVIDENCE, NAME AND CHRONOLOGY
|   +-- Harappan / Indus = Bronze-Age archaeological civilisation
|   |   -> script undeciphered; archaeology is the primary evidence base
|   +-- discovery rail:
|   |   1853 Cunningham seal -> 1921 Daya Ram Sahni at Harappa
|   |   -> R.D. Banerji at Mohenjo-daro -> Marshall's 1920s announcement
|   +-- Early Harappan (c. 3300-2600 BCE)
|   |   -> regionalisation, fortified/proto-urban settlements, craft growth
|   +-- Mature Harappan (c. 2600-1900 BCE)
|   |   -> urban integration, common signs, seals, weights, brick norms
|   `-- Late Harappan (c. 1900-1300 BCE; regionally variable)
|       -> localisation, deurbanisation, settlement shift, crop diversification
|       -> process phases, not three sealed peoples or a sudden extinction
|
+-- 2. EXTENT + ECOLOGICAL NETWORK
|   +-- west: Sutkagen-dor (Makran) | north: Manda
|   +-- east: Alamgirpur (western Uttar Pradesh)
|   +-- south: Malvan (southern Gujarat); Daimabad = later/contact caution
|   +-- core and corridors:
|   |   Indus/Sindh-Punjab + Ghaggar-Hakra/Haryana-Rajasthan
|   |   + Kutch/Saurashtra/Gujarat + Afghanistan routes
|   +-- Shortugai -> mineral-route outpost; not automatically a province
|   `-- palaeochannel course, settlement chronology and textual Sarasvati
|       are separate questions; do not convert one into another
|
+-- 3. URBAN-RURAL SYSTEM
|   resource zones + farms/herds + villages
|       -> specialist centres and regional towns
|       -> cities + public works + exchange
|   +-- cities: Harappa, Mohenjo-daro, Dholavira, Rakhigarhi, Ganweriwala
|   +-- regional centres: Kalibangan, Banawali and fortified towns
|   +-- craft centres: Chanhudaro (beads), Nageshwar (shell), Lothal
|   +-- villages/farmsteads: Allahdino and numerous small settlements
|   `-- standardisation = coordination/shared norms
|       -> not proof of one centralised empire
|
+-- 4. SITE -> FEATURE -> CAUTION LOCK
|   +-- Harappa (Ravi)
|   |   -> first excavated type-site, Cemetery R-37, working platforms
|   |   -> 12-unit "granary" = conventional label, not settled function
|   +-- Mohenjo-daro (Indus, Sindh)
|   |   -> Great Bath, dense wells/drains, bronze Dancing Girl
|   |   -> "Priest-King", college, granary = modern/contested labels
|   +-- Dholavira (Khadir island, Kutch)
|   |   -> stone architecture, multiple sectors, dams/reservoirs, signboard
|   |   -> corrects a universal two-part citadel/lower-town template
|   +-- Kalibangan (Ghaggar zone)
|   |   -> ploughed field, fortified sectors, fire installations
|   |   -> fire installations do not automatically prove Vedic ritual
|   +-- Lothal (Gujarat)
|   |   -> bead/copper craft, basin, drains, scale and burials
|   |   -> "dockyard" is a leading but qualified interpretation
|   +-- Banawali (Haryana)
|   |   -> Early-Mature-Late sequence, moat, plough model, seals/weights
|   +-- Chanhudaro (Sindh)
|   |   -> unfortified specialist craft town; no conventional citadel
|   +-- Rakhigarhi (Haryana)
|   |   -> large inland centre, craft, drains and cemetery
|   +-- Surkotada (Kutch)
|   |   -> fortified settlement; equid/horse identification is disputed
|   `-- Desalpur = Harappan fortified site; do not confuse with Sohgaura
|
+-- 5. BUILT FORM + WATER
|   +-- common tendencies:
|   |   planned streets/lanes, courtyards, bathing floors, wells and drains
|   |   mud brick + baked brick concentrated in water/public structures
|   |   Mature brick norm near 1:2:4; regional materials and layouts vary
|   +-- household:
|   |   side lane -> entrance turn -> courtyard -> rooms/bath/well/stair
|   +-- water chain:
|   |   stream/runoff -> dam/channel -> reservoir/cistern -> urban storage
|   |   household platform -> small drain -> covered street drain -> soak/outfall
|   +-- Mohenjo-daro -> well/drain and bathing infrastructure
|   +-- Dholavira -> dams, channels, stone-lined reservoirs in an arid setting
|   +-- Great Bath -> baked brick + gypsum mortar + bitumen waterproofing
|   `-- inference: civic maintenance and labour coordination
|       -> not proof of a palace, constitution or modern public-health theory
|
+-- 6. SUBSISTENCE + ENVIRONMENT
|   +-- wheat/barley widespread; regional rice, millets, pulses, oilseeds
|   |   fruits, sesame, mustard and cotton broadened the crop base
|   +-- cattle/buffalo prominent; sheep/goat/pig, fish, shellfish and wild foods
|   +-- floodplain, rain-fed, wells, bunds and local water strategies coexisted
|   +-- Kalibangan furrows + Banawali plough model
|   `-- horse/equid remains rare and disputed
|       -> not a horse-centred or securely Vedic civilisation
|
+-- 7. CRAFT, MEASUREMENT + EXCHANGE
|   +-- craft chain:
|   |   raw material -> workshop -> specialist skill -> finished good
|   |   -> household/elite use -> exchange/discard
|   +-- beads: Chanhudaro, Lothal, Rakhigarhi; carnelian heating/drilling
|   +-- shell: Nageshwar and coastal Gujarat; faience, pottery, textiles
|   +-- copper/bronze, stone, bone, shell and wood coexisted
|   |   -> Bronze Age does not mean every tool was bronze; no iron focus
|   +-- weights/scales:
|   |   cubical weights + shell/ivory scales + brick ratios
|   |   -> standardised measurement/coordination, not coinage or known tax code
|   +-- internal routes:
|   |   copper, tin, lapis, carnelian, chert, shell, timber, food
|   |   -> carts, pack animals, river craft and coastal boats
|   `-- no non-local bead or metal alone proves conquest, colony or monopoly
|
+-- 8. LONG-DISTANCE TRADE
|   +-- Mesopotamian terms:
|   |   Meluhha/Meluha -> Indus-related eastern zone; exact scope debated
|   |   Dilmun -> Gulf intermediary commonly linked to Bahrain
|   |   Magan/Makan -> Oman/Makran-linked zone
|   +-- possible exports: carnelian, shell, ivory, textiles
|   +-- possible imports: selected metals and prestige materials
|   `-- contact is secure; colony, volume and direct royal control are not
|
+-- 9. SCRIPT, SEALS + COMMUNICATION
|   +-- short inscriptions on seals, sealings, pottery, tablets and objects
|   +-- several hundred signs; often right-to-left
|   |   -> some other directions/multi-line alternation; not wholly boustrophedon
|   +-- proposed functions: identity, ownership, authentication, office, ritual
|   `-- script/language/sign values remain undeciphered
|       -> no named rulers, law code, dynastic list or readable theology
|
+-- 10. SOCIETY, POLITY + RELIGION
|   +-- houses, ornaments, burials, craft access and diet
|   |   -> occupational diversity and social differentiation
|   |   -> not automatic caste, slavery, matriarchy or exact property rights
|   +-- polity models:
|   |   centralised state | several city-states | corporate/decentralised elites
|   |   -> coordination is strong; sovereign, capital and coercive form unknown
|   +-- religion/ritual evidence:
|   |   female figurines, horned seated figure, pipal/animal motifs
|   |   fire installations, Great Bath, burials and possible linga-like objects
|   |   -> describe object/context first; "Mother Goddess" and "Pashupati"
|   |      are contested, and no unified state religion is proven
|   `-- "Priest-King" = museum nickname, not proof of priesthood or kingship
|
+-- 11. DECLINE, LATE PHASE + LEGACY
|   water/river change + aridity/monsoon stress + trade contraction
|       + internal political/social reorganisation
|       -> uneven deurbanisation and population/settlement dispersal
|   +-- local floods or river shifts can explain local change, not all sites
|   +-- no single Aryan invasion, drought or flood explains the whole process
|   +-- Late Harappan cultures: Jhukar, Cemetery H, Rangpur/Rojdi and others
|   |   -> smaller/rural networks, diversified agriculture, selective continuities
|   +-- continuity: crops, livestock, pottery, crafts, populations, some motifs
|   `-- discontinuity: urban scale, script, seals, common standards, integration
|       -> safest verdict = transformation/localisation, not sudden extinction
|

|   |   spindle whorls -> household spinning; graduated weights/scales
|   |   -> measurement; courtyard houses/private wells do not prove common property

|       secure object/site -> bounded inference -> alternative/limit -> verdict

`-- 14. MAINS SPINE + CLOSE-OPTION TRAPS
    define regionalisation -> integration -> localisation
      -> extent/ecology -> urban-rural hierarchy
      -> architecture/water -> crops/crafts/trade/measurement
      -> script and polity uncertainty -> ritual caution
      -> multi-causal deurbanisation -> selective continuity
    traps:
      "Indus Valley" = not the full distribution
      citadel/granary/dockyard = not settled functions
      standard weights = not coinage or one known empire
      female figurines/Pashupati = not proven theology
      horse evidence = not horse-centred culture
      aDNA = not direct proof of language, caste or religion
    qualified conclusion:
      coordinated diversity and regional adaptation are secure; exact language,
      rulers, institutions and beliefs remain constrained by the undeciphered script
      and uneven archaeological record.
