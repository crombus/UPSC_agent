# Ancient Indian History 13 — State and Varna Society in the Age of the Buddha

## Quick-Glance Tree Chart

> Source voices, fortification, taxation and gana-sangha are always read through chronology, genre and regional variation.

```text
STATE AND VARNA SOCIETY IN THE AGE OF THE BUDDHA
│
├─ 1. BOUNDARY + THESIS
│  ├─ core focus → c. sixth-fourth centuries BCE; longer uneven c. 600-200 BCE transition
│  ├─ densest evidence → middle Ganga basin, not an all-India census
│  ├─ Topic 11 → full mahajanapada/Magadha narrative; Topic 14 → Mauryan bureaucracy
│  └─ thesis → territory + surplus + social ranking changed together, unevenly
│
├─ 2. SOURCE FIREWALL
│  ├─ Nikaya/Vinaya → categories + monastic norms; layered oral/redaction history
│  ├─ Jataka/later Buddhist + Jain traditions → rich memory; chronology/sectarian purpose
│  ├─ Dharmasutra/Grihyasutra → Brahmanical prescription, not uniform practice
│  ├─ archaeology → settlement/NBPW/forts/crafts; rarely varna or office directly
│  ├─ coins → circulation/valuation; issuer, date and social reach may be uncertain
│  └─ write → claim → named evidence → inference → genre/date/region/silence limit
│
├─ 3. SECOND URBANISATION
│  ├─ village food/raw material/labour ↔ towns/crafts/markets/routes/state demand
│  ├─ city bundle → settlement hierarchy + crafts + exchange + works + hinterland
│  ├─ NBPW ≠ city/people/state/single universal date
│  ├─ punch-marked coin ≠ one king/universal money/end of barter
│  └─ iron enabled; labour, land, demand and institutions converted
│
├─ 4. STATE–SURPLUS–STRATIFICATION CHAIN
│  ├─ ecology + crops + tools + water + labour → production possibility
│  ├─ household surplus → tax/tribute/toll/fine + market/credit + gift/service
│  ├─ extraction → court + officials + forts + army + urban/monastic institutions
│  └─ unequal appropriation → wealthy household/business elites + dependencies
│
├─ 5. TERRITORIAL STATE
│  ├─ jana/kin authority → janapada → larger territorial claims
│  ├─ capital → court + storage + exchange + defence + communication
│  ├─ fort → mobilisation/insecurity, not absolute control
│  └─ sovereignty layered → king/clan/village/corporate/household powers coexist
│
├─ 6. MONARCHY vs GANA-SAṄGHA
│  ├─ monarchy → dynastic king + court + concentrated command
│  ├─ gana → restricted ruling-clan body + chief/council/assembly
│  ├─ santhagara / salaka → procedural clues, not one preserved constitution
│  ├─ both → extraction + army + diplomacy + punishment + exclusion
│  └─ trap → “republic” always qualified: oligarchic, not universal citizenship
│
├─ 7. OFFICIALS + FISCAL-MILITARY CAPACITY
│  ├─ amatta/mahamatta, commander, judge/accountant, village head → differentiated roles
│  ├─ same title ≠ same function; no wholesale Arthashastra/Ashokan projection
│  ├─ bhaga/produce share + bali + toll + fine → variable extraction
│  ├─ named fractions → normative options, not audited realised rates
│  └─ forts/forces show coercion; exact army totals remain insecure
│
├─ 8. JUSTICE + SOCIAL ORDER
│  ├─ protection/order/punishment + lineage/ritual/patronage legitimise rule
│  ├─ Brahmanical law ranks persons/penalties
│  ├─ actual adjudication by rulers/agents is unevenly documented
│  └─ ethical kingship narrative ≠ consensual tax contract or modern rule of law
│
├─ 9. AGRARIAN, URBAN AND CORPORATE ECONOMY
│  ├─ land claims overlap → cultivator + household + village + chief/king + beneficiary
│  ├─ gahapati → substantial household/property-holder; not every householder
│  ├─ setthi → urban merchant-financier/corporate figure; not gahapati synonym
│  ├─ vanija + artisans + shreni/puga/nigama → guild-like, source-layer bounded
│  └─ coin terms → kahapana, nikkha, kamsa, pada, masaka, kakanika
│
├─ 10. VARNA IDEOLOGY vs LIVED PRACTICE
│  ├─ varna → broad prescriptive hierarchy; not social census
│  ├─ jati → context-sensitive birth/kind/lineage/group; not mature caste automatically
│  ├─ occupation + wealth + kinship + office + region intersect, never equal one another
│  ├─ Brahmana–Kshatriya → rank contest + ritual-political cooperation
│  ├─ Vaishya ≠ every merchant; vessa/gahapati/setthi overlap imperfectly
│  └─ Shudra prescription ≠ every worker/artisan/slave/forest person
│
├─ 11. LABOUR, DEPENDENCE AND EXCLUSION
│  ├─ kassaka → cultivator with unequal resources/obligations
│  ├─ kammakara/bhataka → hired/service labour; dasa/dasi → dependent/unfree contextually
│  ├─ debt + capture + birth + service → distinct pathways; no reliable proportions
│  ├─ Chandala/Nisada/pukkusa → source-specific stigma/exclusion
│  └─ trap → recognise early exclusion without projecting mature later caste wholesale
│
├─ 12. HOUSEHOLD, PROPERTY AND WOMEN
│  ├─ patriliny + controlled marriage + male inheritance privilege → normative structure
│  ├─ women → labour + management + gifts + patronage, under-recorded by male elite sources
│  ├─ Ambapali → wealthy ganika/donor; Visakha → lay patron; exceptions ≠ general equality
│  ├─ bhikkhuni + Jain female orders → alternative renunciation
│  └─ admission/discipline/status asymmetries → institutional constraints persist
│
├─ 13. ŚRAMAṆA CRITIQUE WITHOUT REVOLUTION MYTH
│  ├─ critique → sacrifice + attachment + moral sufficiency of birth
│  ├─ wider participation → rulers + gahapatis + merchants + artisans + women + others
│  ├─ sangha dependence → alms + gardens + gifts + protection from unequal lay society
│  ├─ debtor/slave/soldier/nun rules reveal limits
│  └─ Buddhism/Jainism → ethical alternatives, not mere merchant/anti-caste revolts
│
├─ 14. PERIPHERIES + MOBILITY
│  ├─ forest/pastoral/hunting groups → exchange + tribute/labour + resistance + autonomy
│  ├─ incorporation graded; route control ≠ assimilation
│  ├─ wealth/office/skill/migration/patronage/renunciation → status claims
│  ├─ birth/debt/patriarchy/stigma → mobility limits
│  └─ donor evidence → claimed identity and institutional tie, not group-wide census
│
├─ 15. COMPARISON + BRIDGE
│  ├─ Later Vedic continuity → kinship + agrarian growth + varna sharpening
│  ├─ Buddha-age visibility → larger states + towns + monetisation + organised renunciation
│  ├─ trend, not total replacement; regional trajectories differ
│  └─ Mauryan bridge → capacities accumulate, but no ready-made empire or bureaucracy
│
```
