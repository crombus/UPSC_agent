│  ├─ Cyrus II → possible antecedent; secure Indian annexation unproved

│  ├─ Imperial Aramaic → strongest context for right-to-left Kharoshthi
│  └─ coins/weights/routes/forms move selectively; no blanket Persianisation
│
├─ 6. ALEXANDER'S ROUTE
│  ├─ 327 BCE → highland/Aornos phase
│  ├─ 326 BCE → Indus, Ambhi at Taxila, Hydaspes against Porus
│  ├─ Chenab/Ravi → Hyphasis/Beas mutiny: eastern limit
│  └─ 326-325 BCE → Indus descent, Malloi, Patala and return
│
├─ 7. HYDASPES AND AGENCY
│  ├─ Ambhi allied; Porus resisted; highland groups and Malloi fought
│  ├─ watched river → feints → upstream crossing → cavalry manoeuvre

│  └─ Greek success + Porus restored/enlarged = indirect rule, not Porus victory
│
├─ 8. WHY ADVANCE STOPPED
│  ├─ fatigue + homesickness + replacement limits
│  ├─ monsoon, rivers, disease and supply distance
│  ├─ accumulated resistance and elephant experience
│  ├─ reports of Nanda/Gangetic forces; exact totals rhetorical
│  └─ cumulative morale crisis; no Indian-unity or one-number myth
│
├─ 9. RETURN AND SOURCE CHAIN
│  ├─ Malloi wound proves passed territory was not pacified
│  ├─ Patala = delta reconnaissance/fleet preparation; channels uncertain
│  ├─ Nearchus survives mainly via Arrian's Indica
│  └─ Onesicritus survives through later writers and ancient criticism
│
├─ 10. ARRANGEMENTS AND FRAGMENTATION
│  ├─ Porus/Ambhi/Abhisara retained as intermediaries
│  ├─ Philip/Peithon/Eudemus + changing satraps, garrisons and settlements
│  └─ 323 BCE death → succession conflict, withdrawals and local reassertion
│
├─ 11. CONSEQUENCES WITH BOUNDARIES
│  ├─ political opening = one condition for later Mauryan expansion
│  ├─ routes/geographical knowledge intensified and documented, not invented
│  └─ later Indo-Greek coinage/Gandhara art ≠ Alexander's personal creation
│
├─ 12. COMPARISON
│  ├─ Achaemenid → longer, tribute/satrapal/scribal, inscriptions strongest
│  ├─ Macedonian → shorter, military/geographical, later narratives strongest
│  └─ shared → local mediation, connected routes, variable control
│
├─ 13. EXAMINER TRAPS
│  ├─ Gandara ≠ automatically Hindush; Hindush ≠ whole India
│  ├─ Hydaspes/Jhelum ≠ Hyphasis/Beas
│  ├─ Arrian ≠ eyewitness; Plutarch's dialogue ≠ transcript
│  └─ Darius/Alexander/Seleucus/Indo-Greeks must not be collapsed
│
└─ 14. EXECUTABLE ANSWER ROUTE
   ├─ define → map → classify sources

   └─ compare duration/mechanism/evidence/legacy → qualified verdict

QUALIFIED VERDICT:
Achaemenid incorporation was longer and administrative-scribal; Alexander's was brief and
military-geographical. Both had bounded reach but selective, durable contact effects.
