# Ancient Indian History 02 — Sources of Ancient Indian History

## Quick-Glance Tree Chart

```text
SOURCES OF ANCIENT INDIAN HISTORY
|
+-- CENTRAL THESIS
|   +-- source != ready-made fact
|   +-- trace -> authenticate -> date -> contextualise -> corroborate -> qualify
|   +-- texts are genre-bound; archaeology is interpreted context
|
+-- ORIGIN / TIMELINE RAIL
|   +-- prehistory -> archaeology and natural science dominate
|   +-- Harappan c. 2600–1900 BCE -> literate material culture, script undeciphered
|   +-- Vedic/post-Vedic -> layered oral-textual traditions + archaeology
|   +-- late 1st millennium BCE onward -> readable inscriptions, coins, cities
|   +-- 3rd c. BCE -> Ashokan epigraphic anchor
|   +-- 1837 -> Prinsep's decisive Brahmi decipherment step
|
+-- ARCHAEOLOGY
|   +-- artefact -> industry -> assemblage -> archaeological culture
|   +-- survey/GIS -> site pattern; anomaly != date/function
|   +-- vertical excavation -> sequence | horizontal -> phase layout
|   +-- lower undisturbed layer generally earlier; intrusion can reverse appearance
|   +-- culture pattern != race/language/tribe/state
|
+-- DATING + SCIENCE
|   +-- relative: stratigraphy, typology, seriation, palaeography
|   +-- C-14 -> calibrated organic range
|   +-- TL -> last heating | OSL -> last sufficient light
|   +-- plants/fauna -> subsistence | isotopes -> diet/mobility | aDNA -> ancestry
|   +-- sample result != whole site/event/civilisation
|
+-- EPIGRAPHY
|   +-- epigraphy = inscriptions | palaeography = old scripts
|   +-- Brahmi left-to-right | Kharoshthi right-to-left, north-west
|   +-- Ashoka: mainly Prakrit-Brahmi; regional script/language variation
|   +-- edict -> policy | prashasti -> royal praise | grant -> legal-fiscal act
|   +-- contemporaneity != neutrality; location != exact imperial frontier
|
+-- NUMISMATICS
|   +-- metal + weight + manufacture + legend + icon + die + context
|   +-- hoard = selected deposit; overstrike = relative sequence
|   +-- Jogalthembi: Nahapana undertypes / Gautamiputra overtypes
|   +-- distribution != sovereignty; debasement != automatic collapse
|
+-- LITERARY SOURCES
|   +-- Vedic -> ritual/kinship/economy vocabulary
|   +-- epics/Puranas -> memory/genealogy, but redaction/interpolation
|   +-- Buddhist/Jaina -> monastery, merchants, towns, doctrine; sectarian frame
|   +-- Sangam -> Tamilakam, chiefs, work, ports; bardic/dating cautions
|   +-- Dharmashastra/Arthashastra -> norm/theory, not transparent practice
|   +-- court/biography -> ideology and patronage, not neutral chronicle
|   +-- composition != redaction != recension != surviving manuscript
|
+-- FOREIGN + VISUAL + ORAL
|   +-- Megasthenes, Periplus, Faxian, Xuanzang, Arab-Persian witnesses
|   +-- test route, purpose, language, informants, hearsay, audience, translation
|   +-- architecture/image/pottery/seal -> patronage, technology, representation
|   +-- image != photograph | style != exact date | language != race
|
+-- TRIANGULATION
|   +-- match chronology + geography + scale + independent origin
|   +-- Pali money terms + punch-marked coins -> monetisation, not uniformity
|   +-- Sangam ports + Tamil-Brahmi/imports -> connectivity, not total volume
|   +-- contradiction may reveal genre, region, chronology or rival claims
|
+-- BIAS / SILENCE / CUSTODY
|   +-- elite/durable survival bias; women/labour/perishable life under-recorded
|   +-- absence matters only after survivability + search + patterned silence
|   +-- provenance/forgery control; unprovenanced object loses context
|   +-- ASI, museums, archives and digital corpora preserve but do not end criticism
|
+-- PYQ ROUTE
|   +-- 2018 GS-I travellers -> assess value + observer limits + corroboration
|   +-- 2023 literary attribution -> local official key unavailable; withhold key
|   +-- 2024 site matching -> official B; verify state, period and site type separately
|
+-- EXECUTABLE ANSWER SPINE
    +-- define source class and answer directive
    +-- claim -> named evidence -> analysis -> qualification
    +-- corroborate at matching time/place/scale
    +-- state residual silence
    +-- conclude: independent convergence strengthens, never makes evidence transparent
```
