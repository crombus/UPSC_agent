# Ancient Indian History 02 — Sources of Ancient Indian History

|   +-- artefact -> industry -> assemblage -> archaeological culture
|   +-- context = layer + exact findspot + association + formation history
|   +-- survey/GIS -> site pattern; anomaly != date/function
|   +-- vertical excavation -> sequence | horizontal -> phase layout
|   +-- lower undisturbed layer generally earlier; intrusion can reverse appearance
|   +-- culture pattern != race/language/tribe/state

|   +-- TL -> last heating | OSL -> last sufficient light
|   +-- plants/fauna -> subsistence | isotopes -> diet/mobility | aDNA -> ancestry
|   +-- sample result != whole site/event/civilisation
|

|   +-- Brahmi left-to-right | Kharoshthi right-to-left, north-west
|   +-- Ashoka: mainly Prakrit-Brahmi; regional script/language variation
|   +-- script != language; palaeographic dates are approximate and region-sensitive
|   +-- edict -> policy | prashasti -> royal praise | grant -> legal-fiscal act
|   +-- contemporaneity != neutrality; location != exact imperial frontier

+-- NUMISMATICS

|   +-- distribution != sovereignty; debasement != automatic collapse
