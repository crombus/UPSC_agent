|
+-- 1. CATEGORY FIREWALL
|   +-- ārya = contextual ancient textual self-description
|   +-- Indo-Aryan = linguistic branch within Indo-Iranian
|   +-- language != race != genes != pottery != ethnicity
|   |   != civilisation != polity
|   +-- archaeological culture -> recurring material pattern
|   |   -> not automatically a language or people
|   `-- ancestry -> sampled biological relationship
|       -> not direct proof of language, religion, caste or identity
|
+-- 2. WHY THE DEBATE PERSISTS
|   +-- Vedic Sanskrit has Indo-European/Indo-Iranian relationships
|   +-- Rig Veda = layered, oral, ritual-poetic corpus, not a chronicle
|   +-- Harappan script remains undeciphered
|   +-- pots, burials and tools do not name their language
|   +-- ancient-DNA samples are uneven by place, period and person
|   `-- population movement, language spread and cultural change
|       can occur at different speeds
|
+-- 3. LINGUISTIC SPINE
|   PROTO-INDO-EUROPEAN

|   |   inherited vocabulary and shared innovations
|   +-- Vedic soma / Avestan haoma -> relationship + later divergence
|   `-- establishes linguistic relatedness
|       -> does not by itself establish homeland, route, genes or conquest
|
+-- 4. MEANING OF ĀRYA + DĀSA/DASYU
|   +-- ārya can mark insider, ally, respectable person,
|   |   ritual-cultural status or participant in an order
|   +-- dāsa/dasyu can mark enemy, outsider or rival ritual group
|   |   -> not automatically a biological or dark-skinned race
|   `-- read by hymn, speaker, opponent, genre and historical layer
|       -> no single timeless ethnic meaning
|
+-- 5. RIG VEDA + TEXTUAL GEOGRAPHY
|   +-- family books 2-7 conventionally older; corpus remains layered
|   +-- north-western horizon:
|   |   Sindhu/Indus + Punjab tributaries + Kabul/Swat river world
|   |   + Sarasvati/Ghaggar-Hakra debate
|   +-- later Vedic material shifts toward Kuru-Panchala/upper Ganga
|   +-- text can preserve memory, metaphor, praise or polemic

+-- 7. HISTORIOGRAPHY: FROM PHILOLOGY TO POLITICS
|   +-- comparative philology -> genuine language relationship
|   +-- colonial racialisation -> language converted into biological hierarchy
|   +-- invasion/massacre model -> weak: no civilisation-wide destruction
|   |   horizon at Harappan sites
|   +-- strict no-movement model -> must explain linguistic branching,
|   |   Mitanni evidence and later ancestry movement
|   `-- present method -> migration + interaction + graded uncertainty

+-- 8. HARAPPAN -> POST-HARAPPAN RELATION
|   +-- Mature Harappan c. 2600-1900 BCE largely precedes
|   |   conventional Early Vedic horizon c. 1500-1000 BCE
|   +-- Late Harappan c. 1900-1300 BCE -> localisation/deurbanisation
|   |   with regional continuity and movement
|   +-- Vedic and Harappan profiles differ in writing, urbanism,
|   |   bricks, material assemblage and textual emphasis
|   +-- no mass assault proves civilisation-wide destruction
|   `-- no mass invasion != no later migration
|       -> cultural continuity can coexist with incoming groups/admixture

|   equid species -> secure context -> date -> frequency/use

|   +-- Surkotada equid -> species/context and wider significance disputed

|   |   -> later Steppe-related movement into parts of South Asia

|   `-- ancestry does not encode language, religion, caste, polity or self-name

+-- 12. COMPETING MODELS + GRADED VERDICT
|   +-- violent mass invasion destroying Harappa
|   |   -> weak: no matching destruction horizon; collapses chronologies

|   |   -> over-simple: must explain branching, Mitanni and DNA chronology
|   +-- multi-phase migration
|   |   -> plausible; route, scale, sex balance and institutions remain debated
|   `-- interaction/admixture model
|       -> migration + local ancestry + bilingualism + acculturation
