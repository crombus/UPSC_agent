# Ancient Indian History 17 — The Satavahanas and the Deccan

## Quick-Glance Tree Chart

```text
SATAVAHANAS AND THE DECCAN
│
├─ 1. BOUNDARY
│  ├─ Post-Mauryan Deccan state formation; megalithic/local settlements did not vanish.
│  ├─ Core problem: connect rulers, routes, agrarian zones, chiefs, towns and donors.
│  └─ Tamilakam's Sangam corpus and Chera-Chola-Pandya detail → Topic 18.
│
├─ 2. NAME + CHRONOLOGY FIREWALL
│  ├─ Puranas: Andhra / Andhra-Bhritya.
│  ├─ Inscriptions/coins: Satavahana / Satakarni.
│  ├─ Equation useful, but homeland, ethnicity and exact start remain debated.
│  └─ Simuka → Satakarni I/Naganika → Gautamiputra → Pulumavi → Yajna Sri.
│
├─ 3. SOURCE METHOD
│  ├─ Naneghat/Nashik/Karla-Kanheri inscriptions → genealogy, claims, grants, donors.
│  ├─ Coins/overstrikes → rulers, metals, symbols, political-monetary succession.
│  ├─ Archaeology → settlements, crafts, irrigation, caves, Amaravati phases.
│  ├─ Puranas/Gatha Saptashati/Periplus → layered memory and trade description.
│  └─ RULE: claim → named evidence → analysis → qualification.
│
├─ 4. EARLY KINGSHIP
│  ├─ Simuka: conventional founder; date/core disputed.
│  ├─ Satakarni I + Naganika: Naneghat genealogy, portraits, sacrifices, dakshina.
│  └─ Queen's agency is secure; matriarchy or female-line succession is not.
│
├─ 5. WESTERN KSHATRAPA CONFLICT
│  ├─ Nahapana/Kshaharata → western routes, caves and coast.
│  ├─ Gautami Balashri's Nashik prashasti → Gautamiputra's victory claims.
│  ├─ Jogalthembi overstrikes → takeover + silver-stock revalidation.
│  ├─ Pulumavi → strong eastern phase after Gautamiputra.
│  └─ Rudradaman/Junagadh → two victories + kinship: warfare and marriage together.
│
├─ 6. POLITICAL GEOGRAPHY
│  ├─ Pratishthana/Paithan = major western centre.
│  ├─ Amaravati-Dharanikota = major eastern religious-political zone.
│  └─ Capital ≠ mint ≠ inscription findspot ≠ coin-circulation zone.
│
├─ 7. LAYERED ADMINISTRATION
│  ├─ ahara → territorial/revenue division.
│  ├─ amatya, mahamatra, mahasenapati, gramika → officers/intermediaries.
│  ├─ maharathi, mahabhoja → regional chiefs, donors, marriage partners.
│  └─ 'Feudatory' is cautious shorthand, not a fixed feudal constitution.
│
├─ 8. AGRARIAN + FISCAL BASE
│  ├─ iron tools + paddy in suitable zones + cotton + wells/tanks.
│  ├─ expanding rural settlements supported towns, courts and donations.
│  └─ grants/immunities = early revenue-right transfer; not mature feudalism automatically.
│
├─ 9. CRAFTS + TRADE
│  ├─ iron, beads, pottery, textiles; shrenis and occupational endowments.
│  ├─ Pratishthana/Tagara ↔ Naneghat ↔ Kalyana/Sopara/Bharukachchha.
│  ├─ eastern routes ↔ Krishna-Godavari/Amaravati.
│  └─ Roman contact is one strand; no universal-prosperity or political-control claim.
│
├─ 10. COINAGE
│  ├─ lead prominent; potin, copper and some silver; regional legends/motifs.
│  ├─ Yajna Sri ship motif → maritime orientation, not measured navy.
│  └─ coin findspot ≠ frontier; overstrike ≠ exact battle date.
│
├─ 11. SOCIETY + CULTURE
│  ├─ varna-restoration language = royal ideology, not census.
│  ├─ matronymics = maternal affiliation; no matriarchy inference.
│  ├─ foreign-linked, occupational and women donors → selective assimilation/agency.
│  ├─ Prakrit-Brahmi; Gatha Saptashati/Gaha Sattasai attributed to Hala, layered.
│  └─ Brahmanical sacrifice + Buddhist patronage = plural political-religious field.
│
├─ 12. SITE NETWORK + ART CROSS-LINK
│  ├─ Nashik → rival records, grants, caves.
│  ├─ Karla/Karle + Kanheri → multi-donor western route monasteries.
│  ├─ Amaravati → lower Krishna mahachaitya, multi-phase and post-Satavahana continuity.
│  └─ Detailed style history routes to Art & Culture; do not turn art spread into empire.
│
├─ 13. DECLINE + CONTINUITY
│  ├─ later rulers unevenly known; end not synchronous.
│  ├─ Ikshvakus, Abhiras, Chutus and other regional formations.
│  └─ dynastic fragmentation ≠ automatic collapse of towns, trade or religious institutions.
│
└─ UPSC RAPID MATCH
   ├─ Satakarni I—Naganika—Naneghat.
   ├─ Gautamiputra—Gautami Balashri—Nashik—Nahapana overstrikes.
   ├─ Pulumavi—eastern phase; Rudradaman—Junagadh rival claim.
   ├─ Yajna Sri—ship motif.
   └─ VERDICT: a powerful but uneven Deccan network polity, not a timeless centralized empire.
```

## PYQ Answer Route

1. Open with the post-Mauryan Deccan and the layered/network-polity thesis.
2. Use a relative ruler sequence, not disputed exact dates.
3. Build body paragraphs as claim → named inscription/coin/site → analysis → limitation.
4. Include agriculture, grants, crafts, inland-maritime trade, society and plural patronage.
5. Close with regional variation, source limits and continuity after dynastic decline.
