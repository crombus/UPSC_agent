# Ancient Indian History 14 — The Mauryan Empire

> Core rule: separate source, chronology, territorial claim and implementation before drawing any conclusion.

```text
THE MAURYAN EMPIRE
│
├─ 1. SOURCE FIREWALL
│  ├─ Ashokan inscriptions → contemporary royal voice; intention > implementation
│  ├─ archaeology/coins → material context; date and attribution first
│  ├─ Megasthenes → lost Indica through later authors; double filter
│  ├─ Arthashastra → layered prescription, not direct Mauryan manual
│  └─ Puranic/Buddhist/Jain traditions → source-qualified memory
│
├─ 2. RISE + CHRONOLOGY
│  ├─ Magadha-Nanda capacity + post-Alexander opportunity + Chandragupta's agency
│  ├─ c. 324/321 Chandragupta → c. 297 Bindusara → c. 268/273-232 Ashoka
│  ├─ accession ≠ consecration; Kalinga after eight completed consecrated years
│  └─ post-232 bridge only → detailed decline belongs Topic 15
│
├─ 3. CHANDRAGUPTA / SELEUCUS / BINDUSARA
│  ├─ Chanakya-Nanda details → late plural tradition, not literal contemporary record
│  ├─ Seleucus settlement → territorial clause debated + 500 elephants
│  ├─ epigamia → marriage/intermarriage uncertain; no named bride as fact
│  └─ Bindusara diplomacy firmer than precisely mapped Deccan conquest
│
├─ 4. TERRITORIAL MAP — RULE ≠ INFLUENCE
│  ├─ core → Pataliputra/middle Ganga
│  ├─ nodes → Taxila | Ujjayini | Tosali | Suvarnagiri, cautiously reconstructed
│  ├─ corridors/frontiers → NW, Saurashtra, Kalinga, Deccan edict belt
│  ├─ Chola/Pandya/Keralaputra/Satiyaputra/Tambapanni → neighbours/outreach, not provinces
│  └─ far south + much north-east unconquered/unproven; edict find-spot ≠ border
│
├─ 5. ADMINISTRATIVE CHAIN
│  ├─ king + ministers/council + mahamattas + princes/governors
│  ├─ pradeshika + rajuka + yukta → district level in official 2025 key
│  ├─ rajuka → justice/welfare; survey association qualified
│  ├─ pativedaka → Rock Edict VI reporting at any time/place
│  └─ town/village/guild/household/local elites → mediation and information gaps
│
├─ 6. COERCION + JUSTICE
│  ├─ army → infantry/cavalry/chariots/elephants; exact totals rhetorical
│  ├─ Megasthenes committees → fragmentary transmission, not universal chart
│  ├─ Arthashastra spies → prescriptive theory unless corroborated
│  ├─ Pillar Edict IV → rajukas + three-day reprieve
│  └─ post-Kalinga army, punishment, death penalty and forest warning remain
│
├─ 7. POLITICAL ECONOMY
│  ├─ agriculture/land/labour → bhaga + bali + tolls + fines → state capacity
│  ├─ Rummindei → local bali exemption + one-eighth bhaga, not universal rate
│  ├─ Sudarshana → later Junagadh evidence for Pushyagupta/Tushaspha
│  ├─ roads/trade/crafts/shrenis/coins → integration with local and private actors
│  └─ Arthashastra control model ≠ modern command economy
│
├─ 8. SOCIETY
│  ├─ Megasthenes' seven groups ≠ varna/jati census
│  ├─ dasa/dasi/bhataka/debt/service → dependency; prevalence unknown
│  ├─ Karuvaki → elite female donation agency, not general equality
│  └─ urban-rural, patriarchal and forest/frontier diversity persists
│
├─ 9. ASHOKA + KALINGA
│  ├─ Minor Rock Edict I → gradual Buddhist commitment; reject instant conversion
│  ├─ Rock Edict XIII → conquest + suffering claims + remorse + dhamma-vijaya
│  ├─ Separate Kalinga Edicts → restrained justice and confidence-building
│  └─ Kalinga retained; sovereignty and deterrence survive
│
├─ 10. DHAMMA
│  ├─ conduct → parents/elders/servants/Brahmanas/Shramanas/non-injury
│  ├─ Rock Edict XII → restraint, listening and sectarian concord
│  ├─ machinery → dhamma-mahamattas + tours + reports + oral/written proclamation
│  ├─ welfare/animal measures → selective moral policy, not modern welfare state
│  └─ Buddhist-rooted public ethic ≠ compulsory conversion / full pacifism
│
├─ 11. EDICTS + SCRIPTS + SITE TRAPS
│  ├─ Minor Rock | Major Rock | Separate Kalinga | Major/Minor Pillar
│  ├─ most → Prakrit-Brahmi; Shahbazgarhi/Mansehra → Kharoshthi
│  ├─ Kandahar/NW → Greek + Aramaic; adaptation, not uniform translation
│  ├─ Maski/Gujarra → Ashoka name; Rummindei/Nigali Sagar → pilgrimage
│  └─ always pair site + corpus + script + theme + audience
│
├─ 12. BUDDHISM + MATERIAL COMMUNICATION
│  ├─ Bhabru/Lumbini/Nigali Sagar/schism records → inscriptional patronage facts
│  ├─ Third Council + missions → later Sri Lankan chronicle tradition
│  ├─ Barabar → Ajivika; Sanchi → Ashokan core + later additions
│  ├─ pillars/Kumrahar → mobilisation and message; function/style qualified
│  └─ detailed art history → cross-link Indian Art and Culture Topic 02
│
├─ 13. HISTORIOGRAPHY
│  ├─ centralised thesis → court/revenue/army/officers/edicts
│  ├─ differentiated thesis → distance/ecology/language/local mediation/uneven archaeology
│  └─ synthesis → strong metropolitan and corridor state, graded reach elsewhere
│
└─ 14. PYQ + ANSWER ROUTE
   ├─ direct routes → 2019 Q8 | 2020 Q30 | 2022 Q60/Q91 | 2025 Q19
   ├─ official key held only where stated: 2025 Q19 = B, district level
   ├─ intro source matrix → rulers/map → administration/economy → Ashoka/dhamma
   └─ conclusion → unprecedented imperial integration without universal bureaucracy

QUALIFIED VERDICT:
Mauryan rule joined conquest, fiscal-military capacity, provincial nodes and public inscriptional
communication, but its depth varied by function and region; Ashoka moralised kingship without
abolishing coercion, religious plurality or local diversity.
```
