NEOLITHIC AND CHALCOLITHIC CULTURES
|
+-- 1. SCOPE AND CENTRAL CLAIM
|   +-- Topic 05 = regional movement toward cultivation, herding, villages and copper-stone
|   +-- Neolithisation = transition, not one sudden/irreversible "revolution"
|   +-- cultivation, domestication, pastoralism, sedentism, pottery, storage and polished stone
|   |   can appear separately; microliths and mobility may continue
|   `-- archaeological culture = recurring material pattern, NOT a people, language or race
|
+-- 2. HOW FOOD PRODUCTION EMERGED AND HOW TO PROVE IT
|   +-- environmental change + resource/population pressure + accumulated knowledge
|   |   + risk management + social demand + contact/mobility -> different regional pathways
|   +-- test independent development, adoption, migration and interaction as hypotheses;
|   |   crops, animals, pottery and tools may travel by different routes
|   +-- plants: presence -> use/processing -> cultivation -> morphology/dependence
|   +-- animals: presence -> management -> slaughter profile/pens -> morphology/dependence
|   `-- require context + stratigraphy + direct/associated date + multiple indicators;
|       wild/domestic and presence/cultivation are not interchangeable
|
+-- 3. REGIONAL NEOLITHIC MOSAIC
|   +-- NW / Mehrgarh -> Kachi plain, Baluchistan (present-day Pakistan);
|   |   7th millennium BCE food production, aceramic/ceramic phases -> regional antecedent,
|   |   NOT an all-India diffusion template
|   +-- Kashmir / Burzahom-Gufkral -> pit then surface houses, crops/animals,
|   |   bone-stone tools, burials -> valley-specific adaptation; not rock-cut shrines
|   +-- Belan-middle Ganga / Koldihwa-Mahagara-Pachoh-Indari-Lahuradewa -> rice/settlement evidence;
|   |   early rice-production pathway, but dates, context and wild/domesticated taxonomy debated
|   |   -> Mesolithic continuity; rice presence != domestication or one origin
|   +-- Eastern India / Chirand-Senuwar-Pandu Rajar Dhibi -> rice + fishing/hunting +
|   |   herding + bone tools; post-built houses; Neolithic-Chalcolithic overlap
|   +-- North-east / Daojali Hading-Sarutaru -> ground/shouldered stone tools + pottery;
|   |   uneven chronology; affinity/contact != automatic migration or ethnicity
|   `-- South India / Utnur-Piklihal-Sanganakallu-Kupgal-Budihal-Hallur-Brahmagiri-
|       Tekkalakota -> cattle, cultivation, ground stone, seasonal movement and ash mounds
|
+-- 4. MATERIAL LIFE, PRODUCTION AND SOCIAL CHANGE
|   +-- houses: Kashmir pits; circular/rectangular mud/reed/wattle structures; pens/camps
|   +-- tools: ground/polished axes and celts + microliths + bone tools + querns/grinders
|   +-- pottery/storage -> cooking, delayed consumption and risk management;
|   |   storage capacity != taxation, state or equality
|   +-- food portfolios -> wheat/barley; rice; millets/pulses; cattle/sheep/goat/pig;
|   |   hunting, fishing and wild foods -> mixed subsistence, not farming-only
|   +-- craft/exchange: ore/raw material -> extraction -> processing -> artisan
|   |   -> exchange -> household/elite use -> discard/burial; each link needs evidence
|   `-- house/storage/grave/craft differences -> possible access/specialisation;
|       do not automatically infer caste, kingship or hereditary class
|
+-- 5. SOUTHERN ASH-MOUND LOGIC
|   cattle penning/dung accumulation -> repeated burning -> ash mound
|   +-- possible sanitation/renewal/pest control
|   +-- possible aggregation/feasting/ritual
|   `-- formation process + settlement context + chronology decide; no single function fits all
|
+-- 6. CHALCOLITHIC = COPPER + STONE, NOT URBANISM
|   +-- copper occurs with stone, bone and wood; Neolithic and copper technologies overlap
|   +-- rural farming/herding + pottery + craft/exchange; writing, iron or planned cities
|   |   are NOT defining features
|   +-- broad textbook bands (use as scaffolding, not exact site dates):
|   |   Kayatha c. 2000-1500 BCE -> Malwa c. 1700-1200 BCE -> Jorwe c. 1400-700 BCE
|   +-- Ahar-Banas / SE Rajasthan (Ahar-Gilund-Balathal) -> copper, black-and-red ware,
|   |   farming/herding; not a Harappan city culture
|   +-- Ganeshwar-Jodhpura / Khetri belt -> copper craft + Harappan contact;
|   |   contact != absorption/control
|   +-- Kayatha-Malwa / western MP (Navdatoli, Eran, Nagda) -> distinctive/painted pottery,
|   |   villages, farming, craft and exchange; not one polity
|   +-- Savalda / Tapi-northern Maharashtra -> early western-Deccan phase
|   +-- Jorwe / Maharashtra (Jorwe, Nevasa, Inamgaon, Daimabad, Prakash)
|   |   -> painted ware, farming, craft and settlement hierarchy
|   `-- Eastern complexes / Bihar-Bengal-Odisha -> rice/fish/animal resources, pottery,
|       post-built houses; sparse excavation != simple society
|
+-- 7. INAMGAON, BURIALS AND INEQUALITY
|   +-- houses + storage + craft + burials + changing subsistence -> rural complexity,
|   |   coordination and differentiation
|   +-- large/fortified site, unequal ornaments or child burials -> evidence of hierarchy/
|   |   access, not automatic city, state, caste or hereditary chiefdom
|   `-- figurines, animal/human burial, grave goods and fire -> object + context +
|       alternatives + confidence; material meaning != automatic theology
|
+-- 8. OCP, COPPER HOARDS AND BOUNDARIES
|   +-- Ochre-Coloured Pottery and copper hoards = partly overlapping but distinct datasets
|   +-- stray copper find != secure settlement association; Ganeshwar-Jodhpura != OCP
|   +-- secure stratigraphy + metallurgy + settlement evidence required
|   `-- copper hoard/OCP != Aryan, race or one migrating ethnic group (Topic 07 owns identity)
|
+-- 9. CHANGE, HARAPPAN RELATION AND LATER TRANSITION
|   +-- decline may mean smaller sites, mobility, altered crops/water, trade change,
|   |   conflict/disease/reorganisation or environmental stress
|   +-- Late Jorwe/Inamgaon aridity is one factor among competing causes;
|   |   specify what declined: size, population, craft, exchange, storage or integration
|   +-- Harappan urbanism overlaps in time but differs in scale, writing, planning/integration;
|   |   rural Chalcolithic cultures are not "failed Harappan cities"
|   `-- Neolithic -> Chalcolithic -> Harappan -> Iron Age is NOT a universal ladder;
|       older technologies and villages persisted unevenly
