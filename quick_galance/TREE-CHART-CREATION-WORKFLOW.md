# Quick-Glance Tree-Chart Creation Workflow

This note records the research and composition steps used to produce the detailed,
terminal-friendly Polity 09 tree chart. It is a workflow reference, not a topic chart.

## Steps followed

1. **Read the repository instructions.** Check `AGENT_MEMORY.md` for the tree-chart
   standard: use the syllabus boundary, build one continuous learning-order tree, retain
   examinable details, and finish with traps, PYQ route and a qualified conclusion.

2. **Resolve the exact topic.** Check the V2 topic catalogue for the topic key, title,
   subject spelling, and canonical Basic and Advanced owners. For this example, Polity
   topic 09 is **Fundamental Duties**.

3. **Check tracker context.** Inspect the quick-glance status record and existing chart
   path to understand whether the topic is already tracked and how its output is named.
   Do not treat an existing chart as a substitute for reading the source owners.

4. **Read the complete Basic owner first.** Extract the core definition, constitutional
   location, history, all clauses, legal character, rights relationship, implementation,
   criticism, prelims traps and answer structure in its natural learning order.

5. **Read the complete Advanced owner.** Add useful depth without making it a
   prerequisite for the core explanation. Preserve case-law distinctions, institutional
   limitations, implementation details and cautions against overstatement.

6. **Reconcile the complete topic package and PYQ evidence.** Use the package and its
   audit/ledger references to identify verified direct questions, supporting
   cross-topic questions and any answer-key uncertainty. Keep routing ownership intact;
   do not invent a direct PYQ or upgrade an inferred answer to an officially verified one.

7. **Set the central question and logical spine.** Arrange the material so the reader can
   follow one connected route:
   origin and amendments -> exact provisions -> legal effect -> relationships and
   mechanisms -> implementation and cases -> criticism and safeguards -> traps ->
   PYQ/answer route -> qualified conclusion.

8. **Draft a continuous terminal tree.** Use a single fenced text diagram with branches,
   arrows and nested sub-branches. Prefer concise claims and claim -> reason ->
   consequence links over paragraphs, while preserving exact dates, Article/clause
   references, statute sections, age ranges and named cases where relevant.

9. **Keep close distinctions together.** Place commonly confused pairs beside each
   other—for example, proposal versus enacted text, non-justiciability versus statutory
   enforcement, interpretive value versus overriding rights, and a verified answer versus
   an inferred answer.

10. **Cross-check coverage and qualifications.** Compare the draft against the Basic
    owner, Advanced owner and PYQ evidence. Confirm that the complete core sequence,
    relevant advanced refinements, case distinctions, limitations, examiner traps and
    answer route are represented without contradicting one another.

11. **Deliver in the requested form.** If the user asks for the chart on the terminal,
    provide it inline and do not create, replace or delete the topic chart file. If the
    user asks to export/save the chart, write it to the established subject/topic path
    and then refresh the completion index, status JSON and pending-command index using
    the repository's inventory tool.

12. **Report changed files exactly.** State every repository-relative path created or
    modified. If none changed, say `Files changed: none`.

## Polity 09 example: coverage checklist

- Part IVA, Article 51A; 42nd Amendment (1976), 86th Amendment (2002), and the
  Swaran Singh Committee's eight recommendations versus ten enacted duties.
- All eleven clauses (a)-(k), including the complete meaning of each duty and the
  parent/guardian and age conditions in clause (k).
- Citizen-only scope; non-justiciability; no self-executing offence; valid legislative
  implementation; interpretive use; and the Fundamental Rights safeguard.
- Relationship with Parts III and IV, including Articles 21A, 45 and 48A where
  relevant.
- Verma Committee's education/awareness approach and its identification of existing
  laws, without claiming it created duties or offences.
- Relevant statutes and case-law distinctions, especially conscience and national
  symbols, environment and animal welfare, with each holding stated within its limits.
- Criticisms, counterarguments, reform safeguards and high-risk close-option traps.
- PYQ ownership, answer-key confidence, an executable answer-writing route and a
  qualified conclusion.

## Scope note

This workflow note does not itself mark a topic chart complete or change the atlas
tracker. For a saved topic chart, follow the repository's catalogue order and refresh
the three quick-glance inventory files after the chart content is complete.
