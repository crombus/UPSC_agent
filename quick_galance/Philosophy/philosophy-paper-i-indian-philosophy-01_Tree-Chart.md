                      CENTRAL THESIS
Restrict valid knowledge to perception (pratyakṣa), and every supersensible entity
leaves the world together. The metaphysics is not an independent preference: it is the
ontological consequence of one epistemic rule. Strength = epistemic economy plus a real
problem about universals. Weakness = the universal denial of inference looks inferential.

+-- 4. THEORY OF KNOWLEDGE ---------------------------------------------------------+
|  THESIS -> perception (pratyakṣa) is the ONLY independent means of valid knowledge  |
|            (pramāṇa). Stronger than "perception is primary".                        |
|  ADMITTED:                                                                          |
|    external perception (bāhya)  -> colours, sounds, tastes, smells, touches, bodies |
|    internal perception (mānasa) -> pleasure, pain, desire, conscious states          |
|  REFUSED AS INDEPENDENT:                                                            |
|    inference (anumāna) · testimony (śabda) · comparison (upamāna) ·                 |
|    postulation (arthāpatti) · non-cognition (anupalabdhi)                            |
|  ARGUMENT -> knowledge must be grounded in the immediately given; only perception    |

+-- 5. WHY INFERENCE IS REJECTED (2018 · 2019 · 2025) ------------------------------+
|  Every inference needs invariable concomitance (vyāpti): "wherever smoke, there     |
|  fire". How could that unrestricted universal be known?                             |
|    DOOR 1 perception -> finite survey; past, future and distant cases unobserved     |
|    DOOR 2 inference  -> needs a further vyāpti -> circularity or infinite regress    |
|    DOOR 3 testimony  -> its own validity is unproved and itself inferred             |
|  Sharma's reductio -> if testimony grounded vyāpti, "none would be able to infer     |
|  anything by himself"                                                               |
|  HIDDEN LIMITING CONDITION (upādhi) -> the observed constancy may have tracked an    |
|  unnoticed qualifier (fire PLUS wet fuel). Structural, not merely "too few cases".   |
|  ACCIDENTAL TRUTH -> some inferences are true by accident, so predictive success     |
|  never converts habit into warrant                                                  |
|  CONCEDED -> movement from sign to signified happens constantly                      |
|  DENIED   -> that it yields necessary, exceptionless knowledge                       |

+-- 6. WHY TESTIMONY IS REJECTED ---------------------------------------------------+
|  Words heard are perceived; their CONTENT is not. The step from utterance to truth  |
|  needs a suppressed premise about the speaker's competence and honesty, which is    |
|  inferred -> testimony is "as precarious as inference".                             |
|  Veda -> authorlessness and infallibility are not perceptually certifiable          |
|  NOT DENIED -> ordinary communication; language may guide action until perception   |
|  checks it. Usefulness is separated from means-of-valid-knowledge status.           |

                    QUALIFIED CONCLUSION
Cārvāka is strongest as a demand that ontology never outrun warranted experience, and as
a live challenge to the move from finite observation to unrestricted universals and
transcendent entities. Its four-element materialism, body-self and anti-ritualism follow
coherently from that single premise. As a complete theory of knowledge it fails: the
strict perception-only rule is self-referentially unstable and too narrow for science,
memory and social knowledge, and Nyāya answers it by exchanging omniscient certainty for
disciplined, defeasible warrant. The refined worldly empiricism and Jayarāśi's
destructive dialectic preserve its critical force without defending the hostile
caricature — which is why Chatterjee and Datta call the school a touchstone, while
Sharma judges that, "born in discontent, it soon died in serious thought".
