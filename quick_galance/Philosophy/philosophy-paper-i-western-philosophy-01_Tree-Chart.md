# Philosophy Optional — Paper I — Western Philosophy 01 — Plato and Aristotle

> **Quick-glance revision tree.** Concise and revision-oriented. It does not
> duplicate the complete learning session, the ASCII master flow diagram or the

> **Terminology:** English concept first, Greek term immediately after in parentheses.

CENTRAL THESIS
Both answer one question - how can many changing things share one knowable
character? Plato separates the character from the thing (transcendent Form);
Aristotle keeps it inside the thing (immanent essence). Everything else they
disagree about follows from that single answer.

|                                                                           |
|  1. WHAT A FORM IS (eidos, idea)                                          |
|     eternal | immutable | non-material | self-identical | separate         |
|     -> each property does a job: knowability, one-for-many, non-relativity |
|     -> Beauty itself, not any beautiful thing                              |
|     -> the Good gives Forms BEING + KNOWABILITY; "beyond being"            |
|        (epekeina tes ousias), Republic 509b                                |
|     TRAP: "realm" is not a place; Forms are not concepts in minds;         |

|                                                                           |
|  2. WHY POSITED - four arguments                                          |
|     one-over-many (Rep. V; Parm. 132a) | from knowledge (Rep. V-VII) |     |
|     opposites (Phaedo 74a-75d) | recollection (Phaedo 72e-77a; Meno 80d-86c)|
|     TRAP: recollection is ONE route, not the whole epistemology            |
|                                                                           |
|  3. TIMELESS AND SPACELESS  [PYQ 2025 Q1a - DERIVE, do not assert]         |
|     non-material -> no magnitude/shape/position -> SPACELESS               |
|     self-identical -> no generation/alteration -> TIMELESS                 |
|     -> cannot be otherwise -> object of knowledge (episteme), not opinion  |
|     TRAP: timeless is NOT everlasting                                      |
|                                                                           |
|  4. SUN - DIVIDED LINE - CAVE (Rep. VI 507a - VII 517a): ONE argument      |
|     SUN (VI 508b-509c): the Good gives Forms being + knowability          |
|     DIVIDED LINE (VI 509d-511e), lowest to highest:                       |
|       eikasia -> images | pistis -> visible things                        |
|       dianoia -> mathematicals | noesis -> Forms, then the Good           |
|       PRIMARY CUT: D+C = doxa | B+A = episteme      MNEMONIC: E-P-D-N      |
|       DISCRIMINATOR: direction of argument + use of images, NOT difficulty |
|         dianoia argues DOWN from hypotheses "taken as known", uses diagrams|
|         noesis argues UP to an unhypothetical principle, uses no images    |
|     CAVE (VII 514a-517a) = the Line narrated as an education               |
|       shadows -> fire and artefacts -> reflections -> things -> the Sun    |
|       ADDS 1: pain and compulsion; education is conversion (periagoge)     |
|               of the whole soul, not information poured in                 |
|       ADDS 2: the return (katabasis) - ridicule, danger, the Socrates      |
|               allusion -> the political argument for philosopher-rulers    |
|       Plato's instruction at 517a-b: apply the image AS A WHOLE            |
|     WEAK LINK: seeing the Good does not by itself entitle one to rule      |
|       -> Popper, The Open Society and Its Enemies I (1945); polemical and  |
|          contested                                                        |
|                                                                           |
|  5. PARTICIPATION (methexis) / IMITATION (mimesis) UNDER PRESSURE          |
|     DILEMMA (Parm. 131a-c): whole -> separated from itself                 |
|                             part  -> divided Smallness enlarges           |
|       reply: Forms are not extended bodies                                |
|     REGRESS (Parm. 132a-b): self-predication + non-identity -> a further   |
|       Form at every stage. NAME "Third Man" from Aristotle's reports       |
|       (Met. 990b17, 1039a2). ESCAPE: deny self-predication                 |
|     CAUSAL IMPOTENCE: survives every escape route                         |
|     VERDICT FORMULA: not proven inconsistent, but EXPLANATORILY EMPTY      |
|                                                                           |
|  6. PLATO'S CAUSAL REPERTOIRE - keep the dialogues distinct                |
|     Phaedo Forms = formal explanation, no mechanism of motion              |
|     Republic Good = ground of being and knowability, not a creator-God     |
|     Timaeus Demiurge = orders becoming after paradigms, creates nothing    |
|       from nothing | Receptacle (chora) = the third kind, NOT hyle         |
|     SAY THIS: separated Forms THEMSELVES explain neither motion,           |
|       generation nor internal organisation. NOT "Plato has no causes"      |

+------------------------- ARISTOTLE ---------------------------------------+
|                                                                           |
|  7. THE CRITIQUE (Metaphysics I.9; XIII.4-5) - five objections             |
|     regress | duplication | participation is a metaphor | causal impotence |
|     | no account of generation                                            |
|     ONLY THE REGRESS needs self-predication, so 2-5 survive every escape   |
|     Stace's report: the Ideas are "nothing but eternalized things of       |
|     nature"; the theory puts the essences OUTSIDE the things               |
|     THE REPAIR: keep the eidos, DELETE the separation                      |
|       form = immanent what-it-is-to-be (to ti en einai) of THIS composite  |
|     TRAP: never "Aristotle rejected forms / denies universals" -           |
|       species and genus survive as SECONDARY substances                    |
|     PRICE: Met. VII (Z).13 - "no universal is a substance"                 |
|                                                                           |
|  8. SUBSTANCE (ousia) - two questions, two criteria                        |
|     CATEGORIES 2a11: WHICH things are substances? logical criterion        |
|       primary = the individual (tode ti) | secondary = species, genus      |
|     METAPHYSICS Z: what is substance-HOOD? causal-explanatory criterion    |
|       Z.3 candidates: matter REJECTED | essence ACCEPTED |                 |
|                       universal REJECTED (Z.13) | genus REJECTED          |
|       Z.17: substance sought as a CAUSE - "why is this matter a house?"    |
|     READINGS (name two): different questions [safest] | Jaeger developmental|
|       | Frede-Patzig individual form | Owen species form  [last 3 contested]|
|     TEN CATEGORIES: substance + quantity, quality, relation, place, time,  |
|       position, state, action, being affected                             |
|       substance IS; accidents BELONG TO. alteration vs generation          |
|       TRAP: they are modes of predication, not physical parts              |
|                                                                           |
|  9. HYLOMORPHISM - matter (hyle) + form (morphe) = compound (synolon)      |
|     matter is RELATIVE (copper+tin -> bronze -> statue); the pair is       |
|       CORRELATIVE - never two objects joined                              |
|     SOUL = the form of the living body (De Anima II.1)                     |
|     CHANGE = subject + acquired form + privation (steresis)                |
|       accidental -> substantial form PERSISTS                             |
|       substantial -> NEW form, NEW substance                              |
|     PRIME MATTER (prote hyle) = limit concept, never independent,          |
|       commitment DISPUTED; not the Receptacle                             |
|     2025 Q1b BOUNDARY on "everything": holds of sensible substances; NOT   |
|       accidents apart, NOT mathematicals, NOT the Unmoved Mover            |
|                                                                           |
| 10. FOUR CAUSES (aitiai) - Physics II.3                                    |
|     material (bronze/wood) | formal (Hermes-shape/table-design) |          |
|     efficient (sculptor/carpenter) | final (honour the god/dining surface) |
|     ALL FOUR OPERATE SIMULTANEOUSLY; "cause" covers reasons too (Stace)    |
|     Mill's "invariable and unconditional antecedent" excludes final causes |
|     IN ORGANISMS formal = efficient = final converge on the mature form    |
|     "Nature does nothing in vain" (De Caelo, Politics, De Part. Anim.) =   |
|       REGULARITY, not deliberation -> DIRECTEDNESS, NOT DESIGN             |
|     TRAP: not four events, not four agents; use ONE worked example         |
|                                                                           |
| 11. POTENTIALITY AND ACTUALITY                                            |
|     dynamis -> kinesis -> energeia / entelecheia                          |
|       wood -> carpenter working -> finished table  [PYQ 2021 Q1b]          |
|     CHANGE = "the actuality of the potential AS POTENTIAL"                 |
|       Physics III.1, 201a10 - the qualifier is essential                   |
|     "POTENTIALITY IS INDEFINABLE": dynamis presupposes energeia            |
|     TRAP: dynamis is a CAPACITY, never a probability                       |
|     PARMENIDES (no becoming) + HERACLITUS (only flux) both assume          |
|       being/non-being only -> Aristotle adds BEING-IN-POTENTIALITY and     |
|       denies the dichotomy; stability moves into the FORM aimed at         |
|     PRIORITY OF ACTUALITY: definition | time at SPECIES level | substance  |
|       CONCEDE: in the individual, the potential state precedes             |
|     FORM OVER MATTER = the same priority stated structurally  [2020 Q1a]   |

|       a FINAL cause, "as the beloved moves the lover"; thought thinking    |

|       TRAP: not an efficient creator, not a first event in time            |

QUALIFIED CONCLUSION
Plato secures stability, objectivity and knowledge and forfeits causation;
Aristotle secures causation, unity and generation and forfeits a clean account
of universals at Z.13. Aristotle therefore defeats SEPARATION, not FORM: he
transforms Plato's insight rather than erasing it, and the unresolved remainder
becomes the problem of universals and every later realism-nominalism debate.
