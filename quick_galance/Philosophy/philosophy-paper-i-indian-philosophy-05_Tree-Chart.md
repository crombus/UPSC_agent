+-- I. EPISTEMOLOGICAL FRAME
|   +-- Three pramāṇas:
|   |   +-- Pratyakṣa: determinate cognition arising through sense-object relation.
|   |   +-- Anumāna: knowledge through a sign pervaded by what is inferred.
|   |   +-- Āptavacana / śabda: trustworthy verbal testimony.
|   +-- Exactly three are admitted; the rest are REDUCED, not rejected as useless:
|   |   +-- Upamāna to inference or testimony.
|   |   +-- Arthāpatti to inference.
|   |   +-- Anupalabdhi to perception's failure-conditions, not a separate pramāṇa.
|   |   +-- Sambhava to inference.
|   |   +-- Aitihya to testimony when reliable; otherwise rejected.
|   +-- Anumāna is threefold:
|   |   +-- Pūrvavat: antecedent/cause to effect. Clouds to rain.
|   |   +-- Śeṣavat: effect/residue to cause. One drop to the sea being salty.
|   |   +-- Sāmānyato-dṛṣṭa: general correlation whose connecting terms are not
|   |       themselves perceived. Sun in different positions to the sun moving.
|   +-- Sāmānyato-dṛṣṭa inference:
|   |   +-- Infers imperceptible principles from general functional facts.
|   |   +-- Central to proving Prakṛti and Puruṣa.
|   |   +-- Does not infer one observed cause from one observed effect alone.
|   +-- Eight causes of non-perception:
|   |   +-- Excessive distance, excessive proximity, defect of the organ, inattention of
|   |   |   mind, saukṣmya (subtlety), obstruction, being overpowered, admixture.
|   |   +-- Mūla-prakṛti's imperceptibility is assigned to saukṣmya; Puruṣa is likewise
|   |       atīndriya. Imperceptibility is therefore not non-existence.
|   +-- The self-imposed burden:
|   |   +-- Both ultimates are atīndriya, so perception cannot reach them, and testimony
|   |   |   alone would beg the question against non-Vedic opponents.
|   |   +-- The whole evidential weight therefore falls on sāmānyato-dṛṣṭa inference.
|   +-- Objections:
|   |   +-- Cārvāka: vyāpti cannot be secured for a term never perceived.
|   |   |   +-- Reply: strict perceptualism cannot explain ordinary causal reasoning.
|   |   +-- Nyāya: legitimate but over-extended; atoms plus Īśvara is more economical.
|   |       +-- Reply: adding God does not explain material continuity itself.
|   +-- Cognition is a modification of buddhi, not an action of Puruṣa.
|   +-- Object affects senses -> manas coordinates -> ahaṃkāra appropriates ->
|       buddhi determines -> consciousness reflected from Puruṣa illuminates cognition.

+-- II. PRAKṚTI
|   +-- Synonyms:
|   |   +-- Pradhāna: chief material principle.
|   |   +-- Avyakta: unmanifest.
|   |   +-- Mūla-prakṛti: root nature.
|   +-- Nature:
|   |   +-- One.
|   |   +-- Eternal and beginningless.
|   |   +-- Uncaused.
|   |   +-- Unconscious.
|   |   +-- Productive but itself not a product.
|   |   +-- Composed of sattva, rajas and tamas in equilibrium.
|   +-- Prakṛti is not gross matter.
|   +-- It is the subtle, unmanifest ground from which intellect, ego, senses and elements
|       all evolve.
|
+-- III. FIVE ARGUMENTS FOR PRAKṚTI
|   +-- 1. Bhedānāṃ parimāṇāt: from finitude/determinateness of effects.
|   |   +-- Limited, differentiated products require a common unlimited causal ground.
|   |   +-- The manifest cannot be its own ultimate explanation.
|   +-- 2. Samanvayāt: from uniformity running through effects.
|   |   +-- Effects display an underlying order and common pattern.
|   |   +-- Diverse products reveal continuity of constitution and dependence.
|   |   +-- Coordinated diversity points to a common material basis.
|   +-- 3. Śaktitaḥ pravṛtteś ca: from operation due to causal power.
|   |   +-- A cause produces only what lies within its power (śakti).
|   |   +-- The world's ordered potential requires a sufficient material source.
|   |   +-- Textual control: Sāṃkhyakārikā 15 reads śaktitaḥ pravṛtteś ca, NOT
|   |       kāryataḥ pravṛtteḥ. The argument is from power, not from planning;
|   |       the misreading turns a nirīśvara argument into a design argument.
|   +-- 4. Kāraṇa-kārya-vibhāgāt: from distinction of cause and effect.
|   |   +-- Manifest products resolve into subtler causes.
|   |   +-- Regress terminates in an unmanifest, non-product cause.
|   +-- 5. Avibhāgāt vaiśvarūpyasya: from the undivided source of the diversified
|       |   universe. THIS IS THE ONLY PROOF THAT SHOWS PRAKṚTI MUST BE ONE.
|       +-- The world is astonishingly diverse, yet the diversity forms one
|       |   interconnected cosmos.
|       +-- A diversified whole points back to an undivided source in which later
|       |   differentiations are not yet separated.
|       +-- Bridge sentence for 2019 Q8(c): plurality at the root would destroy the
|       |   undividedness from which the inference proceeds, falsifying the premise
|       |   rather than merely complicating the conclusion.
|       +-- Proofs 1-4 are each compatible with several material roots, because none
|           of them takes unity as a premise.
|
+-- IV. THREE GUṆAS
|   +-- Guṇa means constituent strand, not merely accidental quality.
|   +-- Sattva:
|   |   +-- Lightness, illumination, buoyancy, clarity.
|   |   +-- Pleasure and knowledge-associated functioning.
|   +-- Rajas:
|   |   +-- Activity, stimulation, motion, restlessness.
|   |   +-- Pain, effort and propulsion-associated functioning.
|   +-- Tamas:
|   |   +-- Heaviness, restraint, obscurity, inertia.
|   |   +-- Indifference, delusion and resistance-associated functioning.
|   +-- All products contain all three in changing ratios.
|   +-- No guṇa operates in complete isolation.
|   +-- Analogies:
|   |   +-- Lamp: oil, wick and flame cooperate despite different functions.
|   |   +-- Rope: three strands form one operative whole.
|   +-- Equilibrium:
|   |   +-- In unmanifest Prakṛti, guṇas are in balanced tension.
|   +-- Disequilibrium:
|       +-- Puruṣa's proximity disturbs balance.
|       +-- Evolution begins through dominance/subordination among guṇas.
|
+-- V. GUṆA-PARIṆĀMA
|   +-- Sarūpa-pariṇāma:
|   |   +-- Homogeneous transformation within equilibrium.
|   |   +-- Guṇas change within their own form without manifest differentiation.
|   +-- Virūpa-pariṇāma:
|   |   +-- Heterogeneous transformation after disequilibrium.
|   |   +-- One guṇa temporarily dominates while others support.
|   |   +-- Produces the manifest tattva sequence.
|   +-- Change is internal reconfiguration of the material cause.
|   +-- Nothing enters Prakṛti from Puruṣa; consciousness is not converted into matter.
|
+-- VI. PURUṢA
|   +-- Pure consciousness / witness.
|   +-- Many, eternal, uncaused and unchanging.
|   +-- Without guṇas.
|   +-- Inactive: akartṛ.
|   +-- Witness: sākṣin.
|   +-- Seer: draṣṭṛ.
|   +-- Experiencer in the sense that buddhi's states are presented to it.
|   +-- Not intellect, ego, mind, body, pleasure or pain.
|   +-- Consciousness is Puruṣa's nature, not an acquired quality.
|   +-- Puruṣa does not evolve and is not a tattva produced from Prakṛti.
|
+-- VII. FIVE ARGUMENTS FOR PURUṢA
|   +-- 1. Saṅghāta-parārthatvāt: composites exist for another.
|   |   +-- Body, senses and mind are organised instruments.
|   |   +-- An instrument serves a conscious non-composite user.
|   |   +-- Objection: one aggregate may serve another aggregate.
|   |   +-- Reply: the chain requires a final conscious beneficiary.
|   +-- 2. Triguṇādi-viparyayāt: witness is contrary to guṇas.
|   |   +-- The known is pleasurable, painful or delusive.
|   |   +-- Awareness of these must differ from them.
|   +-- 3. Adhiṣṭhānāt: coordinated experience needs a presiding principle.
|   |   +-- Unconscious instruments do not illuminate themselves.
|   +-- 4. Bhoktṛ-bhāvāt: experience requires an enjoyer.
|   |   +-- Pleasure and pain are presented as experienced.
|   |   +-- Prakṛti supplies content; Puruṣa supplies illumination.
|   +-- 5. Kaivalyārthaṃ pravṛtteḥ: striving for release implies a liberable witness.
|       +-- Material processes alone do not explain aspiration to transcend guṇa-life.
|   +-- Critical verdict:
|       +-- Together they establish a consciousness/material distinction.
|       +-- They do not compel every attribute of classical Puruṣa without further premises.
|
+-- VIII. PLURALITY OF PURUṢAS
|   +-- Janma-maraṇa-karaṇānāṃ pratiniyamāt:
|   |   +-- Births, deaths and embodied instruments are individually ordered.
|   +-- Ayugapat-pravṛtteḥ:
|   |   +-- Different beings act at different times.
|   +-- Triguṇa-viparyayāt:
|   |   +-- Guṇa constitutions and fortunes differ.
|   +-- The three arguments above map directly onto Sāṃkhyakārikā 18.
|   +-- Liberation is non-simultaneous. SUPPLEMENTARY inference only.
|   |   +-- If one Puruṣa, one's release should release all.
|   |   +-- It is NOT a fourth phrase of that verse; present it as reinforcement.
|   +-- Moral individuality requires distinct witnessing centres.
|   +-- Advaita objection:
|   |   +-- One consciousness appears many through limiting adjuncts.
|   +-- Sāṃkhya reply:
|   |   +-- Distinct causal biographies and release cannot be reduced to one experiencer.
|   +-- Residual pressure:
|       +-- Because Puruṣas are qualitatively identical and inactive, their numerical
|           individuation is asserted more clearly than explained.
|
+-- IX. JĪVA AND PURUṢA
|   +-- Puruṣa:
|   |   +-- Pure, isolated witness.
|   +-- Jīva:
|   |   +-- Puruṣa apparently associated with subtle body, ego and karmic dispositions.
|   +-- Bondage belongs strictly to buddhi/Prakṛti but is attributed to Puruṣa through
|       non-discrimination.
|   +-- Liberation does not transform Puruṣa; it removes false identification.
|
+-- X. TWENTY-FIVE TATTVAS
|   +-- 1. Prakṛti: cause only, never effect.
|   +-- 2. Mahat / buddhi: first evolute.
|   +-- 3. Ahaṃkāra: individuation / I-maker.
|   +-- From sāttvika ahaṃkāra:
|   |   +-- 4. Manas.
|   |   +-- 5-9. Five jñānendriyas:
|   |   |   +-- Hearing, touch, sight, taste, smell.
|   |   +-- 10-14. Five karmendriyas:
|   |       +-- Speech, grasping, locomotion, excretion, reproduction.
|   +-- Rajas supplies activity to both sāttvika and tāmasa evolutions.
|   +-- From tāmasa ahaṃkāra:
|   |   +-- 15-19. Five tanmātras:
|   |   |   +-- Sound, touch, form/colour, taste, smell.
|   |   +-- 20-24. Five mahābhūtas:
|   |       +-- Ākāśa, air, fire, water, earth.
|   +-- 25. Puruṣa: neither cause nor effect within material evolution.
|
+-- XI. CAUSE–EFFECT CLASSIFICATION
|   +-- Prakṛti:
|   |   +-- Avikṛti: cause, not product.
|   +-- Seven prakṛti-vikṛtis:
|   |   +-- Mahat.
|   |   +-- Ahaṃkāra.
|   |   +-- Five tanmātras.
|   |   +-- Each is produced and productive.
|   +-- Sixteen vikṛtis:
|   |   +-- Eleven senses including manas.
|   |   +-- Five gross elements.
|   |   +-- Products, not further productive in the tattva series.
|   +-- Puruṣa:
|       +-- Neither prakṛti nor vikṛti.
|
+-- XII. MAHAT, BUDDHI AND AHAṂKĀRA
|   +-- Mahat:
|   |   +-- Cosmic first evolute viewed universally.
|   +-- Buddhi:
|   |   +-- Same tattva viewed as individual determinative faculty.
|   |   +-- Functions: ascertainment, decision, discrimination.
|   |   +-- Sāttvika dispositions: dharma, knowledge, dispassion, power.
|   |   +-- Tāmasa opposites: adharma, ignorance, attachment, incapacity.
|   +-- Ahaṃkāra:
|       +-- I-maker / appropriation.
|       +-- Converts determined cognition into "I know", "I act", "mine".
|       +-- Root of practical individuality and misidentification.
|   +-- Buddhi is not Puruṣa despite seeming conscious.
|   +-- It is transparent enough to reflect consciousness.
|
+-- XIII. ANTAḤKARAṆA AND COGNITION
|   +-- Internal instrument:
|   |   +-- Buddhi: determination.
|   |   +-- Ahaṃkāra: appropriation.
|   |   +-- Manas: attention, coordination and doubt.
|   +-- External senses deliver differentiated data.
|   +-- Buddhi assumes object's form as vṛtti.
|   +-- Puruṣa's consciousness is reflected in buddhi.
|   +-- Cognition appears conscious and owned.
|   +-- Two-way appearance:
|       +-- Unconscious buddhi appears conscious.
|       +-- Inactive Puruṣa appears agent/enjoyer.
|
+-- XIV. SUBTLE BODY AND TRANSMIGRATION
|   +-- Liṅga-śarīra / sūkṣma-śarīra, commonly counted as EIGHTEEN constituents:
|   |   +-- Buddhi 1 + ahaṃkāra 1 + eleven capacities INCLUDING manas 11 +
|   |   |   five tanmātras 5 = 18.
|   |   +-- Omitting manas from the eleven wrongly yields seventeen.
|   +-- Conditioned by dispositions (bhāva) and the eight tendencies of buddhi:
|   |   +-- Merit/demerit, knowledge/ignorance, detachment/non-detachment,
|   |   |   power/powerlessness.
|   |   +-- Described as primordially arisen within the evolutionary cycle.
|   +-- Gross body ends.
|   +-- Subtle psychophysical complex continues under karma.
|   +-- Puruṣa itself does not travel as an acting thing; association with successive
|       subtle/gross embodiments constitutes transmigration.
|   +-- Kaivalya ends the purpose of subtle-body continuation.
|
+-- XV. SATKĀRYAVĀDA
|   +-- Sat-kārya-vāda:
|   |   +-- Effect exists in material cause before manifestation.
|   +-- Production:
|   |   +-- Manifestation, transformation and rearrangement.
|   |   +-- Not creation of sheer non-being.
|   +-- Five arguments:
|   |   +-- Asadakaraṇāt:
|   |   |   +-- What is wholly non-existent cannot be produced.
|   |   +-- Upādāna-grahaṇāt:
|   |   |   +-- A specific material cause is selected for a specific effect.
|   |   +-- Sarvasambhavābhāvāt:
|   |   |   +-- Everything does not arise from everything.
|   |   +-- Śaktasya śakya-karaṇāt:
|   |   |   +-- A cause produces only what its capacity contains.
|   |   +-- Kāraṇa-bhāvāt:
|   |       +-- Effect shares the nature of its cause.
|   +-- Mango seed:
|       +-- Tree is not visibly miniature inside seed.
|       +-- Tree pre-exists as determinate causal potential/material nature.
|       +-- Water, soil and heat enable manifestation but cannot make a mango seed
|           produce an unrelated species.
|
+-- XVI. PARIṆĀMAVĀDA
|   +-- Material cause really transforms into effect.
|   +-- Cause persists through changed configuration.
|   +-- Milk becomes curd.
|   +-- Prakṛti becomes its evolutes.
|   +-- Effect is both non-different from cause in material being and different as
|       manifest form/function.
|   +-- Not Advaita vivartavāda:
|   |   +-- Vivarta is apparent transformation; Brahman does not really become world.
|   +-- Not Nyāya asatkāryavāda:
|   |   +-- Nyāya effect-whole is newly produced and prior absence terminates.
|   +-- Not Buddhist dependent origination:
|       +-- Buddhism rejects one enduring material substrate and treats conditioned
|           processes as momentary/dependently arisen.
|
+-- XVII. THREE KINDS OF SUFFERING
|   +-- Ādhyātmika:
|   |   +-- Internal bodily/mental suffering.
|   +-- Ādhibhautika:
|   |   +-- Suffering caused by other beings/material environment.
|   +-- Ādhidaivika:
|       +-- Suffering attributed to unseen/cosmic forces.
|   +-- Ordinary remedies are temporary and impure.
|   +-- Final remedy requires knowledge of manifest, unmanifest and knower.
|
+-- XVIII. BONDAGE
|   +-- Root: aviveka / non-discrimination.
|   +-- Puruṣa identifies with buddhi's guṇa-transformations.
|   +-- "I know", "I suffer", "I act" transfer Prakṛti's properties to Puruṣa.
|   +-- Agency actually belongs to guṇa activity.
|   +-- Consciousness actually belongs to Puruṣa.
|   +-- Karma attaches to subtle-body causal stream, not pure Puruṣa.
|   +-- Bondage is beginningless misidentification, not real modification of consciousness.
|
+-- XIX. LIBERATION / KAIVALYA
|   +-- Means: viveka-jñāna / discriminative knowledge.
|   +-- Insight:
|   |   +-- "I am not Prakṛti, guṇas, buddhi, ego, senses or body."
|   |   +-- Puruṣa is pure witness.
|   +-- Prakṛti has two purposes:
|   |   +-- Bhoga: experience.
|   |   +-- Kaivalya: release through discrimination.
|   +-- Three soteriological goals that must never be interchanged:
|   |   +-- Kaivalya (Sāṃkhya): isolation of the witness.
|   |   +-- Mokṣa (Advaita): identity with Brahman.
|   |   +-- Apavarga (Nyāya): cessation of suffering.
|   +-- Dancer analogy:
|   |   +-- Dancer performs until seen, then withdraws.
|   |   +-- Prakṛti ceases display for discriminating Puruṣa.
|   +-- Blind-and-lame analogy:
|   |   +-- Blind active Prakṛti carries lame seeing Puruṣa.
|   |   +-- Cooperation enables experience; after purpose, association ends.
|   +-- Jīvanmukti:
|   |   +-- Knowledge arises while body continues due to prior momentum.
|   +-- Potter's-wheel analogy:
|   |   +-- Existing momentum continues after causal push stops.
|   +-- Videhamukti:
|       +-- On exhaustion of residual karma, complete isolation.
|   +-- Kaivalya is isolation, not merger, divine communion or production of bliss.
|   +-- Strict formulation: Puruṣa is never really bound, liberated or transmigrating;
|       these belong to Prakṛti and the subtle body, and knowledge ends false
|       attribution.
|
+-- XX. PURUṢA–PRAKṚTI RELATION PROBLEM
|   +-- They are independent, eternal and opposite.
|   +-- Puruṣa is inactive; Prakṛti unconscious.
|   +-- How can relation, reflection, experience or purposive evolution begin?
|   +-- Sāṃkhya response:
|   |   +-- Sannidhi / proximity, not physical contact.
|   |   +-- Magnet-iron analogy: explains ACTIVATION BY PRESENCE.
|   |   +-- Crystal-flower analogy: transparent crystal seems coloured without becoming
|   |   |   the flower. Explains APPARENT CONTAMINATION WITHOUT REAL CHANGE.
|   |   +-- The two analogies do different jobs; neither does both.
|   +-- Śaṃkara's objection:
|   |   +-- Even a magnet EXERTS FORCE, so a magnet-like Puruṣa would not be inactive.
|   |   +-- The crystal explains appearance but not the INITIATION of world-process.
|   |   +-- Mere proximity cannot explain influence.
|   |   +-- If relation real, dual absolutes lose independence.
|   |   +-- If relation unreal, experience remains unexplained.
|   |   +-- Pressed verdict: the dualism is unstable and must either collapse toward
|   |       monism or admit a third mediating principle.
|   +-- Residual:
|       +-- Reflection language describes appearance more readily than causal possibility.
|
+-- XXI. TELEOLOGY WITHOUT ĪŚVARA
|   +-- Prakṛti evolves for Puruṣa's experience and liberation.
|   +-- Milk-for-calf analogy:
|   |   +-- Unconscious nature can function beneficially without deliberating.
|   +-- Structural teleology:
|   |   +-- Not conscious planning.
|   |   +-- Nature's constitution yields experience-serving order.
|   +-- Nyāya/Vedānta objection:
|   |   +-- Unconscious material cannot organise itself toward another's end.
|   +-- Sāṃkhya reply, five standard nirīśvara arguments:
|   |   +-- 1. A God acting from desire or motive is neither perfect nor free.
|   |   +-- 2. An eternally fulfilled God has no motive to create a painful world.
|   |   +-- 3. Distributing results under karma limits divine independence; arbitrary
|   |   |   distribution destroys justice.
|   |   +-- 4. An immutable conscious God cannot be the material source of a changing
|   |   |   unconscious world under Sāṃkhya's cause-effect continuity.
|   |   +-- 5. Eternal Puruṣas and Prakṛti already explain consciousness and material
|   |       evolution without a creator hypothesis.
|   +-- Statement discipline: the classical position is non-theistic or God-unproved,
|       not a proof that no divine being could exist.
|   +-- Residual:
|       +-- "For the sake of" language appears purposive even when intention is denied.
|
+-- XXII. WHY ŚAṂKARA CALLS SĀṂKHYA PRADHĀNA-MALLA
|   +-- Sāṃkhya is Vedānta's strongest systematic rival because it offers:
|   |   +-- One ultimate material source.
|   |   +-- Ordered cosmology.
|   |   +-- Consciousness/matter distinction.
|   |   +-- Liberation through knowledge.
|   +-- Śaṃkara's objections:
|   |   +-- Upaniṣadic first cause is conscious; unconscious pradhāna cannot be intended.
|   |   +-- Tajjña-type "knowing-cause" texts exclude an insentient nature.
|   |   +-- Order and goal-direction require intelligence.
|   |   +-- Independent Puruṣa and Prakṛti cannot relate coherently.
|   |   +-- Scriptural passages do not establish pradhāna as ultimate.
|   |   +-- Multiple Puruṣas compromise the non-dual self.
|   +-- Sāṃkhya defence:
|   |   +-- Inference establishes material cause from effect-character.
|   |   +-- Conscious Puruṣa cannot transform, so cannot be material cause.
|   |   +-- Real world requires real material transformation.
|   |   +-- Plural experience requires plural witnesses.
|   +-- Debate:
|       +-- Sāṃkhya preserves world realism but struggles with unconscious teleology.
|       +-- Advaita preserves conscious ultimacy but explains world through māyā/vivarta.
|
+-- XXIII. CLASSIC OBJECTIONS / REPLIES
|   +-- Two absolutes make interaction impossible.
|   |   +-- Reply: reflective proximity, not physical interaction.
|   |   +-- Residual: proximity itself needs an account.
|   +-- Unconscious Prakṛti cannot act purposefully.
|   |   +-- Reply: structural tendency and karma, not intention.
|   +-- Many Puruṣas lack differentiating qualities.
|   |   +-- Reply: separate embodiment and liberation establish numerical plurality.

    +-- Sāṃkhya offers an exceptionally economical map of experience by separating
