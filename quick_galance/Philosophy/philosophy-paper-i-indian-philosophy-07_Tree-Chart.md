# Philosophy Optional — Paper I — Indian Philosophy 07 — Mimamsa

## Quick-Glance Tree Chart

```text
PŪRVA-MĪMĀṂSĀ: VALID KNOWLEDGE, VEDIC LANGUAGE, DUTY AND RITUAL ACTION
|
+-- CENTRAL PRINCIPLE
|   +-- Cognition presents itself as true unless subsequently defeated; therefore validity
|       is intrinsic while falsity depends on later detection of a defect.
|   +-- The beginningless, authorless Veda independently discloses dharma, especially
|       through injunctions whose performance produces an unseen efficacy connecting
|       present action with future result.
|   +-- Bhāṭṭa and Prābhākara Mīmāṃsā share this anti-sceptical and Veda-centred project
|       but differ on pramāṇa count, absence, error, self-awareness, sentence meaning,
|       duty and motivation.
|   +-- Every famous doctrine repairs a specific hole opened by one decision: dharma is
|       supersensible, so only śabda reaches it, so the text must bind without an author
|       and cognition must be trustworthy without a certifier.
|
+-- SCOPE / OWNERSHIP FIREWALL
|   +-- Owns: dharma-jijñāsā; codanā; apauruṣeya Veda; śabda-nityatva; autpattika

|   |   svataḥ-prāmāṇya; parataḥ-aprāmāṇya; Bhāṭṭa six and Prābhākara five pramāṇas;
|   |   arthāpatti; anupalabdhi; abhāva dispute; memory exclusion;
|   |   akhyāti/vivekākhyāti; viparīta-khyāti; tripuṭī-saṃvit; jñātatā; abhihitānvaya;
|   |   anvitābhidhāna; bhāvanā; niyoga; apūrva; nirīśvaravāda; self/agency minimum.
|   +-- Vedānta owns Brahman-centred Upaniṣadic interpretation and mokṣa through
|   |   Brahma-knowledge.
|   +-- Nyāya owns extrinsic validation, anyathā-khyāti, anuvyavasāya and God-grounded Veda.

|   +-- Ritual detail beyond philosophical hermeneutics is outside this chart.

|   +-- Kumārila Bhaṭṭa: Ślokavārttika, Tantravārttika — establishes the Bhāṭṭa line.
|   +-- Prabhākara Miśra: Bṛhatī — establishes the Prābhākara line; Śālikanātha is a major

+-- I. DHARMA-JIJÑĀSĀ
|   +-- Governing inquiry:
|   |   +-- What ought one to do?
|   |   +-- How is supersensible dharma known?
|   +-- Dharma:
|   |   +-- codanā-lakṣaṇo'rtho dharmaḥ — that good whose distinguishing mark is Vedic
|   |   |   injunction.
|   |   +-- Not reducible to visible pleasure, social custom or divine command.
|   +-- Codanā:
|   |   +-- Injunctive Vedic prompting that makes dharma known.
|   +-- Instruments are matched to objects:
|   |   +-- Perception reveals the presently sensible; inference extends where a relation
|   |   |   is already established; neither reaches dharma or a post-mortem fruit.
|   |   +-- Therefore śabda is not a fallback but the ONLY competent instrument here.
|   +-- Ritual action:
|       +-- Produces a result not always immediately perceptible.
|       +-- Requires apūrva as the normative-causal link.
|
+-- II. TWO SUB-SCHOOLS — ONE INSTINCT, SIX CONSEQUENCES
|   +-- BHĀṬṬA / KUMĀRILA — admit what resists reduction, and pay the ontological cost:
|   |   +-- Six pramāṇas.
|   |   +-- Anupalabdhi independently knows absence; abhāva is real with a pratiyogin.
|   |   +-- Viparīta-khyāti: the shell is positively miscognised as silver.
|   |   +-- Cognition not self-luminous; inferred from jñātatā acquired by the object.
|   |   +-- Abhihitānvayavāda: separately denoted meanings are then connected.
|   |   +-- Bhāvanā-vāda: the desired fruit moves the qualified agent.
|   +-- PRĀBHĀKARA — economise; avoid positing extra faculties:
|   |   +-- Five pramāṇas; no separate anupalabdhi.
|   |   +-- Absence is the bare locus perceived as unqualified by the absent object.
|   |   +-- Akhyāti/vivekākhyāti: error is non-discrimination of two valid cognitions.
|   |   +-- Tripuṭī-saṃvit: cognition manifests knower, known and itself.
|   |   +-- Anvitābhidhānavāda: words denote meanings already connected.
|   |   +-- Niyoga-vāda: the command itself binds — duty for duty's sake.
|   +-- Unity in difference: both keep Vedic authority, realism, ritual efficacy through
|       apūrva, intrinsic validity, and irreducibility as the admission test.
|
+-- III. MINIMUM METAPHYSICAL COMMITMENTS
|   +-- External world is real; objects are stable enough to be known, named and acted upon.
|   +-- Enduring plural selves are real; the self is knower, agent and enjoyer.
|   +-- Cognition is an episodic event related to self and object, not the self's essence.
|   +-- Karma and rebirth make ritual consequence intelligible; the series is beginningless.
|   +-- Veda does not require a creator-author.
|   +-- Classical Pūrva-Mīmāṃsā is not merely agnostic about God; its explanatory economy
|   |   rejects the need for a creator, author or distributor of fruits.
|   +-- Devatās function as mantra-denoted ritual recipients without becoming a creator-God.
|
+-- IV. SVATAḤ-PRĀMĀṆYAVĀDA
|   +-- Every cognition is presumed valid by virtue of its arising under normal conditions.
|   +-- Fourfold formula:
|   |   +-- Utpatti of prāmāṇya is INTRINSIC: the same conditions that generate the
|   |   |   cognition generate its validity.
|   |   +-- Jñapti of prāmāṇya is INTRINSIC: it presents itself as trustworthy unaided.
|   |   +-- Utpatti of aprāmāṇya is EXTRINSIC: falsity arises from doṣa — defect,
|   |   |   obstruction, mislocation or other abnormal factor.
|   |   +-- Jñapti of aprāmāṇya is EXTRINSIC: known through bādhaka, contradiction,
|   |       failure or later defect-awareness.
|   +-- Anavasthā argument:
|   |   +-- If every cognition needed another to certify it, the certifier needs a
|   |   |   certifier: infinite regress.
|   |   +-- To avoid regress, some cognition must be valid unaided; most economically, each.
|   |   +-- Practical life confirms default trust, not default doubt; no first action could
|   |       otherwise be launched. The burden lies on the challenger.
|   +-- Presupposition: realism — cognitions aim at real objects and normal causes tend
|   |   toward truth; without it the doctrine collapses into self-certification.
|   +-- Example: I see a pot and act on it at once; only poor light, hallucination or
|       contradiction revokes the cognition.
|
+-- V. INTRINSIC VALIDITY IS NOT INFALLIBILITY
|   +-- It means prima facie entitlement, not that every cognition remains true.
|   +-- Error is defeated when:
|   |   +-- Later cognition conflicts.
|   |   +-- Defect in causal conditions is detected.
|   |   +-- Expected practical result fails.
|   +-- Parataḥ-aprāmāṇya:
|   |   +-- Falsity is extrinsically discovered.
|   +-- Distinctions: validity is not certainty; intrinsic validity is not incorrigibility;
|       extrinsic invalidity does not make error impossible; later confirmation detects
|       rather than creates truth.
|
+-- VI. NYĀYA CONTRAST AND THE FOUR-SCHOOL STRIP
|   +-- Nyāya parataḥ-prāmāṇya:
|   |   +-- Validity extrinsic in origin AND ascertainment.
|   |   +-- Route 1: pravṛtti-sāmarthya, successful practical activity.
|   |   +-- Route 2: saṃvādi-pratyakṣa, a later confirming perception.
|   +-- Mīmāṃsā objection:
|   |   +-- One must act before being entitled to trust; the act already presupposes trust.
|   |   +-- A validating cognition would itself need validating: regress returns.
|   |   +-- Success can at most CONFIRM or DISCLOSE validity, never GENERATE it.
|   |   +-- Decisive distinction: validity itself versus ascertainment of validity.
|   +-- Dream / mirage objection and reply:
|   |   +-- Spontaneous, normal-feeling cognitions can be false.
|   |   +-- Appearance of normalcy is not normalcy: exhaustion, sleep-state, heated air and
|   |       optical distortion are extrinsic defects, so these are abnormal cases.
|   +-- Four-school strip:
|   |   +-- Mīmāṃsā: validity intrinsic / invalidity extrinsic.
|   |   +-- Nyāya: extrinsic / extrinsic.
|   |   +-- Sāṃkhya (as standardly presented): intrinsic / intrinsic — Mīmāṃsā agrees on
|   |   |   validity but refuses intrinsic invalidity, since falsity does not self-announce.
|   |   +-- Buddhist epistemology (as standardly presented): extrinsic / intrinsic — refuted
|   |       because illusion does not present itself as illusion.
|   +-- Residual pressure:
|       +-- Nyāya can press that "abnormal conditions" is a label applied after the fact,
|           so the line between default trust and credulity is drawn by stipulation.
|
+-- VII. SELF-LUMINOSITY AND VALIDITY
|   +-- Svayaṃprakāśatva asks about MANIFESTATION; svataḥ-prāmāṇya asks about
|   |   TRUTH-ENTITLEMENT. They are different questions, so neither entails the other.
|   +-- Nyāya: not self-luminous (anuvyavasāya) and validity extrinsic — accepts NEITHER.
|   +-- Prābhākara: self-luminous and intrinsically valid — CONNECTS both.
|   +-- Bhāṭṭa: NOT self-luminous, cognition inferred from jñātatā, yet validity intrinsic
|   |   — the DECISIVE COUNTEREXAMPLE to necessary entailment.
|   +-- Advaita: self-luminosity of consciousness ITSELF, with empirical cognition valid
|   |   until sublated — connects them inside a wider non-dual theory.
|   +-- Answer the word "necessarily": a single actual case of one without the other
|       refutes a claim of necessity; independence is not, however, irrelevance.
|
+-- VIII. PRAMĀṆA COUNT AND THE ADMISSION RULE
|   +-- Admission rule: a new instrument is admitted ONLY where a type of knowledge cannot
|   |   be reduced to another without remainder or without circularity.
|   +-- Instruments are individuated by the MANNER of generation, not by topic; this is a
|   |   taxonomy of logical structures, not a psychology of faculties.
|   +-- Shared five:
|   |   +-- Pratyakṣa: immediate knowledge from sense-object contact.
|   |   +-- Anumāna: mediate knowledge from a sign through known concomitance.
|   |   +-- Upamāna: fresh knowledge that a previously known but absent object is similar
|   |   |   to a presently perceived object.
|   |   +-- Śabda: valid verbal testimony, especially Vedic testimony regarding dharma.
|   |   +-- Arthāpatti: necessary postulation reconciling incompatible known facts.
|   +-- Bhāṭṭa sixth:
|   |   +-- Anupalabdhi: knowledge of absence through non-apprehension of the presentable.
|   +-- Prābhākara rejects a separate anupalabdhi.
|   +-- Nyāya accepts four; Sāṃkhya accepts three; later Advaita lists commonly run to six
|   |   with a different metaphysical hierarchy.
|   +-- Three-term vocabulary:
|       +-- Pramāṇa is the operative means; pramā/pramiti is the true cognition produced;
|           pravṛtti-sāmarthya may confirm correspondence but never manufactures validity.
|
+-- IX. PERCEPTION
|   +-- Sense-object contact produces cognition of the present object.
|   +-- Nirvikalpaka / ālocana-jñāna:
|   |   +-- First non-verbal awareness that an object is present, before classification.
|   +-- Savikalpaka:
|   |   +-- The object as qualified by class, quality, action and name: "this is a white
|   |       moving cow."
|   +-- Controlling claim:
|   |   +-- The determinate stage INTERPRETS what was implicitly available; it does not
|   |       invent an unreal predicate.
|   +-- This supports realism against the Buddhist claim that perception gives only a
|   |   non-conceptual unique particular, and against any view that classification
|   |   necessarily falsifies the given.
|   +-- Sub-school split inside perception: Prābhākara makes it self-luminous within
|       tripuṭī-saṃvit; Bhāṭṭa denies self-luminosity and infers the cognition.
|
+-- X. INFERENCE / COMPARISON / TESTIMONY
|   +-- Anumāna:
|   |   +-- Knowledge through a sign and known vyāpti; smoke seen, fire inferred.
|   |   +-- Fully accepted. Mīmāṃsā opposes only REDUCTIONISM ABOUT ANUMĀNA — never write
|   |       that Mīmāṃsā rejects inference.
|   +-- Upamāna, in Mīmāṃsā form:
|   |   +-- Having previously seen a cow, one perceives a gavaya as similar to it, and
|   |   |   gains the new cognition "the previously seen cow is similar to this gavaya."
|   |   +-- Not perception (the cow is absent), not memory (the similarity was not known
|   |   |   before), not inference (no universal concomitance is used).
|   |   +-- Nyāya contrast: prior testimony "a gavaya is like a cow" teaches the
|   |   |   word-object relation. Do NOT write that mechanism as the Mīmāṃsā definition.
|   |   +-- Śabara is sometimes read as allowing a wider analogical form, such as reasoning
|   |       from one's own experienced self to other selves; the similarity-cognition
|   |       account is the safe default.
|   +-- Śabda:
|       +-- By source: pauruṣeya testimony depends on a competent speaker and inherits
|       |   speaker-defect; apauruṣeya Vedic testimony is intrinsically valid for dharma.
|       +-- By function: siddhārtha-vākya states a fact; vidhāyaka-vākya enjoins an action.
|       +-- Kumārila keeps the distinction while making injunction central; Prabhākara
|           reads cognition and language through action-guidance more radically.
|
+-- XI. WHY MEMORY IS NOT PRAMĀṆA
|   +-- Pramā must be anadhigata — cognition of what is not already apprehended.
|   +-- Prābhākara's five steps:
|   |   +-- A pramāṇa must generate a new cognition of an object.
|   |   +-- Memory depends on an earlier cognition and a latent saṃskāra.
|   |   +-- It reproduces old content.
|   |   +-- It does not reveal a new object as presently known.
|   |   +-- Therefore it is not a pramāṇa.
|   +-- Memory may be true, useful and action-guiding without being pramāṇa; the ground is
|   |   NOT unreliability but lack of novelty.
|   +-- Nyāya agrees, treating memory as re-presentation rather than fresh disclosure —
|   |   which is why the 2024 paper pairs Prābhākaras and Naiyāyikas in one question.
|   +-- The exclusion concerns STATUS, not irrelevance: memory still operates within
|       upamāna, within Prābhākara's error-theory, and within sentence-comprehension.
|
+-- XII. ARTHĀPATTI
|   +-- Postulation required to remove an anupapatti between facts already known.
|   +-- Core form:
|   |   +-- Fact A is known; Fact B is known.
|   |   +-- A and B cannot stand together unless C is admitted.
|   |   +-- Therefore C is postulated; the necessity is explanatory reconciliation.
|   +-- Devadatta:
|   |   +-- Devadatta is stout (perception).
|   |   +-- Devadatta does not eat by day (testimony or repeated observation).
|   |   +-- Stoutness is incompatible with total absence of nourishment.
|   |   +-- Therefore he eats at night — neither perceived here nor remembered.
|   +-- The output is the MINIMALLY RECONCILING postulate, which is what stops postulation
|   |   from licensing extravagant explanations.
|   +-- Presuppositions: bodily conditions have intelligible causes; stoutness normally
|   |   requires nourishment; rational cognition seeks coherence.
|   +-- Both sub-schools accept it: it is Prābhākara's fifth instrument as well.
|
+-- XIII. TWO FORMS OF ARTHĀPATTI
|   +-- Dṛṣṭārthāpatti:
|   |   +-- Postulation from perceived facts.
|   +-- Śrutārthāpatti:
|   |   +-- Postulation supplying what an utterance needs to be coherent, including
|   |       ellipsis and contextual completion.
|   +-- Both are explanatory necessity, not tentative hypothesis; only the source of the
|   |   initiating tension differs.
|   +-- Candidate example (2024):
|       +-- Never seen studying during the day yet tops the examination.
|       +-- Success is incompatible with no preparation at all, so unobserved preparation
|       |   must be posited — study at night or otherwise outside observed daytime.
|       +-- The postulate must be the least addition that makes the facts coherent.
|
+-- XIV. ARTHĀPATTI VERSUS INFERENCE — THREE ARGUMENTS
|   +-- Argument 1 — no independently established vyāpti:
|   |   +-- Inference needs the hetu-sādhya relation known BEFOREHAND.
|   |   +-- No prior rule "all stout non-day-eaters eat at night" exists.
|   +-- Argument 2 — the direction of reasoning differs:
|   |   +-- Inference moves from observed sign to unobserved signified.
|   |   +-- Postulation moves from explanatory tension to reconciling postulate.
|   +-- Argument 3 — no pakṣa/hetu/sādhya structure:
|   |   +-- There is no identified hetu sitting in a pakṣa from which a sādhya is derived;
|   |       there is a clash of accepted facts and a demanded supplementation.
|   +-- Nyāya reduction and the circularity reply:
|   |   +-- Nyāya: hetu = fatness, sādhya = eating, vyāpti = "whoever is fat eats."
|   |   +-- Mīmāṃsā: that vyāpti is not independently known; if claimed as known it was
|   |       abstracted from lived cases by the very move under dispute — hence circular.
|   +-- Comparison with modern reasoning:
|   |   +-- It resembles inference to the best explanation but the classical claim is
|   |       STRONGER: the postulate is required, not merely best among options.
|   +-- Objection: both are ampliative and can be reconstructed inferentially.
|   +-- Reply: formal reconstruction does not erase the distinct epistemic trigger.
|
+-- XV. ANUPALABDHI
|   +-- Bhāṭṭa's independent pramāṇa for absence.
|   +-- Kumārila's seven steps:
|   |   +-- We do know absences: "there is no pot on the table."
|   |   +-- The cognition is definite and action-guiding.
|   |   +-- Not perception, which gives positive content.
|   |   +-- Not inference, which requires a positive sign.
|   |   +-- Not memory, comparison or testimony in the typical case.
|   |   +-- Therefore an independent source is needed.
|   |   +-- That source is anupalabdhi.
|   +-- Yogyānupalabdhi — the fitness condition:
|   |   +-- The absent object must be perceptible in kind.
|   |   +-- The locus must be suitable; the sense organ must function.
|   |   +-- Light, distance and attention must be proper.
|   +-- Fit and unfit cases:
|   |   +-- "No pot on this bare, well-lit table" is knowledge.
|   |   +-- "There are no atoms here" is not, because atoms are not perceptible.
|   |   +-- Careless overlooking and absorbed inattention are excluded.
|   +-- It is NOT simple ignorance or "I failed to notice"; it is a determinate cognition
|       that something is absent.
|
+-- XVI. WHY BHĀṬṬA TREATS IT AS INDEPENDENT
|   +-- Against reduction to perception:
|   |   +-- Perception gives the table, its colour, shape and spread — positive data.
|   |   +-- "Absence of pot" is not a positive sensible datum of that kind; perceiving the
|   |       empty table is one thing, cognising the pot's absence another.
|   +-- Against reduction to inference:
|   |   +-- Inference needs a positive sign and a known concomitance.
|   |   +-- If "not-seeing the pot" is the sign, one must explain why not-seeing has
|   |       evidentiary force — which already presupposes fitness. Strained or circular.
|   +-- Ontological status of abhāva:
|       +-- Real, not a feature of language; structured by its pratiyogin, the
|       |   counterpositive whose absence is involved.
|       +-- Negative cognition therefore has a real object.
|
+-- XVII. PRĀBHĀKARA AND NYĀYA ON ABSENCE
|   +-- Prābhākara:
|   |   +-- What is known is simply the LOCUS AS UNQUALIFIED by the absent object; we
|   |   |   perceive the table as bare, not as occupied by the pot.
|   |   +-- The bare-locus cognition already carries the negative differentiation needed.
|   |   +-- This is an ECONOMY thesis, not a denial that absences are known.
|   +-- Nyāya:
|   |   +-- Accepts abhāva as a real category but holds that absence is DIRECTLY PERCEIVED:
|   |       looking at the floor, one perceives "pot-absence-on-the-floor."
|   +-- Convergence:
|   |   +-- Nyāya and Prābhākara converge AGAINST Bhāṭṭa on independence, for different
|   |       reasons. Do not therefore say that Nyāya denies abhāva.
|   +-- Kumārila's counter:
|   |   +-- Economy purchased by flattening a determinate negative judgement into a
|   |       positive perception is false economy.
|   +-- Graded verdict:
|       +-- Bhāṭṭa is the most faithful to the phenomenology and carries the heaviest
|           ontology, a cost he expressly accepts.
|
+-- XVIII. ERROR: PRĀBHĀKARA AKHYĀTI / VIVEKĀKHYĀTI
|   +-- Error is non-apprehension of DIFFERENCE, not one wholly false cognition; the label
|   |   vivekākhyāti is the more precise one.
|   +-- Shell-silver:
|   |   +-- The present shining object is validly perceived.
|   |   +-- Previously experienced silver is validly remembered.
|   |   +-- The difference between the two cognitions is not apprehended.
|   |   +-- Resulting action treats the remembered silver as present here.
|   |   +-- No separate false cognition need be posited.
|   +-- Preserves intrinsic validity by keeping EVERY CONSTITUENT COGNITION valid.
|   +-- Objection: the subject positively reports "this is silver."
|   +-- Reply: the utterance and action are explained by the fusion of two valid
|       cognitions; a further false cognition is unnecessary.
|
+-- XIX. ERROR: BHĀṬṬA VIPARĪTA-KHYĀTI, AND THE FOUR-THEORY GRID
|   +-- Bhāṭṭa's seven steps:
|   |   +-- The shell is before the subject.
|   |   +-- Bad light, distance, similarity of shine or sensory defect causes miscognition.
|   |   +-- A single erroneous cognition arises: "this is silver."
|   |   +-- The cognition is false.
|   |   +-- Its falsity is due to EXTRINSIC defect, not to cognition's nature.
|   |   +-- Correction occurs on approaching and seeing the shell clearly.
|   |   +-- Invalidity is then known extrinsically.
|   +-- Four-theory grid:
|   |   +-- Akhyāti / vivekākhyāti (Prābhākara): two valid cognitions not discriminated;
|   |   |   there is NO false silver at all.
|   |   +-- Viparīta-khyāti (Bhāṭṭa): the shell is positively miscognised as silver — a
|   |   |   really wrong IDENTIFICATION.
|   |   +-- Anyathā-khyāti (Nyāya): real silver known ELSEWHERE is presented here — real
|   |   |   but DISPLACED.
|   |   +-- Anirvacanīya-khyāti (Advaita): the illusory object is neither real nor unreal.
|   +-- The highest-value distinction: Bhāṭṭa MISIDENTIFIES the object present; Nyāya
|   |   MISPLACES an object known elsewhere. Both admit a false cognition; they are not
|   |   the same theory.
|   +-- Mīmāṃsā stays more epistemologically anchored and realist than either rival: it
|   |   neither disperses the object elsewhere nor renders it metaphysically indeterminate.
|   +-- The 2022 reconciliation:
|       +-- Both accept intrinsic validity; they differ because they LOCATE error
|       |   differently.
|       +-- Prābhākara protects every constituent cognition; Bhāṭṭa protects the principle
|           governing normal cognition and quarantines falsity in defect.
|
+-- XX. TRIPUṬĪ-SAṂVIT
|   +-- Prābhākara:
|   |   +-- In each cognition, jñātṛ, jñeya and jñāna are simultaneously manifested.
|   |   +-- Six steps: cognition illuminates its object; if not itself manifest another
|   |       cognition is needed; that needs a third; regress; therefore it reveals itself
|   |       in revealing the object; and the subject is disclosed as knower.
|   +-- Lamp analogy:
|   |   +-- A lamp reveals itself and other things at once — economy plus no regress.
|   +-- This is NOT the claim that the self alone shines and the object is projected.
|   +-- Objection: we do not always notice the act of knowing; and does simultaneity
|   |   confuse the three?
|   +-- Reply: reflection is a later articulation of what was already manifest
|       pre-reflectively; the three are disclosed, not ontologically collapsed.
|
+-- XXI. BHĀṬṬA JÑĀTATĀ
|   +-- Cognition is not self-luminous in Prābhākara's way.
|   +-- Four steps:
|   |   +-- After being cognised, the object stands in a new relation: it is now known.
|   |   +-- That status is jñātatā.
|   |   +-- Observing knownness, we infer that a cognition occurred.
|   |   +-- Awareness of cognition is therefore inferential, not immediate.
|   +-- Painter analogy: cognition paints objects but does not paint itself; its occurrence
|   |   is established by what it leaves behind in the object.
|   +-- Consequence: a temporal and logical GAP — I know first, I know that I know after.
|   +-- Objection: jñātatā seems an unnecessary mysterious property.
|   +-- Reply: Bhāṭṭa accepts this cost to avoid the stronger self-luminosity thesis.
|   +-- Nyāya alternative: anuvyavasāya, a distinct second-order cognition of the form
|       "I know the pot," treated as sufficient without endless repetition.
|   +-- Three gaps in three words: none (Prābhākara), inferential (Bhāṭṭa), reflective
|       (Nyāya).
|
+-- XXII. WORD AND SENTENCE CONDITIONS
|   +-- Problem: ekavākyatā — how many words yield one cognition. Vedic obligation is
|   |   grasped through sentence meaning, never through isolated word meanings.
|   +-- Ākāṅkṣā:
|   |   +-- Mutual expectancy; "Bring ..." leaves an open expectation.
|   +-- Yogyatā:
|   |   +-- Semantic compatibility; "sprinkle with fire" is unfit in ordinary usage.
|   +-- Sannidhi / āsatti:
|   |   +-- Proximity; words separated by unrelated discourse fail to cohere.
|   +-- Tātparya:
|   |   +-- Purport, added by Naiyāyikas.
|   |   +-- Mīmāṃsā cannot ground Vedic meaning in a speaker's intention because the Veda
|   |   |   is apauruṣeya; purport must be relocated into textual force, contextual unity
|   |   |   and subordination to vidhi.
|   |   +-- This creates genuine internal pressure, and a strong answer says so.
|   +-- Test sentence: svargakāmo yajeta — the hearer must grasp not "heaven-desirer" plus
|       "sacrifice" but a unified injunction upon the qualified agent.
|
+-- XXIII. ABHIHITĀNVAYAVĀDA
|   +-- Bhāṭṭa: connection of what has ALREADY been denoted.
|   +-- Stage 1: each word denotes its own padārtha through its primary power abhidhā.
|   +-- Stage 2: those meanings are connected, often explained through lakṣaṇā or
|   |   tātparya-śakti.
|   +-- The word is the primary semantic unit; sentence meaning is derivative.
|   +-- The two stages are LOGICAL, not a slow temporal sequence in consciousness.
|   +-- Strength: preserves stable lexical meaning across contexts; meaning is compositional.
|   +-- Objection: the isolated-word stage is not observed and every sentence seems to need
|   |   an extra connecting operation.
|   +-- Reply: the distinction is explanatory, not introspective; stable lexical meaning
|       requires word-priority.
|
+-- XXIV. ANVITĀBHIDHĀNAVĀDA
|   +-- Prābhākara: words denote meanings only AS ALREADY CONNECTED.
|   +-- Vyutpatti learning argument: a child observes an elder command "bring the cow" and
|   |   a younger person comply, and learns the connected sense from the whole event.
|   +-- Sentence meaning is the ORIGINAL mode of understanding, not a later synthesis.
|   +-- He does not deny that words are repeatable; he denies that their primary semantic
|   |   life is an isolated lexical object.
|   +-- Strength: explains language-learning and action-guidance, fitting an
|   |   injunction-centred hermeneutics.
|   +-- Objection: the same word would seem to mean differently in every sentence; and
|   |   single-word commands such as "Cow!" seem meaningful.
|   +-- Reply: recurrent connected uses yield stable competence; single-word utterances are
|   |   elliptical sentences supplied by context.
|   +-- Verdict: Bhāṭṭa secures stable lexical meaning; Prābhākara secures contextual
|       action-guidance.
|
+-- XXV. WORDS: UNIVERSALS OR PARTICULARS
|   +-- Mīmāṃsā generally: the word primarily denotes the UNIVERSAL (jāti), and the
|   |   individual is reached through it as instantiated in a concrete context.
|   +-- Nyāya: the qualified INDIVIDUAL (vyakti), as qualified by universal and form, is
|   |   primary.
|   +-- Both positions reach BOTH; the difference concerns SEMANTIC PRIORITY, not coverage.
|   |   Do not caricature either side.
|   +-- Argument from repeatability: "cow" applies to many individuals, best explained by
|   |   its relation to cow-ness; linguistic repeatability requires a stable semantic ground.
|   +-- Objection: a universal cannot be milked, brought or sacrificed.
|   +-- Reply: the universal is primary for MEANING, while ACTION reaches the qualified
|   |   individual through contextual application.
|   +-- Buddhist apoha objection: "cow" functions by excluding non-cows; no real universal
|   |   is needed.
|   +-- Mīmāṃsā reply: pure exclusion cannot explain stable positive recognition and
|       repeatable application unless a shared class-character is already available.
|
+-- XXVI. SPHOṬA COMPARISON
|   +-- Grammarian view (Bhartṛhari): individual sounds perish, so an indivisible
|   |   vākya-sphoṭa is posited as the real bearer of sentence meaning.
|   +-- Both Bhāṭṭa and Prābhākara reject the additional entity:
|   |   +-- The eternal varṇas and their ordered manifestation are sufficient.
|   |   +-- Word meaning plus the sentence conditions already explain comprehension.
|   +-- Objection: successively heard letters cannot produce one meaning.
|   +-- Reply: memory of the ordered series plus ākāṅkṣā, yogyatā and sannidhi yields unity.
|   +-- Sphoṭa is a comparison to be answered, not an owned Mīmāṃsā doctrine, and this
|       rejection is what protects the eternal word-units used in Vedic authority.
|
+-- XXVII. VEDIC AUTHORITY
|   +-- Veda is apauruṣeya: not composed by any human or divine person, so there is no
|   |   locus for ignorance, deceit, partiality or forgetfulness.
|   +-- Eight-step argument:
|   |   +-- No author of the Veda is remembered in the tradition.
|   |   +-- Such an author would normally have been remembered.
|   |   +-- The śabda-artha relation is autpattika — natural, not instituted.
|   |   +-- Word-units possess śabda-nityatva, so utterance manifests rather than produces.
|   |   +-- Transmission is by disciplined recitation; no composition event is located.
|   |   +-- Hence the Veda need not be a composed book with a fallible author.
|   |   +-- Authorial defects explain unreliability in human testimony.
|   |   +-- Therefore an authorless Veda is free of that class of defect.
|   +-- What it does NOT claim:
|   |   +-- It does not deny that anyone recited, taught or arranged Vedic branches.
|   |   +-- Names such as Kaṭha and Kauṣītaki mark schools, transmitters or branches, not
|   |       composers of Vedic content.
|   +-- Against Nyāya's God-guarantee: one must prove God exists, then that God is
|   |   omniscient, then that God intends truth — each stage needing independent support.
|   +-- Circularity charge, two forms:
|   |   +-- Authorlessness seems accepted because the tradition says so.
|   |   +-- Intrinsic validity proves too much: rival scriptures would be self-valid too.
|   +-- Six replies:
|   |   +-- Authorlessness rests on ordinary reasoning plus the absence of a remembered
|   |   |   author, not on a Vedic quotation.
|   |   +-- The reasoning has an arthāpatti form: extraordinary authority with no
|   |   |   remembered authorial event requires authorless transmission.
|   |   +-- Intrinsic validity is not indefeasibility; invalidity is known through doṣa or
|   |   |   bādhaka.
|   |   +-- Rival scriptures with known or claimed authors possess a locus of defect.
|   |   +-- The Veda is authoritative ONLY for dharma, where no rival pramāṇa operates and
|   |   |   no defeater can arise.
|   |   +-- A divine author is worse: a person, even a divine person, becomes a further
|   |       object needing proof.
|   +-- Residual force:
|       +-- Jayanta and Udayana deny naturalness, treating the relation as saṅketa
|       |   ultimately instituted by Īśvara, and reading the Veda as āpta-testimony.
|       +-- Dharmakīrti-line Buddhists reject eternal words and ask how a changeless word
|           produces a timed cognition; the reply is that it is MANIFESTED, not produced.
|
+-- XXVIII. VEDIC SENTENCE AND INJUNCTION TAXONOMIES
|   +-- Five sentence functions:
|   |   +-- Vidhi: injunction; enjoins a duty or rite not otherwise known.
|   |   +-- Niṣedha: prohibition; grounds avoidance.
|   |   +-- Mantra: recalls deity, material and ritual detail during performance.
|   |   +-- Nāmadheya: names a rite, substance or component.
|   |   +-- Arthavāda: praises, condemns, narrates or explains in support of an injunction.
|   +-- Mantra, nāmadheya and arthavāda are not meaningless; their Vedic function is secured
|   |   by ekavākyatā with an operative injunction.
|   +-- Three logical kinds of injunction:
|   |   +-- Apūrva-vidhi: reveals an otherwise unknown duty.
|   |   +-- Niyama-vidhi: selects one eligible means where alternatives appear available.
|   |   +-- Parisaṃkhyā-vidhi: excludes alternatives.
|   +-- Separate ritual-coordination grid — utpatti, viniyoga, prayoga, adhikāra — for
|   |   coordinating a complex rite. Do NOT conflate it with the threefold classification.
|   +-- Hermeneutic canons: the strength-ordering śruti-liṅga-vākya-prakaraṇa-sthāna-
|       samākhyā and the general/exception pair utsarga-apavāda are held as a controlled
|       comparison with rule-governed legal interpretation; the disanalogy is that Mīmāṃsā
|       presupposes an infallible authorless text admitting no legislative amendment.
|
+-- XXIX. APŪRVA
|   +-- Unseen potency generated by correctly performed ritual action.
|   +-- Five-step argument:
|   |   +-- A ritual act is temporally limited.
|   |   +-- Its promised fruit may be remote and not visibly produced at the time of action.
|   |   +-- If the act perished without remainder, the Vedic connection is unintelligible.
|   |   +-- Therefore apūrva is posited as the unseen link.
|   |   +-- The postulation is defended through arthāpatti.
|   +-- The flames do not travel to heaven; the potency persists until the fruit matures.
|   +-- Objection: apūrva is unverifiable and looks ad hoc.
|   +-- Reply: it is not arbitrary but established by explanatory necessity, and it is a
|   |   lighter posit than an omniscient divine person managing every result.
|   +-- Interpretive caution: some accounts emphasise a real unseen potency, others the
|       normative-causal action-result relation itself.
|
+-- XXX. BHĀVANĀ
|   +-- The efficient force of bringing something into being, expressed by the verbal
|   |   ending; the semantic heart of an injunction-centred scripture.
|   +-- Bhāṭṭa twofold analysis:
|   |   +-- Śābdī bhāvanā: locus is the Vedic sentence; the word-force impels the hearer,
|   |   |   with pravṛtti — the volitional impulse to act — as its immediate result.
|   |   +-- Ārthī bhāvanā: locus is the agent's own effort and ritual performance; the act
|   |       brings about phala such as svarga, mediated by apūrva where needed.
|   +-- Aṃśa-traya — kim? kena? katham?:
|   |   +-- Sādhya / bhāvya: what is to be brought about.
|   |   +-- Karaṇa / sādhana: the means.
|   |   +-- Itikartavyatā: how it is to be done.
|   |   +-- For ārthī bhāvanā in svargakāmo yajeta: svarga, yāga, and the ritual procedure,
|   |   |   materials, sequence and subsidiary acts.
|   |   +-- For śābdī bhāvanā in the same injunction: the agent's pravṛtti, the injunctive
|   |       suffix with knowledge of the injunction, and eulogistic support.
|   +-- Objection: a sentence without a personal speaker cannot command.
|   +-- Reply: imperative force is carried by the liṅ/vidhi verbal form itself, whose
|       relation to its meaning is autpattika; obligation is impersonal and structural.
|
+-- XXXI. PRĀBHĀKARA NIYOGA
|   +-- Injunction presents an obligatory kārya, a directly apprehended "to-be-done."
|   +-- Duty motivates qua duty; bindingness does not wait upon desire for heaven.
|   +-- Doctrinal contrast: Prābhākara niyoga-vāda versus Bhāṭṭa bhāvanā-vāda — a genuine
|   |   Indian anticipation of the deontology/consequentialism contrast.
|   +-- Kantian comparison is permitted only with the disanalogy: niyoga is heteronomous,
|   |   grounded in an impersonal eternal Veda and addressed to the qualified adhikārin.
|   +-- Objection: bare obligatoriness cannot motivate.
|   +-- Reply: the cognition of the act AS ENJOINED is itself action-guiding for the
|   |   qualified agent.
|   +-- Vedānta seam:
|       +-- Mīmāṃsā subordinates non-injunctive passages, so Upaniṣadic sentences such as
|       |   tat tvam asi must serve an injunctional purpose.
|       +-- Advaita replies that knowledge is not an action and Brahman is a siddha-vastu,
|           so such sentences are independently valid.
|
+-- XXXII. NIRĪŚVARAVĀDA
|   +-- Creator and fruit-dispenser are rejected; the rejection is part of the DEFENCE of
|   |   the Veda, since a God-authored Veda would no longer be authorless.
|   +-- Eight arguments:
|   |   +-- God is not perceptually given.
|   |   +-- The inference from world to maker fails: pots are made by embodied artisans,
|   |   |   worlds are not observed to be made by bodiless creators.
|   |   +-- No decisive testimony, since the Veda is authorless.
|   |   +-- Motive problem: if God needed nothing, creation lacks motive; if He needed
|   |   |   something, perfection is compromised.
|   |   +-- Pre-creation problem about the prior status of souls and karma.
|   |   +-- Karma and apūrva suffice, so a divine dispenser is redundant.
|   |   +-- Problem of evil and partiality.
|   |   +-- A God-authored Veda forfeits the advantage of apauruṣeyatva.
|   +-- Objector's case: karma is unconscious; allotment is precise; hence God as
|   |   karmaphaladātṛ.
|   +-- The dilemma:
|   |   +-- If God distributes strictly by karma, karma remains the real principle and God
|   |   |   is REDUNDANT.
|   |   +-- If God distributes otherwise, partiality and injustice arise and God is
|   |       MORALLY PROBLEMATIC.
|   +-- Objection: apūrva cannot "execute" results.
|   +-- Reply: an unseen potency postulated from Vedic efficacy is less burdensome than a
|   |   fully omniscient person postulated to manage every result.
|   +-- Devatā qualification: deities are retained as mantra-denoted entities subordinate
|   |   to the sacrifice; an offering to Agni depends for its fruit on correct performance
|   |   and apūrva, not on Agni's discretionary favour.
|   +-- Kumārila further denies that any individual sarvajña is established by a pramāṇa;
|   |   Jaina and Buddhist traditions answer that omniscience is spiritually attained.
|   +-- Some later Mīmāṃsakas and Mīmāṃsā-influenced Vedāntic traditions soften the
|       anti-theistic edge.
|
+-- XXXIII. SELF, AGENCY AND LIBERATION
|   +-- A plural, enduring ātman as knower, agent and enjoyer is required for cognition,
|   |   memory, agency and moral or ritual result.
|   +-- Argument: if the self were momentary, the agent who sacrifices would not be the
|   |   enjoyer of its fruit, and ritual responsibility would collapse.
|   +-- Body, senses and the internal organ mediate but are not identical to the self.
|   +-- Cognition is episodic, not the self's uninterrupted manifest essence; Prābhākara
|   |   reveals the self within threefold cognition, Bhāṭṭa through acquired knownness.
|   +-- Liberation is late and comparatively thin:
|   |   +-- Not Advaitic identity with Brahman.
|   |   +-- Release from embodied suffering and karmically generated experience.
|   |   +-- Requires stopping fresh merit and demerit and exhausting prior karmic force,
|   |       so that no new body, sense-mediated cognition or pain arises.
|   +-- Objection: a heaven-focused ritualism has no real soteriology.
|   +-- Reply: the earliest centre is duty and ritual fruit, but later doctrine can still
|   |   describe release without making Brahman-knowledge the central means.
|   +-- Do not import Advaita identity-realisation or Nyāya's creator into Pūrva-Mīmāṃsā.
|
+-- XXXIV. CLASSIC OBJECTIONS / REPLIES
|   +-- Default validity is credulity.
|   |   +-- Reply: it is defeasible entitlement, not immunity from correction.
|   +-- Self-luminosity proves truth.
|   |   +-- Reply: manifestation and validity are conceptually distinct; Kumārila is the
|   |       standing counterexample.
|   +-- Arthāpatti is inference.
|   |   +-- Reply: no prior vyāpti, reversed direction, no pakṣa-hetu-sādhya form; the
|   |       Nyāya reduction is circular.
|   +-- Anupalabdhi is perception.
|   |   +-- Reply: absence is not a positive sense-contact object.
|   +-- Anupalabdhi is inference.
|   |   +-- Reply: the required universal depends on prior absence cognition.
|   +-- Akhyāti denies positive illusion.
|   |   +-- Reply: action-error arises from non-discrimination.
|   +-- Viparīta-khyāti threatens intrinsic validity.
|   |   +-- Reply: falsity is later known; initial entitlement remains intrinsic.
|   +-- Authorless language is impossible.
|   |   +-- Reply: the autpattika relation and eternal word-units need no first speaker.
|   +-- Impersonal injunction cannot command.
|   |   +-- Reply: force lies in śābdī bhāvanā and the vidhi-suffix, or in niyoga; the
|   |       pressure is strongest where Upaniṣadic sentences are subordinated to vidhi.
|   +-- Apūrva is occult.
|   |   +-- Reply: it is licensed by arthāpatti from the Vedic action-result structure,
|   |       though explanatory opacity remains.
|   +-- Without God, karma cannot be allocated.
|       +-- Reply: beginningless karma plus apūrva, with the redundant-or-unjust dilemma;
|           critics still find an unconscious potency less intelligible than a conscious
|           Lord.
|
+-- XXXV. COMPARATIVE GRID
|   +-- Mīmāṃsā versus Nyāya:
|   |   +-- Intrinsic versus extrinsic validity — the largest epistemic contrast.
|   |   +-- Arthāpatti and anupalabdhi independent here, reduced there.
|   |   +-- Authorless versus God-grounded Veda.
|   |   +-- Universal primary here, qualified particular there.
|   |   +-- Jñātatā or tripuṭī-saṃvit here, anuvyavasāya there.
|   +-- Mīmāṃsā versus Advaita:
|   |   +-- Injunction-centred versus liberation-centred and non-dualist.
|   |   +-- Realist error theory versus indescribable status of the illusory object.
|   |   +-- Common vocabulary, different ultimate horizon.
|   +-- Mīmāṃsā versus Buddhism:
|   |   +-- Resists validity derived from pragmatic success.
|   |   +-- Denies self-intimating falsity: illusion does not present itself as false.
|   |   +-- Enduring self and real universals against momentariness and apoha.
|   +-- Mīmāṃsā versus Sāṃkhya:
|   |   +-- Shares sympathy for the intrinsic authority of cognition.
|   |   +-- Differs by making invalidity extrinsic and by embedding epistemology in ritual
|   |       hermeneutics.
|   +-- Mīmāṃsā versus Cārvāka:
|       +-- Cārvāka rejects authorless Vedic authority, supersensible duty, unseen potency
|       |   and the non-perceptual instruments.
|       +-- Reply: testimony transmits otherwise inaccessible facts, postulation resolves
|       |   explanatory conflict, and non-cognition discloses qualified absence.
|       +-- Caution: this establishes the INTELLIGIBILITY of non-perceptual knowledge more
|           readily than it PROVES any particular Vedic ritual claim.
|

+-- HIGH-RISK CONCEPTUAL TRAPS
|   +-- Intrinsic validity is not infallibility.
|   +-- Intrinsic validity is not identical to self-luminosity.
|   +-- Falsity is not intrinsic for Mīmāṃsā; Sāṃkhya is I/I and the Buddhist placement E/I.
|   +-- Nyāya is not "self-luminous but extrinsically valid"; it accepts neither thesis.
|   +-- Memory can be true but is not pramāṇa; the ground is novelty, not unreliability.
|   +-- Bhāṭṭa accepts six pramāṇas; Prābhākara accepts five.
|   +-- Mīmāṃsā does not reject inference; it rejects reductionism about inference.
|   +-- The Nyāya word-reference account of upamāna is not the Mīmāṃsā definition.
|   +-- Arthāpatti is not arbitrary guessing, and Prābhākara accepts it.
|   +-- Non-cognition proves absence only under fitness conditions.
|   +-- Bhāṭṭa and Prābhākara do not share one absence theory; Nyāya denies the instrument,
|   |   not abhāva.
|   +-- Akhyāti is non-apprehension of DIFFERENCE, not absence of all cognition.
|   +-- Viparīta-khyāti is not Nyāya anyathā-khyāti: misidentification here versus
|   |   displacement from elsewhere.
|   +-- Tripuṭī-saṃvit is not Nyāya anuvyavasāya; jñātatā is not self-luminous cognition.
|   +-- Abhihitānvaya and anvitābhidhāna must not be reversed.
|   +-- Words denote universals PRIMARILY; both schools reach both, so do not caricature.
|   +-- Sphoṭa is rejected by both sub-schools, not owned by either.
|   +-- Apauruṣeya does not mean authored by God, and it does not deny transmitters.
|   +-- Arthavāda is subordinate, not meaningless.
|   +-- Bhāvanā-vāda is not niyoga-vāda; śābdī yields impulse and ārthī yields fruit.
|   +-- The three injunction taxonomies must not be conflated.
|   +-- Apūrva is not a creator-God, and it is established by arthāpatti.
|   +-- Mīmāṃsā rejects a creator and fruit-dispenser, not the ritual devatās.
|   +-- Pūrva-Mīmāṃsā is not Vedānta, and its mokṣa is not Brahman-realisation.
```
