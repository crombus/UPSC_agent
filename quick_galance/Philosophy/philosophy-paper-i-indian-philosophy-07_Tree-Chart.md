# Philosophy Optional — Paper I — Indian Philosophy 07 — Mimamsa

## Quick-Glance Tree Chart

```text
PŪRVA-MĪMĀṂSĀ: VALID KNOWLEDGE, VEDIC LANGUAGE, DUTY AND RITUAL ACTION
|
+-- CENTRAL PRINCIPLE
|   +-- Cognition presents itself as true unless subsequently defeated; therefore validity
|       is intrinsic while falsity depends on later detection of a defect.
|   +-- The beginningless, authorless Veda independently discloses dharma, especially
|       through injunctions whose performance produces an unseen efficacy connecting
|       present action with future result.
|   +-- Bhāṭṭa and Prābhākara Mīmāṃsā share this anti-sceptical and Veda-centred project
|       but differ on pramāṇa count, absence, error, self-awareness, sentence meaning,
|       duty and motivation.
|
+-- SCOPE / OWNERSHIP FIREWALL
|   +-- Owns: dharma-jijñāsā; codanā; apauruṣeya Veda; śabda-nityatva; vidhi;
|   |   arthavāda/mantra/nāmadheya; svataḥ-prāmāṇya; parataḥ-aprāmāṇya;
|   |   Bhāṭṭa six and Prābhākara five pramāṇas; arthāpatti; anupalabdhi;
|   |   abhāva dispute; memory exclusion; akhyāti/vivekākhyāti; viparīta-khyāti;
|   |   tripuṭī-saṃvit; jñātatā; abhihitānvaya; anvitābhidhāna; bhāvanā;
|   |   niyoga; apūrva; non-theistic Vedic authority; self/agency minimum.
|   +-- Vedānta owns Brahman-centred Upaniṣadic interpretation and mokṣa through
|   |   Brahma-knowledge.
|   +-- Nyāya owns extrinsic validation, anyathākhyāti and God-grounded Veda.
|   +-- Grammarian sphoṭa is only a comparison.
|   +-- Ritual detail beyond philosophical hermeneutics is outside this chart.
|
+-- SOURCE / ATTRIBUTION CAUTION
|   +-- Jaimini: Mīmāṃsā-sūtra.
|   +-- Śabara: Śābara-bhāṣya.
|   +-- Kumārila Bhaṭṭa: Ślokavārttika, Tantravārttika and Bhāṭṭa line.
|   +-- Prabhākara Miśra: Prābhākara/Guru line, represented through Bṛhatī tradition.
|   +-- Maṇḍana Miśra has complex relation to Mīmāṃsā and Advaita; avoid simplistic labels.
|   +-- Later schools refine terminology; do not attribute every mature distinction to
|       Jaimini's earliest text.
|
+-- I. DHARMA-JIJÑĀSĀ
|   +-- Governing inquiry:
|   |   +-- What ought one to do?
|   |   +-- How is supersensible dharma known?
|   +-- Dharma:
|   |   +-- That purpose/obligation indicated by Vedic injunction.
|   |   +-- Not reducible to visible pleasure, social custom or divine command.
|   +-- Codanā:
|   |   +-- Injunctive Vedic prompting that makes dharma known.
|   +-- Ritual action:
|       +-- Produces result not always immediately perceptible.
|       +-- Requires apūrva or equivalent normative-causal link.
|
+-- II. TWO SUB-SCHOOLS
|   +-- BHĀṬṬA / KUMĀRILA:
|   |   +-- Six pramāṇas.
|   |   +-- Anupalabdhi independently knows absence.
|   |   +-- Viparīta-khyāti explains error as positive misrelation.
|   |   +-- Cognition known through inferred jñātatā in object.
|   |   +-- Abhihitānvayavāda: separately denoted meanings are connected.
|   |   +-- Bhāvanā and apūrva strongly structure ritual motivation/result.
|   +-- PRĀBHĀKARA:
|       +-- Five pramāṇas; no separate anupalabdhi.
|       +-- Akhyāti/vivekākhyāti: error is non-discrimination of two valid cognitions.
|       +-- Tripuṭī-pratyakṣa: cognition manifests knower, known and itself.
|       +-- Anvitābhidhānavāda: words convey meanings already connected.
|       +-- Niyoga/kārya and duty for its own sake receive emphasis.
|
+-- III. MINIMUM METAPHYSICAL COMMITMENTS
|   +-- External world is real.
|   +-- Enduring plural selves are real.
|   +-- Cognition is event/act related to self and object.
|   +-- Karma and rebirth make ritual consequence intelligible.
|   +-- Veda does not require creator-author.
|   +-- Classical Pūrva-Mīmāṃsā is not merely agnostic about God in every text; its
|       systematic explanatory economy rejects the need for a creator/author/distributor.
|   +-- Devatās may function as linguistically/ritually specified recipients without
|       becoming creator-God.
|
+-- IV. SVATAḤ-PRĀMĀṆYAVĀDA
|   +-- Every cognition is presumed valid by virtue of its arising as cognition.
|   +-- Fourfold formula:
|   |   +-- Knowledge arises intrinsically from its causal conditions.
|   |   +-- Its validity also arises intrinsically when those conditions function.
|   |   +-- Knowledge is apprehended without a prior validating cognition.
|   |   +-- Invalidity is known extrinsically through later defeating cognition/defect.
|   +-- Pravṛtti:
|   |   +-- Cognition naturally prompts action toward presented object.
|   +-- Anavasthā argument:
|       +-- If every cognition needed another cognition to certify it, infinite regress.
|       +-- If validation stops arbitrarily, original cognition can receive default trust.
|
+-- V. INTRINSIC VALIDITY IS NOT INFALLIBILITY
|   +-- It means prima facie entitlement, not that every cognition remains true.
|   +-- Error is defeated when:
|   |   +-- Later cognition conflicts.
|   |   +-- Defect in causal conditions is detected.
|   |   +-- Expected practical result fails.
|   +-- Parataḥ-aprāmāṇya:
|       +-- Falsity is extrinsically discovered.
|   +-- This preserves action without prior verification while explaining correction.
|
+-- VI. NYĀYA CONTRAST
|   +-- Nyāya parataḥ-prāmāṇya:
|   |   +-- Validity and invalidity determined through subsequent inference from
|   |       successful/unsuccessful activity and defect-free/defective causes.
|   +-- Mīmāṃsā objection:
|   |   +-- Validation cognition itself would need validation.
|   |   +-- Ordinary action would be paralysed by regress.
|   +-- Nyāya reply:
|   |   +-- One need not consciously validate before every act.
|   |   +-- Causal signs can establish truth without endless regress.
|   +-- Core fault-line:
|       +-- Presumption of truth until defeat versus truth certified through external marks.
|
+-- VII. SELF-LUMINOSITY AND VALIDITY
|   +-- Svayaṃprakāśavāda:
|   |   +-- Cognition manifests itself without another cognition.
|   +-- Svataḥ-prāmāṇya:
|   |   +-- Cognition's truth-validity is intrinsic.
|   +-- Logical distinction:
|       +-- Self-manifestation does not automatically prove correspondence with object.
|   +-- Prābhākara:
|       +-- Tripuṭī manifestation closely supports intrinsic validity.
|   +-- Bhāṭṭa:
|       +-- Cognition may be known indirectly while validity remains intrinsic.
|   +-- Advaita:
|       +-- Consciousness self-luminous, but empirical cognition may still be sublated.
|
+-- VIII. PRAMĀṆA COUNT
|   +-- Shared five:
|   |   +-- Pratyakṣa: perception.
|   |   +-- Anumāna: inference.
|   |   +-- Upamāna: comparison.
|   |   +-- Śabda: testimony.
|   |   +-- Arthāpatti: postulation.
|   +-- Bhāṭṭa sixth:
|       +-- Anupalabdhi: non-cognition as means to absence.
|   +-- Prābhākara rejects separate anupalabdhi.
|   +-- Nyāya accepts four.
|   +-- Sāṃkhya accepts three.
|   +-- Advaita generally accepts six, but with different metaphysical hierarchy.
|
+-- IX. PERCEPTION
|   +-- Sense-object contact produces cognition of present object.
|   +-- Nirvikalpaka:
|   |   +-- Pre-predicative apprehension without explicit qualification.
|   +-- Savikalpaka:
|   |   +-- Determinate cognition of qualified object.
|   +-- Mīmāṃsā realism:
|       +-- Cognition discloses independently existing object.
|   +-- Error does not show every perception needs external certification; it shows
|       particular causes may be defective.
|
+-- X. INFERENCE / COMPARISON / TESTIMONY
|   +-- Anumāna:
|   |   +-- Knowledge through sign and invariable relation.
|   |   +-- Accepted but cannot absorb every explanatory cognition.
|   +-- Upamāna:
|   |   +-- Similarity yields knowledge of a relation not supplied by mere perception
|   |       or prior words alone.
|   +-- Śabda:
|       +-- Verbal knowledge from sentence.
|       +-- Human testimony depends on trustworthy speaker.
|       +-- Vedic testimony is authorless and independently authoritative.
|
+-- XI. WHY MEMORY IS NOT PRAMĀṆA
|   +-- Pramā must be anadhigata:
|   |   +-- Cognition of something not already apprehended.
|   +-- Memory re-presents prior experience.
|   +-- It depends on saṃskāra produced by earlier cognition.
|   +-- It does not independently reveal a new object.
|   +-- Memory may be accurate and practically valuable without being pramā.
|   +-- Prābhākara:
|       +-- Strongly excludes memory because it lacks novelty.
|   +-- Nyāya agrees memory is non-pramāṇa but within extrinsic validity framework.
|
+-- XII. ARTHĀPATTI
|   +-- Postulation/presumption required to reconcile otherwise inexplicable known facts.
|   +-- Core form:
|   |   +-- Fact A is known.
|   |   +-- Fact A would be impossible unless B.
|   |   +-- Therefore B is postulated.
|   +-- Devadatta:
|       +-- Devadatta is stout.
|       +-- Devadatta does not eat by day.
|       +-- Therefore he eats at night.
|   +-- Cognition is not arbitrary hypothesis:
|       +-- B is demanded by explanatory impossibility of A without B.
|
+-- XIII. TWO FORMS OF ARTHĀPATTI
|   +-- Dṛṣṭārthāpatti:
|   |   +-- Postulation from perceived/known facts.
|   +-- Śrutārthāpatti:
|       +-- Postulation needed to complete or reconcile verbal meaning.
|   +-- Candidate example:
|       +-- Never seen studying during day yet ranks highly.
|       +-- Bhāṭṭa postulates unobserved study/preparation at another time or through
|           otherwise sufficient means, subject to context.
|       +-- Exact postulate must be the least addition making facts coherent.
|
+-- XIV. ARTHĀPATTI VERSUS INFERENCE
|   +-- Nyāya reduction:
|   |   +-- Whoever is stout and does not eat by day eats at night.
|   |   +-- Devadatta satisfies condition.
|   |   +-- Therefore night eating.
|   +-- Bhāṭṭa reply:
|   |   +-- No independently known universal connects all such cases.
|   |   +-- Universal is formulated only after accepting the postulate.
|   |   +-- Using it to reduce arthāpatti is circular.
|   |   +-- Reasoning starts from incompatibility, not a pre-established vyāpti.
|   +-- Difference:
|       +-- Inference applies known concomitance.
|       +-- Postulation supplies an indispensable explanatory fact.
|   +-- Objection:
|       +-- Both are ampliative reasoning and can be reconstructed inferentially.
|   +-- Reply:
|       +-- Formal reconstruction does not erase distinct epistemic trigger.
|
+-- XV. ANUPALABDHI
|   +-- Bhāṭṭa independent pramāṇa for absence.
|   +-- We know "there is no jar on the floor" because a perceptible jar is not cognised
|       under conditions fit for its cognition.
|   +-- Yogyānupalabdhi:
|       +-- Non-cognition of an object fit to be cognised.
|       +-- Light, eyesight, attention, proximity and unobstructed locus must be adequate.
|   +-- Mere non-seeing is not proof:
|       +-- A microscopic object or object in darkness may exist despite non-cognition.
|
+-- XVI. WHY BHĀṬṬA TREATS IT AS INDEPENDENT
|   +-- Perception contacts positive entities; absence is not a positive sense-object.
|   +-- Inference would require:
|   |   +-- "Whatever is not perceived in fit conditions is absent."
|   +-- But grasp of that universal already depends on knowing absences.
|   +-- Therefore reduction risks circularity.
|   +-- Anupalabdhi directly presents qualified absence in locus.
|
+-- XVII. PRĀBHĀKARA AND NYĀYA ON ABSENCE
|   +-- Prābhākara:
|   |   +-- Does not admit absence as separate ontological entity/pramāṇa in Bhāṭṭa sense.
|   |   +-- Cognition of bare locus and failure to apprehend expected object supports
|   |       practical absence judgement.
|   +-- Nyāya:
|       +-- Accepts abhāva as real category.
|       +-- Later Nyāya treats it as perceived through qualifier-qualified relation,
|           not separate anupalabdhi.
|   +-- Bhāṭṭa:
|       +-- Real absence plus distinct means of knowledge.
|
+-- XVIII. ERROR: PRĀBHĀKARA AKHYĀTI
|   +-- Error is non-apprehension/non-discrimination, not one wholly false cognition.
|   +-- Shell-silver:
|   |   +-- Present shell-feature is perceived.
|   |   +-- Past silver is remembered.
|   |   +-- Both cognitions are individually valid.
|   |   +-- Their difference/source is not apprehended.
|   |   +-- Resulting action treats remembered silver as here.
|   +-- Preserves intrinsic validity:
|       +-- No cognition is intrinsically false; failure lies in missing discrimination.
|   +-- Objection:
|       +-- Subject positively reports "this is silver", not merely two unnoticed acts.
|   +-- Reply:
|       +-- Positive practical synthesis arises from non-discrimination.
|
+-- XIX. ERROR: BHĀṬṬA VIPARĪTA-KHYĀTI
|   +-- Error is a positive false relational judgement.
|   +-- Shell and silver are real, but silverhood is falsely predicated of this shell.
|   +-- Unlike Nyāya anyathākhyāti:
|       +-- Bhāṭṭa need not invoke extraordinary perception of elsewhere silver in the
|           exact Nyāya manner.
|   +-- Intrinsic validity survives:
|       +-- Erroneous cognition is initially accepted.
|       +-- Later sublating cognition reveals mismatch extrinsically.
|   +-- Difference from Advaita:
|       +-- No indeterminable illusory silver entity is required.
|
+-- XX. TRIPUṬĪ-SAṂVIT
|   +-- Prābhākara:
|   |   +-- In each cognition, object, subject and cognition are simultaneously manifested.
|   +-- Lamp analogy:
|   |   +-- Lamp illuminates objects and itself.
|   |   +-- Cognition reveals known object, knowing self and itself.
|   +-- No second cognition required to know first.
|   +-- Supports immediate action and avoids regress.
|   +-- Objection:
|       +-- We do not always explicitly notice the act of knowing.
|   +-- Reply:
|       +-- Manifestation need not become separately attended object.
|
+-- XXI. BHĀṬṬA JÑĀTATĀ
|   +-- Cognition itself is not directly self-manifest in Prābhākara's way.
|   +-- We infer that cognition occurred from jñātatā:
|       +-- The object's acquired character of being-known.
|   +-- Structure:
|       +-- Before cognition, pot is not known by me.
|       +-- After cognition, pot appears as known.
|       +-- This knownness is effect; cognition inferred as cause.
|   +-- Objection:
|       +-- How apprehend knownness without already apprehending cognition?
|   +-- Reply:
|       +-- Object-directed awareness includes the effect from which act is inferred.
|   +-- Nyāya:
|       +-- Anuvyavasāya, a subsequent cognition, knows prior cognition.
|
+-- XXII. WORD AND SENTENCE CONDITIONS
|   +-- Ākāṅkṣā:
|   |   +-- Mutual expectancy among words.
|   +-- Yogyatā:
|   |   +-- Semantic compatibility.
|   +-- Sannidhi / āsatti:
|   |   +-- Proximity.
|   +-- Tātparya:
|       +-- Intended purport, emphasised in broader traditions.
|   +-- Sentence meaning is not a mere heap of dictionary meanings.
|
+-- XXIII. ABHIHITĀNVAYAVĀDA
|   +-- Bhāṭṭa theory: connection of what has already been denoted.
|   +-- Stage 1:
|   |   +-- Each word independently denotes its meaning.
|   +-- Stage 2:
|   |   +-- These meanings are syntactically/semantically connected.
|   +-- Sentence meaning is derived after denotation through lakṣaṇā/relational synthesis.
|   +-- Strength:
|       +-- Preserves independent lexical meaning.
|   +-- Objection:
|       +-- Duplicates semantic operations and delays sentence unity.
|   +-- Reply:
|       +-- Word meanings must be available before relation can be cognised.
|
+-- XXIV. ANVITĀBHIDHĀNAVĀDA
|   +-- Prābhākara theory: words denote connected meanings.
|   +-- A word learned in sentences is never first grasped as isolated atom.
|   +-- Each word contributes a meaning already qualified by relation to others.
|   +-- Sentence meaning emerges directly from connected denotation.
|   +-- Strength:
|       +-- Explains immediate comprehension without second synthesis.
|   +-- Objection:
|       +-- Circularity: relation cannot be known before all word meanings.
|   +-- Reply:
|       +-- Incremental expectancy and contextual learning disclose relation as sentence unfolds.
|
+-- XXV. WORDS: UNIVERSALS OR PARTICULARS
|   +-- Bhāṭṭa tendency:
|   |   +-- Word primarily denotes universal, with particular reached through context.
|   +-- Prābhākara:
|   |   +-- Word communicates an action-connected particular qualified by universal.
|   +-- Nyāya:
|       +-- Word meaning involves individual, universal and qualifying form according to
|           developed account.
|   +-- Buddhist apoha:
|       +-- Meaning through exclusion, not real universal.
|   +-- Do not state one undifferentiated "Mīmāṃsā theory" where sub-schools diverge.
|
+-- XXVI. SPHOṬA COMPARISON
|   +-- Grammarian view:
|   |   +-- Indivisible linguistic unit manifests sentence meaning.
|   +-- Bhāṭṭa/Prābhākara:
|       +-- Explain unity through word meanings and syntactic relations, not independent
|           eternal sphoṭa entity.
|   +-- Sphoṭa is not an owned Mīmāṃsā doctrine.
|
+-- XXVII. VEDIC AUTHORITY
|   +-- Veda is apauruṣeya:
|   |   +-- Not authored by human or God.
|   +-- Words and word-meaning relation are beginningless.
|   +-- Human testimony risks:
|   |   +-- Ignorance.
|   |   +-- Deception.
|   |   +-- Memory failure.
|   +-- Authorless Veda lacks speaker defects.
|   +-- Its authority is intrinsic, not certified by external author.
|   +-- It discloses supersensible dharma unavailable to perception/inference.
|   +-- Nyāya objection:
|       +-- Meaningful ordered text requires intelligent author.
|   +-- Mīmāṃsā reply:
|       +-- Vedic phoneme/word tradition is beginningless; no first composition needs proof.
|       +-- God-guarantee creates circularity because God's reliability needs proof/scripture.
|
+-- XXVIII. VEDIC SENTENCE TAXONOMY
|   +-- Vidhi:
|   |   +-- Injunction; action-directing core.
|   +-- Niṣedha:
|   |   +-- Prohibition.
|   +-- Mantra:
|   |   +-- Recitation/remembrance supporting ritual performance.
|   +-- Nāmadheya:
|   |   +-- Naming.
|   +-- Arthavāda:
|       +-- Praise, blame, explanatory or narrative passage supporting injunction.
|   +-- Mantra/arthavāda are not necessarily useless; their authority is interpreted in
|       relation to action and injunction.
|
+-- XXIX. APŪRVA
|   +-- Unseen potency generated by correctly performed ritual action.
|   +-- Bridges temporal gap between momentary act and later fruit.
|   +-- Preserves causal/normative continuity without divine reward-distributor.
|   +-- Not directly perceived.
|   +-- Known because Vedic injunction and delayed efficacy require explanatory connection.
|   +-- Objection:
|       +-- Mysterious placeholder no clearer than God/adṛṣṭa.
|   +-- Reply:
|       +-- It is tied specifically to authorised action rather than an independent
|           personal creator.
|   +-- Interpretive caution:
|       +-- Some accounts emphasise potency; others the action-result relation itself.
|
+-- XXX. BHĀVANĀ
|   +-- Dynamic productive force/impulsion expressed by injunction.
|   +-- Bhāṭṭa twofold analysis:
|   |   +-- Śābdī-bhāvanā:
|   |   |   +-- Linguistic prompting conveyed by optative/injunctive expression.
|   |   +-- Ārthī-bhāvanā:
|   |       +-- Agent's productive activity bringing result about.
|   +-- Aṃśa-traya:
|       +-- Sādhya: what is to be accomplished.
|       +-- Sādhana: means.
|       +-- Itikartavyatā: manner/procedure.
|   +-- Connects sentence semantics, motivation and ritual performance.
|
+-- XXXI. PRĀBHĀKARA NIYOGA
|   +-- Injunction presents obligatory task/kārya.
|   +-- Duty motivates qua duty, not merely desire for heaven.
|   +-- The agent apprehends "this is to be done".
|   +-- Bhāṭṭa tendency:
|       +-- Desired result and productive operation receive greater role.
|   +-- Objection:
|       +-- Bare obligatoriness cannot motivate.
|   +-- Reply:
|       +-- Awareness of duty itself supplies action-guiding force.
|
+-- XXXII. NON-THEISM
|   +-- Creator is unnecessary:
|   |   +-- World and selves are beginningless.
|   |   +-- Karma/apūrva explains results.
|   |   +-- Veda is authorless.
|   +-- Creator problems:
|   |   +-- Embodied or disembodied agency?
|   |   +-- Motive for creation?
|   |   +-- Partiality/cruelty amid suffering?
|   |   +-- Need for material/instrumental causes?
|   +-- Nyāya:
|       +-- God coordinates atoms, language and karma.
|   +-- Mīmāṃsā:
|       +-- Such coordination is either redundant or unsupported.
|   +-- Devatā references:
|       +-- Ritual-linguistic roles do not prove one creator-God.
|
+-- XXXIII. SELF, AGENCY AND LIBERATION
|   +-- Plural enduring self required for:
|   |   +-- Cognition.
|   |   +-- Memory.
|   |   +-- Agency.
|   |   +-- Moral/ritual result.
|   +-- Body, senses and cognition are not identical to self.
|   +-- Liberation doctrines differ in emphasis and are less central than dharma/pramāṇa.
|   +-- Common classical trajectory:
|       +-- Exhaustion of dharma/adharma and end of embodiment/suffering.
|   +-- Do not import Advaita identity-realisation into Pūrva-Mīmāṃsā.
|
+-- XXXIV. CLASSIC OBJECTIONS / REPLIES
|   +-- Default validity is credulity.
|   |   +-- Reply: it is defeasible entitlement, not immunity from correction.
|   +-- Self-luminosity proves truth.
|   |   +-- Reply: manifestation and validity are conceptually distinct.
|   +-- Arthāpatti is inference.
|   |   +-- Reply: no prior vyāpti; incompatibility generates postulate.
|   +-- Anupalabdhi is perception.
|   |   +-- Reply: absence is not positive sense-contact object.
|   +-- Anupalabdhi is inference.
|   |   +-- Reply: universal depends on prior absence cognition.
|   +-- Akhyāti denies positive illusion.
|   |   +-- Reply: action-error arises from non-discrimination.
|   +-- Viparīta-khyāti threatens intrinsic validity.
|   |   +-- Reply: falsity is later known; initial entitlement remains intrinsic.
|   +-- Authorless language is impossible.
|   |   +-- Reply: beginningless word-use relation needs no first speaker.
|   +-- Apūrva is occult.
|       +-- Reply: it is an inference licensed by Vedic action-result structure, though
|           explanatory opacity remains.
|
+-- XXXV. COMPARATIVE GRID
|   +-- Mīmāṃsā versus Nyāya:
|   |   +-- Intrinsic versus extrinsic validity.
|   |   +-- Authorless versus God-grounded Veda.
|   |   +-- Arthāpatti/anupalabdhi independence versus reduction.
|   +-- Mīmāṃsā versus Advaita:
|   |   +-- Ritual injunction/dharma versus Upaniṣadic Brahma-knowledge.
|   |   +-- Real plural world versus graded non-duality.
|   +-- Mīmāṃsā versus Buddhism:
|   |   +-- Enduring self/universals/Veda versus no-self/momentariness/apoha.
|   +-- Mīmāṃsā versus Cārvāka:
|       +-- Multiple pramāṇas and supersensible duty versus perception-only critique.

|   +-- Intrinsic validity is not infallibility.
|   +-- Intrinsic validity is not identical to self-luminosity.
|   +-- Falsity is not intrinsic for Mīmāṃsā.
|   +-- Memory can be true but is not pramāṇa.
|   +-- Bhāṭṭa accepts six pramāṇas; Prābhākara accepts five.
|   +-- Arthāpatti is not arbitrary guessing.
|   +-- Non-cognition proves absence only under fitness conditions.
```
