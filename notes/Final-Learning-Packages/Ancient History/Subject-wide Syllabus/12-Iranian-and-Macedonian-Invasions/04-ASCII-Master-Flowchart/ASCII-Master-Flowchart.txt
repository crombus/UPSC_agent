| PANEL 1/14 - BOUNDARY AND CENTRAL THESIS                                                         |
+--------------------------------------------------------------------------------------------------+
| -> Achaemenid incorporation and Alexander's campaign are distinct episodes in one north-west     |
|    frontier.                                                                                     |
| -> Achaemenid rule was longer and obligation-based; the Macedonian passage was brief and         |
|    military.                                                                                     |
| -> Neither conquered the whole subcontinent; later Seleucids and Indo-Greeks are successor       |
|    histories.                                                                                    |
| -> Answer line: limited conquest, selective adaptation and durable contact across a connected    |
|    frontier.                                                                                     |
+--------------------------------------------------------------------------------------------------+

+--------------------------------------------------------------------------------------------------+
| PANEL 2/14 - EVIDENCE FIREWALL                                                                   |
+--------------------------------------------------------------------------------------------------+
| -> Behistun, DNa and XPh are contemporary royal claims; reliefs visualise imperial ideology.     |
| -> Herodotus is near-period Greek narrative; tribute units, ethnography and totals require       |
|    caution.                                                                                      |
| -> Arrian, Curtius, Diodorus, Plutarch and Justin are later and transmit lost earlier            |
|    traditions.                                                                                   |
| -> Claim is not exact border; detailed narrative is not eyewitness; circulation is not           |
|    sovereignty.                                                                                  |
+--------------------------------------------------------------------------------------------------+

                                                 v

| PANEL 3/14 - FRONTIER MAP                                                                        |
+--------------------------------------------------------------------------------------------------+
| -> Hindu Kush -> Kabul/Swat -> Gandhara/Taxila -> Indus crossing.                                |
| -> Hydaspes/Jhelum -> Acesines/Chenab -> Hydraotes/Ravi -> Hyphasis/Beas.                        |
| -> Return: Jhelum fleet -> lower Indus/Patala -> sea route and Gedrosia/Makran land route.       |
| -> Connectivity enabled movement; terrain, rivers, monsoon, supply and local polities created    |
|    friction.                                                                                     |
+--------------------------------------------------------------------------------------------------+

+--------------------------------------------------------------------------------------------------+
| PANEL 4/14 - ACHAEMENID CHRONOLOGY                                                               |
+--------------------------------------------------------------------------------------------------+
| -> Cyrus II: possible eastern antecedent; no securely mapped Indian annexation.                  |
| -> Darius I: Gandara at Behistun; Gandara and Hindush in DNa; Scylax report.                     |
| -> c. 518/516 BCE is a textbook reconstruction, not a dated frontier charter.                    |
| -> Xerxes: continued lists and contingents; later eastern control varied and weakened.           |
+--------------------------------------------------------------------------------------------------+
                                                 |
                                                 v

+--------------------------------------------------------------------------------------------------+
| PANEL 5/14 - ROYAL LISTS AND HERODOTUS                                                           |
+--------------------------------------------------------------------------------------------------+
| -> Naqsh-i Rustam and Persepolis programs order subject lands within royal ideology.             |
| -> Herodotus places Indians in the twentieth district and reports 360 talents of gold dust.      |
| -> Book 7 describes contingents; later Indian service could be mercenary, allied or mediated.    |
| -> Use for claim, wealth perception and obligation; reject modern audit and census readings.     |
+--------------------------------------------------------------------------------------------------+
                                                 |
                                                 v

+--------------------------------------------------------------------------------------------------+
| PANEL 6/14 - ADMINISTRATION AND CONTACT                                                          |
+--------------------------------------------------------------------------------------------------+
| -> Satrapal supervision could combine tribute, levies, routes and local intermediaries.          |
| -> Imperial Aramaic supplies the strongest context for right-to-left Kharoshthi.                 |
| -> Coins, weights, artisans, vocabulary and artistic forms moved selectively through networks.   |
| -> No blanket Persianisation or wholesale Persian origin for punch-marked coins or Mauryan       |
|    institutions.                                                                                 |
+--------------------------------------------------------------------------------------------------+
                                                 |
                                                 v

+--------------------------------------------------------------------------------------------------+
| PANEL 7/14 - ALEXANDER'S EASTWARD CAMPAIGN                                                       |
+--------------------------------------------------------------------------------------------------+
| -> 327 BCE: Hindu Kush and highland campaigns, including debated Aornos identification.          |
| -> 326 BCE: Indus crossing, Ambhi at Taxila, Hydaspes battle against Porus.                      |
| -> Then Chenab and Ravi zones; troops refuse advance at Hyphasis/Beas.                           |
| -> The route stopped far short of the Ganga plain and did not equal conquest of India.           |
+--------------------------------------------------------------------------------------------------+

+--------------------------------------------------------------------------------------------------+
| PANEL 8/14 - HYDASPES AND REGIONAL AGENCY                                                        |
+--------------------------------------------------------------------------------------------------+
| -> Ambhi allied; Porus fought; highland communities and Malloi resisted.                         |
| -> Greek sources describe feints, upstream crossing, cavalry manoeuvre and an elephant-centred   |
|    line.                                                                                         |
| -> Macedonian battlefield success was followed by Porus's restoration and enlargement.           |
| -> Tactics, casualty totals, speeches and the Porus medallion remain source-dependent.           |
+--------------------------------------------------------------------------------------------------+
                                                 |

+--------------------------------------------------------------------------------------------------+
| PANEL 9/14 - WHY THE ARMY STOPPED                                                                |
+--------------------------------------------------------------------------------------------------+
| -> Years of campaigning and homesickness weakened morale before the Beas.                        |
| -> Monsoon, rivers, disease, supply distance and replacement limits raised future costs.         |
| -> Recent resistance and reports of Gangetic/Nanda forces and elephants sharpened risk.          |
| -> Cumulative command-morale crisis, not Indian-unity myth or one exact army figure.             |
+--------------------------------------------------------------------------------------------------+
                                                 |
                                                 v

+--------------------------------------------------------------------------------------------------+
| PANEL 10/14 - INDUS DESCENT AND RETURN                                                           |
+--------------------------------------------------------------------------------------------------+
| -> After Hyphasis the army returned to the Jhelum, assembled a fleet and descended the Indus.    |
| -> Malloi resistance seriously wounded Alexander; passed territory was not automatically         |
|    pacified.                                                                                     |
| -> Patala served delta reconnaissance and fleet preparation; channels and identifications need   |
|    caution.                                                                                      |
| -> Nearchus sailed west; Alexander crossed Gedrosia/Makran amid severe, uncertain losses.        |
+--------------------------------------------------------------------------------------------------+

+--------------------------------------------------------------------------------------------------+
| PANEL 11/14 - CLASSICAL SOURCE CHAIN                                                             |
+--------------------------------------------------------------------------------------------------+
| -> Ptolemy and Aristobulus feed Arrian; Nearchus survives especially in Arrian's Indica.         |
| -> Onesicritus survives through later writers and was criticised in antiquity for marvels.       |
| -> Curtius dramatises, Plutarch moralises, Diodorus universalises and Justin epitomises.         |
| -> Compare versions; treat speeches, motives, totals and exotic customs as high-risk.            |
+--------------------------------------------------------------------------------------------------+

+--------------------------------------------------------------------------------------------------+
| PANEL 12/14 - ARRANGEMENTS AND FRAGMENTATION                                                     |
+--------------------------------------------------------------------------------------------------+
| -> Porus, Ambhi and Abhisara remained local intermediaries under changing settlements.           |
| -> Philip, Peithon, Eudemus and other officers held shifting commands and garrisons.             |
| -> Greek-named settlements signalled presence but not durable pan-regional government.           |
| -> After 323 BCE succession conflict and local agency rapidly fragmented coherence.              |

+--------------------------------------------------------------------------------------------------+
| PANEL 13/14 - CONSEQUENCES AND BOUNDARIES                                                        |
+--------------------------------------------------------------------------------------------------+
| -> A political opening aided but did not cause Chandragupta's later Mauryan consolidation.       |
| -> Routes, coastal reconnaissance and Greek geographical knowledge were intensified, not         |
|    invented.                                                                                     |
| -> Later Indo-Greek coinage and Gandhara art cannot be attributed personally to Alexander.       |
| -> Immediate effect, indirect opportunity and later successor development must remain separate.  |
