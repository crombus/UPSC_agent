| PANEL 1/14 — 1. SOURCE AND CHRONOLOGY                                                        |
+----------------------------------------------------------------------------------------------+
| Rig Veda = ten-mandala oral ritual-poetic corpus, not chronicle/census.                      |
| Books 2-7 = conventional older family-book baseline; Book 10 generally later.                |
| Working horizon = c.1500/1200-1000 BCE; no single date for every hymn.                       |
| Composition -> performance -> oral preservation -> recension -> manuscripts.                 |
| ANSWER LINE: read every claim through genre, layer and representativeness.                   |
+----------------------------------------------------------------------------------------------+

| PANEL 2/14 — 2. SAPTA-SINDHU GEOGRAPHY                                                       |
+----------------------------------------------------------------------------------------------+
| North-western river world centred on Sindhu/Indus and Punjab tributaries.                    |
| Vitasta-Jhelum; Asikni-Chenab; Parushni-Ravi; Vipasha-Beas; Shutudri-Sutlej.                 |
| Kubha-Kabul; Suvastu-Swat; Krumu-Kurram; Gomati-Gomal in this context.                       |
| Sarasvati/Ghaggar-Hakra and Drishadvati/Chautang remain qualified.                           |
| Nadi-stuti = poetic geography, not hydrological or territorial survey.                       |
+----------------------------------------------------------------------------------------------+

+----------------------------------------------------------------------------------------------+
| PANEL 3/14 — 3. KIN-BASED POLITICAL SCALE                                                    |
+----------------------------------------------------------------------------------------------+
| Kula -> grama -> vis -> jana is a heuristic social scale, not bureaucracy.                   |
| Grama may mean moving/fighting group; vis and jana are people formations.                    |
| Gotra's later exogamous system cannot be projected fully backward.                           |
| People and kin organised authority before bounded territory did.                             |
| TRAP: do not translate every term by its later dictionary meaning.                           |
+----------------------------------------------------------------------------------------------+
                                               |
                                               v

+----------------------------------------------------------------------------------------------+
| PANEL 4/14 — 4. RAJAN AND FUNCTIONARIES                                                      |
+----------------------------------------------------------------------------------------------+
| Rajan = protector + war leader + ritual patron + distributor of wealth.                      |
| Purohita = priestly adviser; senani = war leader; gramani = group leader.                    |
| Authority rested on kin support, success, generosity and ritual legitimacy.                  |
| Bali = offering/tribute, not assessed regular land tax.                                      |
| NO secure bureaucracy, standing army or mature territorial monarchy.                         |
+----------------------------------------------------------------------------------------------+
                                               |
                                               v

+----------------------------------------------------------------------------------------------+
| PANEL 5/14 — 5. ASSEMBLIES AND PARTICIPATION                                                 |
+----------------------------------------------------------------------------------------------+
| Sabha = deliberative/social/ritual/adjudicative possibilities.                               |
| Samiti = broader tribal gathering/support; exact distinction remains debated.                |
| Vidatha = ritual + military + distributive + social functions by context.                    |
| Female visibility in some contexts != universal equality or representation.                  |
| ASSEMBLIES show collective life; they are not modern democratic parliaments.                 |
+----------------------------------------------------------------------------------------------+
                                               |

+----------------------------------------------------------------------------------------------+
| PANEL 6/14 — 6. WARFARE AND BOUNDARY TERMS                                                   |
+----------------------------------------------------------------------------------------------+
| Gavishti links cattle-search/raid with conflict and prestige.                                |
| Book 7: Sudas of Bharatas defeats confederacy near Parushni/Ravi.                            |
| Dasharajna may preserve history but remains patronage-shaped victory poetry.                 |
| Dasa/dasyu = contextual enemy, outsider, subordinate or mythic adversary.                    |
| TRAP: no fixed racial census, ethnic bloc or territorial empire follows.                     |
+----------------------------------------------------------------------------------------------+
                                               |
                                               v

+----------------------------------------------------------------------------------------------+
| PANEL 7/14 — 7. CATTLE-CENTRED MIXED ECONOMY                                                 |
+----------------------------------------------------------------------------------------------+
| Gomat = cattle wealth/status; cattle = gift, traction, ritual and booty.                     |
| Pastoral predominance describes relative value, not exclusive nomadism.                      |
| Kshetra, ploughing, yava, harvest, wells and oxen show cultivation.                          |
| Crafts: wood/chariot, leather, weaving, pottery, metal and household work.                   |
| FORMULA: cattle + cultivation + craft + mobility + exchange.                                 |
+----------------------------------------------------------------------------------------------+
                                               |
                                               v

+----------------------------------------------------------------------------------------------+
| PANEL 8/14 — 8. GIFTS, EXCHANGE AND FISCAL LIMIT                                             |
+----------------------------------------------------------------------------------------------+
| Dana = chiefly gift; dakshina = sacrificial fee; bali = offering/tribute.                    |
| Nishka = valuable metal object/ornament, not automatically a coin.                           |
| Booty and barter moved cattle, horses, produce and crafted goods.                            |
| Redistribution produced status and priest-chief alliance.                                    |
| NO coin-tax bureaucracy or regular territorial fiscal state is demonstrated.                 |
+----------------------------------------------------------------------------------------------+
                                               |
                                               v

+----------------------------------------------------------------------------------------------+
| PANEL 9/14 — 9. HOUSEHOLD, GENDER AND DIFFERENTIATION                                        |
+----------------------------------------------------------------------------------------------+
| Household combined kinship, herding, farming, craft, ritual and alliance.                    |
| Patriliny, son preference and unequal authority indicate patriarchy.                         |
| Ghosha, Apala, Lopamudra, Vishvavara = female-seer traditions, layer-cautious.               |
| Chiefs, priests, warriors, producers, artisans and dependants were unequal.                  |
| Female visibility qualifies patriarchy; it does not establish equality.                      |
+----------------------------------------------------------------------------------------------+

+----------------------------------------------------------------------------------------------+
| PANEL 10/14 — 10. VARNA AND PURUSHA LAYER                                                    |
+----------------------------------------------------------------------------------------------+
| Varna language expresses order/status/boundary and varies by context.                        |
| Rig Veda 10.90: Brahmana + Rajanya + Vaishya + Shudra.                                       |
| Book 10 is generally later within the corpus.                                                |
| PROVES: emerging/finally articulated fourfold ideology.                                      |
| DOES NOT PROVE: rigid hereditary jati/caste across all Early Vedic society.                  |
+----------------------------------------------------------------------------------------------+

+----------------------------------------------------------------------------------------------+
| PANEL 11/14 — 11. RELIGIOUS WORLD                                                            |
+----------------------------------------------------------------------------------------------+
| Indra = battle/storm/rain; Agni = mediation; Varuna = rta/order.                             |
| Soma = drink/deity/inspiration; Ushas = dawn; Ashvins = healing/rescue.                      |
| Rta = cosmic-ritual-moral regularity; yajna = patron-priest-deity reciprocity.               |
| Henotheism is a bounded modern label for hymnic exaltation, not a creed.                     |
| No monumental temple/idol institution defines the Rigvedic baseline.                         |
+----------------------------------------------------------------------------------------------+
                                               |
                                               v

+----------------------------------------------------------------------------------------------+
| PANEL 12/14 — 12. MATERIAL, FUNERARY AND ARCHAEOLOGY                                         |
+----------------------------------------------------------------------------------------------+
| Ashva/ratha = elite mobility and martial symbolism; not a numerical census.                  |
| Ayas = metal, generally copper/bronze range; not automatic iron.                             |
| Cremation and burial vary; Nasadiya 10.129 questions cosmic origins.                         |
| Late Harappan/Swat/OCP supply contexts; PGW mainly Later Vedic comparison.                   |
| ARCHAEOLOGY identifies assemblages, not language or ethnicity by itself.                     |

+----------------------------------------------------------------------------------------------+
| PANEL 13/14 — 13. EARLY TO LATER VEDIC DIRECTION                                             |
+----------------------------------------------------------------------------------------------+
| Sapta-Sindhu -> Kuru-Panchala/upper Ganga.                                                   |
| Cattle-valued mixed economy -> more stable agrarian surplus.                                 |
| Kin chiefship/assemblies -> stronger territorial kingship and hierarchy.                     |
| Emerging differentiation -> harder varna-patriarchal ideology.                               |
| Transition was gradual, regional and uneven; continuities persisted.                         |
