JAHANGIR & THE EARLY SEVENTEENTH CENTURY (NUR JAHAN)
=================================================

CENTRAL FORMULA
---------------
continuity of Mughal structure
    + negotiated consolidation
    + documented household authority
    + sharp succession crises
    + source criticism
= Jahangir as a governing emperor under pressure

1. ACCESSION FRAME
------------------
Salim's Allahabad autonomy + Abu'l Fazl link
        -> trust problem before 1605
        -> accession bargain
           = dynastic claim + noble recognition + offices/rewards + public justice language

2. JUSTICE EVIDENCE
-------------------
Jahangirnama records twelve orders
        -> proclaimed regulation / rectitude
        -> NOT automatic empire-wide implementation
zanjir-i-adl
        -> ruler-centred accessibility symbol
        -> NOT modern judiciary / equal-rights proof

3. KHUSRAU / GURU ARJAN
-----------------------
1606 Khusrau revolt
        -> Punjab-Lahore movement corridor
        -> Bhairowal defeat + exemplary punishment
Guru Arjan
        -> Jahangir's accusation after revolt
        + Sikh memory / fine-execution debate
        -> political suspicion + religious language + long-term consequence

4. CONSOLIDATION
----------------
Mewar 1615
        -> suzerainty with Sisodia honour
        -> Amar Singh not forced to personal attendance
        -> Karan Singh honoured in service
Bengal
        -> Islam Khan + Dacca + Barah-Bhuiyan suppression + selective incorporation
Kangra 1620
        -> strategic fort + khutba/mosque sovereignty gesture
Bounded Deccan note
        -> Khurram useful here only as Jahangir-period commander; Topic 18 owns the full system

5. COMMERCIAL DIPLOMACY
-----------------------
Hawkins = English Company petitioner
Swally 1612 = stronger bargaining vs Portuguese
Roe 1615-19 = commercial diplomacy on Mughal terms
1618 permissions = limited facility, NOT sovereignty / monopoly / territorial state

6. NUR JAHAN AS POLITICAL ACTOR
-------------------------------
Mihr-un-Nisa -> marriage in 1611
Evidence ladder:
    farmans in her name
    coin legends / Badshah Begum
    household access / petitions / patronage
    Itimad-ud-Daulah + Asaf Khan nexus
    Itimad-ud-Daulah tomb as family memorial-patronage evidence
Conclusion:
    exceptional formal and household authority
    BUT not proof that Jahangir disappeared as ruler

7. JUNTA DEBATE
---------------
Beni Prasad -> fixed four-person dominant bloc
Nurul Hasan / Satish Chandra -> promotion spread + fluid alignments + no secure fixed 1611-20 alliance
Irfan Habib -> strong family concentration still real
Best verdict:
    real family power
    without proof of one permanent monopoly
Periodise:
    1611-21 = influence with fluid alignments
    post-1622 = overt crisis politics

8. KHURRAM'S REBELLION
----------------------
Khurram's strength
    = Mewar + Deccan prestige + high mansab + title "Shah Jahan"
1622 trigger bundle
    = Qandahar command issue + fear of absence from court + jagirs/troops + Shahryar factor
Result
    = prolonged princely rebellion -> eastern/Deccan movement -> negotiated submission + hostages
Meaning
    = succession politics + resource bargaining shaped the empire deeply

9. MAHABAT KHAN COUP, 1626
--------------------------
accounts / elephants / transfer / fear of reprisal
        -> Jhelum seizure of Jahangir
        -> immediate leverage from emperor's body
        -> NO durable control of treasury, bureaucracy, nobility or legitimacy
Nur Jahan
        -> tactical resistance + political recovery manoeuvre

10. JAHANGIR AS RULER / SOURCE BASE
-----------------------------------
composite nobility retained
religion = broad accommodation + coercive episodes
named support = Jadrup / no jizya restoration / multiple festival contacts
named cautions = Guru Arjan / Pushkar / anti-Jain order / Sirhindi
culture = Ustad Mansur / naturalism / memoir / painting
source ladder = Tuzuk + chronicles + coins/farmans + monuments + Roe/Hawkins + Sikh memory

11. PRELIMS + MAINS RECALL
--------------------------
1606 = Khusrau + Guru Arjan
1611 = Nur Jahan marriage
1615 = Mewar + Roe begins
1620 = Kangra
1622 = Qandahar loss + Khurram crisis sharpened
1626 = Mahabat coup
Main answer route:
intro -> continuity under pressure
body -> accession / crisis / consolidation / Nur Jahan / Khurram / Mahabat / source method
conclusion -> strain without proven collapse
