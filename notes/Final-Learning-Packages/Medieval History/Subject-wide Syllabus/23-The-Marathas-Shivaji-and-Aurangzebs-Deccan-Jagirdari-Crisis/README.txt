FINAL LEARNING PACKAGE
======================

Topic 23: The Marathas, Shivaji & Aurangzeb's Deccan; Jagirdari Crisis
Subject: Medieval History — Subject-wide Syllabus

What's inside
-------------
1. Complete Learning Session (PDF) — 20 visual-first sessions: definitions, worked
   evidence, keywords, recall flows, 16 MCQs, verified PYQ ledger, optional advanced
   depth, and consolidated register notes.
2. Solved Practice Workbook (PDF) — 32 advanced MCQs (statement / matching /
   chronology / evidence / application / inference) with option-by-option
   explanations, six solved Mains answers (2x10, 2x15, 2x20 marks), and its own
   register-notes summary.
3. Graphical Flowchart — At-a-Glance-Poster.pdf, Printable-Tiled-Version.pdf
   (5-page print set), High-Resolution-Master.png, a contact sheet and previews.
4. ASCII Master Flowchart — standalone plain-text and PDF revision flow (16 panels
   across 3 normal pages), matching the flow embedded in the Learning Session's
   register notes.

How to use it
--------------
Start with the Learning Session end to end, attempt its 16 MCQs, then use the
Workbook for advanced practice and the six Mains answers. Use the Graphical
Flowchart or ASCII Master Flowchart for quick revision passes before an exam.
