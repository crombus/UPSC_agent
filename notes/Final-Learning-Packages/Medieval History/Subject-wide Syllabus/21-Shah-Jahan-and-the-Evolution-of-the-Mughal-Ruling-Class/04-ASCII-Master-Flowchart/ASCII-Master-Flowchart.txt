SHAH JAHAN & THE EVOLUTION OF THE MUGHAL RULING CLASS
====================================================

STARTING QUESTION
-----------------
How could the Mughal empire look so confident under Shah Jahan and yet leave behind
clear signs of pressure inside its ruling class and jagir structure?

1. REIGN FRAME
--------------
1628 enthronement
  -> visible imperial confidence
  -> larger, more composite service elite
  -> more claims on office / cavalry / jagirs
  -> month-scale and contingent adjustments
  -> 1657-58 succession war exposes transfer vulnerability

2. ACCESSION AND CONSOLIDATION
------------------------------
Jahangir dies (1627)
  -> Asaf Khan + leading nobles + army back Khurram
  -> rival princes / claimants removed
  -> Shah Jahan enthroned (1628)
  -> Bundela challenge + Khan Jahan Lodi challenge suppressed
  -> message: Mughal succession remains political-military, but becomes harsher

3. FRONTIER AND DECCAN AS BOUNDED EVIDENCE
------------------------------------------
Daulatabad / Ahmadnagar (1633)
  -> Deccan settlement (1636) = hierarchy / suzerainty, not total annexation
Balkh (1646-47)
  -> tactical reach
  -> logistical unsustainability
Qandahar (lost 1649; failed recoveries to 1653)
  -> siege and supply limits
Use in Topic 21:
  -> campaigns enlarge burden and claims
  -> full foreign-policy detail stays in Topic 19

4. MAGNIFICENCE AS POLITICAL LANGUAGE
-------------------------------------
Peacock Throne (1635 use)
  -> precedence / jewelled sovereignty
Taj Mahal
  -> dynastic memory / memorial kingship
Shahjahanabad (1638 onward)
  -> new capital / urban sovereignty / elite residence
Red Fort + Jama Masjid
  -> ceremonial centre / court-city axis
Moosvi cost caution
  -> significant spending, not automatic fiscal ruin

5. WHAT THE RULING CLASS WAS
----------------------------
ranked imperial service elite
  -> mansab
  -> office
  -> jagir assignment
  -> military command
  -> court access / household proximity
  -> kinship and reputation
Trap:
  -> not a racial caste
  -> not a hereditary peerage in a simple European sense

6. COMPOSITIONAL CHANGE (500 ZAT AND ABOVE)
-------------------------------------------
1595 total 123
1621 total 242
1647-48 total 443
1656 total 518
Key readings:
  -> Iranis and Turanis remain major, but combined proportional share falls
  -> Rajputs remain major military-political partners
  -> Afghans recover some space
  -> Indian Muslims remain important (Sadullah Khan as key name)
  -> small but real Maratha / Deccani inclusion
Conclusion:
  -> wider incorporation + denser competition for reward

7. MANSAB VOCABULARY
--------------------
zat   = personal rank / pay grade
sawar = cavalry obligation and related pay claim
jagir = transferable revenue assignment
jama  = assessed revenue on paper
hasil = realised collection
khalisa = crown-retained revenue

dagh   = branding of horses
chehra = descriptive muster roll
Limit:
  -> verification matters, but borrowed men / horses show evasion remained possible

8. DU-ASPA SIH-ASPA + EFFECTIVE CONTINGENTS
-------------------------------------------
du-aspa sih-aspa
  -> first placed under Jahangir in the assigned source
  -> intensifies specified cavalry duty
  -> does NOT itself raise zat

one-third / one-fourth / one-fifth rules
  -> same-province jagir -> about one-third
  -> outside-province jagir -> about one-fourth
  -> harsh theatres (Balkh-Badakhshan, perhaps Deccan) -> one-fifth

Worked example:
  2000 zat / 2000 sawar
  with 1000 du-aspa sih-aspa
  outside-province jagir
  -> 250 ordinary + 500 doubled = 750 effective contingent

9. MONTH-SCALE
--------------
Why needed?
  -> paper assessment and real support diverge
Jagir scale:
  12-month -> 10-month -> 8-month -> 6-month -> 4-month
  Deccan could fall to 3-4 months because jama was especially inflated
Illustrative sawar rates:
  12-month -> Rs 40
  8-month  -> Rs 30
  6-month  -> Rs 25
Trap:
  -> month-scale is not a bonus
  -> it is a downward adjustment to effective yield

10. REVENUE GROWTH VERSUS ELITE GROWTH
--------------------------------------
jama index:
  1595-96 = 100
  1627    = about 122
  1647-48 = about 162
  1656-57 = 176
higher elite:
  123 -> 518
Mechanism:
  more ranks / more claims + uneven hasil + limited productive jagirs + costly theatres
  -> be-jagiri roots + pressure on assignees, troopers and collectors
Verdict:
  -> system still functions
  -> later full jagirdari crisis belongs elsewhere

11. SUCCESSION WAR, 1657-58
---------------------------
Shah Jahan ill (September 1657)
  -> Dara favoured but not constitutionally secured
  -> Shuja, Murad, Aurangzeb mobilise separate bases
  -> Dharmat + Samugarh = decisive battle sequence
  -> Shah Jahan confined in Agra
Meaning:
  -> princely households + noble networks become succession armies
  -> no fixed primogeniture
  -> not a simple liberal-vs-orthodox referendum
Boundary:
  -> Topic 21 stops at accession outcome
  -> Topic 22 begins after that outcome

12. EXAM TRAPS
--------------
- jagir is not landownership
- jama is not hasil
- month-scale is not a reward
- du-aspa is not higher zat
- composite elite is not a harmonious federation
- frontier campaigning is not the same as durable control
- classical age is not identical to effortless empire

13. ANSWER SPINE
----------------
Opening line:
  Shah Jahan's reign displayed the Mughal empire at its most visibly ordered,
  but the same reign had to manage widening pressure inside the ruling class
  and jagir system.
Body order:
  accession and coercive consolidation
  -> bounded frontier and Deccan evidence
  -> magnificence as political language
  -> ruling-class composition
  -> mansab vocabulary and contingent rules
  -> month-scale and revenue pressure
  -> 1657-58 succession war
Qualified conclusion:
  visible apex + composite expansion + adaptive fiscal strain
