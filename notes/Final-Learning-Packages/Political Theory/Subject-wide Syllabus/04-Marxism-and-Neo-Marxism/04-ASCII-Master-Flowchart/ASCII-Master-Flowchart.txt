ASCII MASTER FLOW — PANEL 5/14: Chapter Spine
+----------------------------------------------------------------------------------------------+
| CHAPTER SPINE                                                                                |
+----------------------------------------------------------------------------------------------+
| 01. Gauba begins with capitalism's oppressive conditions and presents Marxism as a response  |
| to the failure of laissez-faire liberalism to deliver real human freedom. (PDF pp.46-47)     |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 02. Marxism argues that private property in the means of production divides society into     |
| dominant and dependent classes with antagonistic interests. (PDF p.47)                       |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 03. The mode of production shapes the social structure; when productive forces clash with    |
| existing relations of production, revolution replaces one social formation with another.     |
| (PDF pp.48-50)                                                                               |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 04. Class struggle continues from slave society to feudalism to capitalism, and Marxism      |
| expects a socialist revolution to end this cycle in a classless society. (PDF pp.49-52)      |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 05. Neo-Marxism reopens Marxism by focusing on alienation, ideology, technological           |
| domination and the relative autonomy of superstructural factors. (PDF pp.53-54)              |
+----------------------------------------------------------------------------------------------+

ASCII MASTER FLOW — PANEL 6/14: Illustrations Attached to Claims
+----------------------------------------------------------------------------------------------+
| ILLUSTRATIONS ATTACHED TO CLAIMS                                                             |
+----------------------------------------------------------------------------------------------+
| 01. Gauba's stage-chart example shows how different modes of production generate different   |
| social formations: slave-owning, feudal, capitalist, socialist and communist. (PDF pp.49-50) |
| 02. The wage relation illustrates surplus value: the worker produces more value than is      |
| returned as subsistence wages, and the unpaid residue becomes capitalist profit. (PDF        |
| pp.52-53)                                                                                    |
| 03. Neo-Marxist cultural critique treats communication and consumer desire as sites of       |
| domination, not merely reflections of factory ownership. (PDF pp.53-54)                      |
| 04. For answer-writing, a safe illustration is to compare direct workplace exploitation with |
| indirect ideological consent produced through culture and media                              |
+----------------------------------------------------------------------------------------------+

ASCII MASTER FLOW — PANEL 7/14: Comparison Matrix
+----------------------------------------------------------------------------------------------+
| COMPARISON MATRIX                                                                            |
+----------------------------------------------------------------------------------------------+
| 01. CORE FOCUS | Classical Marxism = Property, class division and revolutionary              |
| transformation of capitalism. (PDF p.47) | Neo-Marxism = Ideology, alienation, culture and   |
| subtle domination. (PDF pp.53-54)                                                            |
| 02. HUMAN PROBLEM | Classical Marxism = Exploitation rooted in ownership of means of         |
| production. (PDF p.47) | Neo-Marxism = Distorted consciousness and managed unfreedom in      |
| advanced society. (PDF pp.53-54)                                                             |
| 03. METHOD | Classical Marxism = Historical materialism and class struggle. (PDF pp.48-52) | |
| Neo-Marxism = Critical theory, humanist critique, structural analysis. (PDF pp.53-54)        |
| 04. BASE-SUPERSTRUCTURE VIEW | Classical Marxism = Base-centred explanation. (PDF p.48) |    |
| Neo-Marxism = Relative interdependence between base and superstructure. (PDF p.53)           |
| 05. KEY NAMES | Classical Marxism = Marx, Engels, Lenin, Luxemburg, Mao. (PDF p.47) | Neo-   |
| Marxism = Frankfurt School, Marcuse, Althusser, dependency theorists. (PDF pp.53-54)         |

ASCII MASTER FLOW — PANEL 8/14: Examiner Trap Firewall
+----------------------------------------------------------------------------------------------+
| EXAMINER TRAP FIREWALL                                                                       |
+----------------------------------------------------------------------------------------------+
| 01. TRAP: Marx simply said thesis-antithesis-synthesis => REPAIR: That triadic language is a |
| teaching shorthand drawn from Gauba's discussion of Hegel's dialectic; do not present it as  |
| Marx's own settled formula. (PDF p.48)                                                       |
| 02. TRAP: Historical materialism means economics alone explains everything => REPAIR:        |
| Gauba's neo-Marxist section explicitly notes growing recognition of interdependence between  |
| base and superstructure. (PDF p.53)                                                          |
| 03. TRAP: Neo-Marxism abandons Marxism => REPAIR: Gauba presents it as a development within  |
| Marxism, especially around alienation, ideology and emancipation. (PDF pp.47, 53-54)         |
| 04. TRAP: Surplus value means any profit whatsoever is automatically identical with market   |
| price movement => REPAIR: Gauba defines it as the unpaid part of labour appropriated by the  |
| capitalist, not simply any change in sale price. (PDF pp.52-53)                              |
+----------------------------------------------------------------------------------------------+
