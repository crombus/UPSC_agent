ASCII MASTER FLOW — PANEL 4/14: Core Definitions
+----------------------------------------------------------------------------------------------+
| CORE DEFINITIONS                                                                             |
+----------------------------------------------------------------------------------------------+
| 01. DISCIPLINE: A branch or field of learning. (PDF p.136)                                   |
| 02. INTERDISCIPLINARY APPROACH: Use of more than one discipline to study a problem,          |
| especially where common or overlapping phenomena are involved. (PDF p.136)                   |
| 03. EMPIRICAL APPROACH: Focus on observable facts, explanation, correlation, generalization  |
| and prediction. (PDF p.138)                                                                  |
| 04. NORMATIVE APPROACH: Focus on values, prescriptions and what ought to be done. (PDF       |
| p.138)                                                                                       |
| 05. POLITICAL ECONOMY: Analysis of political aspects of economic policy-making and of the    |
| mutual impact of economic forces and political decisions. (PDF p.143)                        |
| 06. POLITICAL SOCIOLOGY: Study of political institutions, processes and ideologies in        |
| relation to social structures and modes of thought. (PDF p.144)                              |
| 07. POLITICAL PSYCHOLOGY: Use of psychological models and techniques to analyse political    |
| behaviour, attitudes, learning, socialization, leadership and propaganda. (PDF p.145)        |
| 08. POLITICAL PHILOSOPHY: Inquiry into moral and substantive dimensions of politics,         |
| including values, obligation, good life and the worth of political systems. (PDF p.146)      |
+----------------------------------------------------------------------------------------------+

ASCII MASTER FLOW — PANEL 5/14: Chapter Spine
+----------------------------------------------------------------------------------------------+
| CHAPTER SPINE                                                                                |
+----------------------------------------------------------------------------------------------+
| 01. Gauba begins by treating social sciences as related disciplines dealing with common      |
| human problems, which makes interdisciplinarity especially suitable to politics. (PDF p.136) |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 02. He insists that political inquiry should borrow from other disciplines purposefully,     |
| always to understand political problems, not randomly for their own sake. (PDF p.137)        |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 03. Empirical orientation, behavioural analysis and systems analysis pushed political        |
| science toward other social sciences because real politics cannot be grasped by ideal-state  |
| speculation or formal institutions alone. (PDF pp.138-139)                                   |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 04. Political science therefore uses data, theories and models from history, economics,      |
| sociology, psychology and philosophy. (PDF pp.139-146)                                       |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 05. Yet the conclusion is not merger into one master science; the integrated approach keeps  |
| politics central while using all relevant disciplines for verification and understanding.    |
| (PDF p.146)                                                                                  |
+----------------------------------------------------------------------------------------------+

ASCII MASTER FLOW — PANEL 6/14: Illustrations Attached to Claims
+----------------------------------------------------------------------------------------------+
| ILLUSTRATIONS ATTACHED TO CLAIMS                                                             |
+----------------------------------------------------------------------------------------------+
| 01. Gauba says a political scientist assessing whether democracy will be sustained may need  |
| data on literacy, income distribution, ownership patterns, religious attitudes, family       |
| structure and rural-urban composition. (PDF p.139)                                           |
| 02. Labour-management relations or crowd psychology should be studied politically only when  |
| they illuminate their impact on politics. (PDF p.137)                                        |
| 03. Political development requires understanding social mobilization and value change, not   |
| merely constitutions or legal forms. (PDF p.140)                                             |
| 04. Political communication, propaganda, charismatic leadership and public opinion formation |
| draw directly on political psychology. (PDF pp.144-145)                                      |
| 05. A good UPSC answer on welfare politics can therefore move from economic scarcity, to     |
| class/group conflict, to mass attitudes, and finally to philosophical evaluation of justice  |
+----------------------------------------------------------------------------------------------+

ASCII MASTER FLOW — PANEL 7/14: Comparison Matrix
+----------------------------------------------------------------------------------------------+
| COMPARISON MATRIX                                                                            |
+----------------------------------------------------------------------------------------------+
| 01. HISTORY | What it mainly contributes = Verification through past events, sequences and   |
| long-term causation. (PDF p.141) | Typical political-theory use = Testing a theory about     |
| state formation or democracy against historical cases | Limit if used alone = May become     |
| mere chronicle if not politically interpreted                                                |
| 02. ECONOMICS | What it mainly contributes = Insight into production, distribution,          |
| exchange, scarcity and economic conflict. (PDF pp.142-143) | Typical political-theory use =  |
| Understanding welfare state claims, class conflict, policy choice and political economy |    |
| Limit if used alone = Cannot by itself settle legitimacy or justice                          |
| 03. SOCIOLOGY | What it mainly contributes = Group life, institutions, status, attitudes,    |
| participation and political culture. (PDF pp.143-144) | Typical political-theory use =       |
| Explaining political socialization, cleavage, leadership and legitimacy | Limit if used      |
| alone = Risks reducing politics to social structure alone                                    |
| 04. PSYCHOLOGY | What it mainly contributes = Motives, attitudes, personality, propaganda    |
| and leadership appeal. (PDF pp.144-145) | Typical political-theory use = Explaining          |
| extremist appeal, public opinion and charismatic authority | Limit if used alone = Cannot    |
| alone explain institutions or economic conflict                                              |
| 05. PHILOSOPHY | What it mainly contributes = Conceptual clarification, values, moral        |
| foundations and ends of public life. (PDF pp.145-146) | Typical political-theory use =       |
| Clarifying liberty, equality, obligation, justice and the goals of policy | Limit if used    |
| alone = Without empirical grounding, it can become purely speculative                        |

ASCII MASTER FLOW — PANEL 8/14: Examiner Trap Firewall
+----------------------------------------------------------------------------------------------+
| EXAMINER TRAP FIREWALL                                                                       |
+----------------------------------------------------------------------------------------------+
| 01. TRAP: "Interdisciplinary study means political science has lost its identity." =>        |
| REPAIR: Gauba says political science remains focused on politics while using other           |
| disciplines for broader and better-grounded analysis. (PDF pp.137, 146)                      |
| 02. TRAP: "Empirical political science made philosophy irrelevant." => REPAIR: Gauba says    |
| political philosophy regained prominence after post-behaviouralism and still helps define    |
| policy goals. (PDF pp.145-146)                                                               |
| 03. TRAP: "History and political science are the same thing." => REPAIR: Gauba treats this   |
| older formula as an oversimplification; history is used selectively and critically. (PDF     |
| p.141)                                                                                       |
| 04. TRAP: "One discipline can fully explain politics." => REPAIR: The chapter concludes that |
| philosophical, historical, legal, economic, sociological and psychological approaches are    |
| partial when used alone. (PDF p.146)                                                         |
