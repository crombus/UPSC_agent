ASCII MASTER FLOW — PANEL 4/19: Core Definitions
+----------------------------------------------------------------------------------------------+
| CORE DEFINITIONS                                                                             |
+----------------------------------------------------------------------------------------------+
| 01. JUSTICE: Gauba introduces justice through the fair allocation of benefits and burdens,   |
| especially where valued goods are scarce and criteria are open to contestation; this is his  |
| chapter frame, not an exhaustive definition of every form of justice                         |
| 02. OPEN SOCIETY: A society where existing arrangements may be criticized and revised        |
| through public reasoning, making the search for justice meaningful                           |
| 03. LEGAL JUSTICE: Justice in the legal sphere may mean either fair administration according |
| to existing law or testing law itself against standards of justice                           |
| 04. POLITICAL JUSTICE: Transformation of institutions, rights and procedures so that         |
| political power reflects the people rather than privileged groups                            |
| 05. SOCIO-ECONOMIC JUSTICE: Reordering social and economic relations so that exploitation is |
| checked and the material and moral gains of social life reach weaker sections                |
| 06. PROCEDURAL JUSTICE: Justice secured through fair rules, impartial application and non-   |
| cheating, often modeled on market or competition rules                                       |
| 07. SUBSTANTIVE / DISTRIBUTIVE JUSTICE: In this chapter Gauba treats substantive, social and |
| distributive concerns together: justice is judged by whether actual arrangements improve the |
| condition and life-chances of the poor and underprivileged, not by procedure alone. The      |
| terms are not universally synonymous across political theory                                 |
| 08. SOCIAL JUSTICE: In Gauba's modern usage, a progressive demand to transform oppressive    |
| social conditions and secure what is due to the underprivileged from organized social life   |
+----------------------------------------------------------------------------------------------+

ASCII MASTER FLOW — PANEL 5/19: Chapter Spine (1/2)
+----------------------------------------------------------------------------------------------+
| CHAPTER SPINE (1/2)                                                                          |
+----------------------------------------------------------------------------------------------+
| 01. Gauba frames justice as a political allocation question where social advantages are      |
| scarce and their distribution can be openly debated and revised; corrective, penal and other |
| justice questions need not all take this allocative form                                     |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 02. Gauba distinguishes good/bad from right/wrong and treats justice as aligned with the     |
| latter: a question of what is right and reasonable, not merely what is useful. This is his   |
| anti-utilitarian contrast, not proof that every utilitarian theory is incapable of giving an |
| account of justice                                                                           |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 03. Justice is dynamic because social consciousness changes; arrangements once accepted as   |
| just may later be condemned as unjust, as with slavery, serfdom or caste-based degradation   |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 04. Ernest Barker's key point is that justice orders liberty, equality and fraternity into   |
| an integrated whole rather than leaving them as three isolated slogans                       |
+----------------------------------------------------------------------------------------------+

| CHAPTER SPINE (2/2)                                                                          |
+----------------------------------------------------------------------------------------------+
| 05. Modern social justice shifts emphasis from the virtuous individual in a fixed order to   |
| the just society that must transform oppressive conditions themselves                        |
|                                                                                              |

ASCII MASTER FLOW — PANEL 7/19: Essential Distinctions
+----------------------------------------------------------------------------------------------+
| ESSENTIAL DISTINCTIONS                                                                       |
+----------------------------------------------------------------------------------------------+
| 01. Justice according to law => This asks whether decisions are made by general rules,       |
| applied impartially and efficiently under existing law; Alf Ross represents this line        |
| 02. Law according to justice => This asks whether the law itself has moral value and         |
| conforms to what is right-in-itself; Ernest Barker represents this line                      |
| 03. Core warning => If law is valid, it is automatically just. -> Gauba prefers Barker's     |
| view that validity and value are distinct, and that law is strongest when it has both        |
| authority and justice                                                                        |
| 04. Distinction => What to say precisely                                                     |
| 05. Procedural justice => It stresses fair rules, impartiality and absence of force or       |
| fraud, much like a fair race where cheating is disallowed                                    |
| 06. Substantive / distributive justice => In Gauba's chapter usage, it stresses whether the  |
| poor and underprivileged gain real opportunities to improve their lot, even if this requires |
| altering background structures and not just policing rules; substantive and distributive     |
| justice remain distinguishable in wider theory                                               |
| 07. Core warning => A procedurally regular result is automatically substantively just. ->    |
| Gauba rejects that simplification because open competition inside deep inequality can still  |
| leave many trapped in sub-human conditions                                                   |
| 08. Balance point => Due process still matters; substantive justice does not erase the need  |
| for impartial procedures                                                                     |
+----------------------------------------------------------------------------------------------+

ASCII MASTER FLOW — PANEL 8/19: Thinkers and Named Positions (1)
+----------------------------------------------------------------------------------------------+
| THINKERS AND NAMED POSITIONS (1)                                                             |
+----------------------------------------------------------------------------------------------+
| 01. PLATO: Justice in the traditional sense means each part of the soul and each class in    |
| the state doing its proper function under rule of reason; Gauba treats this as a classic     |
| conservative/functional view                                                                 |
| 02. D.D. RAPHAEL: Justice should be read through modern consciousness; legal, political and  |
| social change alter what counts as just                                                      |
| 03. ERNEST BARKER: Justice is the integrating principle behind liberty, equality and         |
| fraternity, and law gains true force when validity is joined with moral value                |
| 04. ALF ROSS: Justice in law primarily means efficient, rule-bound and impartial             |
| administration according to existing law, not appeal to external moral standards             |
+----------------------------------------------------------------------------------------------+

ASCII MASTER FLOW — PANEL 9/19: Thinkers and Named Positions (2)
+----------------------------------------------------------------------------------------------+
| THINKERS AND NAMED POSITIONS (2)                                                             |
+----------------------------------------------------------------------------------------------+
| 01. JEREMY BENTHAM: Mainstream utilitarianism focuses on utility and felicific calculation,  |
| which Gauba treats as insufficiently attentive to justice as rightness                       |
| 02. J.S. MILL: Mill develops a utilitarian account of justice rather than abandoning         |
| utility. His liberty principle and account of justice show why Gauba's criticism should be   |
| directed at reduction of justice to aggregate advantage, not at every utilitarian treatment  |
| of rights and justice                                                                        |
| 03. JOHN RAWLS: Rawls is noted as a critic of utilitarianism and as a thinker who tries to   |
| accommodate substantive concerns within a procedural framework                               |
| 04. C.B. MACPHERSON: Macpherson is used against market-centered proceduralism because        |
| capitalist conditions can destroy ordinary people's creative freedom and thus the background |
| fairness of competition                                                                      |
+----------------------------------------------------------------------------------------------+

ASCII MASTER FLOW — PANEL 10/19: Illustrations Attached to Claims
+----------------------------------------------------------------------------------------------+
| ILLUSTRATIONS ATTACHED TO CLAIMS                                                             |
+----------------------------------------------------------------------------------------------+
| 01. A law that is impartially applied but bars the poor from real access to courts shows why |
| legal regularity alone may fall short of justice                                             |
| 02. Gauba's own contrast between open society and authoritarian order explains why           |
| allocative criteria become publicly contestable where arrangements can be criticized and     |
| revised; authoritarian institutions can still be judged unjust even when such contestation   |
| is suppressed                                                                                |
| 03. His use of liberty-equality-fraternity shows that equal formal treatment of worker and   |
| employer may still be unjust if the weaker party faces systematic exploitation               |
| 04. A fair exam rulebook does not settle justice if only a narrow class can realistically    |
| prepare; this is a simple way to explain the gap between procedure and substance             |
| 05. Gauba's concluding argument says minimum needs such as subsistence, health care,         |
| education and work opportunities must be secured before desert-based differences are         |
| defended                                                                                     |
+----------------------------------------------------------------------------------------------+

ASCII MASTER FLOW — PANEL 11/19: Comparison Matrix
+----------------------------------------------------------------------------------------------+
| COMPARISON MATRIX                                                                            |
+----------------------------------------------------------------------------------------------+
| 01. LEGAL JUSTICE | What it focuses on = Fair administration of law and/or evaluation of     |
| whether law itself is just | Why it matters = Without it, authority becomes arbitrary or     |
| morally empty                                                                                |
| 02. POLITICAL JUSTICE | What it focuses on = Democratic institutions, rule of law,           |
| constitutional government, free criticism and free association | Why it matters = It ensures |
| that power is not monopolized by privileged groups                                           |
| 03. SOCIO-ECONOMIC JUSTICE | What it focuses on = Reordering economic and social relations   |
| so the lower and weaker sections gain dignity, protection and material opportunity | Why it  |
| matters = It prevents economic disparity from hollowing out legal and political justice      |
| 04. VALUE | What it focuses on = Justice-related role                                        |
| 05. LIBERTY | What it focuses on = Justice requires liberty, but only as equal and regulated |
| liberty so one person's freedom does not destroy another's                                   |
| 06. EQUALITY | What it focuses on = Justice requires equality, but not merely formal non-    |
| discrimination where structural deprivation persists                                         |
| 07. FRATERNITY | What it focuses on = Justice further qualifies equality by demanding        |
| protection of weaker sections and fair sharing of social advantages as a matter of right,    |
| not charity                                                                                  |

ASCII MASTER FLOW — PANEL 12/19: Examiner Trap Firewall
+----------------------------------------------------------------------------------------------+
| EXAMINER TRAP FIREWALL                                                                       |
+----------------------------------------------------------------------------------------------+
| 01. TRAP: Justice is only whatever the law says => REPAIR: Gauba explicitly distinguishes    |
| legal validity from moral value and prefers a richer view where law must also answer to      |
| justice                                                                                      |
| 02. TRAP: Social justice means only welfare charity => REPAIR: Gauba treats it as a          |
| structural and rights-based transformation of social conditions, especially for the          |
| oppressed and underprivileged                                                                |
| 03. TRAP: Procedural fairness settles everything => REPAIR: A fair-looking procedure can     |
| still operate inside severe inequality and leave outcomes unjust                             |
| 04. TRAP: Substantive justice can ignore due process => REPAIR: Gauba does not reject        |
| procedure; he rejects the claim that procedure alone is enough                               |
| 05. TRAP: Liberty, equality and fraternity are separate slogans to be listed one after       |
| another => REPAIR: Barker's central point is that justice orders and reconciles them into    |
| one coherent scheme                                                                          |
