ASCII MASTER FLOW — PANEL 6/15: Chapter Spine
+----------------------------------------------------------------------------------------------+
| CHAPTER SPINE                                                                                |
+----------------------------------------------------------------------------------------------+
| 01. Gauba starts with citizenship as reciprocal membership, then distinguishes it from mere  |
| subjecthood (PDF pp.324-325)                                                                 |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 02. He next traces a stylised Western genealogy from ancient restricted citizenship to       |
| modern mass citizenship based increasingly on rights (PDF pp.325-327). It is not a universal |
| or automatically progressive history of every political community                            |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 03. Modern substantive citizenship, for Gauba, is organized through Marshall's triad of      |
| civil, political and social rights (PDF pp.327-329)                                          |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 04. The chapter then compares liberal, libertarian, communitarian, Marxist and pluralist     |
| theories of citizenship (PDF pp.329-334)                                                     |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 05. Finally, feminist and subaltern critiques expose how legal equality can coexist with     |
| actual exclusion, under-representation and discrimination (PDF pp.334-337)                   |
+----------------------------------------------------------------------------------------------+

ASCII MASTER FLOW — PANEL 7/15: Illustrations Attached to Claims
+----------------------------------------------------------------------------------------------+
| ILLUSTRATIONS ATTACHED TO CLAIMS                                                             |
+----------------------------------------------------------------------------------------------+
| 01. Ancient Greek city-states limited citizenship to a small body of freemen while excluding |
| slaves, women and aliens; this is a historical warning against romanticizing classical       |
| citizenship (PDF p.325)                                                                      |
| 02. Gauba uses the American civil rights movement to show the gap between formal rights in   |
| law and substantive access in practice (PDF p.328)                                           |
| 03. He uses the 1989 Tiananmen Square repression in China as a book-period illustration of   |
| the gap between formal claims and genuine political rights (PDF p.328). It does not by       |
| itself establish a claim about every communist system                                        |
| 04. The feminist section notes that voting rights alone did not ensure equal representation  |
| of women in legislatures or public authority; treat Gauba's country figures as               |
| historical/book-period data (PDF pp.335-336)                                                 |
| 05. Gauba presents reservation for women in panchayats as a starting point toward fuller     |
| participation from a feminist perspective (PDF p.336)                                        |
+----------------------------------------------------------------------------------------------+

ASCII MASTER FLOW — PANEL 8/15: Comparison Matrix
+----------------------------------------------------------------------------------------------+
| COMPARISON MATRIX                                                                            |
+----------------------------------------------------------------------------------------------+
| 01. FORMAL VS SUBSTANTIVE CITIZENSHIP | Side A = Legal membership and nominal rights (PDF    |
| p.325) | Side B = Actual enjoyment and enforcement of rights in practice (PDF pp.325,        |
| 327-329) | Exam use = Do not assume legal inclusion means lived equality                     |
| 02. UNIVERSAL VS DIFFERENTIATED CITIZENSHIP | Side A = Same formal status for all citizens | |
| Side B = Group-sensitive remedies where historic exclusion blocks equal participation | Exam |
| use = Use to explain feminist/subaltern critiques                                            |
| 03. MARSHALL'S TRIAD | Side A = Civil rights: liberty, speech, property, equality before law |
| (PDF p.327) | Side B = Political rights: voting/office; social rights: welfare/social        |
| heritage (PDF pp.327-329) | Exam use = Marshall's sequence is an English historical model,   |
| not a universal chronology                                                                   |

ASCII MASTER FLOW — PANEL 9/15: Examiner Trap Firewall
+----------------------------------------------------------------------------------------------+
| EXAMINER TRAP FIREWALL                                                                       |
+----------------------------------------------------------------------------------------------+
| 01. TRAP: "Citizen and subject are interchangeable." => REPAIR: Gauba separates them         |
| sharply; citizenship presupposes a community where rule is authorized procedurally and non-  |
| discriminatorily (PDF pp.324-325)                                                            |
| 02. TRAP: "Citizenship is only a bundle of rights." => REPAIR: It is reciprocal status       |
| involving duties, obligations and allegiance as well (PDF p.324)                             |
| 03. TRAP: "Marshall gives a universal, necessary three-stage chronology for all countries."  |
| => REPAIR: His sequence is drawn from England and is best treated as a historical model, not |
| a law of development (PDF pp.327-330)                                                        |
| 04. TRAP: "Once legal equality is granted, feminist critique is over." => REPAIR: Gauba      |
| shows that under-representation, domestic role expectations and unequal opportunities        |
| persist despite formal equality (PDF pp.334-336)                                             |
| 05. TRAP: "Subaltern critique is only about class." => REPAIR: Gauba expands it to all       |
| groups discriminated against on irrelevant grounds such as caste, gender, religion,          |
| language, age, region or vocation (PDF pp.336-337)                                           |
| 06. TRAP: "Gauba's subaltern category is identical to every use of subaltern." => REPAIR:    |
| His broad grouping must be distinguished from Gramsci's vocabulary, Subaltern Studies and    |
| Spivak's later intervention                                                                  |
+----------------------------------------------------------------------------------------------+
