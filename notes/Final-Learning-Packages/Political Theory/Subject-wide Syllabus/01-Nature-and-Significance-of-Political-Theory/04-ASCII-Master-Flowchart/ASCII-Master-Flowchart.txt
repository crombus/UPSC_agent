ASCII MASTER FLOW — PANEL 4/17: Theory and Three Statement Types
+----------------------------------------------------------------------------------------------+
| THEORY AND THREE STATEMENT TYPES                                                             |
+----------------------------------------------------------------------------------------------+
| 01. THEORY -> systematic knowledge, not isolated opinion.                                    |
|                                                                                              |
|                                             v                                                |
|                                                                                              |
| 02. EMPIRICAL -> observation / sense-experience -> what happens?                             |
|                                                                                              |
|                                             v                                                |
|                                                                                              |
| 03. LOGICAL -> reasoning / inference -> does the conclusion follow?                          |
|                                                                                              |
|                                             v                                                |
|                                                                                              |
| 04. EVALUATIVE -> right / good / desirable -> what ought to be?                              |
|                                                                                              |
|                                             v                                                |
|                                                                                              |
| 05. LOGICAL POSITIVISM -> valid knowledge only by empirical method; values excluded.         |
|                                                                                              |
|                                             v                                                |
|                                                                                              |
| 06. GAUBA'S REPLY -> values have a logical structure and can be argued toward agreement.     |
|                                                                                              |
|                                             v                                                |
|                                                                                              |
| 07. TRAP -> evaluative does not mean irrational; it requires public reasons.                 |
+----------------------------------------------------------------------------------------------+

ASCII MASTER FLOW — PANEL 5/17: Political Science: Method
+----------------------------------------------------------------------------------------------+
| POLITICAL SCIENCE: METHOD                                                                    |
+----------------------------------------------------------------------------------------------+
| 01. OBSERVATION -> sense-experience alone; supernatural/metaphysical causation ruled out.    |
|                                                                                              |
|                                             v                                                |
|                                                                                              |
| 02. GENERALISATION -> regularities and correlations, preferably quantitative and verifiable. |
|                                                                                              |
|                                             v                                                |
|                                                                                              |
| 03. INDUCTION -> particular cases to a general rule.                                         |
|                                                                                              |
|                                             v                                                |
|                                                                                              |
| 04. DEDUCTION -> a postulated general rule confirmed on particular cases.                    |
|                                                                                              |
|                                             v                                                |
|                                                                                              |
| 05. EXPLANATION -> reasons for the rule; without them a correlation may be coincidence.      |
|                                                                                              |
|                                             v                                                |
|                                                                                              |
| 06. PREDICTION / PRESCRIPTION -> efficiency, stability, satisfaction.                        |
|                                                                                              |
|                                             v                                                |
|                                                                                              |
| 07. BEHAVIOURALISM -> formal institutions dissolved into 'systems' and 'processes'.          |
|                                                                                              |
|                                             v                                                |
|                                                                                              |
| 08. LIMIT -> evidence identifies consequences but cannot alone justify ends.                 |
+----------------------------------------------------------------------------------------------+

ASCII MASTER FLOW — PANEL 6/17: Political Philosophy: Function
+----------------------------------------------------------------------------------------------+
| POLITICAL PHILOSOPHY: FUNCTION                                                               |
+----------------------------------------------------------------------------------------------+
| 01. RAPHAEL, Problems of Political Philosophy (1976) -> explanation versus justification.    |
|                                                                                              |
|                                             v                                                |
|                                                                                              |
| 02. NOT 'ideal versus real' -> even Plato's ideal society is drawn to criticise the actual   |
|     one.                                                                                     |
|                                                                                              |
|                                             v                                                |
|                                                                                              |
| 03. JUSTIFICATION -> rational grounds for accepting or rejecting taken-for-granted beliefs.  |
|                                                                                              |
|                                             v                                                |
|                                                                                              |
| 04. ANALYSIS -> elements of a concept, e.g. sovereignty = supreme legal authority.           |
|                                                                                              |
|                                             v                                                |
|                                                                                              |
| 05. SYNTHESIS -> relations between concepts, e.g. a right involves an obligation.            |
|                                                                                              |
|                                             v                                                |
|                                                                                              |
| 06. IMPROVEMENT -> restrict sovereignty to legal authority, not to coercive power.           |
|                                                                                              |
|                                             v                                                |
|                                                                                              |
| 07. SOCRATIC FUNCTION -> philosophy arose from critical reflection; it speaks truth to power.|
