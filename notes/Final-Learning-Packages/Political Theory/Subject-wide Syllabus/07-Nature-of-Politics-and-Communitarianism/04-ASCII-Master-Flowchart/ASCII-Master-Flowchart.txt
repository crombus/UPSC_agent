ASCII MASTER FLOW — PANEL 3/16: Core Definitions
+----------------------------------------------------------------------------------------------+
| CORE DEFINITIONS                                                                             |
+----------------------------------------------------------------------------------------------+
| 01. POLITICS: A public process involving conflict, its resolution, and authoritative value-  |
| allocation in society. (PDF pp.95-99)                                                        |
| 02. POLITICAL SITUATION: A situation of public conflict among major groups that calls for a  |
| universal/public solution, not a private settlement. (PDF p.96)                              |
| 03. AUTHORITATIVE ALLOCATION OF VALUES: Easton's idea that politics distributes valued       |
| things through decisions treated as binding because they carry authority, not mere brute     |
| force. (PDF pp.96-97)                                                                        |
| 04. LIBERAL VIEW OF POLITICS: Politics as group-and-state activity aimed at reconciling      |
| competing interests and promoting a common good compatible with them. (PDF pp.101-102)       |
| 05. MARXIST VIEW OF POLITICS: Politics as an effect of class division, used by the dominant  |
| class to hold down the dependent class until class society is abolished. (PDF pp.102-104)    |
| 06. COMMUNITARIANISM: A view stressing that persons are socially constituted, owe duties to  |
| the community, and should seek their good through the good of the community. (PDF pp.101,    |
| 104-105)                                                                                     |
+----------------------------------------------------------------------------------------------+

ASCII MASTER FLOW — PANEL 4/16: Chapter Spine (1/2)
+----------------------------------------------------------------------------------------------+
| CHAPTER SPINE (1/2)                                                                          |
+----------------------------------------------------------------------------------------------+
| 01. Gauba moves from the layman's narrow image of politics to a broader account of politics  |
| as a social process. (PDF pp.94-95)                                                          |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 02. He argues that politics requires public conflict, not merely private disagreement, and   |
| that war is a failure of political solution rather than politics itself. (PDF p.96)          |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 03. Easton's formulation adds the key element of authority: political decisions allocate     |
| scarce values in a manner treated as binding. (PDF pp.96-99)                                 |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 04. Liberal theory then presents politics as a process of conciliating interests and         |
| securing order, justice and welfare. (PDF pp.101-102)                                        |
+----------------------------------------------------------------------------------------------+

ASCII MASTER FLOW — PANEL 5/16: Chapter Spine (2/2)
+----------------------------------------------------------------------------------------------+
| CHAPTER SPINE (2/2)                                                                          |
+----------------------------------------------------------------------------------------------+
| 05. Marxist theory shifts the centre of analysis to the mode of production and class         |
| struggle, treating politics as class domination and suppression. (PDF pp.102-104)            |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 06. Communitarian theory shifts the centre again, arguing that the deeper point of politics  |
| is not bargaining among isolated selves but discovering and pursuing a shared common good.   |
| (PDF pp.104-105)                                                                             |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 07. Gauba's conclusion is comparative and conditional: each view fits different social       |
| conditions rather than functioning as a universal key. (PDF p.106)                           |

ASCII MASTER FLOW — PANEL 6/16: Thinkers and Named Positions (1)
+----------------------------------------------------------------------------------------------+
| THINKERS AND NAMED POSITIONS (1)                                                             |
+----------------------------------------------------------------------------------------------+
| 01. ARISTOTLE: Politics begins with the polis, and communitarian strands later revive his    |
| idea that political association is tied to good life. (PDF pp.95, 104)                       |
| 02. DAVID EASTON: Politics is the authoritative allocation of values for society. (PDF       |
| pp.96-97)                                                                                    |
| 03. LIBERAL-PLURALIST STREAM: Locke-linked liberalism treats society as composed of multiple |
| organized groups seeking accommodation through the state. (PDF pp.100-102)                   |

ASCII MASTER FLOW — PANEL 7/16: Thinkers and Named Positions (2)
+----------------------------------------------------------------------------------------------+
| THINKERS AND NAMED POSITIONS (2)                                                             |
+----------------------------------------------------------------------------------------------+
| 01. MARX AND ENGELS: Politics and the state arise from class division and serve dominant-    |
| class interests until class conflict ends in a classless order. (PDF pp.102-104)             |
| 02. MACINTYRE, TAYLOR, SANDEL: Contemporary communitarians criticize the atomistic           |

ASCII MASTER FLOW — PANEL 8/16: Illustrations Attached to Claims
+----------------------------------------------------------------------------------------------+
| ILLUSTRATIONS ATTACHED TO CLAIMS                                                             |
+----------------------------------------------------------------------------------------------+
| 01. Reserved seats, taxation and similar distributive arrangements show how authoritative    |
| allocation binds both beneficiaries and contributors. (PDF p.99)                             |
| 02. The queue system or traffic-signal type example captures the liberal hope that           |
| institutional rules can reconcile competing claims. (PDF p.102)                              |
| 03. Marxist analysis would treat labour-capital compromise in class society as unstable      |
| because the underlying relation of dominance remains intact. (PDF pp.103-106)                |
| 04. Communitarian analysis would read family breakdown, loneliness, crime or drug abuse in   |
| modern liberal society as signs of weakened social bonds. (PDF pp.101, 105)                  |
| 05. In answers, use such examples as conceptual illustrations, not as present-day data       |
| claims                                                                                       |

ASCII MASTER FLOW — PANEL 9/16: Comparison Matrix
+----------------------------------------------------------------------------------------------+
| COMPARISON MATRIX                                                                            |
+----------------------------------------------------------------------------------------------+
| 01. IMAGE OF SOCIETY | Liberal view = A plurality of individuals and groups with             |
| reconcilable interests. (PDF pp.101-102) | Marxist view = Antagonistic classes structured by |
| ownership and exploitation. (PDF pp.102-104) | Communitarian view = Interconnected persons   |
| whose identity is formed within community. (PDF pp.101, 104-105)                             |
| 02. NATURE OF POLITICS | Liberal view = Reconciliation and authoritative settlement of       |
| disputes. (PDF pp.101-102) | Marxist view = Suppression/management of class conflict under   |
| class rule. (PDF pp.103-104) | Communitarian view = Identification and pursuit of the common |
| good. (PDF pp.104-105)                                                                       |
| 03. COMMON GOOD | Liberal view = A balanced outcome accommodating contending interests. (PDF |
| p.102) | Marxist view = Not genuinely available under class society dominated by class       |
| interests. (PDF p.107) | Communitarian view = A shared good comprehending the interest of    |
| each member. (PDF p.107)                                                                     |
| 04. ORGANIZING IDEAL | Liberal view = Liberty. (PDF p.107) | Marxist view = Equality. (PDF   |
| p.107) | Communitarian view = Fraternity. (PDF p.107)                                        |
| 05. END-POINT | Liberal view = Order, justice and welfare within society. (PDF p.102) |      |
| Marxist view = Classless society where politics withers away. (PDF pp.104, 107) |            |
| Communitarian view = Social solidarity through cooperation and belonging. (PDF pp.104-107)   |
+----------------------------------------------------------------------------------------------+

ASCII MASTER FLOW — PANEL 10/16: Examiner Trap Firewall
+----------------------------------------------------------------------------------------------+
| EXAMINER TRAP FIREWALL                                                                       |
+----------------------------------------------------------------------------------------------+
| 01. TRAP: Politics means only party competition or elections => REPAIR: Gauba widens         |
| politics to public conflict-resolution and authoritative value-allocation. (PDF pp.95-99)    |
| 02. TRAP: Any quarrel becomes political => REPAIR: Only public conflicts requiring a         |
| universal/public solution count as properly political. (PDF p.96)                            |
| 03. TRAP: Communitarianism means total unanimity or denial of all real tensions => REPAIR:   |
| Gauba presents it as a stress on common interest and cooperation, but he also says it        |
| becomes futile where wide disparities of power and opinion persist. (PDF pp.106-107)         |
| 04. TRAP: Marxism treats every visible compromise as genuine reconciliation => REPAIR:       |
| Marxist analysis treats such compromise as often imposed within relations of domination.     |
| (PDF pp.103-106)                                                                             |
| 05. TRAP: Liberalism ignores common good altogether => REPAIR: In Gauba, liberalism does     |
| speak of a common good, but as something worked out through accommodation of interests. (PDF |
| p.102)                                                                                       |
