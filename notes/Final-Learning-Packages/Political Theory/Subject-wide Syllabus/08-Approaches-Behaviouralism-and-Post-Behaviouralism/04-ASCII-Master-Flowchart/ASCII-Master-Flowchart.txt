ASCII MASTER FLOW — PANEL 4/17: Core Definitions
+----------------------------------------------------------------------------------------------+
| CORE DEFINITIONS                                                                             |
+----------------------------------------------------------------------------------------------+
| 01. METHOD: The procedure of inquiry by which reliable knowledge and conclusions are         |
| obtained. (PDF p.108)                                                                        |
| 02. APPROACH: A wider frame that includes method plus criteria for selecting problems,       |
| questions and relevant data. (PDF pp.108-109)                                                |
| 03. EMPIRICAL STATEMENT: A claim about an observable situation that can be tested or         |
| verified by repeated observation. (PDF pp.110-111)                                           |
| 04. NORMATIVE STATEMENT: A claim expressing a preference, duty or moral principle about what |
| ought to be valued or prescribed. (PDF pp.110-112)                                           |
| 05. BEHAVIOURALISM: A scientific orientation focusing on actual political behaviour,         |
| especially of actors such as voters, leaders and groups. (PDF pp.118-121)                    |
| 06. POST-BEHAVIOURALISM: A corrective within behavioural political science stressing         |
| relevance, action and concern for values. (PDF pp.121-122)                                   |
+----------------------------------------------------------------------------------------------+

+----------------------------------------------------------------------------------------------+
| THINKERS AND NAMED POSITIONS (1)                                                             |
+----------------------------------------------------------------------------------------------+
| 01. VERNON VAN DYKE: Clarifies the distinction between approach and method and explains      |
| philosophical analysis as conceptual clarification plus evaluation. (PDF pp.108-109, 113)    |
| 02. LEO STRAUSS: Defends political philosophy as inseparable from facts and values and       |
| criticizes behavioural value-neutrality. (PDF pp.112, 114, 121)                              |
| 03. GRAHAM WALLAS AND ARTHUR BENTLEY: Early forerunners of behaviouralism who shift          |
| attention toward actual behaviour and informal processes. (PDF p.118)                        |

ASCII MASTER FLOW — PANEL 9/17: Illustrations Attached to Claims
+----------------------------------------------------------------------------------------------+
| ILLUSTRATIONS ATTACHED TO CLAIMS                                                             |
+----------------------------------------------------------------------------------------------+
| 01. "Everybody ought to vote if democracy is to work" is empirical in content because its    |
| claim can be checked against political functioning. (PDF pp.110-111)                         |
| 02. "Justice is treating equals equally..." is normative in content even though it appears   |
| in the form of an "is" statement. (PDF p.110)                                                |
| 03. Legal analysis of Indian politics would ask what constitutional provisions authorize     |
| institutions and actions. (PDF pp.115-116)                                                   |
| 04. Institutional analysis would map legislature, executive, judiciary, parties and their    |
| formal relations. (PDF pp.116-117)                                                           |
| 05. Behavioural analysis of the same political scene would ask how voters, leaders, parties  |
| and interest groups actually behave                                                          |

ASCII MASTER FLOW — PANEL 10/17: Comparison Matrix
+----------------------------------------------------------------------------------------------+
| COMPARISON MATRIX                                                                            |
+----------------------------------------------------------------------------------------------+
| 01. TRADITIONAL | Core claim = Politics is illuminated through philosophy, history, law and  |
| institutions. (PDF pp.109-117) | Main focus = Concepts, thought, legal framework,            |
| institutions. (PDF pp.113-117) | Limitation flagged by Gauba = Often descriptive or          |
| normative without enough behavioural/process analysis. (PDF pp.117-118)                      |
| 02. BEHAVIOURAL | Core claim = Political science should study actual political behaviour     |
| scientifically through regularities, verification, techniques and quantification. (PDF       |
| pp.118-121) | Main focus = Individuals, attitudes, participation, communication, decision-   |
| processes. (PDF pp.119-121) | Limitation flagged by Gauba = Risk of excessive micro-focus,   |
| method-fetish and value-neutral distance from urgent public issues. (PDF pp.121-122)         |
| 03. POST-BEHAVIOURAL | Core claim = Science should remain rigorous but also relevant,        |
| action-oriented and attentive to value-construction. (PDF pp.121-122) | Main focus = Social  |
| problems, public responsibility, applied knowledge. (PDF pp.121-122) | Limitation flagged by |
| Gauba = It must not become a licence for untested moralism; relevance still needs            |
| disciplined inquiry                                                                          |
+----------------------------------------------------------------------------------------------+

ASCII MASTER FLOW — PANEL 11/17: Examiner Trap Firewall
+----------------------------------------------------------------------------------------------+
| EXAMINER TRAP FIREWALL                                                                       |
+----------------------------------------------------------------------------------------------+
| 01. TRAP: Method and approach are synonyms => REPAIR: Approach is wider because it includes  |
| selection-criteria for problems and data. (PDF pp.108-109)                                   |
| 02. TRAP: Traditional always means normative, and contemporary always means empirical =>     |
| REPAIR: Gauba explicitly rejects that mechanical equation. (PDF pp.109-110)                  |
| 03. TRAP: Any sentence with "ought" is normative => REPAIR: Its content may still be         |
| empirical if it states an instrumentally testable condition. (PDF pp.110-111)                |
| 04. TRAP: Value-free means politically consequence-free => REPAIR: Behavioural inquiry can   |
| shape what gets studied and ignored, which is why post-behaviouralism raised the issue of    |
| relevance. (PDF pp.121-122)                                                                  |
| 05. TRAP: Post-behaviouralism means abandoning science for activism => REPAIR: Easton        |
| presents it as retaining behavioural gains while reconnecting them to problem-solving. (PDF  |
| pp.121-122)                                                                                  |
