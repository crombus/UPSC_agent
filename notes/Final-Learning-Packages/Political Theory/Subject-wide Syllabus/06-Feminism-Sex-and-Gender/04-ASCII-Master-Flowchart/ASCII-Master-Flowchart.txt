ASCII MASTER FLOW — PANEL 4/13: Chapter Spine
+----------------------------------------------------------------------------------------------+
| CHAPTER SPINE                                                                                |
+----------------------------------------------------------------------------------------------+
| 01. Gauba starts by defining feminism as resistance to unjust female subordination produced  |
| by patriarchy. (PDF p.84)                                                                    |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 02. He then distinguishes sex from gender so that biological difference is separated from    |
| socially assigned inferiority. (PDF pp.84-86)                                                |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 03. Gender roles such as aggressiveness/dominance for men and submissiveness/expressiveness  |
| for women are treated as cultural instruments of social control. (PDF p.85)                  |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 04. Gauba argues that biological differences do not justify inferior status for women; the   |
| main causes lie in social arrangements and cultural conditioning. (PDF pp.86-87)             |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 05. He ends by classifying feminism into liberal, radical and socialist streams. (PDF        |
| pp.88-90)                                                                                    |
+----------------------------------------------------------------------------------------------+

ASCII MASTER FLOW — PANEL 5/13: Illustrations Attached to Claims
+----------------------------------------------------------------------------------------------+
| ILLUSTRATIONS ATTACHED TO CLAIMS                                                             |
+----------------------------------------------------------------------------------------------+
| 01. Gauba's examples of girls being socialized toward obedience and boys toward              |
| assertiveness show how gender roles are culturally produced. (PDF p.87)                      |
| 02. The early rights agenda focused on education, property, divorce and suffrage because     |
| these exclusions had no necessary connection with female biology. (PDF pp.87-88)             |
| 03. A safe classroom example is to contrast biological maternity with culturally assigned    |
| ideas that women must therefore remain outside public life                                   |
| 04. Gauba's cited 1980 UN numerical claim and the follow-up line saying the condition        |
| remained unchanged should never be repeated as current fact; at most they are dated book-    |
| period illustrations. (PDF p.86)                                                             |
+----------------------------------------------------------------------------------------------+

ASCII MASTER FLOW — PANEL 6/13: Comparison Matrix
+----------------------------------------------------------------------------------------------+
| COMPARISON MATRIX                                                                            |
+----------------------------------------------------------------------------------------------+
| 01. LIBERAL FEMINISM | Core claim = Women deserve equal opportunity and equal rights in all  |
| walks of life. (PDF p.88) | Main obstacle identified = Formal legal, educational and         |
| professional barriers. (PDF pp.88-89) | Remedy emphasized = Equal pay, representation,       |
| reform of discriminatory laws. (PDF p.88)                                                    |
| 02. RADICAL FEMINISM | Core claim = Women's oppression is primary and cannot be reduced to   |
| some deeper system alone. (PDF p.89) | Main obstacle identified = Patriarchal sexual power   |
| and reproductive dependence. (PDF p.89) | Remedy emphasized = Transform sex-power relations  |
| and dismantle domination. (PDF p.89)                                                         |
| 03. SOCIALIST FEMINISM | Core claim = Women's oppression is linked both to patriarchy and    |
| capitalism. (PDF pp.89-90) | Main obstacle identified = Wage labour, domestic labour and     |
| class exploitation together. (PDF pp.89-90) | Remedy emphasized = Link women's liberation    |
| with broader anti-capitalist and anti-oppression struggles. (PDF p.90)                       |
+----------------------------------------------------------------------------------------------+

ASCII MASTER FLOW — PANEL 7/13: Examiner Trap Firewall
+----------------------------------------------------------------------------------------------+
| EXAMINER TRAP FIREWALL                                                                       |
+----------------------------------------------------------------------------------------------+
| 01. TRAP: Sex and gender mean the same thing => REPAIR: Gauba makes the distinction          |
| foundational: sex is biological, gender is cultural. (PDF pp.84-86)                          |
| 02. TRAP: All feminism says women are biologically determined => REPAIR: Firestone's         |
| reproductive-biology argument is one radical-feminist position, not feminism's consensus.    |
| (PDF p.89)                                                                                   |
| 03. TRAP: If women receive equal legal rights, feminism has no further issue => REPAIR:      |
| Gauba shows later feminism asking about representation, social status and unequal            |
| participation in public power. (PDF pp.91-93)                                                |
| 04. TRAP: Old statistics in the book can be quoted as present reality => REPAIR: The 1980 UN |
| figure and book-era representation data are historical and must not be presented as current  |
| fact. (PDF pp.86, 91-93)                                                                     |

ASCII MASTER FLOW — PANEL 10/13: Answer-Grabbing Line Bank
+----------------------------------------------------------------------------------------------+
| ANSWER-GRABBING LINE BANK                                                                    |
+----------------------------------------------------------------------------------------------+
| 01. Gauba treats feminism as a protest against the inferior status assigned to women by      |
| patriarchy, not as a denial that biological differences exist. (PDF pp.84-86)                |
| 02. Feminism: concern with the status and role of women in relation to men, combined with    |
| protest against injustice suffered because of sex. (PDF p.84)                                |
| 03. Sex vs gender: sex is natural/biological; gender is cultural/social. (PDF pp.84-86)      |
| 04. Gauba's examples of girls being socialized toward obedience and boys toward              |
| assertiveness show how gender roles are culturally produced. (PDF p.87)                      |
| 05. Read the deeper companion at Political-Theory/advanced/06_Feminism-Sex-and-Gender.md     |
| 06. Ann Oakley (Sex, Gender and Society, 1972) is usually credited with popularising the     |
| working sex/gender terminology in sociology - sex as biological, gender as the culturally    |
| learned                                                                                      |
| 07. Carole Pateman (The Sexual Contract, 1988): Claim - classical social-contract theory     |
| (Hobbes, Locke, Rousseau) silently assumes a prior "sexual contract" securing men's access   |
| to women's                                                                                   |
| 08. Judith Butler (Gender Trouble, 1990): gender is not a cultural coating on a stable       |
| biological sex but performative - produced through repeated, stylised acts (speech, gesture, |
| dress                                                                                        |
| 09. 1. Objection: if gender is entirely performative/socially constructed (Butler), feminism |
| loses a stable category of "woman" around which to organise and to claim rights              |
| 10. "Discuss/Examine feminism as a critique of patriarchy" -> needs both diagnosis (what     |
| patriarchy is, how gender is produced) and the feminist reply; do not describe patriarchy    |
| without the                                                                                  |
