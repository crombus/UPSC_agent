| CHAPTER SPINE (1/2)                                                                          |
+----------------------------------------------------------------------------------------------+
| 01. Gauba begins with rival grounds of political obligation: force, divine right,            |
| conservative prudence, consent, idealism, Marxism, anarchism and Gandhian civil disobedience |
| (PDF pp.280-287)                                                                             |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 02. He rejects purely force-based and divine-right views because they do not secure morally  |
| reasoned obedience and leave no room for judging unjust commands (PDF pp.281-282)            |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 03. Among consent theories, Hobbes and Rousseau tend toward strong obligation, whereas Locke |
| gives the clearest limited version by making government a trust answerable to rights and     |
| consent (PDF pp.283-284)                                                                     |
|                                                                                              |
|                                              v                                               |
|                                                                                              |
| 04. Green's idealist revision places obligation toward the organized power of society and    |
| the common good rather than toward any government demanding blind obedience (PDF pp.284-286) |

| case where legal duty and moral conscience can clash (PDF p.287)                             |

| civil disobedience against colonial law (PDF p.287)                                          |
| 05. Gauba's law chapter uses reform of child marriage, widow-burning, untouchability and     |
| bonded labour as historical examples of law leading social-moral reform (PDF p.296)          |
| 06. Traffic regulation appears as Gauba's simple illustration of morally neutral but order-  |
| preserving law and of rule-of-law clarity (PDF pp.296, 300)                                  |

| 01. UNLIMITED / NEAR-UNLIMITED | Core logic = Obey because force, divine command, absolutist |

| rule-bound but critical citizenship                                                          |

| 04. MODE | Core logic = What it targets | Main examples = Method | Scope = Relation to law   |
| 05. RESISTANCE | Core logic = Specific unjust command, policy or authority abuse (PDF        |

| within or move against law                                                                   |
| 06. REVOLUTION | Core logic = The wider political or social order itself (PDF p.288) | Main  |

ASCII MASTER FLOW — PANEL 12/20: Examiner Trap Firewall (1/3)
+----------------------------------------------------------------------------------------------+
| EXAMINER TRAP FIREWALL (1/3)                                                                 |
+----------------------------------------------------------------------------------------------+
| 01. TRAP: "Civil disobedience means any illegal act done for a cause." => REPAIR: Gauba's    |
| version is public, non-violent, principled, last-resort and penalty-accepting (PDF p.287)    |
| 02. TRAP: "A valid law is automatically a just law." => REPAIR: Legal validity and moral     |
| legitimacy can diverge; the whole discussion of natural law, equity and conscience depends   |
| on this (PDF pp.290-296)                                                                     |
| 03. TRAP: "Rule of law means identical rights and duties in all situations." => REPAIR:      |
| Gauba's traffic example shows generality and clarity do not exclude differentiated           |
| regulation by relevant situation (PDF p.300)                                                 |
| 04. TRAP: "Hobbes, Locke and Rousseau all justify the same kind of consent." => REPAIR:      |
| Hobbes prioritizes security, Locke trust and limited government, Rousseau general will and   |
| civic freedom (PDF pp.283-284)                                                               |
| 05. TRAP: "Law always reduces liberty." => REPAIR: Under a democratic welfare state, law     |
| often secures equal liberty and social welfare by rational restraint (PDF pp.296-298)        |
| 06. TRAP: "This topic is basically Indian Polity." => REPAIR: This file gives conceptual     |
| tests; Indian statutes, Articles and case-law belong elsewhere                               |
| 07. TRAP: "Retribution means unlimited revenge." => REPAIR: A defensible retributive theory  |
| is proportional and public, not private vengeance                                            |
| 08. TRAP: "A severe sentence is automatically an effective deterrent." => REPAIR: Deterrence |
| is an empirical proposition; severity alone is neither necessary nor sufficient proof of     |
| prevention                                                                                   |
+----------------------------------------------------------------------------------------------+

ASCII MASTER FLOW — PANEL 13/20: Examiner Trap Firewall (2/3)
+----------------------------------------------------------------------------------------------+
| EXAMINER TRAP FIREWALL (2/3)                                                                 |
+----------------------------------------------------------------------------------------------+
| 09. TRAP: "Reformative theory denies responsibility." => REPAIR: It changes the purpose and  |
| method of punishment; it does not by itself erase guilt, accountability or protection of     |
| society                                                                                      |
| 10. TRAP: "Capital punishment follows automatically from a heinous crime." => REPAIR: The    |
| source presents rival arguments; irreversibility, error, human dignity, proportionality and  |
| deterrence must be separately examined                                                       |
| 11. TRAP: "Austin's command theory and Hart's rule theory are the same thing with different  |
| names." => REPAIR: Hart explicitly rejects Austin's coercive-command model as too narrow     |
| (built on the criminal-law model) and replaces it with a structure of rules covering duties, |
| powers and procedure (PDF pp.291-292)                                                        |
| 12. TRAP: "Kelsen's Grundnorm is a moral standard smuggled into positivism." => REPAIR:      |
| Kelsen keeps the basic norm purely as a validity-conferring apex of the legal hierarchy,     |
| deliberately separate from questions of morality or moral obligation - this is exactly why   |
| he remains a positivist despite using a normative concept (PDF p.291)                        |
| 13. TRAP: "Kelsen's General Theory of Law and State is a 1961 work." => REPAIR: 1945 is the  |
| year of its first English publication (Harvard University Press, tr. Anders Wedberg); 1961   |
| belongs to Hart's The Concept of Law. The two dates sit adjacent in the Austin -> Kelsen ->  |
| Hart -> Dworkin sequence and are easily swapped - if unsure in the exam hall, name the works |
| and the sequence without dates rather than guessing a year (?12, bibliographic-dates note)   |
+----------------------------------------------------------------------------------------------+

+----------------------------------------------------------------------------------------------+
| 14. TRAP: "Dworkin says judges can decide hard cases however they like." => REPAIR: Dworkin  |
| insists principles are part of law and constrain judicial reasoning even though they are     |
| less precise than rules and cannot be hierarchically ranked; discretion is bounded, not      |
| unlimited (PDF p.292)                                                                        |
| 15. TRAP: "Political obligation, resistance, civil disobedience and revolution are           |
| interchangeable terms for defying the state." => REPAIR: Keep them analytically separate:    |
| obligation asks whether/why one should obey at all; resistance targets a specific unjust     |
| act; civil disobedience is a disciplined, public, penalty-accepting mode of resistance;      |
| revolution targets the wider order itself and carries the highest risk (PDF pp.287-288,      |
| Table B)                                                                                     |
