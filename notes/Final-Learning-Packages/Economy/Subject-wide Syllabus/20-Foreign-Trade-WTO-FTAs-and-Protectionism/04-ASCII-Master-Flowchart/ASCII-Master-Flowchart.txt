Current-source cutoff: 9 September 2026

PANEL 01: TRADE LOGIC
+------------------------------------------------------------------------------+
| Comparative advantage = lower relative opportunity cost                     |
| Specialisation -> exchange -> aggregate gain                                 |
| Distribution, mobility and adjustment decide who gains                       |
+------------------------------------------------------------------------------+

PANEL 02: TERMS AND WELFARE
+------------------------------------------------------------------------------+
| Terms of trade = export-price index / import-price index x 100                |
| Trade creation: high-cost domestic -> lower-cost partner                      |
| Trade diversion: lower-cost outsider -> higher-cost preferred partner         |
+------------------------------------------------------------------------------+

PANEL 03: BORDER INSTRUMENTS
+------------------------------------------------------------------------------+
| Ad valorem = percentage of value | Specific = fixed amount per unit           |
| Quota fixes quantity and creates rent | TRQ uses two tariff tiers              |
| Subsidy legality depends on design, specificity and effects                   |
+------------------------------------------------------------------------------+

PANEL 04: STANDARDS AND REMEDIES
+------------------------------------------------------------------------------+
| SPS = defined health/pest risks | TBT = other technical requirements          |
| Anti-dumping = dumping + injury + causation                                   |
| CVD = subsidy + injury | Safeguard = fair-trade surge + serious injury         |
+------------------------------------------------------------------------------+

PANEL 05: PROTECTION MEASURES
+------------------------------------------------------------------------------+
| Nominal protection = final-product price wedge                                |
| Effective protection = change in domestic value added                         |
| Tariff escalation penalises later processing stages                           |
+------------------------------------------------------------------------------+

PANEL 06: WTO ARCHITECTURE
+------------------------------------------------------------------------------+
| GATT 1947 -> Marrakesh 1994 -> WTO 1995                                       |
| Ministerial Conference -> General Council/DSB/TPRB -> councils                 |
| Member-driven; consensus is normal                                             |
+------------------------------------------------------------------------------+

PANEL 07: CORE WTO PRINCIPLES
+------------------------------------------------------------------------------+
| MFN = equal treatment among foreign partners                                  |
| National treatment = imported versus domestic after entry                     |
| Bindings + transparency + negotiated reciprocity + agreement-specific S&DT    |
+------------------------------------------------------------------------------+

PANEL 08: WTO AGREEMENTS
+------------------------------------------------------------------------------+
| GATT = goods | GATS = four service modes | TRIPS = IP standards                |
| TRIMS = goods-related investment measures                                     |
| AoA = market access + domestic support + export competition                    |
+------------------------------------------------------------------------------+
