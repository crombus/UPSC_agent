ASCII MASTER FLOW - PANEL 1/12: HOW TO READ A PAINTING

READING CHAIN
support / surface
  -> technique / pigment
  -> patron / workshop
  -> audience / function
  -> theme / iconography
  -> stylistic comparison
  -> evidence limit

RULE
Style is not the starting point.
A wall, folio, album page and ritual cloth belong to different visual worlds.

ASCII MASTER FLOW - PANEL 2/12: VOCABULARY AND TECHNIQUE

SHADANGA
Roopbheda / Pramana / Bhava / Lavanya Yojana / Sadrishya / Varnikabhanga

FORMAT TERMS
mural = fixed architectural surface
miniature = small portable format
album = curated folio for private viewing

TECHNIQUE CAUTION
Ajanta is safer as fresco secco / tempera on prepared dry plaster,
not as an unqualified true fresco.

ASCII MASTER FLOW - PANEL 3/12: PREHISTORIC BASELINE

ROCK ART
Bhimbetka
Lakhudiyar
  -> hunting / dancing / animals / group scenes
  -> mineral colours on rock surface

LIMIT
Useful for environment and community memory.
Not enough for named dynasties or rigid doctrinal claims.

ASCII MASTER FLOW - PANEL 4/12: AJANTA DOSSIER

AJANTA
early phase + Vakataka flowering
  -> Buddhist caves
  -> Jataka and Buddha narratives
  -> Bodhisattvas such as Padmapani
  -> courtly detail and emotional modelling

TRAP
Ajanta is not a single-phase event.
Technique caution must remain explicit.

ASCII MASTER FLOW - PANEL 5/12: BAGH AND HALLISALASYA

BAGH
Dhar district, on the Baghni river
  -> Gupta-era mural anchor
  -> stronger outlines, more earthly human register
  -> Cave 4 = Rang Mahal

HALLISALASYA RULE
Keep only the source-safe line:
royal courts + temples + ceremonial gatherings;
Gupta-period devotional or courtly dance in art and sculpture.
Do not assign a modern named classical form.

ASCII MASTER FLOW - PANEL 6/12: SOUTH INDIAN MURAL LINE

Sittanavasal
  -> Pallava site bank: Kanchipuram / Panamalai / Mamandur
  -> Armamalai bridge
  -> Brihadisvara mural memory
  -> Lepakshi continuation

FINAL RULE
Survival gaps, repainting and damage distort what remains.
Few murals today do not prove weak original production.

ASCII MASTER FLOW - PANEL 7/12: EARLY PORTABLE PAINTING

Pala School
  -> Buddhist illustrated manuscripts
  -> palm leaf / compact compositions / subdued grounds

Western Indian / Apabhramsa
  -> Jain-dominant manuscripts
  -> red / yellow / ochre
  -> angular face / fish-shaped eye / strong contour
  -> Kalpasutra / Kalakacharya Katha

ASCII MASTER FLOW - PANEL 8/12: SULTANATE TO MUGHAL FORMATION

TRANSITION
Persianate contact + indigenous manuscript habits
  -> Nimatnama at Mandu

MUGHAL FORMATION
Humayun -> Mir Sayyid Ali + Abdus Samad
Akbar -> Tasvir Khana -> Tutinama / Hamzanama / Razmnama / Akbarnama

RULE
Synthesis precedes Mughal maturity.

ASCII MASTER FLOW - PANEL 10/12: REGIONAL MINIATURE FAMILIES

DECCANI

RAJASTHANI
Mewar / Bundi / Kota / Jaipur / Kishangarh
Bani Thani -> Kishangarh

PAHARI
Basohli -> Guler -> Kangra

ASCII MASTER FLOW - PANEL 11/12: DEVOTIONAL, COLONIAL AND MODERN TURNS

COLONIAL / MODERN

Kalighat -> urban market sheet

Santiniketan -> experimentation

ASCII MASTER FLOW - PANEL 12/12: FOLK / TRIBAL CONTINUITY AND FINAL FORMULA

FOLK / TRIBAL BANK
Madhubani -> Mithila / ritual / bold colour
Pattachitra -> Odisha / treated cloth / Jagannath world
Kalamkari -> treated cloth / pen-block process
Warli -> white on ochre / geometric wall language
Gond -> patterned sacred-natural world
Phad / Cheriyal -> long scroll + performance

FINAL FORMULA
Indian painting shows continuity through adaptation of support,
technique, patronage and audience - from rock shelter to mural,
manuscript, album, market sheet and living ritual wall.
