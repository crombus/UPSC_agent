INDIAN MUSIC - ASCII MASTER FLOWCHART

ASCII PANEL 01/12 - CENTRAL THESIS
----------------------------------
+--------------------------------------------------------------+
| INDIAN MUSIC = CODIFIED SOUND + PERFORMANCE GRAMMAR +        |
| PATRONAGE HISTORY + MODERN CONTINUITY                        |
|                                                              |
| READ IN THIS ORDER:                                          |
| SOUND -> CLASSIFICATION -> FORM -> LINEAGE -> INSTITUTION    |
+--------------------------------------------------------------+

ASCII PANEL 02/12 - SOUND TO NOTE
---------------------------------
+--------------------------------------------------------------+
| Nada (musical sound)                                         |
|    -> Shruti = smallest audible pitch unit / microtone       |
|    -> Swara = usable note                                    |
|    -> Saptak / Sargam = Sa Re Ga Ma Pa Dha Ni                |
| Fixed tonal anchors = Sa, Pa                                 |
| Variable field = Re, Ga, Ma, Dha, Ni                         |
+--------------------------------------------------------------+

ASCII PANEL 03/12 - MELODY AND RHYTHM
-------------------------------------
+--------------------------------------------------------------+
| RAGA                                                         |
| - arohana / avarohana                                        |
| - vadi / samvadi                                             |
| - pakad / chalan                                             |
| - rasa / time link                                           |
|                                                              |
| THAAT != RAGA                                                |
| - thaat = unsung parent scale                                |
| - raga = performed melodic entity                            |
|                                                              |
| TALA != LAYA                                                 |
| - tala = rhythmic cycle                                      |
| - laya = tempo                                               |
+--------------------------------------------------------------+

ASCII PANEL 04/12 - TEXTUAL TIMELINE
------------------------------------
+--------------------------------------------------------------+
| Samaveda / chant world                                       |
| -> Dattilam (22 shrutis; gandharva transition)               |
| -> Natyashastra (music with drama, shruti, swara, jati)      |
| -> Brihaddeshi (raga-definition pivot)                       |
| -> Sangita Ratnakara (pre-bifurcation synthesis)             |
| -> Chaturdandiprakashika (melakarta logic)                   |
| -> Bhatkhande / Paluskar (modern pedagogy)                   |
+--------------------------------------------------------------+

ASCII PANEL 05/12 - HINDUSTANI / CARNATIC COMPARISON
----------------------------------------------------
+--------------------------------------------------------------+
| HINDUSTANI                                                   |
| - 10 thaats                                                  |
| - alap / bandish / taan / layakari                           |
| - court + lineage ecology                                    |
|                                                              |
| CARNATIC                                                     |
| - 72 melakarta + janya                                       |
| - kriti / varnam / alapana / neraval / RTP                   |
| - temple + composer + sabha ecology                          |
|                                                              |
| COMMON TRAP: Carnatic is NOT improvisation-free.             |
+--------------------------------------------------------------+

ASCII PANEL 10/12 - INSTRUMENT FAMILIES
---------------------------------------
+--------------------------------------------------------------+
| Tata       -> string vibrates -> sitar / veena / santoor     |
| Sushira    -> air column     -> bansuri / shehnai / pungi    |
| Avanaddha  -> membrane       -> tabla / mridangam / dhol     |
| Ghana      -> body vibrates  -> ghatam / manjira / jaltarang |
|                                                              |
| MEMBRANE TEST: struck != drum unless stretched skin sounds.  |
| GENRE TEST: Sufiana kalam is a genre, not an instrument.     |
+--------------------------------------------------------------+
