ASCII PANEL 03/12 - CORE VOCABULARY
-----------------------------------
+--------------------------------------------------------------+
| Nritta = pure rhythmic movement                              |
| Nritya = expression through gesture and emotion              |
| Natya  = dramatic enactment                                  |
| Lasya / Tandava = graceful / vigorous emphases               |
| Bhava -> performed emotion; Rasa -> audience relish          |
+--------------------------------------------------------------+

ASCII PANEL 04/12 - BODY GRAMMAR AND TRANSMISSION
-------------------------------------------------
+--------------------------------------------------------------+
| Hasta / Mudra = codified hand gesture                        |
| Karana = coordinated whole-body movement unit                |
| 108 belongs to karanas, NOT to a universal mudra count       |
|                                                              |
| Guru -> Shishya -> Sampradaya -> style memory                |
+--------------------------------------------------------------+
