ASCII MASTER FLOW — PANEL 2/40: WHAT A VALUE IS - THE FIVE-LEVEL LADDER
+-- [01] WHAT A VALUE IS - THE FIVE-LEVEL LADDER --------------------------------------------------+
| L5 LAW / RULE / CODE      'you must'      external, enforceable, sanction attached               |
| L4 NORM                   'we do'         social expectation, stigma attached                    |
| L3 VALUE                  'this is worth' ENDURING + TRANS-SITUATIONAL  <- SYLLABUS              |
| L2 ATTITUDE               'I favour X'    OBJECT-SPECIFIC  -> owned by Topic 03                  |
| L1 BELIEF + FEELING       'I think/feel'  momentary, unstable                                    |
|--------------------------------------------------------------------------------------------------|
| DEFINING FEATURES OF L3: enduring (not a mood) + trans-situational (not object-bound)            |
| + evaluative (ranks options rather than describing them).                                        |
| ADJACENT TERMS KEPT SEPARATE: norm (shared expectation) / virtue (settled excellence)            |
| / interest (what benefits me) / aptitude (capacity to perform -> Topic 04).                      |
|--------------------------------------------------------------------------------------------------|
| PRIMARY AUTHORITY BOTH WAYS:                                                                     |
|   ARC 2.2.1  values UPSTREAM of law - 'Ethics provides the basis for the creation of             |
|              such laws and rules ... Our legal system emanates from a shared vision              |
|              of what is good and just.'                                                          |
|   ARC 2.2.4  values INDISPENSABLE DOWNSTREAM - rules 'cannot provide for all                     |
|              situations'; 'the higher the echelon ... the greater is the ambit of                |
|              discretion'.                                                                        |
|   PREFACE    'One cannot mandate honesty. The rule of law can only defeat the perverse           |
|              mind. However, it cannot defeat the perversity of the heart.'                       |
|--------------------------------------------------------------------------------------------------|
| TRAP -> defining a value as 'a good moral quality such as honesty' gives an EXAMPLE,             |
| not a definition, and collapses value into virtue.                                               |

ASCII MASTER FLOW — PANEL 6/40: FIVE TRANSMISSION MECHANISMS - AND THE FAILURE MODE OF EACH
+-- [04] FIVE TRANSMISSION MECHANISMS - AND THE FAILURE MODE OF EACH ------------------------------+
| 1 MODELLING       copied from an observed actor; 'what is done here' beats 'what is              |
|                   said here'.  ARC PREFACE (Confucius): the ruler who governs by his             |
|                   virtues 'may be compared to the Pole star which keeps its place and            |
|                   all other stars turn towards it'.                                              |
|                   FAILS WHEN: the model is unrepresentative or copied selectively.               |
| 2 REINFORCEMENT   conduct that is rewarded is repeated (incentives, appraisal,                   |
|                   promotion, stigma).  FAILS WHEN: espoused != rewarded (Cut 4).                 |
| 3 IDENTIFICATION  'people like us behave like this'.  ARC Annexure-I(2), p.217:                  |
|                   dismissal 'means disgrace for the entire family, and therefore,                |
|                   members of the family have an incentive to discourage corruption'.             |
|                   FAILS WHEN: the reference group's own norm is corrupt.                         |
| 4 INSTRUCTION     explicit teaching of a standard and its reasons (curriculum, code,             |
|                   iGOT module).  WEAKEST ALONE.  FAILS WHEN: taught as recall.                   |
| 5 REFLECTIVE      inherited values tested against experience.  ARC BOX 2.7                       |
|   REVISION        (Vivekananda): 'as knowledge comes, person grows, morality is                  |
|                   evolved, and idea of non-separateness begins.'                                 |
|                   FAILS WHEN: revision without an anchor = rationalised convenience.             |
|--------------------------------------------------------------------------------------------------|
| DIAGNOSTIC RULE -> name WHICH mechanism failed. A modelling failure is not cured by a            |
| curriculum; a reinforcement failure is not cured by a website statement.                         |

+-- [05] LIMB B(i) - FAMILY: FIRST SCHOOL, LEAST REGULABLE INSTITUTION ----------------------------+
| FOUR CHANNELS                         RISK WHEN INVERTED                                         |
| 1 earliest modelling (pre-verbal)     models deceit as competence                                |
| 2 reputational identification         shields wrongdoing to protect family honour                |

| (iii) remove the material barriers - distance, escort, toilets, cost of the uniform.             |
|--------------------------------------------------------------------------------------------------|
| MECHANISM CONDITION -> the ARC's family incentive works ONLY where office carries                |
| prestige AND dismissal is credible. Slow or reversible sanction flips the incentive.             |

ASCII MASTER FLOW — PANEL 11/40: AFTER FORMATION - INTERNALISATION, PERFORMANCE AND FOUR CORROSION PATHS
+-- [08] AFTER FORMATION - INTERNALISATION, PERFORMANCE AND FOUR CORROSION PATHS ------------------+
| THE OBSERVABILITY TEST                                                                           |
|   unobserved AND conduct unchanged        -> INTERNALISED (robust under discretion)              |
|   unobserved AND conduct changes          -> PERFORMANCE (display for appraisal,                 |
|                                              publicity or fear of sanction)                      |
|   observed                                -> UNINFORMATIVE: both look identical                  |
| STRUCTURAL CONSEQUENCE -> any system that relies on observation can only ever detect             |
| PERFORMANCE. This is why vigilance cannot manufacture integrity.                                 |
|--------------------------------------------------------------------------------------------------|
| FOUR CORROSION PATHWAYS            MATCHING COUNTER-MOVE                                         |
| 1 NORMALISATION 'everyone does it'  make the deviation visible and countable                     |
|   [ARC 1.3 records this as the                                                                   |
|    prevailing Indian condition]                                                                  |
| 2 INCREMENTALISM small steps       declare a BRIGHT LINE (gift ceiling, mandatory                |
|                                     recusal trigger): converts gradient -> threshold             |
| 3 EUPHEMISM 'facilitation',        restore ACCURATE NAMING in the record: the                    |
|   'adjustment', 'courtesy'          prohibition was attached to the honest word                  |
| 4 DIFFUSED AGENCY 'I only signed'  fix PERSONAL ATTRIBUTION: one named officer per               |
|                                     decision, with recorded reasons                              |
|--------------------------------------------------------------------------------------------------|
| PROXIES, NOT PROOF -> conduct under low observability; consistency across differently            |
| placed beneficiaries; willingness to record a reason a hostile reader will see.                  |
| TRAP -> a completed training module or a signed integrity pledge is exactly what                 |
| PERFORMANCE produces.                                                                            |

+-- [09] USING VALUES IN A DECISION - CONFLICT, HIERARCHY AND THE TRADE-OFF (PART 1 OF 2) ---------+
| TWO SHAPES:                                                                                      |
|   TYPE A CIRCLE vs CIRCLE   family loyalty vs impartiality; community custom vs                  |
|                             constitutional equality; conscience vs lawful order                  |
|   TYPE B CLAIM vs CLAIM     transparency vs privacy; speed vs due process;                       |
|                             compassion vs equal treatment; many vs the rights of few             |
|--------------------------------------------------------------------------------------------------|
| FOUR-STEP RESOLUTION SPINE:                                                                      |
|   1 NAME BOTH VALUES PRECISELY - not 'a dilemma', say WHICH two                                  |
|   2 APPLY THE LEXICAL FILTER IN ORDER: (i) constitutional value / fundamental right              |
|     (ii) binding statute or rule (iii) institutional mandate and code                            |
|     (iv) professional norm (v) personal conscience                                               |
|     -> a lower tier NEVER overrides a higher one; it chooses among options the                   |
|        higher tier leaves open. Where conscience cannot: recorded dissent, lawful                |
|        escalation or resignation - never quiet non-compliance.                                   |
|   3 SEEK THE OPTION THAT DISSOLVES THE CLASH BEFORE TRADING: redact and disclose;                |
|     interim order with a short-dated review; grant relief AND record it as a CLASS               |
|     rule so the next similarly placed claimant also receives it                                  |
|   4 IF A TRADE-OFF IS UNAVOIDABLE: state the THRESHOLD crossed, the SAFEGUARD                    |
|     attached and the RESIDUAL RISK accepted                                                      |
|--------------------------------------------------------------------------------------------------|
| DIRECTION-SETTING AUTHORITY [ARC 2.2.2]: 'all persons holding authority derive it from           |
| the people ... all public functionaries are trustees of the people', and authority must          |
| be exercised 'in the best interest of the people or in "public interest"'.                       |
| -> A PRIVATE CLAIM IS DISQUALIFIED, NOT MERELY OUTWEIGHED. Hence RECUSAL, not careful            |
|    personal balancing.                                                                           |
| LOSES MARKS -> 'a balance must be struck between the two': no threshold, no safeguard,           |
