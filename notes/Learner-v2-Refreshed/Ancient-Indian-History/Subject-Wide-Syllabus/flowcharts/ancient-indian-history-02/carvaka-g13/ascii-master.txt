ASCII MASTER FLOW — PANEL 2/12: Archaeology: context before object
SURVEY -> SITE -> GRID/TRENCH -> STRATIGRAPHY -> ASSEMBLAGE -> INTERPRETATION
                         |
                         v
Law of superposition: an undisturbed lower layer is relatively earlier.
Artefact alone: weak provenance | artefact in sealed context: stronger association
Industry = recurrent technique/tool set; culture = patterned material assemblage.
Intrusion, redeposition and mixed layers can break a simple sequence.

ASCII MASTER FLOW — PANEL 3/12: Dating ladder: precision with error bars
RELATIVE DATE                         ABSOLUTE/CHRONOMETRIC DATE
stratigraphy -> seriation -> typology | radiocarbon -> calibrated range
cross-dating -> association           | TL/OSL -> last heating or light exposure
                                      | dendrochronology where wood survives
             +------------------------+------------------------+
                                      v
A date belongs to a sample and context, not automatically to an entire culture.
Report range, calibration and contamination risk; probability is not certainty.

ASCII MASTER FLOW — PANEL 9/12: Source-based answer architecture: 10/15/20 marks
10 MARKS: identify source -> what it reveals -> named example -> one limitation
15 MARKS: classify sources -> compare powers -> triangulate a case -> qualify
20 MARKS: problem -> source matrix -> method/dating -> case clinics -> conflicts
          -> silences/preservation -> reasoned verdict on confidence
EVIDENCE SENTENCE: X indicates Y because Z; however, genre/context limits W.
Never end with all sources are important; state which source answers which question.
