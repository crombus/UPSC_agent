# Political Theory — Mains-Focused Live Editions

This folder contains compact UPSC Mains editions derived from the comprehensive
Political Theory live sessions.

## Purpose

- Preserve the comprehensive sessions as the authoritative teaching and reference layer.
- Reduce each topic to 8-12 lessons for GS-II, GS-IV and Essay preparation.
- Prioritise concepts that improve analysis, introductions, arguments, comparisons,
  conclusions and answer-writing.
- Exclude optional-only detail unless it materially strengthens a General Studies or
  Essay answer.

## Artifact layout

```text
Mains\
  INDEX.md
  MAINS-FOCUSED-GENERATION-RULES.md
  <topic-folder>\
    Mains-Focused-Live-Edition.md
```

Mains-focused editions are indexed only in `Mains\INDEX.md`. They do not replace or
duplicate rows in `live_sessions\INDEX.md`.
