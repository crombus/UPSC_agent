## BASIC LEARNING SESSION

### 0. What this session builds

```text
   YOU ALREADY HAVE                    THIS FILE ADDS                    EXAM OUTPUT
 ┌──────────────────────┐       ┌───────────────────────────┐      ┌────────────────────┐
 │ Static concepts      │       │ A dated, field-structured │      │ Concept + exact    │
 │ (Topics 01–27):      │  ──▶  │ record of WHICH species / │ ──▶  │ dated instance +   │
 │ what a Ramsar site,  │       │ WHICH site / WHICH status │      │ honest statement   │

 │ a Tiger Reserve IS   │       │ and HOW CONFIDENT we are  │      │ verified           │
 └──────────────────────┘       └───────────────────────────┘      └────────────────────┘
        stable                       changes monthly                 what UPSC rewards
```

A tracker is **not** a news diary and **not** a schema essay. It is a set of records with fixed
fields, each field either filled from a named source on a named date or marked `N/A`/`GAP`.
Sections 4–8 build that artefact; Sections 1–3 explain why it has the shape it has.

### 1. Why a separate tracker file exists

**F2 — Basic owner §1, §3.** Static conceptual knowledge explains *what* a Ramsar site, IUCN
category or Tiger Reserve is and *how* it works; it does not change year to year. Current affairs
supply the *latest specific instance* of that concept, and change constantly. Keeping the two in
one file means every news update forces a rewrite of the concept text. Keeping them apart means
the concept files stay stable and only this file is refreshed.

> **The rule that makes the file worth having (F2, Basic owner §1 and §3.5):** if a claim cannot be
> traced to a specific official source, it is **omitted**, not estimated. An omission register is a
> deliverable, not an apology.

```text
   STATIC FILE (Topic 07)              TRACKER RECORD (this file)
   "A Ramsar site is a wetland    +    "Glaw Lake, Arunachal Pradesh, became
    of international importance         India's 101st Ramsar Site and the State's
    designated under the 1971           first, designated 3 August 2026"
    Convention; criteria 1–9."          [F3: PIB PRID 2294036; Ramsar Secretariat]
            │                                        │
            └──────────────── ONE ANSWER ────────────┘
   Neither half alone scores. The concept without a date reads unprepared;
   the date without the concept reads memorised.
```

### 2. Essential definitions

| Term | Exam-ready meaning |
|---|---|
| **Current-affairs anchor** (F2) | A specific, dated, source-attributed fact used to update or exemplify a static concept. |
| **Source attribution** (F2) | Naming the originating document — PIB release ID, MoEFCC/NTCA notification, convention Secretariat announcement — *and* its date. |
| **Milestone tracking** (F2) | Recording threshold events (India's 100th Ramsar site; the 58th Tiger Reserve) with precise dates. |
| **Status-change tracking** (F2) | Recording changes in a taxon's IUCN category, CITES Appendix or Wildlife Protection Act Schedule, each with its effective date. |
| **Unit of assessment** | The exact thing a claim is about: species, subspecies, named population, or a region-bounded assessment. Claims do not transfer between units. |
| **Scope** | Whether a status is **global** or **regional/national**. A global category and a national assessment are different records. |
| **Verification date** | The date *you* checked the source — distinct from the source's own publication or assessment date. |
| **Recheck-by date** | The date after which the record must be re-verified before reuse. |

### 4. The record schema — the actual tracker method

Every tracker record carries these fields. **A field may legitimately be `N/A` or `GAP`; filling a
field by guessing is the single failure mode this schema exists to prevent.**

| # | Field | What it must contain | When `N/A` is correct |
|---:|---|---|---|
| 1 | Exact taxon / unit | Species, subspecies, named population, or a non-biological unit (site, reserve, count) | Never — a record without a unit is not a record |
| 2 | Common name(s) | Including regional/vernacular names actually used in Indian sources | Rarely; some taxa have no settled English name |
| 3 | Scientific name | Binomial (with trinomial where the claim is subspecific) | For site/count records |
| 4 | Higher group | Family / order / class — this is where "crustacean vs arachnid" errors die | — |
| 5 | Source | Named issuer and document identifier (PRID, notification number, report title) | Never |
| 6 | Assessment / publication / effective date | The date *the source* attaches to the fact | Never |
| 7 | Verification date | The date you opened that source | Never |
| 8 | Scope | Global vs regional/national vs subpopulation | Never |
| 9 | IUCN category + assessment year | Category **and** the year of the assessment that produced it | When the taxon has not been assessed |
| 10 | WPA Schedule + amendment vintage | Schedule number, and under which version of the Act | For non-Indian taxa and for site/count records |
| 11 | CITES Appendix + effective basis | Appendix, and the CoP/annotation that produced it | When the taxon is unlisted |
| 12 | CMS Appendix | Appendix I / II and the listing COP | For non-migratory taxa |
| 13 | Range | Global native range, then the India range separately | — |
| 14 | Habitat | The habitat the exam actually tests (arboreal, epiphytic, alpine scrub) | — |
| 15 | Population / trend | Only first-party figures with their own date | Very often — see the omission register |
| 16 | News trigger | The dated event that put the item in the news | When the record is purely static reference |
| 17 | Status verb | announced / notified / designated / allocated / released / observed / assessed | Never |
| 18 | Static-topic link | The Topic 01–27 owner the record plugs into | Never |
| 19 | Recheck-by date | Explicit | Never |
| 20 | Omission / failure log | What could not be verified, and what was attempted | Never — an empty log is itself suspicious |

### 5. Three firewalls that stop most tracker errors

```text
 FIREWALL 1 — NEWS TRIGGER  ≠  CURRENT STATUS
   trigger : "Minister announced Glaw Lake's designation on 3 August 2026"
   status  : "India has 101 Ramsar Sites as on 1 October 2026"
   The trigger is an event with a date. The status is a state with an as-on date.
   Writing the trigger where the status belongs is how stale counts survive for years.

 FIREWALL 2 — SPECIES ≠ SUBSPECIES ≠ POPULATION ≠ REGIONAL ASSESSMENT
   Elephas maximus (species, global)   ≠  Elephas maximus indicus (Indian subspecies)
   Acinonyx jubatus (species, global)  ≠  A. j. venaticus (Asiatic subspecies)
   Dugong dugon (species, global)      ≠  an East African subpopulation assessment
   A category assigned to one of these units may not be reported as the category of another.

 FIREWALL 3 — THREE LISTS THAT ARE NOT THE SAME LIST
   ┌─ IUCN Red List ──────┐  ┌─ WPA Schedules ───────┐  ┌─ CITES / CMS Appendices ─┐
   │ scientific extinction│  │ Indian domestic law   │  │ international trade (CITES)│
   │ risk assessment      │  │ hunting/possession/   │  │ and migratory-species      │
   │ no legal force       │  │ penalty consequences  │  │ cooperation (CMS)          │
   │ assessed + dated     │  │ amended by Parliament │  │ changed at CoPs, annotated │
   └──────────────────────┘  └───────────────────────┘  └────────────────────────────┘
   "Critically Endangered" is not a legal status. "Schedule I" is not a global category.
   "Appendix II" restricts trade; it does not state extinction risk.
```

**Status verbs — the four that must never be substituted (F2, Basic owner §13.1).**

| Verb | Safe to claim | Unsafe substitution |
|---|---|---|
| announced / targeted | a policy intention exists | an achievement |
| notified / designated | a legal or administrative status exists | operational protection or outcome |
| allocated / sanctioned | money or capacity is committed | commissioned output |
| released / observed / assessed | a document, sighting or assessment exists | a verified population or a legal status |

### 6. Institutions and source routes

| Route | What it is authoritative for | Caution |
|---|---|---|
| **PIB** (F2) | Government of India announcements; each release carries a citable PRID | A PIB release reports a decision; it is not itself the gazette notification |
| **MoEFCC** (F2) | Protected-area and Schedule notifications, policy instruments | Schedule text must be read in the gazette, not in a summary |
| **NTCA** (F2) | Tiger Reserve count, tiger estimation cycles | Count changes between cycles — always date it |
| **Ramsar Secretariat** (F2) | Official site register and global totals | National totals and global totals are separate records |
| **IUCN / BirdLife** (F2) | Red List categories, criteria, assessment years | Category without assessment year is an incomplete record |
| **CITES / Species+** | Appendix listings, annotations, effective dates | Family-level listings carry exceptions; read the annotation |
| **CMS** | Appendix I/II listings for migratory species | Listing COP and year matter |
| **WII / ZSI / BSI** | Population assessments, faunal and floral discovery compilations | Survey period ≠ release date |
| Secondary summaries (F2) | Discovery aid only | Must be cross-checked against the primary route before entry |

### 7. Species fact-card bank

Two card classes, by design:

- **Full-field cards** — for taxa whose *current status* is examinable (the Direct PYQ routes and the
  flagship longitudinal set). All 20 schema fields apply.
- **Application cards** — for taxa whose examinable content is **biology, use or behaviour**, not
  current legal status. Fields 9–12 are deliberately left `GAP`/`N/A` rather than padded; these
  organisms reach this file through a PYQ route, not because their conservation status is current news.

> discipline — exact taxon, exact group, exact claim — not status reporting.

### A3. Handling contested or discrepant figures

1. ⚠️ A widely circulated figure that cannot be traced to a primary source is either omitted or

2. ⚠️ Where official sources themselves differ — commonly because of different reporting cut-offs —

3. ⚠️ This mirrors the "data and conceptual limitations" section carried by every advanced-tier file:

### A4. Why longitudinal flagship tracking outperforms breadth

⚠️ Tracking one flagship across successive updates — IUCN category, WPA Schedule, court proceedings,

the interaction is the analysis. The Advanced owner recommends three to five such species; §7D keeps
six, each chosen for a different layer: GIB for judicial enforcement, the elephant for subspecies and
scope discipline, the snow leopard for national assessment method, the red panda for habitat

|---|---|

### A7. Advanced must-know and advanced traps

- ✅ Source-and-date attribution is itself an evidentiary standard the examiner can see.
