`FORMAL-COVERAGE-REVIEW.json` is the separately authored semantic decision layer. Each decision
is keyed by stable block ID and bound to a canonical full-block SHA-256 retaining source path,
heading level and text, ancestor context, semantic labels and complete block text. Parent headings
with descendants are structural umbrellas: validation requires the recursive union of every child
decision plus separately evidenced parent-only prose. Large leaf blocks require beginning,
middle and end proposition inventories. Each inventory proposition is an independently meaningful
conceptual claim with discriminative multi-term evidence and an explicit relationship; adjacent
token fragments and generic phrases fail. The formal master flow additionally requires one unique
conceptual claim, source hash and panel-specific destination section for every one of its 55
panels. Normalization is limited to line endings, Unicode composition and trailing whitespace.
The validator never creates, infers, modifies or auto-approves this file.

`FORMAL-COVERAGE-AUDIT.json` is generated evidence only. It extracts current source identities,
full-block hashes, body signatures and witnesses, then applies a decision only when the authored
review contains the same stable ID and canonical full-block hash. `--refresh-formal-audit`
preserves the review file byte-for-byte. New, removed or changed blocks remain unresolved until
deliberately reviewed. Regression gates mutate a semantic label, heading and ancestor context. Six true negative tests
run through the same structural, proposition and distributed-inventory validators: they drop
parent-only prose, remove a structural child, reduce chronology to its opening segment, replace
chronology claims with generic token fragments, reduce the master flow to ten panels, and replace
all panel claims/anchors with one generic witness and destination. Every mutation must fail for
its expected reason.
