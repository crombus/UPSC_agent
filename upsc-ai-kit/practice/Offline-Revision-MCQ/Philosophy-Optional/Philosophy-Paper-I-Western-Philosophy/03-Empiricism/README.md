`FORMAL-COVERAGE-REVIEW.json` is the separately authored semantic decision layer. Each decision
is keyed by stable block ID and bound to a canonical full-block SHA-256. That representation
retains the source heading, ancestor context, semantic labels and complete block text, while
normalizing only line endings, Unicode composition and trailing whitespace. Each decision records its
classification, destination anchors, witnesses and required propositions. The validator never
creates or modifies this file.

`FORMAL-COVERAGE-AUDIT.json` is generated evidence only: it extracts current source identities,
full-block hashes, body signatures and witnesses, then applies a decision only when the authored
review contains the same block ID and canonical full-block hash. `--refresh-formal-audit` preserves the review
file byte-for-byte. A new block, removed block or changed body remains unreviewed and fails
validation until a new decision is deliberately authored. A built-in regression mutates the
semantic label `Plain-language definition`, the heading and the ancestor context and requires all
three mutations to change the decision-bound hash. Exact matching headings are candidates,
not approval. Composite practice blocks remain manually mapped proposition by proposition across
the split question, solution, toolkit and coverage surfaces.
