# Economy 01 — Question 8

**Learner answer:** D  
**Correct answer:** B  
**Result:** Incorrect

If nominal GDP is 126 and constant-price GDP is 120 for the same period and compatible series, the implied GDP deflator (base = 100) is:

A. 100  
B. 105  
C. 95  
D. 120

**Explanation:** GDP deflator = (nominal GDP / real GDP) × 100 = (126 / 120) × 100 = 105.

- **A:** Incorrect; it would imply no price-level difference between the current-price and constant-price aggregates.
- **B:** Correct; the ratio 1.05, expressed with a base of 100, is 105.
- **C:** Incorrect; it reverses the ratio.
- **D:** Incorrect; it mistakes the constant-price GDP value for the index.

**Examiner trap:** Use nominal divided by real, then multiply by 100; ensure both GDP values refer to compatible periods and series.
