# Economy 01 — Question 3

**Learner answer:** D  
**Correct answer:** D  
**Result:** Correct

In a wheat–flour–bread chain, sales are 20, 35 and 50, while flour uses wheat and bread uses flour. Total value added is:

A. 105  
B. 70  
C. 35  
D. 50

**Explanation:** Value added is output value minus intermediate consumption at each stage: wheat 20, flour 35 − 20 = 15, bread 50 − 35 = 15. Total = 20 + 15 + 15 = 50, equal to final bread value.

- **A:** Incorrect; adding gross sales at each stage double-counts intermediate output.
- **B:** Incorrect; it does not sum the stages' net contributions.
- **C:** Incorrect; it omits the value added at earlier stages.
- **D:** Correct; total value added equals final output value, 50.

**Examiner trap:** Avoid double counting intermediate goods.
