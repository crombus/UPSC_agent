# Interactive UPSC Learning Game

**Started:** 2026-08-29  
**Mode:** One challenge at a time  
**Status:** Active

## Purpose

This programme converts revision and answer writing into short, interactive levels that become
progressively harder. The learner never receives a long passive lesson before attempting
something.

All questions, responses, explanations, scores and doubts for this programme must remain inside
this folder.

## Two arenas

### Polity Arena - Prelims and Mains

Each topic progresses through:

1. **Recognition:** one conceptual MCQ.
2. **Distinction:** close statements, exceptions or chronology.
3. **Recall:** explain the rule without options.
4. **Construction:** build an introduction, body point or conclusion.
5. **Full Answer:** write a 150-word or 250-word answer.
6. **Boss Round:** mixed MCQs plus one timed Mains response.

### Philosophy Arena - Mains answer writing only

Philosophy will not use ordinary fact-recall MCQs as its main progression. Each topic advances
through:

1. **Demand Decode:** identify the directive and components of the question.
2. **Thesis:** state a precise philosophical position.
3. **Argument:** construct one argument with philosopher/text/doctrine.
4. **Objection:** present a serious criticism.
5. **Reply and Evaluation:** qualify the doctrine rather than merely describing it.
6. **Full Answer:** combine the parts into an examiner-ready response.
7. **Boss Round:** timed answer with no scaffolding.

Initial Philosophy topics:

- Carvaka
- Notions of God

## Adaptive rules

- Only one challenge is presented at a time.
- A correct answer unlocks a harder challenge.
- An incomplete answer receives one hint and a smaller remedial challenge.
- A conceptual error sends the learner to a simpler explanation and retry.
- Two successful challenges at one level unlock the next level.
- Full answers are evaluated for demand fulfilment, content, structure, evidence, criticism and
  conclusion.
- Difficulty increases through fewer hints, closer alternatives, more dimensions and tighter time
  or word limits.
- Wrong answers are treated as information, not failure.

## Scoring

| Performance | XP |
|---|---:|
| Correct/complete without hint | +10 |
| Correct after one hint | +7 |
| Correct after remedial retry | +5 |
| Strong original distinction or example | +3 bonus |
| Completed timed boss round | +20 |

XP measures consistency and increasing independence; it does not replace marks.

## Starting order

The opening sequence targets recorded weaknesses before adding new material:

1. Preamble
2. Making of the Constitution
3. Carvaka answer writing
4. Notions of God answer writing
5. Historical Background
6. Union and Territory
7. Citizenship

The order may change adaptively when errors show that a prerequisite needs attention.

## Persistence

- `PROGRESS.md` stores levels, XP, streaks, weaknesses and next challenge.
- Each challenge is saved as `ROUND-NNN.md`.
- The learner's answer, evaluation, teaching, hints and retry are appended to the same round.
- A new round is created only after the current one is resolved.
