# शब्दावली, मुहावरे और लोकोक्तियाँ - अनिवार्य आधार

## 1. पर्यायवाची

| शब्द | पर्याय |
|---|---|
| आँख | नेत्र, नयन |
| सूर्य | रवि, भानु |
| जल | नीर, पानी |
| आकाश | नभ, गगन |
| पृथ्वी | धरती, वसुंधरा |
| पक्षी | खग, विहंग |
| दर्पण | आईना, मुकुर |

प्रश्न में सामान्यतः दो पर्याय माँगे जाते हैं; अस्पष्ट या अत्यन्त दुर्लभ शब्द से बचें।

## 2. विलोम

उन्नति-अवनति, आशा-निराशा, स्वतंत्र-परतंत्र, स्वीकार-अस्वीकार, स्थायी-अस्थायी।

## 3. श्रुतिसम/भिन्नार्थक शब्द-युग्म

| युग्म | अर्थ |
|---|---|
| दिन / दीन | दिवस / गरीब |
| पास / पाश | निकट / बंधन |
| प्रसाद / प्रासाद | कृपा/भोग / महल |
| पानी / पाणि | जल / हाथ |
| अभिनय / अभिनव | नाट्य-प्रस्तुति / नया |
| कपट / कपाट | छल / दरवाज़ा |
| जूठा / झूठा | खाया हुआ / असत्य |

दोनों शब्दों का ऐसे वाक्यों में प्रयोग करें कि अंतर स्वतः स्पष्ट हो।

## 4. मुहावरा और लोकोक्ति

- **मुहावरा:** वाक्यांश, जिसका लाक्षणिक अर्थ होता है।
- **लोकोक्ति:** पूर्ण कथन, जो अनुभवजन्य शिक्षा देता है।

| मुहावरा | अर्थ |
|---|---|
| आकाश-पाताल एक करना | अत्यधिक प्रयास करना |
| आँख खुलना | वास्तविकता का ज्ञान होना |
| घी के दीये जलाना | बहुत प्रसन्नता मनाना |
| टेढ़ी खीर | कठिन काम |
| घर भरना | अनुचित ढंग से धन जुटाना |
| तारे तोड़ लाना | असंभव-सा कठिन कार्य करना |

| लोकोक्ति | अर्थ |
|---|---|
| जैसा बोओगे वैसा काटोगे | कर्म के अनुरूप फल |
| देर आए दुरुस्त आए | देर से सही, पर ठीक होना |
| नाच न जाने आँगन टेढ़ा | अपनी कमी का दोष दूसरे पर |
| एकता में बल है | सहयोग से शक्ति |
| अब पछताए होत क्या | अवसर निकलने के बाद पछतावा व्यर्थ |

## 5. प्रयोग नियम

अर्थ लिखें और फिर स्वाभाविक वाक्य बनाएँ। मुहावरे के शब्द अनावश्यक रूप से न बदलें।
