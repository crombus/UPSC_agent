# Medieval Indian History Learning Session Command Index

> **Topics indexed:** 23  
> **Subject method:** Chronology -> state formation -> administration/economy -> culture -> historian debate/PYQs.

## How to use these commands

- **Core learning:** copy `Start Medieval Indian History <number>`. The tutor must analyse the Core owner and cluster it into efficient 45-75 minute blocks instead of following every Markdown heading.
- **Deep mode is optional:** use `Deep Medieval Indian History <number>` only for a difficult concept, a direct Mains/PYQ theme, or Core-test accuracy below 70%. It is not a compulsory second reading.
- **Practice:** use `Test Medieval Indian History <number>` after Core learning. Answers must not be leaked before submission.
- **Revision:** use `Revise Medieval Indian History <number>` for the final register, error log and high-yield distinctions.
- **Resume:** use `Resume Medieval Indian History` to continue from saved progress.
- **Progress:** use `Progress Medieval Indian History` for completed blocks, accuracy and due revisions.

### Learning-session rule

The complete package remains the master reference. A live session should select all exam-relevant Core material, use advanced material only where it adds marks, run one genuine current-affairs check per integrated block, and end with cumulative retrieval rather than an MCQ after every small heading.
