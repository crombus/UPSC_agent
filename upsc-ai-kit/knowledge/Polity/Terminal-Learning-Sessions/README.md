# Polity Terminal Learning Sessions

This folder preserves substantive teaching, doubts, assessment history, remediation and progress from interactive terminal sessions.

## Session rules

- Core Markdown is the primary teaching source; advanced material is optional.
- Topics are taught in integrated 45-75 minute blocks rather than heading by heading.
- Current affairs are used only when securely verified and genuinely relevant.
- Interactive MCQ answers use balanced, non-predictable option placement.
- Correct options are never disclosed before submission.
- Advancement requires two consecutive correct answers or at least 2/3 correct in a mastery round.
