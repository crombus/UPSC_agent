# PYQ Trigger Dictionary

> **Canonical owner:** Fast routing from UPSC question wording to the repository's static owner,
> supporting revision asset and answer framework.
>
> **Evidence base:** Audited PYQ routing ledgers for 2018-2026. This is a retrieval map, not a
> prediction list or substitute for reading the complete question.
>
> **Companions:** [`_PYQ-INDEX.md`](_PYQ-INDEX.md) for question-level provenance,
> [`DIRECTIVE-WISE-ANSWER-TEMPLATES.md`](DIRECTIVE-WISE-ANSWER-TEMPLATES.md) for command compliance,
> and [`DATA-AND-EXAMPLES-BANK.md`](DATA-AND-EXAMPLES-BANK.md) for qualified evidence.

## 1. The five-part trigger scan

Read every question in this order:

```text
1. COMMAND       discuss / examine / analyse / evaluate / explain...
        |
2. NAMED ANCHOR  Article / Act / institution / scheme / place / report / treaty...
        |
3. CORE CONCEPT  federalism / inflation / monsoon / integrity / deterrence...
        |
4. HIDDEN TASK   causes / effects / comparison / effectiveness / reforms / examples...
        |
5. LIMITER       India / contemporary / vulnerable groups / South Asia / since 1991...
        |
        v
PRIMARY OWNER + SUPPORT OWNER + ANSWER FRAMEWORK + EVIDENCE
```

**Routing rule:** the primary owner must explain the central mechanism. A named Act, scheme or
institution is not automatically the primary owner if the question is really testing a wider
concept. Add a support owner only when a separate clause cannot be answered from the primary file.

## 3. Hidden task signals

| Wording signal | Hidden demand | Framework |
|---|---|---|
| **Why / factors responsible / reasons** | Weighted causality, not a feature list | Structural causes -> proximate triggers -> enabling conditions -> ranked cause |
| **Impact / implications / consequences** | Transmission channels and differentiated effects | Mechanism -> positive/negative -> stakeholder/space/time distribution -> net effect |
| **Role / contribution / significance** | Functions plus demonstrated value | Mandate/mechanism -> contribution -> evidence -> limits -> significance judgment |
| **Challenges / issues / constraints** | Diagnosed failure mechanisms | Design -> capacity -> coordination -> incentives -> inclusion -> accountability |
| **Measures / suggest / way forward** | Problem-linked and sequenced remedies | Each diagnosed gap -> responsible institution -> instrument -> safeguard -> metric |
| **Effectiveness / success / performance** | Criteria-based evaluation | Objectives -> criteria -> outputs -> outcomes -> exclusions/costs -> verdict |
| **Salient features** | Prioritised architecture | Legal status/objective -> major components -> distinctive feature -> implication |
| **Evolution / changing nature** | Chronology with continuity and change | Baseline -> turning points -> present form -> persistent element |
| **Relationship / nexus / link** | A connecting mechanism | Define A and B -> mechanism linking them -> evidence -> feedback -> boundary |
| **Balance / reconcile / versus** | Value or policy trade-off | Competing claims -> non-negotiables -> proportionality -> institutional synthesis |
| **Adequate / sufficient / capable** | Benchmark plus gap analysis | Define adequacy -> formal capacity -> operational evidence -> deficit -> reform |
| **Only / merely / always / primarily** | Test an absolute or dominant-cause claim | Accepted domain -> counter-case -> relative weight -> qualified verdict |
| **Examples / illustrate / cite cases** | Example-led proof | Example -> mechanism -> inference; repeat across dimensions |
| **India's commitments / initiatives** | International-to-domestic implementation map | Global obligation -> Indian target/law/programme -> progress -> gap |
| **Compare / distinguish** | Matched parameters | Source -> scope -> mechanism -> authority -> effect -> decisive difference |
| **Current / contemporary / recent** | Static core plus dated update | Stable concept first -> verified update -> status caveat |

## 16. Collision rules

| Collision | Primary-owner rule |
|---|---|
| **Polity vs Governance** | Polity owns constitutional/legal design; Governance owns implementation, citizen experience and administrative performance. |
| **Indian Society vs Social Justice** | Society owns social structure and change; Social Justice owns rights, welfare architecture and state response. |
| **Geography vs Environment** | Geography owns physical process and spatial distribution; Environment owns ecological pressure, regulation and conservation. |
| **Geography vs Disaster Management** | Geography owns hazard formation; Disaster Management owns risk, vulnerability, preparedness, response and recovery. |
| **Economy vs Social Justice** | Economy owns production, finance, markets and macro transmission; Social Justice owns capability, access and welfare delivery. |
| **Economy vs Science and Technology** | S&T owns how the technology works; Economy owns adoption incentives, value chains, jobs and industrial policy. |
| **IR vs Internal Security** | IR owns external strategy and interstate relations; Internal Security owns domestic threat pathways and response architecture. |
| **Polity vs Ethics** | Polity owns legality and institutional competence; Ethics owns value conflict, integrity and reasoned choice. |
| **Named scheme vs topic owner** | The scheme matrix supplies design facts; the substantive topic remains primary unless the question asks only scheme features. |
| **Current affairs vs static concept** | Current affairs supplies the trigger/status/example; static knowledge supplies most of the answer. |

When two owners remain genuinely necessary, label one **primary** and use the second only for the
specific clause it controls. Do not merge two complete generic notes.

## 18. Evidence loading order

After selecting the owner:

1. **Core concept:** read the primary `basic/` owner.
2. **Exact entity:** open the relevant canonical index from Section 2.
3. **Distinction:** use the confusing-pairs master if close terms appear.
4. **Evidence:** load two to four qualified items from the data/examples bank.
5. **Current status:** refresh only the volatile element.
6. **Architecture:** apply the directive and mark-wise template.
7. **Provenance:** consult the exact ledger through [`_PYQ-INDEX.md`](_PYQ-INDEX.md) when wording,
   year, marks or routing history matters.

This order prevents a current-affairs detail or named scheme from displacing the static concept
that the question is actually testing.

## 19. Final routing test

Before writing, complete this one-line card:

```text
[DIRECTIVE] + [PRIMARY CONCEPT] + [LIMITER] + [ADDITIONAL TASKS]
-> [PRIMARY OWNER] + [SUPPORT OWNER]
-> [FRAMEWORK] + [2-4 EVIDENCE ANCHORS] + [VERDICT TYPE]
```

**Example:**

```text
Critically evaluate + education as welfare/investment + India + reconcile the binary
-> Social-Justice/basic/04 + Economy/data support
-> criteria matrix + rights/human-capital evidence + integrated conditional verdict
```

If the selected owner cannot explain the main causal or institutional mechanism without relying
on the support file, the routing is reversed.
