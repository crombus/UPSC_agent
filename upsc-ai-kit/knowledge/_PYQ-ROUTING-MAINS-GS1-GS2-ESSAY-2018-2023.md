# UPSC Mains GS-I, GS-II and Essay - PYQ Routing Ledger, 2018-2023

> ## What this file is - and what it is not
>
> **Read-only provenance.** Every row below was produced by reading the official UPSC
> question-paper PDFs that already sit, unmodified, in `books/more_previous_papers/`.
> Those PDFs carry an OCR text layer added by an earlier remediation pass (see
> `MORE_PREVIOUS_PAPERS_OCR_AUDIT.md`); this ledger **did not open them for writing, did not
> re-OCR them and did not move or rename them**. No Qdrant collection, no RAG retrieval and no
> web source was consulted - only the printed English text of the papers themselves.
>
> **This is linkage metadata, not content.** Each row records *where in this knowledge base a
> question already belongs*. A row is a pointer. It is **not** an answer key, **not** a claim
> that the linked topic file already contains the answer, and **not** an assertion about what
> the correct option or the model answer is. Nothing in any subject file was added, edited or
> re-scoped to create this ledger.
>
> **Neutral labels.** The topic/theme column names the subject matter of a question in neutral
> words. It deliberately avoids resolving the item: no option letters, no "the answer is", no
> statement-by-statement verdicts.
>
> **Honesty rule.** Where the OCR layer could not be read with confidence, the row says
> `manual verification needed` and the missing wording is left missing. Nothing was
> reconstructed from memory, from a coaching site or from an aggregator.

> ## Route link convention
>
> Route links are ordinary relative Markdown links resolved from this file, which sits at the
> root of `upsc-ai-kit/knowledge/`. The visible link text is the target path with the `.md`
> extension stripped, so the destination is readable without following the link:
>
> `[Economy/basic/03_Inflation-Price-Indices-and-Business-Cycles](Economy/basic/03_Inflation-Price-Indices-and-Business-Cycles.md)`
>
> A second link is added with a ` · ` separator only where a question genuinely straddles two
> owning topics. Shotgun linking was avoided on purpose: a long link list would make the ledger
> unusable as a revision router.

> ## Tier policy
>
> Mains rows route to the **`advanced/` tier** of the owning topic, because a Mains question asks
> for the analytical treatment rather than the foundational one. Three deliberate exceptions:
>
> - World physical-geography questions route to `Geography/basic/...`, because Geography's
>   `advanced/` tier in this kit is India-specific (`01_India-Location-and-Extent`,
>   `16_India-Monsoon-Mechanism`, and so on) and is therefore *not* the owner of a question about
>   mantle plumes, fjords or the Circum-Pacific belt.
> - India-specific physical-geography questions do route to the Geography `advanced/` tier, which
>   is exactly what that tier is for.
> - Essay rows route to Essay **method** topics only (see the Essay section).

> ## Marks, word limits and directives
>
> The `Directive · marks · word limit` column preserves what the paper prints. Two recorded
> irregularities:
>
> - **Word limit printed only in the instruction block.** The 2019 GS-II and 2023 GS-II papers
>   print the marks against each question but carry the 150-word / 250-word split only in the
>   paper's own instruction block. Those rows say so in the integration note.
> - **OCR-corrupted word tails in the 2018 scans.** In `GENERAL-STUDIES-PAPER-I.pdf` and
>   `GENERAL-STUDIES-PAPER-II.pdf` the OCR layer renders some `(Answer in 150 words)` and
>   `(Answer in 250 words)` tails with a corrupted leading digit (e.g. `750`). The ledger records
>   the instruction-block limits - 150 words for Q1-Q10 and 250 words for Q11-Q20 - and flags the
>   affected rows individually. The corrupted digit is an artefact of the text layer, not a claim
>   about the printed paper.

# Mains Essay

Essay rows carry the **printed prompt number and its printed Section**. Section A is prompts 1-4
and Section B is prompts 5-8 in all six papers; a candidate writes one essay from each section, so
the paper is 2 x 125 = 250 marks.

**Routing rule for Essay.** An essay prompt is never "already taught" - there is no topic file in
this kit that contains the content of `Not all who wander are lost`. Essay rows therefore route to
the **method** modules that tell a candidate how to open, scope, structure and argue that kind of
prompt, and to nothing else. The prompt wording itself is already held, with its own verification
levels, in [Essay/PYQ-Corpus-2013-2025](Essay/PYQ-Corpus-2013-2025.md); this ledger does not
duplicate that corpus and does not override it. Where the two disagree about a printed number,
the corpus's own labelling note applies - it uses internal `YYYY-A1…B8` references, whereas this
ledger records the number printed on the paper.
