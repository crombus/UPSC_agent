# Governance Learning Session Command Index

> **Topics indexed:** 16  
> **Subject method:** Framework -> institution/process -> implementation gap -> evidence -> reforms and case studies.

## How to use these commands

- **Core learning:** copy `Start Governance <number>`. The tutor must analyse the Core owner and cluster it into efficient 45-75 minute blocks instead of following every Markdown heading.
- **Deep mode is optional:** use `Deep Governance <number>` only for a difficult concept, a direct Mains/PYQ theme, or Core-test accuracy below 70%. It is not a compulsory second reading.
- **Practice:** use `Test Governance <number>` after Core learning. Answers must not be leaked before submission.
- **Revision:** use `Revise Governance <number>` for the final register, error log and high-yield distinctions.
- **Resume:** use `Resume Governance` to continue from saved progress.
- **Progress:** use `Progress Governance` for completed blocks, accuracy and due revisions.

### Learning-session rule

The complete package remains the master reference. A live session should select all exam-relevant Core material, use advanced material only where it adds marks, run one genuine current-affairs check per integrated block, and end with cumulative retrieval rather than an MCQ after every small heading.
