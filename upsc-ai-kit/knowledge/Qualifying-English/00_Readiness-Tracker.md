## Section diagnostic rules

| Symptom | Diagnosis | Repair owner before next mock |
|---|---|---|
| Misses command, tone, title, reference or context meaning | Reading-demand failure | `basic/06` §§1–3 |
| Omits one limb of a question | Multipart allocation failure | `basic/06` §2 |
| Correct ideas but wrong ratio/title/copied wording | Précis execution failure | `basic/06` §§4–7 |
| Essay describes but has no arguable position | Thesis/structure failure | `basic/07` §§2–4 |
| Essay is thin, one-sided or unsupported | Development/balance failure | `basic/07` §§5–6 |
| Marks lost to agreement, preposition or punctuation | Usage failure | `basic/01`–`05`; log the exact rule |
