# Comprehension and Precis - MUST-DO

## 1. Comprehension method

```text
read question -> locate relevant lines -> identify claim/reason/example
-> answer directly -> compress -> check against passage
```

### Rules

- Answer from the passage, even if outside knowledge differs.
- Use complete sentences and your own concise wording.
- Match the command: *what*, *why*, *how*, *distinguish*, *explain*.
- Include every requested part but no unrelated summary.
- Do not copy a long paragraph when two precise sentences will answer.

## 2. Paragraph anatomy

| Element | Function |
|---|---|
| Topic sentence | Main point |
| Support | Reason, evidence or explanation |
| Example | Illustration; often removable in précis |
| Contrast | Qualification or opposing point |
| Conclusion | Implication or recommendation |

## 3. Precis method

A précis is an accurate, coherent compression of the whole passage to about **one-third** of its original length.

1. Count or estimate the original words.
2. Set a target near one-third.
3. Identify the central thesis.
4. Divide the passage into idea units.
5. Remove examples, quotations, repetition and decorative detail.
6. Combine related points.
7. Write in your own words and preserve the author's logic.
8. Check length, grammar and neutrality.

### Do

- retain central argument, major causes, effects and conclusion;
- use indirect speech;
- maintain proportion: do not spend half the précis on the first paragraph;
- create transitions so it reads as one piece.

### Do not

- add a title when the paper says not to;
- add personal opinion;
- copy distinctive phrases unnecessarily;
- reduce the passage to disconnected notes;
- change the author's position.

## 4. Compression tools

| Wordy form | Concise form |
|---|---|
| due to the fact that | because |
| in order to | to |
| at this point in time | now |
| a large number of | many |
| made a decision | decided |
| is able to | can |

## 5. Self-check rubric

| Criterion | Question |
|---|---|
| Fidelity | Did I preserve the author's meaning? |
| Coverage | Are all major idea units present? |
| Compression | Is it near one-third? |
| Independence | Is it substantially in my own words? |
| Coherence | Does it read as connected prose? |
| Correctness | Are grammar and punctuation accurate? |
