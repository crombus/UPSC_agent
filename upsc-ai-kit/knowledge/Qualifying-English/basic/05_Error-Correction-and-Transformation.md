# Error Correction and Sentence Transformation - MUST-DO

## 1. Correction order

```text
subject-verb -> tense -> pronoun -> article -> preposition
-> word form/confusable -> modifier -> punctuation
```

Make only necessary changes.

## 2. Common correction families

- Agreement: *One of the answers **was** wrong.*
- Countability: *new **furniture***, not *furnitures*.
- Preposition: *angry **with** the employee*.
- Verb form: *The woodcutter was **felling** trees*; *the tree was **falling***.
- Redundancy: *comprises several departments*, not *comprises of*.
- Negative logic: *The mother sings until the child goes to sleep*, not *until...does not*.
- Phrasal verb: *look after children*, not *look at children* when meaning care.
- Passive idiom: *A reply is awaited*, not *awaited for*.

## 3. Voice

Active: *The committee approved the plan.*  
Passive: *The plan was approved by the committee.*

Keep tense:

| Active | Passive |
|---|---|
| writes | is written |
| wrote | was written |
| has written | has been written |
| will write | will be written |
| can write | can be written |

Only transitive verbs normally form a passive.

## 4. Direct and indirect speech

- Statement: *He said, "I am tired."* -> *He said that he was tired.*
- Question: *The judge asked, "Were you present?"* -> *The judge asked whether I was present.*
- Command: *He said, "Close the door."* -> *He ordered me to close the door.*

Adjust person, time and place logically; universal truths normally retain present tense.

## 5. Meaning-preserving transformations

| Pattern | Transformation |
|---|---|
| as soon as | no sooner...than / hardly...when |
| if...not | unless |
| so...that...cannot | too...to |
| both negatives | neither...nor |
| purpose | so that / in order that |
| although | however + adjective/adverb |

Examples:

- *As soon as the bell rang, students left.* -> *No sooner had the bell rung than students left.*
- *If you do not practise, you will not improve.* -> *Unless you practise, you will not improve.*
- *The box is so heavy that I cannot lift it.* -> *The box is too heavy for me to lift.*

## 6. Question tags

- Positive statement -> negative tag: *They will come, won't they?*
- Negative statement -> positive tag: *She is not ready, is she?*
- *I am late, aren't I?*
- Imperative often uses *will you?*: *Open the door, will you?*
