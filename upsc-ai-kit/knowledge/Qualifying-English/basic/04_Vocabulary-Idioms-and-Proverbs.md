# Vocabulary, Confusables, Idioms and Proverbs - MUST-DO

## 1. Build meaning through use

For a "use in a sentence" question, the sentence must make the meaning unmistakable.

- Weak: *The man was philanthropic.*
- Clear: *The philanthropist financed a free hospital for workers who could not afford treatment.*

## 2. High-frequency confusables

| Word 1 | Word 2 |
|---|---|
| accept = receive | except = excluding |
| advice = noun | advise = verb |
| affect = usually verb | effect = usually noun |
| conscience = moral sense | conscious = aware |
| stationary = not moving | stationery = writing material |
| principal = chief / capital sum | principle = rule |
| complement = complete | compliment = praise |
| discreet = tactful | discrete = separate |
| cite = quote | site = place | 
| climatic = climate-related | climactic = climax-related |
| horde = crowd | hoard = stored stock |
| lose = misplace | loose = not tight |
| beside = next to | besides = in addition |
| credible = believable | credulous = too ready to believe |

## 3. Antonyms and word families

Learn a word with:

```text
meaning + part of speech + synonym + antonym + one clear sentence
```

Example: **scarce** (adjective) = insufficient; synonym: rare; antonym: abundant.

## 4. Idioms

Idioms have a conventional meaning not obtained word by word.

| Idiom | Meaning |
|---|---|
| at sea | confused |
| a thorn in the flesh | persistent source of annoyance |
| move heaven and earth | make every possible effort |
| step into someone's shoes | assume another person's role |
| know the ins and outs | know all details |
| cut adrift | leave unsupported |
| go berserk | become uncontrollably angry/excited |
| rank and file | ordinary members |

Use the idiom unchanged in a natural sentence.

## 5. Proverbs

A proverb states a general lesson; an idiom functions as part of a sentence.

| Proverb | Meaning |
|---|---|
| A stitch in time saves nine. | Early action prevents a larger problem. |
| Where there is a will, there is a way. | Determination helps overcome difficulty. |
| Look before you leap. | Consider consequences before acting. |
| Too many cooks spoil the broth. | Excessive, uncoordinated control harms work. |
| Actions speak louder than words. | Conduct is stronger evidence than promises. |
| All that glitters is not gold. | Attractive appearance may hide poor value. |

In essays, use only a proverb that directly supports the argument; do not decorate every paragraph.
