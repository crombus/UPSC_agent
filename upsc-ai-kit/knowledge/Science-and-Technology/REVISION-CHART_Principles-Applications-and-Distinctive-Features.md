# Science and Technology: Principles, Applications and Distinctive Features - Last-Minute Revision Chart

> **Purpose:** One-place revision immediately before Prelims or GS-III Mains.
> **Coverage:** Space, nuclear, defence, digital public infrastructure, AI, quantum technology, semiconductors, data and cyber governance, biotechnology, genetics, vaccines, nanotechnology, IPR, clean mobility, drones, critical minerals, general science, research institutions, computing and discoveries.
> **Two-pass design:** Core is independently exam-complete. Advanced adds engineering, governance, ethics and strategic depth; skipping it must not affect the paper outcome.
> **Status rule:** Distinguish scientific possibility, laboratory proof, prototype, test, regulatory approval, operational deployment and commercial scale.

## 2. Universal technology-answer framework

| Step | Question |
|---|---|
| Principle | Which physical, chemical, biological or computational mechanism enables it? |
| Architecture | What are its main components and data/material/energy flows? |
| Readiness | Proposed, approved, developed, tested, operational or scaled? |
| Institution | Who funds, builds, regulates, certifies or procures it? |
| Application | Which Indian development, economic or security problem does it solve? |
| Dependency | Which material, component, IP, skill or supplier is critical? |
| Risk | Safety, privacy, bias, misuse, environment, exclusion or dual use? |
| Outcome | What demonstrated capability—not announcement—proves success? |

### C-A-P-A-C-I-T-Y test

`Concept -> Architecture -> Performance -> Approval -> Capacity created -> Indian application -> Threat/safeguard -> Yield`

## 3. Technology status ladders

| Domain | Correct ladder |
|---|---|
| Mission/technology | Proposed -> approved -> development -> test -> operational -> scaled deployment |
| Law | Enacted -> notified -> commenced -> rules -> enforcement |
| Facility | Approved -> agreement -> construction -> inauguration -> pilot output -> commercial production |
| Weapon | Developmental trial -> user evaluation -> acceptance -> contract -> induction -> deployment |
| Funding | Announced outlay -> sanctioned -> disbursed -> infrastructure/output created |
| Medicine/vaccine | Discovery -> preclinical -> clinical phases -> regulator approval -> manufacture -> pharmacovigilance |

### Three distinctions that prevent overclaiming

- scientific feasibility is not engineering readiness;
- indigenous manufacture is not necessarily indigenous design or high domestic value addition;
- activity—MoU, portal, proposal, inauguration—is not demonstrated capability.

## 4. Space programme and launch vehicles

### Launch chain

`payload + launch vehicle -> propulsion/staging -> guidance -> orbital injection -> satellite operations`

| Concept | Meaning |
|---|---|
| Launch vehicle | Carries payload to space/orbit |
| Payload | Satellite, spacecraft or instrument |
| Stage | Propulsion section discarded or reused sequentially |
| Geostationary orbit | Equatorial circular orbit with Earth’s rotational period |
| Polar orbit | High-inclination orbit passing near poles |
| Sun-synchronous orbit | Near-polar orbit crossing locations at similar local solar time |
| Escape velocity | Minimum ideal speed to escape gravitational field without further propulsion |

### Indian institutional map

| Institution | Primary role |
|---|---|
| ISRO | National space research, missions and launch capability |
| Department of Space | Government space-policy/administrative umbrella |
| IN-SPACe | Authorisation, promotion and facilitation of non-government space activity |
| NSIL | Commercial space-sector PSU |

> **Trap:** A launch vehicle places payloads in space; a missile delivers a weapon toward a target. Similar propulsion concepts do not make them identical systems.

## 6. Human spaceflight and planetary missions

### Human-spaceflight requirements

`human-rated launcher + crew module + environmental control/life support + abort system + tracking/recovery + trained crew`

| Mission type | Core distinction |
|---|---|
| Orbiter | Studies body from orbit |
| Lander | Reaches and operates on surface |
| Rover | Mobile surface platform |
| Flyby | Passes target without orbiting |
| Sample return | Returns extraterrestrial material |

### Why human spaceflight is harder

- life support and thermal control;
- launch/entry/recovery safety;
- redundancy and fault tolerance;
- radiation and microgravity health;
- continuous mission control and rescue planning.

> **Core verdict:** Human spaceflight creates technology spillovers and strategic capability but must be assessed against safety, cost, scientific value and opportunity cost.

## 7. Nuclear fission and India’s three-stage programme

### Fission chain

`neutron absorbed -> heavy nucleus splits -> energy + neutrons -> controlled chain reaction`

| Component | Function |
|---|---|
| Fuel | Fissile/fertile material |
| Moderator | Slows neutrons in relevant reactor designs |
| Control rods | Absorb neutrons to regulate reaction |
| Coolant | Transfers heat |
| Containment | Limits release and protects reactor system |

### Three-stage logic

| Stage | Broad strategy |
|---|---|
| I | Pressurised heavy-water reactors using natural uranium |
| II | Fast breeder reactors using plutonium-based fuel and breeding |
| III | Thorium-uranium-233 cycle |

| Pair | Distinction |
|---|---|
| Fissile vs fertile | Directly sustains chain reaction under suitable conditions vs convertible to fissile material |
| Reactor vs weapon | Controlled energy production vs rapid uncontrolled energy release |
| Radiation vs radioactive material | Energy/particles emitted vs unstable material emitting them |

> **Trap:** Nuclear power is low-carbon in operation but not impact-free; safety, waste, water, cost, liability and fuel-cycle issues remain.

## 8. Nuclear fusion and ITER

### Fusion mechanism

`light nuclei + extreme temperature/confinement -> overcome electrostatic repulsion -> heavier nucleus + energy`

| Concept | Meaning |
|---|---|
| Plasma | Ionised state containing charged particles |
| Tokamak | Toroidal magnetic-confinement device |
| Stellarator | Alternative magnetic-confinement geometry |
| Inertial confinement | Compresses fuel rapidly using lasers/other drivers |
| Fusion gain | Ratio defined for a stated boundary; always specify which input/output is counted |

### Three thresholds

1. plasma/scientific energy gain;
2. sustained engineering operation with materials and fuel cycle;
3. net, reliable and commercially competitive electricity.

> **Trap:** ITER is an experimental international fusion facility, not a commercial power plant.

### System chain

`sensor/targeting -> command and guidance -> propulsion -> navigation/control -> warhead/effect -> test and user evaluation`

> **Status rule:** A successful developmental trial is not the same as induction or deployment. Avoid recalling unverified ranges and capabilities.

## 13. Quantum technology

| Principle | Meaning |
|---|---|
| Superposition | Quantum state can combine basis states until measurement |
| Entanglement | Correlations not classically reproducible |
| Interference | Probability amplitudes combine |
| Measurement | Observation yields outcome and alters state description |
| Decoherence | Loss of usable quantum behaviour through environmental interaction |

| Application | Mechanism |
|---|---|
| Quantum computing | Qubits and quantum gates for selected problem classes |

> **Trap:** Physical qubits are not logical error-corrected qubits. QKD and post-quantum cryptography are different approaches.

| Data principal | Individual to whom personal data relates |
| Data fiduciary | Entity determining purpose and means under legal framework |
| Consent | Free, specific, informed and unambiguous indication under applicable rules |

|---|---|

## 18. Vaccines, monoclonal antibodies and biopharma

|---|---|
| Live attenuated vaccine | Weakened pathogen induces active immunity |
| Inactivated vaccine | Killed pathogen antigen |
| Subunit/recombinant vaccine | Selected antigen component |
| Viral-vector vaccine | Harmless vector delivers antigen instructions |
| mRNA vaccine | mRNA directs temporary antigen production |
| DNA vaccine | DNA platform directs antigen expression |
| Monoclonal antibody | Laboratory-made specific antibody; passive protection/therapy |

### Active versus passive immunity

| Active | Passive |
|---|---|
| Body develops immune response/memory | Ready-made antibodies supplied |
| Slower onset, often longer duration | Immediate but generally temporary |

> **Trap:** Vaccine efficacy in a trial, effectiveness in real use and population immunity are distinct.

## 25. General chemistry

## 28. Computing fundamentals

### Computing stack

`hardware -> firmware -> operating system -> application -> data -> network/cloud service`

| Pair | Correct distinction |
|---|---|
| CPU vs GPU | General sequential/control processing vs highly parallel processing |
| RAM vs storage | Volatile working memory vs persistent storage |
| Hardware vs software | Physical component vs executable instructions |
| Firmware vs application | Low-level persistent control vs user-facing software |
| OS vs application | Resource/platform manager vs task-specific program |
| Router vs switch | Routes between networks vs connects devices mainly within LAN |
| Internet vs Web | Network of networks vs service using web protocols |
| Cloud vs data centre | On-demand service model vs physical facility |
| Database vs blockchain | Managed data store vs distributed append-oriented ledger architecture |

### Network concepts

| Term | Meaning |
|---|---|
| IP address | Network-layer identifier |
| DNS | Maps domain names to network addresses |
| HTTP/HTTPS | Web application protocols; HTTPS adds protected transport |
| Encryption | Converts plaintext using key/algorithm |
| Hash | One-way fixed-length digest function |
| Digital signature | Authenticity/integrity/non-repudiation mechanism using asymmetric cryptography |

> **Trap:** Blockchain does not make input data true; it can make recorded history tamper-evident under system assumptions.

## 31. UPSC traps and safe corrections

| Trap | Safe correction |
|---|---|
| “Approved mission means operational capability.” | State the exact readiness stage. |
| “Indigenous manufacture means indigenous design.” | Separate design, production and value addition. |
| “Successful test means deployed weapon.” | Follow evaluation-contract-induction ladder. |
| “Satellite navigation and augmentation are identical.” | Separate constellation from correction layer. |
| “Fusion gain means commercial electricity.” | Specify system boundary and engineering threshold. |
| “UPI is digital currency.” | It is a payment interface; money remains a separate liability. |
| “More qubits always means better quantum computer.” | Quality, error, connectivity and logical qubits matter. |
| “Chip assembly equals fab capability.” | Map the full semiconductor chain. |
| “Data protection equals cybersecurity.” | Rights/governance and system defence overlap but differ. |
| “Gene editing is automatically transgenic.” | Technique and resulting organism must be identified. |
| “Vaccine treats disease immediately.” | Vaccines primarily induce active immunity; timing/use varies. |
| “Nano means harmless and efficient.” | Test dose, exposure and lifecycle. |
| “Patent means product can be marketed.” | Regulatory approval and commercialisation remain separate. |
| “EV has zero emissions.” | It has zero tailpipe emissions; lifecycle differs. |
| “Critical mineral means rare earth.” | Critical category is broader. |

## 32. Reusable Mains answer skeletons

### A. Emerging technology

1. Define principle and architecture.
2. State current readiness accurately.
3. Give Indian applications and institutions.
4. Explain material, skill, finance and scale constraints.
5. Add ethics/safety/regulation and measurable capability.

### B. Strategic autonomy

1. Identify dependency and national-security/economic relevance.
2. Map complete value chain.
3. Separate assembly from design and component capability.
4. Recommend R&D, procurement, standards, skills and diversification.
5. End with scalable domestic value addition.

### C. Digital governance

1. Explain technical layer.
2. State public-value application.
3. Test privacy, security, exclusion and market power.
4. Add standards, audit, grievance and human oversight.
5. Preserve innovation with risk-proportionate regulation.

### D. Biotechnology/health

1. Explain biological mechanism.
2. Trace laboratory-to-regulatory pipeline.
3. State application and benefit.
4. Analyse biosafety, ethics, access and surveillance.
5. Recommend transparent evidence-based regulation.

### E. Mission/programme evaluation

1. State objective and approved design.
2. Identify readiness/status.
3. Separate outlay, activity, capacity and outcome.
4. Diagnose ecosystem dependencies.
5. Recommend milestones, independent testing and diffusion.
