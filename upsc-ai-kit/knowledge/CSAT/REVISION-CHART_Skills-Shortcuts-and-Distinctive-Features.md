# CSAT: Skills, Shortcuts and Distinctive Features - Last-Minute Revision Chart

> **Purpose:** One-place revision for safe qualification in Prelims Paper II.
> **Coverage:** All eight Core/Advanced pairs: comprehension, number systems, arithmetic, rates/motion/geometry, algebra/data sufficiency, logical reasoning/DI, communication and integrated General Mental Ability.
> **Two-pass design:** Core is independently sufficient for qualifying-paper preparation. Advanced adds harder variants and mixed drills; skipping it must not endanger the paper outcome if Core mastery and timed practice are secure.
> **Rule-status caution:** Verify the current notification's qualifying threshold. Keep the official minimum separate from your higher internal mock target.

---

## 1. The 60-second CSAT system

```text
80 items | 200 marks | 2 hours
correct = +2.5 | wrong = -5/6 | blank = 0
three wrong cancel exactly one correct
                    |
                    v
CLASSIFY -> SELECT -> SOLVE -> VERIFY -> DECIDE
                    |
       +------------+-------------+
       |                          |
positive confidence/EV       time sink or weak guess
       |                          |
    ATTEMPT                      PARK/SKIP
                    |
                    v
SAFE QUALIFYING MARGIN
```

> **Core principle:** CSAT rewards selection, accuracy and time control—not heroic attempts at every item.

---

## 2. Paper facts and risk logic

### Printed-paper facts in the audited corpus

- 80 items, 200 marks and two hours.
- Equal marks: `200 / 80 = 2.5` per correct answer.
- One-third penalty: `2.5 / 3 = 5/6` per wrong answer.
- More than one marked option is treated as wrong.
- Blank answer carries no penalty.

### Exact scoring

`Net = 2.5C - (5/6)W`

`3 wrong = loss from 1 correct`

### Expected value

`EV(p) = 2.5p - (5/6)(1-p)`

| Live options | Approximate success probability | Decision logic |
|---:|---:|---|
| 4 | 1/4 | Zero expected value; adds variance |
| 3 | 1/3 | Positive EV after genuine elimination |
| 2 | 1/2 | Strong positive EV |
| 1 | High confidence | Attempt |

> **Trap:** Blind guessing is break-even in expectation, not free marks.

## 3. Three-pass attempt strategy

| Pass | Attempt |
|---|---|
| 1 — Harvest | Direct RC, one-step quant, obvious series/coding and familiar items |
| 2 — Grind | Multi-step quant, data sufficiency, arrangements and DI |
| 3 — Decide | Remaining items: solve, eliminate-and-attempt, or leave |

### Parking rule

If an item:

- has no clear first step;
- requires rebuilding a long calculation;
- contains multiple uncertain interpretations; or
- exceeds your pass-specific time ceiling,

mark it and move.

> **Memory line:** A blank costs zero; a six-minute obsession costs several reachable questions.

## 4. Universal question workflow

```text
1. CLASSIFY the question family
2. IDENTIFY what is actually asked
3. CHOOSE the least-work valid method
4. SOLVE only as far as needed
5. VERIFY sign, unit, magnitude or logic
6. MATCH the printed option
7. DECIDE based on confidence, time and risk
```

### Least-work hierarchy

`property/logic -> estimation -> option substitution -> smart numbers -> full computation`

Use a shortcut only when its conditions hold.

## 5. Reading comprehension

### Passage workflow

```text
read stem -> identify question type -> read passage once
-> mark claim/contrast/qualifier -> eliminate -> choose text-defensible option
```

### Question types

| Type | Test |
|---|---|
| Central idea | What does the whole passage mainly establish? |
| Inference | What must follow from the passage? |
| Assumption | What unstated premise is required? |
| Tone | What attitude is revealed by wording? |
| Scope | How broad or narrow is the author's claim? |

### Distractor families

| Distractor | Why wrong |
|---|---|
| Too broad | Claims more than passage supports |
| Too narrow | Captures one detail, not required answer |
| Unstated truth | May be factually correct but absent |
| Distortion | Alters relation, degree or direction |
| Extreme | Converts qualified claim into absolute |
| Reversal | Swaps cause/effect or approval/criticism |

### Key distinctions

`inference = forced out of text`  
`assumption = required under argument`

> **Core rule:** Answer from the passage, not from your knowledge of the world.

## 6. Number systems and number sense

### Property-first map

```text
divisibility -> remainders -> unit digits -> factors
-> HCF/LCM -> powers -> trailing zeros -> series
```

### Divisibility essentials

| Divisor | Test |
|---:|---|
| 2 | Last digit even |
| 3 | Digit sum divisible by 3 |
| 4 | Last two digits divisible by 4 |
| 5 | Last digit 0 or 5 |
| 6 | Divisible by 2 and 3 |
| 8 | Last three digits divisible by 8 |
| 9 | Digit sum divisible by 9 |
| 11 | Alternating digit-sum difference divisible by 11 |

### Core formulas

- For two positive integers: `HCF × LCM = product`.
- If `n = p^a q^b ...`, number of positive factors = `(a+1)(b+1)...`.
- Trailing zeros in `n!` = `floor(n/5) + floor(n/25) + ...`.
- Unit digits of powers repeat in cycles; reduce exponent modulo cycle length.

### Remainder rules

`(a+b) mod m`, `(a-b) mod m`, `(ab) mod m` may be reduced term by term.

> **Trap:** Cyclicity shortcuts may fail or change when base and modulus share factors; verify conditions.

## 7. Arithmetic and commercial mathematics

### Ratios and percentages

| Concept | Formula |
|---|---|
| Percentage | `(part/whole) × 100` |
| Successive changes | Net = `a + b + ab/100` with signs |
| Percentage-point change | New percentage − old percentage |
| Relative percent change | `(change/original) × 100` |

### Average

`average = total / number`

`combined average = weighted total / total weight`

> A plain average of subgroup averages works only with equal subgroup sizes.

### Profit, loss and discount

`Profit% = profit/CP × 100`  
`Loss% = loss/CP × 100`  
`Discount% = discount/MP × 100`

### Interest

`SI = PRT/100`

`Amount under annual CI = P(1+r/100)^t`

### Mixture/alligation

For two components with values `L < M < H`:

`quantity of L : quantity of H = (H-M) : (M-L)`

### Partnership

Profit share ∝ `capital × time`.

> **Trap:** Percentage bases change. A 20% rise followed by a 20% fall does not restore the original.

## 8. Rates, work, motion and geometry

### Universal rate identity

`quantity = rate × time`

### Time and work

- If A completes work in `a` days, daily rate = `1/a`.
- Combined rate = sum of rates.
- Time = `1 / combined rate`.
- Leaks or opposing work use negative rates.

### Speed and motion

`distance = speed × time`

`relative speed`:

- opposite direction: add;
- same direction: subtract.

### Average speed

`total distance / total time`

For equal distances at speeds `a` and `b`:

`2ab/(a+b)`

### Trains

Crossing a point/person: train length / relative speed.  
Crossing a platform/train: combined relevant length / relative speed.

### Boats

`downstream = boat + stream`  
`upstream = boat - stream`

### Clocks

Angle at `h:m`:

`|30h - 5.5m|`, use smaller angle if required.

### Geometry essentials

| Shape | Area |
|---|---|
| Rectangle | `lb` |
| Triangle | `1/2 bh` |
| Circle | `πr²` |
| Trapezium | `1/2(a+b)h` |

| Solid | Volume |
|---|---|
| Cuboid | `lbh` |
| Cylinder | `πr²h` |
| Cone | `1/3 πr²h` |
| Sphere | `4/3 πr³` |

> **Trap:** Speed uses distance; velocity uses displacement. Returning to the start gives zero displacement, not zero distance.

## 9. Algebra and inequalities

### Translation workflow

`define variable -> convert words to relation -> simplify -> check domain -> verify`

### Core rules

- Apply the same valid operation to both sides of an equation.
- Multiplying/dividing an inequality by a negative reverses its sign.
- Squaring may introduce extraneous solutions; plug back.
- Denominators cannot be zero.
- Even roots require non-negative real radicand where real values are assumed.

### Option methods

Use substitution when:

- options are concrete;
- testing is faster than solving;
- only one option can satisfy all conditions.

> **Trap:** Do not divide by an expression whose sign or zero-status is unknown.

## 10. Data sufficiency

### Decision process

```text
READ THE PRINTED FOUR OPTIONS
         |
TEST Statement I alone
         |
TEST Statement II alone
         |
TEST both only if necessary
         |
STATE VERDICT first
         |
MAP verdict to the paper's printed option
```

### Rules

- The question asks whether information determines the answer, not necessarily what the answer is.
- Do not combine statements before testing each alone.
- A statement is sufficient only if it pins the answer uniquely for all valid cases.
- Two dependent statements may add no new information.
- The fourth option is not a stable template across audited papers.
- Some printed formats include an option meaning the question can be answered without either statement.

### Necessary vs sufficient

In `A -> B`:

- A is sufficient for B.
- B is necessary for A.

> **Core rule:** Verdict first, option letter second.

## 11. Logical reasoning

### Representation toolkit

| Problem | Best representation |
|---|---|
| Linear arrangement | Ordered slots |
| Circular arrangement | Fix one person, use relative positions |
| Blood relations | Family tree |
| Directions | Coordinate sketch |
| Syllogism | Venn/set relation |
| Conditional logic | Arrow chain |
| Coding | Position/frequency/transformation table |

### Conditional logic

From `A -> B`, valid:

`not B -> not A` (contrapositive)

Invalid without extra premise:

`B -> A` (converse)  
`not A -> not B` (inverse)

### Syllogism

- “All A are B” does not imply all B are A.
- “Some A are B” guarantees overlap, not universal inclusion.
- “No A are B” makes sets disjoint.
- Existence cannot be assumed where the statement does not establish it.

> **Trap:** One-way implication is not equivalence.

## 12. Coding, series and directions

### Series scan order

`difference -> second difference -> ratio -> alternating streams -> digit/letter position -> cumulative pattern`

### Coding workflow

1. Compare corresponding symbols.
2. Test shift, reversal, position, alternation or grouping.
3. Verify the rule on every given pair.
4. Reject a rule fitting only one example.

### Directions

Use coordinates:

`north = +y`, `south = -y`, `east = +x`, `west = -x`

Net displacement:

`sqrt(x² + y²)`

> **Trap:** Total path length and shortest displacement answer different questions.

## 13. Counting and probability

### Counting principle

- Sequential independent choices: multiply.
- Mutually exclusive cases: add.

### Permutation and combination

`nPr = n!/(n-r)!` — order matters.

`nCr = n!/[r!(n-r)!]` — order does not matter.

### Probability

For equally likely outcomes:

`P(E) = favourable / total`

`P(not E) = 1 - P(E)`

`P(at least one) = 1 - P(none)`

### Common counting correction

If identical objects/letters repeat:

`n!/(a!b!...)`

> **Trap:** Possibility means at least one feasible outcome; probability measures how often within the outcome space.

## 14. Data interpretation

### DI workflow

```text
read title/unit/base year -> identify exact quantity
-> estimate order -> compute minimum needed
-> check percentage base -> verify against table
```

### Common DI traps

- lakh/crore/thousand or percentage units;
- totals versus subgroups;
- percentage share versus percentage change;
- average of ratios versus ratio of totals;
- missing base year;
- cumulative versus annual value;
- visually distorted graph scale.

> **Core rule:** Read the unit and denominator before touching the numbers.

## 15. Interpersonal and communication skills

### Communication cycle

`sender -> encoding -> message/channel -> receiver -> decoding -> feedback`

Noise can enter at every stage.

| Concept | Meaning |
|---|---|
| Active listening | Attend, clarify, paraphrase and confirm |
| Feedback | Response showing reception/understanding |
| Empathy | Understand the other's perspective |
| Assertiveness | Clear and respectful expression of needs/boundaries |
| Negotiation | Seek acceptable agreement among interests |
| Mediation | Neutral assistance to disputing parties |

### Response styles

| Passive | Aggressive | Assertive |
|---|---|---|
| Suppresses own legitimate needs | Violates others' dignity | States position clearly while respecting others |

### Scenario engine

`facts -> stakeholders -> objective -> constraints -> options -> lawful/fair/proportionate response -> communication`

### Public communication

`clear + accurate + timely + accessible + two-way + audience-sensitive`

> **Trap:** Persuasion, manipulation and coercion are not interchangeable.

## 17. High-frequency distinctions

| Pair | Correct distinction |
|---|---|
| Inference vs assumption | Forced from text vs required beneath argument |
| Necessary vs sufficient | Required condition vs condition that settles outcome |
| Implication vs equivalence | One-way relation vs two-way relation |
| Percentage point vs percent change | Absolute difference in rates vs relative change |
| Average vs weighted average | Equal weight vs quantity-sensitive mean |
| Simple vs compound interest | Original principal vs running amount |
| Distance vs displacement | Path length vs net positional change |
| Speed vs velocity | Distance rate vs displacement rate/direction |
| Permutation vs combination | Order matters vs does not |
| Probability vs possibility | Measured likelihood vs feasibility |
| Data sufficiency vs solving | Whether answer is pinned vs computing answer |
| Passage truth vs real-world truth | Supported by text vs generally factual |
| Assertive vs aggressive | Respectful firmness vs rights-violating force |

## 18. Common traps and corrections

| Trap | Correction |
|---|---|
| Attempt everything because paper is qualifying | Select for net marks, not attempt count |
| Spend equal time on every item | Allocate by solvability and family strength |
| Use outside knowledge in RC | Demand textual support |
| Treat absolute RC options as automatically wrong | Test; eliminate only if unsupported |
| Average subgroup averages directly | Weight by subgroup size |
| Apply equal-distance average-speed formula to unequal distances | Use total distance/total time |
| Combine DS statements immediately | Test each alone first |
| Memorise DS option letters | Read printed wording every time |
| Use converse of implication | Use only original implication and contrapositive |
| Calculate exact DI value when options are far apart | Estimate safely |
| Treat “cannot determine” as filler | Prove or disprove sufficiency |
| Guess before eliminating | Eliminate first; then assess EV |
| Revise only notes | Prioritise error log and timed reattempt |

## 19. Error taxonomy

| Code | Error | Repair |
|---|---|---|
| C | Concept gap | Relearn formula/method |
| A | Application error | Write relation before calculating |
| X | Calculation slip | Add estimation or plug-back |
| R | Reading error | Mark `not`, `except`, unit and condition |
| P | Passage-only violation | Identify exact supporting line |
| T | Time error | Enforce parking and pass ceiling |
| G | Guess error | Require real elimination |

### Diagnostic

- High attempts + low accuracy = over-attempting.
- Low attempts + high accuracy = improve speed/reach.
- Mostly X = verification problem.
- Mostly P = RC discipline problem.
- Mostly T = selection/clock problem.

## 20. Readiness and revision

### Revision cycle

`Day 0 learn -> Day 1 redo errors -> Day 3 harder drill -> Day 7 mixed set -> Day 15 error log -> Day 30 full mock`

### Readiness checks

- Core techniques can be executed without notes.
- Timed mixed sets are completed within the paper limit.
- Accuracy and attempt rate are stable.
- Guess quality exceeds blind chance.
- Net marks repeatedly exceed your verified official bar by a comfortable personal margin.
- You can state the scoring and DS-format cautions correctly.

> **Firewall:** Advanced puzzles are optional. Weak RC, arithmetic accuracy, reasoning representation or time control are not optional.
