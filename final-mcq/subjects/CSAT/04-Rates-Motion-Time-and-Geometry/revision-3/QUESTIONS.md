# CSAT 04 — Revision 3: original questions

All items are original practice questions written for this bank; none is a UPSC PYQ. Each question has four options (A–D) and exactly one defensible answer.

**Time budget:** 54 questions in 65 minutes (about 72 seconds per question). Hard items may take longer; move on and return if time allows.

**Scoring for practice:** +2.5 for a correct answer, −0.83 for a wrong answer, 0 for a skipped question.
