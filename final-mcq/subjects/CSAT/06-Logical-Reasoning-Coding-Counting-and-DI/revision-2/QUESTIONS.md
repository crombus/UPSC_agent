Time budget: 72 minutes for 60 questions (about 72 seconds per question). Scoring: +2.5 for a correct answer, -0.83 for a wrong answer, 0 for a skipped question. Every question is original practice material, not a UPSC PYQ. Each question has exactly four options; choose one.

### R2-Q01

Read the three statements and decide which conclusions follow. A conclusion follows only if it is true in every case that satisfies all the statements.

**Statements**
1. All panel members are graduates.
2. Some interns are panel members.
3. No graduate is a retired officer.

**Conclusions**
I. Some interns are retired officers.
II. No panel member is a retired officer.
III. Some interns are not graduates.

Which of the conclusions follow?

A. I only
B. I and III only
C. II only
D. I, II and III
