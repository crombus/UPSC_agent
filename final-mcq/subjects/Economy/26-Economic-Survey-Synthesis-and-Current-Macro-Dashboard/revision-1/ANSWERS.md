**Question:** dashboard synthesis rule
**Correct proposition:** A dashboard is diagnostic: every headline should be decomposed by level, rate, composition, distribution, data vintage and cross-checks before a causal verdict is offered.
**Evidence:** Advanced §§3, 6; Basic §§1, 11A; Learning Session 18.
**Source/date hold:** Static proposition is source-grounded; source/date boundary checked 2026-10-03. Any later number, policy status or release must be rechecked against the responsible official source before future delivery.
**Option-specific rationales:**

- **B.** Correct — A dashboard is diagnostic: every headline should be decomposed by level, rate, composition, distribution, data vintage and cross-checks before a causal verdict is offered. This preserves the relevant concept, source authority, mechanism and qualification.
- **C.** Incorrect — A dashboard becomes final merely by combining more indicators, regardless of definitions. It fails because More data cannot repair incompatible concepts or periods.
