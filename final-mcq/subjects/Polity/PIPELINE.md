# Polity — final-MCQ continuation pipeline

Complete catalogue topics strictly in `INDEX.md` order. Finish exactly one topic per
continuation; do not open a later topic while the active topic has unresolved release work.

At the start and end of every continuation:

1. Read `AGENT_MEMORY.md`, `AGENTS.md`, `final-mcq/INSTRUCTIONS.md`, this file,
   `final-mcq/INDEX.md`, the Polity `INDEX.md`, and the active topic ledgers.
2. Read the active Basic/Advanced Markdown, complete package, solved workbook/practice
   material and mandated OCR sources before authoring or auditing.
3. Keep three independently comprehensive original banks. Each bank needs answer-free
   `QUESTIONS.md`, answer-separated `ANSWERS.md` with the key, evidence, four
   option-specific rationales and traps, and its own `COVERAGE.md`.
4. Keep exact PYQs out unless same-paper/key provenance and reproduction permission are
   documented. Record every unresolved provenance, key or rights issue as an explicit hold.
5. Run structural and hostile audits, repair actionable findings, then update the subject
   index only after the active topic passes.
6. Run `python final-mcq/tools/polity_pipeline.py` as the final repository action. The helper
   is a gate for queue order and structure, not a substitute for source or editorial review.
