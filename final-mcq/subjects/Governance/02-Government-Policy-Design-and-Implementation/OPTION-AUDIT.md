# Topic 02 Option Audit

## Method

Each bank independently shuffles the correct position with a reproducible seed. Distractors come from adjacent but different owner facts/applications/limitations, so the active concept must be identified rather than guessed from formatting.

## Release checks

- Four options per question: required and structurally checked.
- Duplicate options: none generated.
- Correct-position balance: recorded at the end of each ANSWERS.md; no fixed A-B-C-D sequence.
- Option-length cue: checked by the release script; options use parallel full-sentence forms.
- Absolute/specificity cues: hostile review retained the dated and held qualifiers instead of inventing precision.
- Stem distinctness: R1 recognition, R2 applied inference, R3 hostile-audit qualification.
