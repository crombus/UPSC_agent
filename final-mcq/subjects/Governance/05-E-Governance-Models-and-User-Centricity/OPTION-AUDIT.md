# Topic 05 Option Audit

## Method

Each bank independently places the correct option using a reproducible seed. Distractors are drawn from neighbouring owner facts and application/limitation concepts; all choices are full-sentence, parallel and source-bounded.

## Release checks

- Four options per question; duplicate options rejected.
- Correct positions are independently shuffled; no fixed A-B-C-D sequence.
- Key counts: R1 `{'B': 11, 'A': 10, 'C': 11, 'D': 10}`, R2 `{'A': 10, 'D': 10, 'C': 11, 'B': 11}`, R3 `{'B': 11, 'C': 11, 'A': 10, 'D': 10}`.
- R1 uses foundation and classification frames; R2 uses application and diagnostic frames; R3 uses qualification, evidence and hostile-audit frames.
- No option is labelled with a source cue, answer cue, or explanatory suffix in QUESTIONS.md.
