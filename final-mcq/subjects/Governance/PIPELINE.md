# Governance final-MCQ continuation pipeline

**Queue:** Follow `final-mcq/subjects/Governance/INDEX.md` in catalogue order. An
`in_progress` topic retains its own holds and must be finished before the next `pending`
topic is opened. This continuation owns only the first active topic.

At the start and end of every continuation:

1. Read `AGENT_MEMORY.md`, `AGENTS.md`, `final-mcq/INSTRUCTIONS.md`, this pipeline,
   `MCQ-COMPLIANCE-INSTRUCTIONS.md`, `final-mcq/INDEX.md`, the Governance index and all
   active-topic ledgers.
2. Read the complete Basic and Advanced owners, complete package, solved workbook/practice
   source, and relevant official/OCR evidence before authoring or repairing.
3. Require three independent banks with answer-free questions, detailed separate answers,
   question-level coverage ledgers, and explicit source/PYQ holds.
4. For institutions and measurement tools, audit applicable origin, mandate, headquarters,
   membership, reports/frequency, funding, leadership, committees, timeline, India linkage
   and verified awards. Do not invent fields that are not applicable or not sourced.
5. Run structural, option-balance, leakage, cross-revision distinctness, source/date,
   institutional-fact and hostile audits. Repair every actionable finding.
6. Re-read the compliance instructions after the topic pass. Update subject and repository
   indexes only after a clean audit, then run:

   `python final-mcq/tools/governance_pipeline.py`

The pipeline is a release gate, not a substitute for substantive source review or PYQ
authentication. It must report the next pending Governance topic and must not start
Social Justice, Disaster Management or Internal Security.
