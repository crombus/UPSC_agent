# Topic 04 Option Audit

## Method

Each bank independently shuffles the correct option with a reproducible seed. Distractors are selected from neighbouring owner facts, applications or limitations and length-matched to reduce visual cues.

## Release checks

- Four options per question; duplicate options rejected.
- Correct positions are independently shuffled and recorded per bank; no fixed A-B-C-D rotation.
- Options use parallel full-sentence forms and retain source-bounded qualifiers.
- R1 tests foundation, R2 tests application and R3 tests qualification; no bank is a position-only reshuffle.
