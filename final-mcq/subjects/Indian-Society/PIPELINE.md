# Indian Society final-MCQ continuation pipeline

**Queue:** Follow `final-mcq/subjects/Indian-Society/INDEX.md` in catalogue order. Complete
exactly one pending topic per continuation. Existing `in_progress` topics retain their own
holds; do not silently promote them.

At the start and end of every continuation:

1. Read `AGENT_MEMORY.md`, `AGENTS.md`, `final-mcq/INSTRUCTIONS.md`, this pipeline,
   `MCQ-COMPLIANCE-INSTRUCTIONS.md`, `final-mcq/INDEX.md`, the subject index, and the active
   topic ledgers.
2. Read the active Basic and Advanced owners, complete package, practice source, and relevant
   official/OCR evidence before authoring.
3. Build three independent banks. Each bank needs answer-free questions, detailed separate
   answers, a question-level coverage ledger, and explicit source/PYQ holds.
4. Cover the complete topic independently in every bank. No skipping, compression, generic
   placeholder, answer leakage, patterned keys, or hallucinated data is acceptable.
5. For institutions, reports and schemes, record authoritative origin/timeline, mandate,
   implementing agencies, monitoring/reporting route, funding/outlay where verified, and social
   effect. Route detailed constitutional/statutory doctrine to its owning subject.
6. Run structural, option-balance, leakage, duplicate/distinctness, source-date, hostile and
   institutional-fact audits. Repair all actionable findings before indexing.
7. Update the subject and repository indexes only after all three banks pass clean audit, then
   run `python final-mcq/tools/indian_society_pipeline.py` as the final repository action.

The pipeline is a release gate, not a substitute for source review or PYQ authentication.
