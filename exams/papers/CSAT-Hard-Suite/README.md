Generated 2026-10-04. This is a CSAT-only special-case suite; no ordinary final-mcq subject files are changed.

## Difficulty contract

**Very Hard** — every item is checked for linked deductions/constraints, plausible balanced distractors, independent answer verification and strict timed use.

- Complete papers: 80 questions in 120 minutes.
- Revision drills: 40 questions in 75 minutes.
- Rubric metadata is repeated in `MANIFEST.json`, keyed data and `SPECIAL-CASE-AUDIT.json`.

## Timed usage

1. Use one `*_QP.pdf` without opening the matching answer-key folder.
2. Set a strict **120-minute** timer for each complete paper.
3. Record attempted, correct, wrong and blank counts by category.
4. Score `2.5 × correct − (5/6) × wrong`; blanks score zero. Treat 33% as the notified qualifying benchmark only after checking the current UPSC notification.
5. Open the matching `_AK.pdf` and `*_Solutions.md` only after submission. Revision folders use a 75-minute drill clock.
