# Essay Model Suite

This suite separates a provenance-aware question bank from original model answers. See `MANIFEST.json` for counts and generated paths. V1 prompt rows are locally verified against official papers held in the repository; V2 rows remain explicit holds. No full copyrighted essay is reproduced.

The answer books use the repository Essay framework: 1000-1200 words, a qualified thesis, multidimensional analysis, named examples, counterargument and synthesis. They are practice models, not official UPSC answers.
